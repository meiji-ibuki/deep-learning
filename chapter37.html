37.1 アンサンブルの原理

第36章では単一モデルの性能を改善した。本章では異なるモデルの誤りを補い合うことで汎化性能を改善する。回帰で各モデルの誤差を $e_m=\hat y_m-y$ とすると、等重み平均の誤差は $\bar e=M^{-1}\sum_m e_m$ である。各誤差の分散が $\sigma^2$、相関が共通の $\rho$ なら

$$\mathrm{Var}(\bar e)=\sigma^2\left(\rho+\frac{1-\rho}{M}\right).$$

これは共分散を展開して得られる。平均は共通のバイアスを消さない。相関が1なら分散低減はない。強い単体性能と誤りの多様性を両立することが重要である。

37.2 予測の平均と重み付き平均

回帰では $\hat y=\sum_m w_m\hat y_m$、分類では確率ベクトル $p=\sum_m w_mp_m$ を用いる。$w_m\ge0,\sum_mw_m=1$ なら確率の総和は1を保つ。Hard votingは各モデルのクラス票を数えるが、Soft votingは予測確率を利用する。確率が校正されているとは限らない。logitを平均してからsoftmaxを取る方法は確率平均と異なる。モデルのクラス順序を統一し、同じ尺度・前処理で予測する。

対数損失は確率に関して凸なので、平均確率の損失は構成モデルの損失の加重平均以下になる。ただし最良の単体より必ず良くなるわけではない。重みは開発データで選択し、独立テストで評価する。

コード37.1　確率平均とlogit平均の違い
import numpy as np
p=np.array([[.9,.1],[.4,.6]])
weights=np.array([.5,.5])
soft=weights@p
logpool=np.exp(weights@np.log(p)); logpool/=logpool.sum()
print(soft,logpool)
assert np.isclose(soft.sum(),1)

37.3 BaggingとBoosting

Baggingは訓練集合から復元抽出した標本で独立にモデルを学習し、平均する。Random Forestはさらに分割候補の特徴量をランダム化する。N個の標本からN回復元抽出すると、特定の標本が一度も選ばれない確率は (1−1/N)^N（Nが十分大きいと約0.368） であり、Out-of-Bag評価に利用できる。

Boostingは先行モデルの誤りを後続モデルが補う逐次的な学習である。AdaBoostは誤分類標本を重視し、Gradient Boostingは現在の予測における損失の負の勾配を近似する弱学習器を加える。二乗誤差では残差に対応する。深層学習とGBDTを組み合わせることもできる。

37.4 BlendingとStacking

Blendingは独立した検証集合に対する各モデルの予測を入力とし、重みやメタモデルを学習する。実装は簡単だがメタ学習に使える標本が少なくなる。Stackingでは交差検証によるOut-of-Fold（OOF）予測を使い、開発集合の全標本について未学習の予測を作る。メタモデルにはロジスティック回帰やRidgeなどの単純なモデルをまず使う。

訓練データへの当てはめ予測をメタモデルに与えると、過学習したベースモデルを過大評価する。メタモデルの訓練スコアも最終性能ではない。最終評価には独立テスト、またはStacking全体を内包する外側CVが必要である。

37.5 OOF予測の構築

各Foldで訓練行だけから前処理とモデルを学習し、検証行の元のインデックスへ予測を格納する。テスト予測はFoldごとに生成して平均する。K個のFoldの全検証行が重複なく開発集合を覆うことを確認する。時系列やグループデータでは第22章の分割原則を守る。Early Stoppingや探索にOOF対象のラベルを使う場合は内側分割を用いる。

37.6 実践：複数モデルの比較

scikit-learnの手書き数字を利用し、ロジスティック回帰、Random Forest、MLPを比較する。テストを最初に分離し、メタモデルの学習には開発集合のみを用いる。以下の3コードは順番に実行する。各モデルの設定は固定し、テスト結果で再選択しない。

コード37.2　データと固定ベースモデル
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split,StratifiedKFold
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.neural_network import MLPClassifier
from sklearn.base import clone
from sklearn.metrics import log_loss,accuracy_score
X,y=load_digits(return_X_y=True); X=X/16
Xdev,Xtest,ydev,ytest=train_test_split(X,y,test_size=.2,stratify=y,random_state=37)
models=[LogisticRegression(max_iter=1000),
        RandomForestClassifier(n_estimators=100,random_state=37),
        MLPClassifier(hidden_layer_sizes=(64,),max_iter=350,random_state=37)]
folds=list(StratifiedKFold(5,shuffle=True,random_state=37).split(Xdev,ydev))
コード37.3　OOF行列とFold平均テスト予測
oof=np.zeros((len(Xdev),len(models),10))
test=np.zeros((len(Xtest),len(models),10))
seen=np.zeros(len(Xdev),int)
for tr,va in folds:
    seen[va]+=1
    for j,base in enumerate(models):
        model=clone(base).fit(Xdev[tr],ydev[tr])
        assert np.array_equal(model.classes_,np.arange(10))
        oof[va,j]=model.predict_proba(Xdev[va])
        test[:,j]+=model.predict_proba(Xtest)/len(folds)
assert np.all(seen==1)
assert np.allclose(oof.sum(-1),1) and np.allclose(test.sum(-1),1)
コード37.4　メタモデルと独立評価
meta=LogisticRegression(max_iter=1000).fit(oof.reshape(len(Xdev),-1),ydev)
results={name:test[:,j] for j,name in enumerate(['LR','RF','MLP'])}
results['Mean']=test.mean(axis=1)
results['Stack']=meta.predict_proba(test.reshape(len(Xtest),-1))
for name,probs in results.items():
    print(name,log_loss(ytest,probs),accuracy_score(ytest,probs.argmax(1)))

37.7 深層学習のFold・Seed・Snapshot Ensemble

深層学習では異なる初期値・データ順序（Seed Ensemble）、異なるFold、異なるアーキテクチャを組み合わせる。Snapshot Ensembleは周期的な学習率で異なる局所解に到達することを狙い、同じ訓練過程の複数の時点を保存する。単なる連続エポックの保存より多様性を期待できるが保証はない。推論コストは保存したモデル数に応じて増える。SWAは重みを平均して単一モデルを得る別手法であり、予測平均とは異なる。

コード37.5　KerasのSeed Ensemble（コード37.1〜37.2の後に実行）
import tensorflow as tf
from tensorflow import keras
from sklearn.model_selection import train_test_split
xa,xb,ya,yb=train_test_split(Xdev,ydev,test_size=.2,stratify=ydev,random_state=37)
probs=[]
for seed in [37,38,39]:
    keras.backend.clear_session(); keras.utils.set_random_seed(seed)
    model=keras.Sequential([keras.Input((64,)),keras.layers.Dense(64,activation='relu'),keras.layers.Dense(10)])
    model.compile(optimizer='adam',loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True))
    model.fit(xa,ya,validation_data=(xb,yb),epochs=40,verbose=0,
        callbacks=[keras.callbacks.EarlyStopping(patience=5,restore_best_weights=True)])
    probs.append(tf.nn.softmax(model.predict(Xtest,verbose=0),axis=-1).numpy())
ensemble=np.mean(probs,axis=0)

37.8 知識蒸留

知識蒸留は教師モデルの予測分布を小さな生徒モデルに学習させる。正の温度 $T>0$ を使い（混合係数は $0\le\alpha\le1$ とする）、 $p_i^{(T)}=\exp(z_i/T)/\sum_j\exp(z_j/T)$ とする。温度が高いと非正解クラス間の相対的な情報も伝わりやすい。

$$L=\alpha CE(y,p_s^{(1)})+(1-\alpha)T^2 D_{KL}(p_t^{(T)}\Vert p_s^{(T)}).$$

$T^2$ は高温で小さくなる勾配の尺度を補う慣例である。教師の重みは固定し推論モードにする。推論時の生徒は通常温度1で使用する。教師の誤りも引き継ぐ可能性がある。

コード37.6　蒸留の学習ループ（コード37.1〜37.2の後に実行、教師も学習）
import tensorflow as tf
from tensorflow import keras
keras.utils.set_random_seed(37)
def net(width):
    return keras.Sequential([keras.Input((64,)),keras.layers.Dense(width,activation='relu'),keras.layers.Dense(10)])
teacher=net(256); student=net(32)
ce=keras.losses.SparseCategoricalCrossentropy(from_logits=True)
teacher.compile(optimizer='adam',loss=ce)
teacher.fit(Xdev,ydev,epochs=30,verbose=0)
teacher.trainable=False
opt=keras.optimizers.Adam(); T=3.; alpha=.5
for epoch in range(30):
    for x,yb in tf.data.Dataset.from_tensor_slices((Xdev.astype('float32'),ydev)).shuffle(len(Xdev),seed=37).batch(64):
        t=tf.stop_gradient(teacher(x,training=False))
        with tf.GradientTape() as tape:
            s=student(x,training=True)
            log_t=tf.nn.log_softmax(t/T); log_s=tf.nn.log_softmax(s/T)
            kl=tf.reduce_mean(tf.reduce_sum(tf.exp(log_t)*(log_t-log_s),axis=-1))
            loss=alpha*ce(yb,s)+(1-alpha)*T*T*kl
        opt.apply_gradients(zip(tape.gradient(loss,student.trainable_variables),student.trainable_variables))
print(accuracy_score(ytest,student.predict(Xtest,verbose=0).argmax(1)))

37.9 半教師あり学習と擬似ラベリング

半教師あり学習は少数のラベル付きデータと多数の未ラベルデータを利用する。擬似ラベリングでは教師の予測最大確率が閾値以上の入力にargmaxラベルを付ける。閾値を高めると採用数が減る一方、誤ラベルを減らせる可能性がある。ただし確率の校正や分布差に依存する。Consistency Regularizationでは同一標本への異なる摂動で予測を一致させる。FixMatchは弱い拡張の高信頼予測を強い拡張の教師として使う。

未ラベル集合に独立テストを混ぜない。コンペでテスト入力を学習に使うtransductive手法は規約を確認し、通常の独立評価と区別する。誤った高信頼予測を反復して強化するconfirmation bias、少数クラスの排除、分布外データの混入に注意する。

37.10 実践：擬似ラベルの検証

開発集合からラベル付き部分だけを抽出し、残りのラベルを隠す。教育用実験なので隠した正解を事後診断できるが、教師の学習や採用には使わない。閾値は事前に0.95と固定する。独立テストでラベル付きのみのモデルと比較する。

コード37.7　擬似ラベルの採用と再学習（コード37.1〜37.2の後に実行）
xl,xu,yl,yu=train_test_split(Xdev,ydev,train_size=.15,stratify=ydev,random_state=37)
base=LogisticRegression(max_iter=1000).fit(xl,yl)
pu=base.predict_proba(xu); conf=pu.max(1); pseudo=base.classes_[pu.argmax(1)]
keep=conf>=.95
student_lr=LogisticRegression(max_iter=1000).fit(np.concatenate([xl,xu[keep]]),np.concatenate([yl,pseudo[keep]]))
print('Accepted:',keep.sum(),'of',len(xu))
print('Test accuracy:',base.score(Xtest,ytest),student_lr.score(Xtest,ytest))
# 教育用の事後診断のみ
print('Pseudo-label accuracy:',(pseudo[keep]==yu[keep]).mean() if keep.any() else np.nan)

37.11 運用と計算予算

モデル数を増やす前にOOF残差の相関、単体スコア、推論時間を確認する。平均の重みを最適化する場合は検証集合だけを使い、過剰な自由度を避ける。異なるシードやFoldの予測を保存すると後から組合せを比較しやすい。

手法長所注意点
平均実装が簡単弱いモデルの混入
Stacking組合せを学習リーク・メタ過学習
Snapshot学習予算の節約推論は複数モデル
蒸留単一モデルで推論教師の誤り・容量不足
擬似ラベル未ラベルデータ活用誤ラベルの強化

Kaggleでは提出IDと行順、クラス順、予測の尺度、欠損の有無を確認する。公開順位で重みを繰り返し調整しない。運用では精度だけでなくレイテンシ・メモリ・保守性を評価する。次章で効率化を詳しく扱う。

37.12 まとめと確認問題

複数モデルの誤りの多様性と、独立した評価がアンサンブルの基礎である。まず等重み平均を基準にし、必要ならOOF Stackingを導入する。蒸留や擬似ラベリングは目的とデータ条件に応じて選ぶ。

問1　誤差相関1の平均で分散は減るか？

共通分散の仮定では減らない。

問2　確率平均と多数決の違いは？

前者は予測確率、後者はクラス票を使う。

問3　BaggingとBoostingの違いは？

独立な復元標本の学習と逐次的な誤差補正。

問4　OOF予測とは？

その標本を学習していないFoldモデルによる予測。

問5　メタモデルの訓練損失で性能評価できるか？

できない。独立テストか外側CVが必要。

問6　温度を上げると何が起こるか？

確率分布が平坦になる。

問7　擬似ラベルの高閾値の欠点は？

採用数の減少やクラス偏り。

問8　SnapshotとSWAの違いは？

複数予測の平均と重みの平均。

問9　発展：3モデルのアンサンブルを設計せよ。

コード37.2〜37.4のように独立テストを先に分離し、開発集合の共通5-Foldで3モデルのOOFを生成する。等重み平均と固定ロジスティック回帰のメタモデルを比較し、独立テストのLog Loss・Accuracy、15個のベースモデルの推論時間と容量を記録する。テスト結果を見て重みを再調整しない。

実測ではMLPの一部Foldが最大反復回数に到達し、収束警告が出た。固定予算の結果として掲載する。擬似ラベルは127件採用され、事後診断では全件正解だったが、テスト精度は94.72%から94.44%へ低下した。正しい擬似ラベルでも改善は保証されない。
