25.1 CNNの発展を設計思想から理解する

モデルの発展には、精度を高めるための深層化、勾配を伝える接続設計、計算量を削減する演算設計という三つの軸がある。新しいモデルが常に最良とは限らず、データ量・解像度・推論デバイス・事前学習の有無によって選択が変わる。

モデル（発表年）主な設計着目点
LeNet-5 (1998)畳み込みとサブサンプリング局所特徴
AlexNet (2012)ReLU、GPU、Dropout大規模学習
VGG (2014)3×3の積層均質な深層化
GoogLeNet (2014/15)Inception多尺度・1×1
ResNet (2015/16)加算ショートカット最適化
DenseNet (2016/17)連結ショートカット特徴再利用
MobileNet (2017/18)深さ方向分離畳み込み軽量化
EfficientNet (2019)複合スケーリング計算予算
ConvNeXt (2022)大カーネル・現代的設計CNNの再設計

年は論文公開・会議発表の時期を示す。モデル間の精度を比較する際には訓練データ、拡張、評価解像度、事前学習条件をそろえる必要がある。

25.2 LeNetとAlexNet：画像認識の出発点

LeNet-5は手書き数字認識を対象にした初期の代表的CNNである。32×32の入力から局所特徴を抽出し、空間サイズを減らしながら分類する。原型には学習可能なサブサンプリングや部分接続があり、現代的なConv2D＋AveragePoolingによる再現は近似である。

AlexNetは2012年のImageNet大規模画像認識でCNNの有効性を広く示した。5つの畳み込み層と3つの全結合層、ReLU、最大プーリング、データ拡張、Dropout、GPUによる学習を組み合わせた。初期層の大きなカーネルや局所応答正規化は歴史的な設計であり、現代のCNNでそのまま採用されるとは限らない。

25.3 VGGとNetwork in Network：小さな畳み込み

VGGは主に3×3の畳み込みを繰り返す。stride=1・膨張率1なら2層の3×3は5×5、3層は7×7の理論受容野を持つ。全層の入出力チャネル数が同じ $C$ なら5×5一層は $25C^2$、3×3二層は $18C^2$（biasなし）であり、後者は非線形変換も増やせる。ただし中間活性化の保存コストが増える。

Network in Networkで用いられる1×1畳み込みは各位置のチャネルベクトルをアフィン変換する（バイアスなしなら線形変換）。$C_{in}C_{out}$ 個の重みでチャネルを増減できる。Global Average Pooling（GAP）は各特徴マップの空間平均を取り、Flatten後の巨大な全結合層を避けられる。

コード25.1　VGG風ブロック（以下のKeras例はTensorFlowバックエンド）
from tensorflow import keras
from tensorflow.keras import layers

def vgg_block(x, filters):
    for _ in range(2):
        x = layers.Conv2D(filters, 3, padding="same", activation="relu")(x)
    return layers.MaxPooling2D(2)(x)

25.4 GoogLeNetとInception：分岐による多尺度処理

Inceptionは異なる空間スケールを並列に処理し、チャネル方向に連結する。高価な3×3や5×5の前に1×1でチャネルを減らすと計算量を抑えられる。バイアスを除いた重み数で比較する。例えば入力64チャネルから出力32チャネルの5×5は51,200重みだが、16チャネルへ射影してから行えば $64\times16+25\times16\times32=13,824$ となる。

コード25.2　Inception風ブロック
def inception(x):
    a = layers.Conv2D(16, 1, activation="relu")(x)
    b = layers.Conv2D(16, 1, activation="relu")(x)
    b = layers.Conv2D(32, 3, padding="same", activation="relu")(b)
    c = layers.Conv2D(8, 1, activation="relu")(x)
    c = layers.Conv2D(16, 5, padding="same", activation="relu")(c)
    d = layers.MaxPooling2D(3, strides=1, padding="same")(x)
    d = layers.Conv2D(16, 1, activation="relu")(d)
    return layers.Concatenate()([a,b,c,d])

25.5 ResNet：残差学習と深層化

深いネットワークでは訓練誤差さえ悪化する劣化問題が生じる場合がある。ResNetは目標写像 $H(x)$ を直接学ぶ代わりに $F(x)=H(x)-x$ を学ぶ。恒等接続なら $y=x+F(x)$ であり、逆伝播では $\partial L/\partial x=(I+J_F)^\top\partial L/\partial y$ となる（列ベクトル表記）。恒等経路があるため勾配の伝達を助けるが、勾配消失を必ず防ぐわけではない。

strideやチャネル数が異なる場合は1×1の射影を用いる。ResNet-18/34は基本ブロック、ResNet-50/101/152は主に1×1→3×3→1×1のボトルネックを使用する。バイアス・正規化のパラメータを除き、例えば256→64→64→256なら重み数は69,632で、256→256の3×3二層（1,179,648）より少ない。これは同じ表現能力を保証する比較ではない。

コード25.3　射影付き残差ブロック
def residual(x, filters, stride=1):
    shortcut = x
    y = layers.Conv2D(filters, 3, strides=stride, padding="same", use_bias=False)(x)
    y = layers.BatchNormalization()(y)
    y = layers.ReLU()(y)
    y = layers.Conv2D(filters, 3, padding="same", use_bias=False)(y)
    y = layers.BatchNormalization()(y)
    if stride != 1 or x.shape[-1] != filters:
        shortcut = layers.Conv2D(filters, 1, strides=stride, use_bias=False)(shortcut)
        shortcut = layers.BatchNormalization()(shortcut)
    return layers.ReLU()(layers.Add()([shortcut, y]))

25.6 DenseNet：特徴の再利用

DenseNetでは各層がそれ以前の特徴をチャネル方向に連結して受け取る。$x_l=H_l([x_0,x_1,\ldots,x_{l-1}])$。各層が $k$ チャネルを生成するなら、初期 $C_0$ から $L$ 層後には $C_0+Lk$ チャネルとなる。$k$ はgrowth rateである。特徴の再利用と勾配伝達を促進する一方、連結される活性化のメモリ消費には注意が必要である。

コード25.4　DenseNet風ブロック
def dense_block(x, depth=3, growth=16):
    for _ in range(depth):
        y = layers.BatchNormalization()(x)
        y = layers.ReLU()(y)
        y = layers.Conv2D(growth, 3, padding="same", use_bias=False)(y)
        x = layers.Concatenate()([x, y])
    return x

def transition(x, filters):
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    x = layers.Conv2D(filters, 1, use_bias=False)(x)
    return layers.AveragePooling2D(2)(x)

25.7 MobileNet：軽量な畳み込み

通常の畳み込みは空間とチャネルを同時に混合する。MobileNet V1の深さ方向分離畳み込みは、チャネルごとの空間畳み込み（Depthwise）と1×1によるチャネル混合（Pointwise）に分ける。depth multiplier=1、biasなしでは通常の重み数は $K^2 C_{in}C_{out}$、分離型は $K^2 C_{in}+C_{in}C_{out}$ となる。両段の出力空間が通常畳み込みと同じならMAC数の比も同じである。

3×3、入力32・出力64の場合、通常18,432重みに対し分離型2,336重み（約12.7%）。実行速度はメモリアクセスやデバイスの演算最適化にも依存する。MobileNet V2はチャネルを拡張しDepthwiseで処理した後、線形の1×1で圧縮するinverted residualを導入した。V3ではSEやhard-swishなども採用される。

コード25.5　MobileNet V2風ブロック
def inverted_residual(x, filters, expansion=6, stride=1):
    y = layers.Conv2D(int(x.shape[-1])*expansion, 1, use_bias=False)(x)
    y = layers.ReLU(max_value=6)(layers.BatchNormalization()(y))
    y = layers.DepthwiseConv2D(3, strides=stride, padding="same", use_bias=False)(y)
    y = layers.ReLU(max_value=6)(layers.BatchNormalization()(y))
    y = layers.Conv2D(filters, 1, use_bias=False)(y)
    y = layers.BatchNormalization()(y)
    if stride == 1 and x.shape[-1] == filters:
        y = layers.Add()([x,y])
    return y
コード25.6　NumPyで分離型の等価カーネルを検証
import numpy as np
rng = np.random.default_rng(25)
x = rng.normal(size=(5, 5, 3))
d = rng.normal(size=(3, 3, 3))
p = rng.normal(size=(3, 4))
# 分離型と、それに等価な通常畳み込みカーネル
w = d[..., None] * p[None, None, :, :]
a = np.empty((3, 3, 4)); b = np.empty_like(a)
for i in range(3):
    for j in range(3):
        patch = x[i:i+3,j:j+3]
        a[i,j] = (patch*d).sum(axis=(0,1)) @ p
        b[i,j] = np.einsum("hwc,hwco->o", patch, w)
np.testing.assert_allclose(a,b,atol=1e-12)
print(np.max(np.abs(a-b)))

この等価性は途中に非線形変換を挟まない場合に成立する。任意の通常畳み込みをdepth multiplier=1の分離型で表現できるわけではない。

25.8 EfficientNet：モデル規模の最適化

EfficientNetは深さ $d$、幅 $w$、画像解像度 $r$ を同時に拡大するcompound scalingを提案した。$d=\alpha^\phi,w=\beta^\phi,r=\gamma^\phi$ とし、概算計算量が $d w^2 r^2$ に比例すると仮定して $\alpha\beta^2\gamma^2\approx2$ を目標にする（各係数は1以上）。実際にはチャネルの丸め、各層の構造、ハードウェアにより異なる。

基本構成にはMBConv（inverted bottleneck）とSqueeze-and-Excitation（SE）が使われる。SEは空間平均からチャネルごとの重みを計算し、特徴マップを再重み付けする。

コード25.7　SEブロック
def se(x, ratio=4):
    c = int(x.shape[-1])
    s = layers.GlobalAveragePooling2D(keepdims=True)(x)
    s = layers.Conv2D(max(1,c//ratio), 1, activation="relu")(s)
    s = layers.Conv2D(c, 1, activation="sigmoid")(s)
    return layers.Multiply()([x,s])

25.9 ConvNeXt：現代的なCNNの設計

ConvNeXtはVision Transformerの設計上の知見を踏まえ、CNNを現代化したモデルである。代表的なブロックでは7×7 Depthwise Conv、Layer Normalization、チャネル拡張、GELU、チャネル圧縮、残差接続を組み合わせる。原型ではLayer Scaleと確率的深度も用いる。畳み込みに基づく空間処理は維持しており、自己注意そのものを導入したモデルではない。

コード25.8　簡略ConvNeXtブロック
def convnext_block(x):
    c = int(x.shape[-1])
    y = layers.DepthwiseConv2D(7, padding="same")(x)
    y = layers.LayerNormalization(epsilon=1e-6)(y)
    y = layers.Dense(4*c, activation="gelu")(y)
    y = layers.Dense(c)(y)
    return layers.Add()([x,y])

このコードはLayer Scaleと確率的深度を省いた教育用ブロックであり、公式ConvNeXtの完全再現ではない。

25.10 実践：Kerasでモデルを構築・比較する

まず同じ画像データ・分割・学習予算で、小型VGG風、ResNet風、MobileNet風を比較する。公式の大型モデルをそのまま比較する実験ではない。モデルごとにパラメータ数が異なるので、構造のみの因果効果とは解釈しない。コード25.1〜25.5を同じセッションで先に実行する。以下はchannels_last形式を前提とする。

コード25.9　Fashion-MNISTで小型CNNを比較する
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
import time

(x,y),(xt,yt)=keras.datasets.fashion_mnist.load_data()
x=x[...,None].astype("float32")/255
xt=xt[...,None].astype("float32")/255
xa,xv,ya,yv=train_test_split(x,y,test_size=0.2,stratify=y,random_state=25)

def make_model(kind):
    inp=keras.Input((28,28,1))
    z=layers.Conv2D(16,3,padding="same",activation="relu")(inp)
    if kind=="VGG":
        z=vgg_block(z,32)
        z=vgg_block(z,64)
    elif kind=="ResNet":
        z=residual(z,32,2)
        z=residual(z,64,2)
    elif kind=="MobileNet":
        z=inverted_residual(z,32,2,2)
        z=inverted_residual(z,64,2,2)
    z=layers.GlobalAveragePooling2D()(z)
    return keras.Model(inp,layers.Dense(10)(z))

results=[]
for kind in ["VGG","ResNet","MobileNet"]:
    for seed in [25,26,27]:
        keras.backend.clear_session()
        keras.utils.set_random_seed(seed)
        m=make_model(kind)
        m.compile(optimizer=keras.optimizers.Adam(1e-3),
                  loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
                  metrics=["accuracy"])
        start=time.perf_counter()
        h=m.fit(xa,ya,validation_data=(xv,yv),epochs=10,batch_size=128,verbose=0)
        results.append((kind,seed,m.count_params(),h.history["val_accuracy"][-1],time.perf_counter()-start))
for kind in ["VGG","ResNet","MobileNet"]:
    rows=[r for r in results if r[0]==kind]
    print(kind, rows[0][2], np.mean([r[3] for r in rows]), np.std([r[3] for r in rows]), np.mean([r[4] for r in rows]))
# テストデータはモデル・設定の選択後に一度だけ評価する。

同一の学習率を用いた比較は出発点にすぎない。公平な性能比較には各モデルへの同等の探索予算も必要。実行時間は環境依存なのでGPUの種類、バッチサイズ、初回コンパイル時間も記録する。

事前学習モデルの利用

Keras ApplicationsにはVGG、ResNet、DenseNet、MobileNet、EfficientNet、ConvNeXtなどが用意される。入力前処理はモデルによって異なるため、公式仕様を確認する。例えばMobileNet V2は通常0〜255の画素を−1〜1に変換するが、EfficientNetは前処理を内部に含む。二重正規化を避ける。

25.11 まとめと確認問題

設計の違いは、空間演算・チャネル混合・接続・スケーリングという観点で整理できる。パラメータ数だけでは学習メモリや推論速度は決まらない。目的に応じて実測することが大切である。

問1　VGGで3×3を2層重ねる受容野は？

stride=1、膨張率1なら5×5。

問2　1×1畳み込みの役割は？

各空間位置でチャネルを混合し、チャネル数を変換する。

問3　Inceptionの分岐を結合する条件は？

チャネル方向に連結するなら高さ・幅・バッチサイズを一致させる。

問4　残差接続のshapeが異なる場合は？

1×1射影などで空間サイズとチャネル数を合わせる。

問5　DenseNetで初期32ch、growth rate 12、4層後は？

32+12×4=80ch。

問6　3×3、入力16、出力32の分離型の重み数は？

depth multiplier=1、biasなしなら9×16+16×32=656。通常は9×16×32=4608。

問7　EfficientNetの複合スケーリングとは？

深さ・幅・解像度を計算予算に応じて同時に調整する。

問8　ConvNeXtは自己注意を必須とするか？

いいえ。空間処理は主にDepthwise Convで行う。

問9　発展：分離型と通常畳み込みの表現力の違いを説明せよ。

depth multiplier=1なら各入力チャネルの空間カーネルは出力チャネル間で共通の形に制約される。通常畳み込みはこの制約がない。コード25.6の等価カーネル実験を変更し、途中にReLUを追加すると一般には単一の線形畳み込みで表せなくなることを確認する。

具体例：1チャネル、1×1、Depthwise重み1、Pointwise重み1、バイアスなしとすると、途中のReLUにより f(1)=1、f(−1)=0 となる。線形写像なら f(−1)=−f(1) でなければならないため、単一の線形畳み込みとは等価でない。
