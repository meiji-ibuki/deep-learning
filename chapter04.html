4.1 微分はなぜ必要なのか

第3章では、入力と重みから予測を計算する方法を学びました。しかし、重みは最初から正しい値を持つわけではありません。学習とは、予測と正解のずれを測り、そのずれが小さくなるように重みを調整することです。

例えば、ある住宅の面積を60㎡、価格を3000万円とし、簡単なモデルを $\hat y=60w$ とします。重み $w=40$ なら予測は2400万円です。誤差の二乗を損失とすると、$L(w)=(60w-3000)^2$ になります。重みを増やすべきか減らすべきか、どれほど変えるべきかを判断する手がかりが微分です。

本章ではまず一変数の関数を扱い、複数の変数、合成関数、最適化へと進みます。実際のネットワークでは何百万もの重みがあっても、基本的な考え方は同じです。

4.2 微分と接線の傾き

関数 $f(x)$ の入力を $h$ だけ変化させたとき、平均変化率は $(f(x+h)-f(x))/h$ です。$h$ を0に近づけた極限が存在するとき、その値を微分係数と呼びます。

$$f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}$$

$f(x)=x^2$ では分子が $2xh+h^2$ なので、割り算の結果は $2x+h$、極限は $2x$ です。$x=2$ では傾き4。入力をわずかに増やすと出力も増えます。接線は局所的な近似 $f(x+h)\approx f(x)+f'(x)h$ を与えます。これは有限の変化に対して常に正確な等式ではありません。

関数導関数条件・意味
定数 c0変化しない
$x^n$$nx^{n-1}$整数 n≠0（微分可能な定義域内）。n=0 は定数として扱う。
$e^x$$e^x$指数関数
$\ln x$$1/x$$x>0$
$\sin x$$\cos x$ラジアン
$f+g$$f'+g'$和の微分
$fg$$f'g+fg'$積の微分

微分係数が正なら、その点から十分小さく入力を増やすと関数値は増加し、負なら減少します。微分係数0は停留点の候補ですが、必ず最小値とは限りません。例えば $x^3$ は原点で傾き0でも最小値を取りません。$|x|$ は原点で左右の傾きが異なるため微分できません。

コード4.1　中央差分による数値微分
def f(x):
    return x**2

x = 2.0
for h in [0.1, 0.001, 1e-5]:
    print(h, (f(x+h)-f(x-h))/(2*h))
# いずれも約4

中央差分は左右の点を使う近似です。近傍で3階連続微分可能なら中央差分の打切り誤差は $O(h^2)$ で、2階連続微分可能な関数の前進差分の $O(h)$ より一般に小さくなりますが、$h$ を小さくしすぎると浮動小数点の丸め誤差が増えます。

4.3 偏微分と勾配

複数の変数を持つ関数では、一つの変数だけを変化させ、残りを固定した微分を偏微分と呼びます。$f(x,y)=x^2+2y^2$ の場合、$\partial f/\partial x=2x$、$\partial f/\partial y=4y$ です。

$$\nabla f(x,y)=\begin{pmatrix}2x\\4y\end{pmatrix}$$

偏微分を並べたベクトルが勾配です。点 $(2,1)$ では $(4,4)$ となります。ユークリッド距離で測った単位方向のうち、勾配方向は関数値が最も急に増える方向、負の勾配は最も急に減る方向です（勾配がゼロでない場合）。全微分可能な関数について、単位ベクトル $u$ に沿う方向微分は $\nabla f^\top u$ です。

コード4.2　複数変数の数値勾配
import numpy as np

def f(v):
    return v[0]**2 + 2*v[1]**2

v = np.array([2., 1.])
h = 1e-5
g = np.zeros_like(v)
for i in range(v.size):
    d = np.zeros_like(v)
    d[i] = h
    g[i] = (f(v+d)-f(v-d))/(2*h)
print(g)  # [4. 4.]

重みが行列なら、各要素について偏微分した結果も同じshapeの行列になります。数値微分はパラメータ数に比例して関数評価が必要なため、大規模な学習には非効率です。

4.4 合成関数と連鎖律

ニューラルネットワークは関数を何層も重ねた合成関数です。$z=2x+1$、$y=z^2$ とすると、$x$ の変化が $z$ を通じて $y$ に伝わります。

$$\frac{dy}{dx}=\frac{dy}{dz}\frac{dz}{dx}=2z\cdot2=4(2x+1)$$

途中で分岐がある場合は、各経路の寄与を足します。例えば $z=x^2$、$u=3x$、$y=z+u$ なら $dy/dx=2x+3$ です。複数入力・複数出力の場合、偏微分を並べたヤコビ行列を使うと連鎖律は行列積として表せます。スカラー損失を多くの重みで微分する逆モード自動微分が、誤差逆伝播法の基礎になります。

コード4.3　合成関数の微分を確認
def f(x):
    return (2*x+1)**2
x = 3.
z = 2*x+1
analytic = 2*z*2
h = 1e-5
numeric = (f(x+h)-f(x-h))/(2*h)
print(analytic, numeric)  # 28, 約28

4.5 勾配降下法と学習率

最小化したい関数を目的関数と呼びます。深層学習では多くの場合、予測誤差を表す損失関数を最小化します。現在のパラメータ $w_t$ を負の勾配方向に少し動かすのが勾配降下法です。

$$w_{t+1}=w_t-\eta\nabla L(w_t)$$

$\eta>0$ は学習率です。$L(w)=w^2$、初期値3、学習率0.2なら、一回目は $3-0.2\times6=1.8$、二回目は1.08です。

コード4.4　勾配降下法の最小実装
w = 3.0
eta = 0.2
for step in range(6):
    print(step, round(w, 5), round(w*w, 5))
    w -= eta * 2*w

更新前の値からすべての偏微分を計算し、まとめて更新するのが基本です。勾配の値は方向だけでなく傾きの大きさも含むので、学習率が同じでも更新幅は変化します。

4.6 学習率と収束の関係

$L(w)=w^2$ では更新式を $w_{t+1}=(1-2\eta)w_t$ と変形できます。初期値が0でない場合、$|1-2\eta|<1$、すなわち $0<\eta<1$ なら0に収束します。$\eta=0.5$ なら一回で0に到達し、$0.5<\eta<1$ なら符号を交互に変えながら収束します。$\eta=1$ では振動し続け、$\eta>1$ では発散します。この範囲はこの関数固有のもので、一般のネットワークにそのまま適用できません。

コード4.5　学習率を変えて実験する
import numpy as np
import matplotlib.pyplot as plt
for eta in [0.02, 0.2, 0.9, 1.1]:
    w = 3.0
    losses = []
    for _ in range(16):
        losses.append(w*w)
        w -= eta * 2*w
    plt.semilogy(losses, label=str(eta))
plt.xlabel("step")
plt.ylabel("loss")
plt.legend()
plt.show()

実際の学習では損失が毎回減少するとは限りません。特にミニバッチごとにデータが異なる場合、損失の変動は自然です。発散、長期的な停滞、検証損失の悪化を区別して判断します。学習率スケジューリングやAdamなどは第18・21章で扱います。

4.7 凸関数・局所最適解・鞍点

凸な定義域の任意の2点に対し、関数値が両端の関数値の線形補間以下であるとき、関数は凸です。

$$f(\lambda x+(1-\lambda)y)\le\lambda f(x)+(1-\lambda)f(y),\quad 0\le\lambda\le1$$

微分可能な凸関数では勾配0の点は大域的最小点です。厳密凸なら最小点が存在する場合に一意です。深層ネットワークの損失は一般に非凸であり、局所最小点や鞍点が現れます。

二階微分は傾きの変化を表します。近傍で2階連続微分可能な一変数関数の場合、停留点で $f''(x)>0$ なら厳密な局所最小、$f''(x)<0$ なら厳密な局所最大です。0の場合は判定できません。多変数では二階偏微分を並べたヘッセ行列を使います。以下の判定は近傍で2階連続微分可能で、定義域の内点にある停留点を対象とします。停留点でヘッセ行列が正定値なら厳密な局所最小、負定値なら厳密な局所最大、正負の固有値を持てば鞍点です。

例えば $f(x,y)=x^2-y^2$ のヘッセ行列は $\operatorname{diag}(2,-2)$ です。原点からx方向には増加、y方向には減少するので最小値ではありません。深層学習では完全な大域最適解の発見よりも、検証データで良好な性能を持つ解を見つけることが重要です。

4.8 線形回帰を勾配降下法で学習する

住宅価格の例に戻り、面積を10㎡単位、価格を100万円単位で表した架空データを使います。$\hat y_i=wx_i+b$ とし、平均二乗誤差を最小化します。

$$L(w,b)=\frac1N\sum_{i=1}^N(wx_i+b-y_i)^2$$$$\frac{\partial L}{\partial w}=\frac2N\sum_i(wx_i+b-y_i)x_i,\quad\frac{\partial L}{\partial b}=\frac2N\sum_i(wx_i+b-y_i)$$

連鎖律によって、誤差の二乗の微分に予測値の各パラメータに対する微分を掛けています。両方の勾配は更新前の同じ予測値から計算します。この単一特徴量の例では、入力を平均0・分散1（分母N）に標準化すると、損失のヘッセ行列が $2I$ になり、重みとバイアスの曲率が揃います。一般の多特徴量では特徴間の相関が残るため、標準化だけで曲率が揃うとは限りません。

コード4.6　NumPyによる線形回帰の学習
import numpy as np
x = np.array([4., 5., 6., 7., 8.])
y = np.array([20., 24., 28., 32., 36.])
x = (x-x.mean())/x.std()
w, b = 0., 0.
for _ in range(100):
    err = w*x+b-y
    dw = 2*np.mean(err*x)
    db = 2*np.mean(err)
    w -= 0.1*dw
    b -= 0.1*db
print(w, b)  # 約5.657, 28
print(np.mean((w*x+b-y)**2))  # ほぼ0

この例は学習原理の確認用です。実際の予測性能を測るには、訓練・検証データを分割し、標準化の統計量を訓練データのみから求める必要があります。

方式1回の更新に使うデータ特徴
バッチ勾配降下法全訓練データ勾配が安定しやすいが計算量が大きい
確率的勾配降下法1件更新が頻繁で変動が大きい
ミニバッチ勾配降下法複数件並列計算と更新頻度のバランス

実務ではミニバッチが一般的です。KerasのSGDという名称は1件ずつに限定されず、ミニバッチにも使われます。

4.9 TensorFlowの自動微分

TensorFlowの GradientTape は、記録した演算を逆向きにたどって勾配を計算します。数値微分とは異なり、微小な差分を取る必要はありません。ただし浮動小数点誤差は存在します。

コード4.7　連鎖律をGradientTapeで確認
import tensorflow as tf
x = tf.Variable(3.0)
with tf.GradientTape() as tape:
    z = 2*x+1
    y = z**2
print(tape.gradient(y, x).numpy())  # 28.0
コード4.8　TensorFlowによる線形回帰
import tensorflow as tf
x = tf.constant([4., 5., 6., 7., 8.])
y = tf.constant([20., 24., 28., 32., 36.])
x = (x-tf.reduce_mean(x))/tf.math.reduce_std(x)
w, b = tf.Variable(0.), tf.Variable(0.)
for _ in range(100):
    with tf.GradientTape() as tape:
        loss = tf.reduce_mean((w*x+b-y)**2)
    dw, db = tape.gradient(loss, [w, b])
    w.assign_sub(0.1*dw)
    b.assign_sub(0.1*db)
print(w.numpy(), b.numpy())

学習対象の tf.Variable は通常自動で監視されます。定数テンソルを微分したい場合は tape.watch(x) が必要です。計算をNumPyに変換すると計算グラフが途切れ、勾配がNoneになることがあります。整数型テンソル、微分規則がない演算、損失と接続されていない変数にも注意します。非微分点で実装上の勾配値が定義されている演算もあります。persistent=False（既定値）のTapeは、一度の gradient 呼び出しで記録したリソースを解放します。

症状確認事項
勾配がNone監視対象か、損失への経路があるか
NaN / Inf入力値、ゼロ除算、指数演算、学習率
勾配がほぼ0飽和、初期化、計算経路
shape不一致予測と正解の形状、意図しないブロードキャスト

4.10 まとめと確認問題

微分は局所的な変化率、勾配は偏微分の集合、連鎖律は合成関数の微分規則です。勾配降下法は負の勾配方向へパラメータを更新します。自動微分によって大規模なネットワークでもこの計算を効率化できます。

問1　f(x)=3x²−2x+1 の x=2 における微分係数は？

6x−2 より10。

問2　f(x,y)=x²+3y² の (1,2) における勾配は？

(2,12)。

問3　y=(3x−1)² の導関数は？

6(3x−1)。

問4　L(w)=w²、w=4、学習率0.1の更新後の値は？

4−0.1×8=3.2。

問5　同じ関数で学習率1ならどうなるか？

初期値が非ゼロなら符号が交互に変わり、損失は一定。初期値0ならそのままです。

問6　勾配0なら必ず最小点か？

いいえ。局所最大や鞍点、例えば f(x)=x³ の原点のような停留変曲点もあり得ます。

問7　数値微分と自動微分の違いは？

数値微分は差分による近似、自動微分は演算の微分規則と連鎖律を使います。自動微分にも浮動小数点の丸め誤差はあります。

発展演習：勾配チェック

$L(w,b)$ の解析的勾配と中央差分を比較してください。学習率を変えたときの損失推移も観察しましょう。

解答例
コード4.9　解析勾配と数値勾配の比較
import numpy as np
x = np.array([-1., 0., 1.])
y = np.array([1., 3., 5.])
p = np.array([0.5, 1.])
def loss(p):
    return np.mean((p[0]*x+p[1]-y)**2)
e = p[0]*x+p[1]-y
g = np.array([2*np.mean(e*x), 2*np.mean(e)])
h = 1e-5
g_num = np.array([(loss(p+h*d)-loss(p-h*d))/(2*h)
                  for d in np.eye(2)])
assert np.allclose(g, g_num)
print(g, g_num)
for eta in [0.01, 0.1, 1.1]:
    w, b = p.copy()
    history = []
    for _ in range(20):
        e = w*x+b-y
        history.append(np.mean(e**2))
        w -= eta*2*np.mean(e*x)
        b -= eta*2*np.mean(e)
    print(eta, history[0], history[-1])

解析勾配と数値勾配は約 (−2,−4) で一致します。損失を展開すると $L(w,b)=\frac23(w-2)^2+(b-3)^2$ となるので、勾配は $((4/3)(w-2),2(b-3))$ です。初期値 (0.5,1) で損失5.5、勾配 (−2,−4) を得ます。学習率0.1は0.01より速く損失が減少し、1.1ではバイアス方向の更新が発散します。

独立検算：中央差分との最大絶対誤差は 2.62e-11（float64、検証環境での値）。2つの曲率は4/3と2なので、両方向の収束条件は $0<\eta<1$ です。
