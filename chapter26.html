26.1 系列データと再帰構造

画像の空間的な近傍関係に対し、系列では順序が重要である。文章の単語、センサーの観測、売上の時系列などは、同じ値でも並び方によって意味が変わる。RNN（Recurrent Neural Network）は過去の情報を隠れ状態に圧縮して次の時点へ渡す。日本語では回帰型・再帰型・リカレントニューラルネットワークとも呼ばれるが、回帰問題専用ではない。

入力は通常 $(B,T,D)$（バッチ、時点、特徴量）。隠れ状態は $(B,H)$。各時点で同じ重みを使うため、系列長に依存せずパラメータ数が決まる。

形式出力例
many-to-one(B,K)文章分類
many-to-many（整列）(B,T,K)各時点のラベル
encoder-decoder(B,U,K)異なる長さの系列変換

26.2 SimpleRNNの順伝播とshape

初期状態を通常 $h_0=0$ とし、行ベクトル規約で次のように計算する。

$$z_t=x_tW_x+h_{t-1}W_h+b,\quad h_t=\tanh(z_t),\quad o_t=h_tW_o+c$$

$W_x:(D,H),W_h:(H,H),b:(H,),W_o:(H,K)$。バイアスを使用する場合、セルのパラメータ数は $H(D+H+1)$。出力層は別途 $(H+1)K$。例えば D=3,H=4,K=2 なら32+10=42個（バイアスあり）。

スカラー例で $W_x=1,W_h=0.5,b=0$、入力が1,0,0なら、状態は約0.762,0.363,0.180。入力がゼロでも過去の影響は残る。

コード26.1
import numpy as np
x = np.array([1., 0., 0.])
h = 0.
for v in x:
    h = np.tanh(v + .5*h)
    print(h)

26.3 時間方向の誤差逆伝播（BPTT）

時間展開したRNNは深い計算グラフとみなせる。Backpropagation Through Timeでは最後の時点から逆順に勾配を伝える。各時点の損失から直接届く状態勾配を $q_t$、前活性化値への勾配を $\delta_t$ とする。

$$\delta_t=(q_t+\delta_{t+1}W_h^\top)\odot(1-h_t^2),\qquad \delta_{T+1}=0$$ $$\nabla W_x=\sum_t x_t^\top\delta_t,\quad \nabla W_h=\sum_t h_{t-1}^\top\delta_t,\quad \nabla b=\sum_{t,i}\delta_{t,i}$$

many-to-oneでは最後の時点以外の $q_t$ はゼロ。共有された重みへの勾配は全時点から加算する。更新は逆伝播完了後に行う。以下は最終状態を用いた回帰と全パラメータの中央差分検証。

コード26.2
import numpy as np
rng = np.random.default_rng(26)
X = rng.normal(size=(3, 5, 2))
y = rng.normal(size=(3, 1))
P = [rng.normal(0,.2,size=s) for s in [(2,4),(4,4),(4,),(4,1),(1,)]]
def forward(P):
    Wx, Wh, b, Wo, c = P
    hs = [np.zeros((len(X),4))]
    for xt in X.transpose(1,0,2):
        hs.append(np.tanh(xt@Wx + hs[-1]@Wh + b))
    pred = hs[-1]@Wo+c
    return np.mean((pred-y)**2), hs, pred

def backward(P):
    Wx, Wh, b, Wo, c = P
    loss, hs, pred = forward(P)
    d = 2*(pred-y)/y.size
    g = [np.zeros_like(v) for v in P]
    g[3] = hs[-1].T@d
    g[4] = d.sum(axis=0)
    dh = d@Wo.T
    for t in reversed(range(X.shape[1])):
        dz = dh*(1-hs[t+1]**2)
        g[0] += X[:,t].T@dz
        g[1] += hs[t].T@dz
        g[2] += dz.sum(axis=0)
        dh = dz@Wh.T
    return g

g = backward(P)
errors = []
for a, grad in zip(P,g):
    for idx in np.ndindex(a.shape):
        orig = a[idx]; eps = 1e-5
        a[idx] = orig+eps; plus = forward(P)[0]
        a[idx] = orig-eps; minus = forward(P)[0]
        a[idx] = orig
        errors.append(abs((plus-minus)/(2*eps)-grad[idx]))
print(max(errors))
assert max(errors) < 1e-7

実行結果：最大絶対誤差 4.066e-11（float64、刻み幅10⁻⁵）。

26.4 長期依存と勾配消失・爆発

状態のヤコビ行列の積が長くなると、勾配が小さくなったり大きくなったりする。スカラー線形モデルでは $\partial h_T/\partial h_0=w^T$。tanhの導関数も掛かるため、実際には重みだけで決まらない。

対策はゲート付きセル、適切な初期化、勾配クリッピング、短い区間で逆伝播を打ち切るTruncated BPTTなど。クリッピングは爆発を抑えるが消失を解決しない。打ち切りは計算量を削減する一方、区間をまたぐ直接の勾配を失う。

26.5 LSTM：セル状態と三つのゲート

LSTMは隠れ状態 $h_t$ に加えてセル状態 $c_t$ を持つ。忘却ゲート f、入力ゲート i、出力ゲート o が情報の保持・書き込み・読み出しを制御する。$u_t=[x_t,h_{t-1}]$ とすると、

$$f_t=\sigma(u_tW_f+b_f),\quad i_t=\sigma(u_tW_i+b_i)$$ $$o_t=\sigma(u_tW_o+b_o),\quad \tilde c_t=\tanh(u_tW_c+b_c)$$ $$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\quad h_t=o_t\odot\tanh(c_t)$$

セル状態には加算経路があり、忘却ゲートが1に近いと直接経路の勾配を保ちやすい。ただし全微分にはゲートを経由する経路もあり、長期記憶を保証するものではない。バイアスありの標準LSTMのパラメータ数は $4H(D+H+1)$。

コード26.3
import numpy as np
f, i, o = .9, .2, .8
c = 1.0
for candidate in [.5, 0., -.5]:
    c = f*c + i*candidate
    h = o*np.tanh(c)
    print(c,h)

26.6 GRU：状態とゲートの簡略化

GRUは独立したセル状態を持たず、更新ゲート z とリセットゲート r を使用する。以下はreset-before形式の一例で、更新ゲートが大きいほど前状態を保持する規約。

$$z_t=\sigma(x_tW_z+h_{t-1}U_z+b_z)$$ $$r_t=\sigma(x_tW_r+h_{t-1}U_r+b_r)$$ $$n_t=\tanh(x_tW_n+(r_t\odot h_{t-1})U_n+b_n)$$ $$h_t=z_t\odot h_{t-1}+(1-z_t)\odot n_t$$

上の式はreset-before方式である。KerasのGRUは通常reset_after=Trueで、リセットゲートを再帰行列積の後に適用し、入力側と再帰側に別々のバイアスを持つ。候補状態は $n_t=\tanh(x_tW_n+b_{n,x}+r_t\odot(h_{t-1}U_n+b_{n,h}))$ となり、ゲートのバイアスも入力側と再帰側の和を用いる。したがってバイアスありのパラメータ数は $3H(D+H+2)$。reset-beforeでは $3H(D+H+1)$。

26.7 Kerasによる系列モデルと双方向RNN

return_sequences=Trueは全時点の状態を返し、Falseは最終出力を返す。RNN層へ系列を直接渡して積層する場合は前段でTrueが必要。return_state=Trueで最終状態も取得でき、LSTMではhとcが返る。Bidirectionalは前向きと後ろ向きの出力を結合する（既定は連結）。文章全体が利用できる分類には有効だが、未来の観測が未知の予測では使い方に注意する。

コード26.4
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
x = tf.ones((4, 10, 8))
for cell in [layers.SimpleRNN, layers.LSTM, layers.GRU]:
    model = keras.Sequential([keras.Input((None,8)),
        cell(16, return_sequences=True), cell(8), layers.Dense(1)])
    print(model(x).shape, model.count_params())
bi = layers.Bidirectional(layers.LSTM(16, return_sequences=True))
assert tuple(bi(x).shape) == (4,10,32)

26.8 可変長系列・パディング・マスキング

バッチ内の系列長をそろえるためにパディングする。パディングが実データと区別できる場合はMaskingやEmbedding(mask_zero=True)を用いる。全特徴が0の時点やID 0を有効な入力として使う場合は明示的な長さからマスクを生成する。マスクは状態更新をスキップするための情報であり、系列ラベルの損失の除外も別途確認する。

コード26.5
import tensorflow as tf
from tensorflow import keras
seq = tf.constant([[4,7,2,0,0],[3,5,6,8,9]])
model = keras.Sequential([keras.Input((None,), dtype="int32"),
    keras.layers.Embedding(10, 8, mask_zero=True),
    keras.layers.GRU(16), keras.layers.Dense(1)])
a = model(seq[:1], training=False)
b = model(seq[:1,:3], training=False)
tf.debugging.assert_near(a,b,atol=1e-5)

GPUの高速実装では右パディング等の条件がある。stateful=Trueでは次バッチの同じ標本位置へ状態が引き継がれるため、標本の対応順と境界での状態リセットが必要。独立した標本の通常の分類ではstateful=Falseを使う。

26.9 Seq2Seqとエンコーダ・デコーダ

入力系列をエンコーダで状態へ圧縮し、デコーダの初期状態に渡す。訓練時に正解の一つ前のトークンを入力するTeacher Forcingと、推論時に自分の予測を次へ入力する自己回帰処理を区別する。両者の入力分布が異なる問題をExposure Biasという。固定長状態への圧縮が難しい長系列ではAttentionが有用となる（第27章）。

コード26.6
from tensorflow import keras
from tensorflow.keras import layers
src = keras.Input((None,8))
tgt = keras.Input((None,8))
_, h, c = layers.LSTM(16, return_state=True)(src)
out = layers.LSTM(16, return_sequences=True)(tgt, initial_state=[h,c])
logits = layers.Dense(10)(out)
model = keras.Model([src,tgt],logits)
# tgtには訓練時のシフト済み入力を渡す。
# 推論ループや開始・終了トークンの処理は別途必要。

26.10 実践：長期依存を持つ分類課題

系列の最初の符号を最後まで保持する人工課題で、SimpleRNN・LSTM・GRUを比較する。入力はノイズを含む20または80時点の系列。正解は先頭の信号のみから決まる。訓練・検証・テストは独立生成し、検証損失で最良重みを復元する。ユニット数をそろえる比較であり、パラメータ数や実行時間は一致しない。複数シードで再実験し、平均とばらつきを記録するとよい。

コード26.7
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def make(n,t,seed):
    rng = np.random.default_rng(seed)
    y = rng.integers(0,2,size=(n,1)).astype("float32")
    x = rng.normal(0,.3,(n,t,1)).astype("float32")
    x[:,0,0] = 2*y[:,0]-1
    return x,y

for t in (20,80):
    X,y = make(2000,t,1)
    V,v = make(400,t,2)
    Q,q = make(400,t,3)
    for cell in (layers.SimpleRNN,layers.LSTM,layers.GRU):
        keras.backend.clear_session()
        keras.utils.set_random_seed(26)
        model = keras.Sequential([keras.Input((t,1)),cell(16),layers.Dense(1)])
        model.compile(optimizer=keras.optimizers.Adam(1e-3,global_clipnorm=1.),
            loss=keras.losses.BinaryCrossentropy(from_logits=True),
            metrics=[keras.metrics.BinaryAccuracy(threshold=0.)])
        history = model.fit(X,y,validation_data=(V,v),epochs=40,batch_size=64,
            callbacks=[keras.callbacks.EarlyStopping(patience=6,restore_best_weights=True)],verbose=0)
        print(t,cell.__name__,model.count_params(),model.evaluate(Q,q,verbose=0,return_dict=True))
        import matplotlib.pyplot as plt
        plt.plot(range(1, len(history.history['val_loss'])+1), history.history['val_loss'],label=cell.__name__)
    plt.xlabel('Epoch'); plt.ylabel('Validation loss'); plt.legend(); plt.show()

学習曲線、テスト精度を比較する。計算時間も比較する場合はfit前後をtime.perf_counter()で計測し、同じ実行環境で記録する。結果が悪い場合は先頭の信号が届いているか、勾配ノルム、マスク、学習率を確認する。実験はTensorFlow環境で実行すること。本教材では学習結果を未測定のため掲載していない。

26.11 まとめと確認問題

RNNは時間方向に状態を伝え、BPTTによって共有重みを学習する。ゲート付きセルは長期依存への対策だが、系列の逐次処理という制約は残る。次章ではAttentionによる直接的な情報参照へ進む。

問1　RNNの入力shapeは？

(B,T,D)。

問2　D=3,H=5のSimpleRNNのパラメータ数は？

5(3+5+1)=45。

問3　BPTTで勾配を加算する理由は？

同じ重みが複数時点の計算に使われるため。

問4　勾配クリッピングは勾配消失を解決するか？

しない。大きすぎる勾配を抑制する。

問5　LSTMの忘却ゲートの役割は？

前セル状態の保持量を調整する。

問6　GRUとLSTMの状態の違いは？

GRUは独立したセル状態を持たない。

問7　双方向RNNを未来予測で使う注意点は？

予測時点で未知の未来観測を入力しない。

問8　マスクとパディングの違いは？

パディングは長さをそろえる値、マスクは有効時点を示す情報。

問9　発展：全時点の回帰損失にBPTTを拡張せよ。

各状態から出力を計算し、全B×T×K要素でMSEを平均。各時点の出力勾配に出力重みの転置を右から掛けた状態勾配をq_tとして逆伝播に加え、出力重みの勾配も全時点で加算する。中央差分で検証する。

独立検算例：コード26.2と同じX・Pを使用し、np.random.default_rng(260).normal(size=(3,5,1))で全時点の目標値を生成する。各時点で d_t=2(pred_t−y_t)/(B T K) とし、dhに d_t @ Wo.T を加えてからtanhの導関数を掛ける。出力重みは hs[t+1].T @ d_t、出力バイアスは d_t.sum(axis=0) を全時点で加算する。全パラメータの中央差分（刻み幅10⁻⁵）との最大絶対誤差は 2.895e-11。
