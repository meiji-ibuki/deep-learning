D.2　活性化関数：基本形

非線形な写像を表現するには、隠れ層などに非線形な演算が必要である。微分は逆伝播時の勾配を左右する。

名称定義微分（非微分点を除く）用途・注意
Identity$f(x)=x$$1$回帰出力。恒等活性化の全結合層を重ねても一つのアフィン写像（バイアスなしなら線形写像）にまとめられる
Sigmoid$s=1/(1+e^{-x})$$s(1-s)$二値確率・ゲート。飽和に注意
Tanh$t=\tanh x$$1-t^2$RNNなど。原点対称だが飽和する。出力の平均が0になるとは限らない
ReLU$\max(0,x)$$\mathbf{1}_{x>0}$CNN・MLP。負側の勾配がゼロ
Leaky ReLU$\max(x,\alpha x)$（$0<\alpha<1$）$1$ または $\alpha$負側も勾配を残す
PReLU$\max(0,x)+a\min(0,x)$$1$ または $a$負側係数を学習。過学習に注意

D.3　活性化関数：発展形と出力層

名称定義Keras・特徴
ELU$x$ ($x>0$), $\alpha(e^x-1)$（それ以外）ELU(alpha=1.0)：負側が飽和
SELU$\lambda\,\mathrm{ELU}_{\alpha}(x)$selu：LeCunNormalとAlphaDropout、自己正規化の前提あり
Softplus$\log(1+e^x)$softplus：有限の実数入力では正の出力、ReLUの滑らかな近似（浮動小数点では0に丸められる場合がある）
GELU$x\Phi(x)$gelu：Transformerで頻出、Φは標準正規CDF
SiLU / Swish$x\sigma(x)$silu：滑らか、負側で非単調
Mish$x\tanh(\log(1+e^x))$mish：滑らか、非単調
Softmax$p_k=e^{z_k}/\sum_j e^{z_j}$softmax：排他的なクラス確率。軸指定に注意
Hard sigmoid$\mathrm{clip}(x/6+1/2,0,1)$hard_sigmoid：Keras 3の定義。旧版との差に注意

Softmaxのヤコビ行列は $\partial p_i/\partial z_j=p_i(\delta_{ij}-p_j)$。成分ごとに適用するSigmoidとは異なる（ラベルの統計的独立性を意味しない）。有限のロジットでは計算時に最大ロジットを引いて指数のオーバーフローを防ぐ。

コードD.1　安定なSoftmax（NumPy）
import numpy as np
z = np.array([[1000., 1001., 1002.]])
a = z - z.max(axis=-1, keepdims=True)
p = np.exp(a) / np.exp(a).sum(axis=-1, keepdims=True)
assert np.allclose(p.sum(axis=-1), 1)
print(p.round(6))

D.4　回帰の損失関数

残差 $e=\hat y-y$ とする。表の式は原則として単一標本・単一出力の値であり、バッチ集約は別に行う。

損失数式特徴・適用条件
MSE$e^2$大きな誤差に強い罰則。MeanSquaredError
MAE$|e|$外れ値の影響を抑えやすい。MeanAbsoluteError
Huber$e^2/2$（$|e|\le\delta$）、$\delta(|e|-\delta/2)$（それ以外）Huber(delta=...)。δ>0とし、単位に合わせて選ぶ
Log-cosh$\log\cosh(e)$小誤差は二乗、大誤差は絶対値に近い。LogCosh
MSLE$(\log(1+y)-\log(1+\hat y))^2$通常は非負の目的値・予測を対象とする。Kerasの実装では下限処理がある。MeanSquaredLogarithmicError
MAPE$100|e|/|y|$ゼロでは理論式は未定義。Kerasでは分母をepsilonで下から制限する。MeanAbsolutePercentageError
Pinball$\max(\tau(y-\hat y),(\tau-1)(y-\hat y))$条件付きτ分位点（0<τ<1）。自作
Poisson$\hat y-y\log\hat y$非負カウント、予測平均は正。Poisson。定数項省略

D.5　分類の損失関数

損失数式使い分け
BCE$-[y\log p+(1-y)\log(1-p)]$二値・多ラベル。BinaryCrossentropy
Categorical CE$-\sum_k y_k\log p_k$One-hot・ソフトラベル。CategoricalCrossentropy
Sparse CE$-\log p_c$整数クラスc。SparseCategoricalCrossentropy
Focal loss$-\alpha_t(1-p_t)^\gamma\log p_t$難しい標本を相対的に重視。γ≥0、α_t≥0。p_tは正解クラスに割り当てた確率（第31章）。BinaryFocalCrossentropy（クラス重みは設定が必要）
Hinge$\max(0,1-yz)$ラベル±1、スコア出力。Hinge
Label smoothing$y_k^*=(1-\epsilon)y_k+\epsilon/K$CategoricalCrossentropy(label_smoothing=...)。確率の過信を抑える目的（0≤ε≤1）

ロジットからのBCEは $\max(z,0)-yz+\log(1+e^{-|z|})$ と書ける。確率を経由するより安定である。クラス重みやFocal lossは確率の校正を変える可能性がある。

コードD.2　ロジットからBCEを安定計算
import numpy as np
z = np.array([-1000., 0., 1000.])
y = np.array([0., 1., 1.])
loss = np.maximum(z, 0) - z*y + np.log1p(np.exp(-abs(z)))
assert np.isfinite(loss).all()
print(loss)

D.6　領域・系列・分布の損失関数

損失数式・定義用途・注意
Dice loss$1-(2\sum yp+\epsilon)/(\sum y+\sum p+\epsilon)$領域の重なり。確率入力。正の平滑化定数・集約軸を明示
Tversky loss$1-TP_s/(TP_s+\alpha FP_s+\beta FN_s)$soft TP/FP/FN。α・βは非負。見逃しを重くするならβを増やす（実装の係数定義とゼロ分母の扱いを確認）
KL divergence$\sum_k p_k\log(p_k/q_k)$分布の差。KLDivergence。非対称。正規化が必要。p=0の項は0、p>0かつq=0の項は+∞とする（理論式）
Cosine similarity loss$-u^\top v/(\|u\|\|v\|)$非ゼロの埋め込みの方向を比較。Kerasのlosses.CosineSimilarityは負の類似度、metrics.CosineSimilarityは類似度そのもの
Triplet loss$\max(0,d(a,p)-d(a,n)+m)$距離学習。正負標本の選択が重要
CTC$-\log\sum_{\pi:B(\pi)=y}P(\pi|x)$アラインメント未知の系列。blank、長さ、ラベル形式に注意
InfoNCE$-\log\frac{\exp(s_+/\tau)}{\sum_j\exp(s_j/\tau)}$対照学習。温度τ>0、分母に正例を含め、負例の定義を確認

関連：第28章（表現学習）、第31章（領域予測）、第34章（音声・推薦）。

D.7　回帰・時系列の評価指標

ここでは標本平均を $\overline{a}=\frac{1}{N}\sum_i a_i$ とする。

指標定義方向・注意
MAE$\overline{|e|}$小。目的値と同単位
MSE$\overline{e^2}$小。単位の二乗
RMSE$\sqrt{\overline{e^2}}$小。目的値と同単位。バッチRMSE平均とは異なる
R²$1-\sum e_i^2/\sum(y_i-\bar y)^2$大。負もあり得る。定数目的値は要注意
MAPE$100\overline{|e/y|}$小。ゼロ・負値の解釈に注意。ライブラリによる倍率差
sMAPE$200\overline{|e|/(|y|+|\hat y|)}$小。両方ゼロの扱いを規定
RMSLE$\sqrt{\overline{(\log(1+\hat y)-\log(1+y))^2}}$小。通常非負値を対象
WAPE$100\sum|e|/\sum|y|$小。分母ゼロは未定義
MASE$\mathrm{MAE}/\mathrm{mean}_{t>m}|y_t-y_{t-m}|$小。分母は訓練系列から算出。季節周期mは正整数、訓練系列長はmより大きく、分母が正であることが必要
区間被覆率$N^{-1}\sum_i\mathbf{1}_{L_i\le y_i\le U_i}$目標被覆率との一致と区間幅を併記

D.8　分類の評価指標

TP・FP・TN・FNは正例の定義と閾値に依存する。多クラスではクラスごとにone-vs-restとして計算できる。

指標定義方向・注意
Accuracy$(TP+TN)/N$大。二値分類の式。単一ラベル多クラスでは正解件数/N。不均衡では多数派に偏ることがある
Precision$TP/(TP+FP)$大。誤検出を重視。分母ゼロの処理を明示
Recall / TPR$TP/(TP+FN)$大。見逃しを重視。分母ゼロの処理を明示
Specificity / TNR$TN/(TN+FP)$大。負例の識別。分母ゼロの処理を明示
F1$2TP/(2TP+FP+FN)$大。TNは使わない。分母が0の場合の処理を明示
Fβ$(1+\beta^2)PR/(\beta^2P+R)$大。β>0、β>1でRecall重視。分母ゼロの処理を明示
Balanced accuracy$(TPR+TNR)/2$大。多クラスはクラス別Recall平均
MCC$(TP\,TN-FP\,FN)/\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}$大。分母ゼロの処理を明示
ROC-AUC$\int TPR\,dFPR$大。順位性能。正例・負例の双方が必要で、確率校正を測らない
AP$\sum_n(R_n-R_{n-1})P_n$大。Recallが増加する順の式。PR曲線の台形積分やKerasのAUC(curve="PR")の近似値と同一とは限らない
Log lossBCE / CEの標本平均小。確率品質を評価
Brier score$\overline{(p-y)^2}$小。二値確率の二乗誤差
ECE$\sum_b(n_b/N)|\mathrm{acc}_b-\mathrm{conf}_b|$小。ビン分割と信頼度の定義に依存
Top-k accuracy$N^{-1}\sum_i\mathbf{1}_{y_i\in\mathrm{TopK}(p_i)}$大。kと同点処理を確認
コードD.3　分類指標の数値例
import numpy as np
from sklearn.metrics import (roc_auc_score, average_precision_score,
                             f1_score, confusion_matrix, brier_score_loss)
y = np.array([0,0,0,1,1,1])
p = np.array([.1,.4,.7,.3,.8,.9])
h = p >= .5
print(confusion_matrix(y,h))
print(roc_auc_score(y,p), average_precision_score(y,p))
print(f1_score(y,h), brier_score_loss(y,p))

上の人工データ（正例率10%）ではROC-AUC=0.909、AP=0.638。PR曲線の基準線は正例率に依存する。

D.9　ランキング・検出・領域・系列の評価指標

指標定義注意
IoU$|A\cap B|/|A\cup B|$領域・ボックス。空集合同士の扱いを規定
Dice$2|A\cap B|/(|A|+|B|)$領域。IoUとの関係は同じ集合で2IoU/(1+IoU)（和集合が非空の場合）
mIoUクラス別IoUの平均背景・存在しないクラスの扱いを確認
Detection AP / mAPIoU閾値で対応付け、クラス別APを平均COCOではIoU 0.50〜0.95を0.05刻みで平均するAPが代表的
Precision@k$|R_k\cap G|/k$推薦上位k件の適合率
Recall@k$|R_k\cap G|/|G|$正解集合Gが空の場合の方針が必要
MRR$\overline{1/r}$最初の正解順位r。正解なしは0
NDCG@k$DCG_k/IDCG_k$, $DCG_k=\sum_{i=1}^k(2^{rel_i}-1)/\log_2(i+1)$順位と関連度。理想DCGが0の場合を規定
WER / CER$(S+D+I)/N$語・文字の置換、削除、挿入。100%超もあり得る
Perplexity$\exp(-N^{-1}\sum_t\log p(y_t|\text{context}))$小。トークン化とマスクが同じ場合に比較

コードD.6　カスタム分位点損失
import tensorflow as tf
@tf.keras.utils.register_keras_serializable(package="Textbook")
def pinball_90(y_true, y_pred):
    y_true = tf.cast(y_true, y_pred.dtype)
    e = y_true - y_pred  # 両者の形状を (B, 1) に揃える
    return tf.reduce_mean(tf.maximum(.9*e, -.1*e), axis=-1)

m = tf.keras.Sequential([tf.keras.Input((8,)), tf.keras.layers.Dense(1)])
m.compile(optimizer="adam", loss=pinball_90)
コードD.7　二値領域予測：BCE＋Dice
import tensorflow as tf
@tf.keras.utils.register_keras_serializable(package="Textbook")
def bce_dice(y_true, logits):
    y = tf.cast(y_true, tf.float32)  # (B,H,W,1)
    z = tf.cast(logits, tf.float32)
    p = tf.sigmoid(z)
    axes = (1,2,3)
    bce = tf.reduce_mean(tf.nn.sigmoid_cross_entropy_with_logits(labels=y, logits=z), axis=axes)
    dice = (2*tf.reduce_sum(y*p, axis=axes)+1e-6)/(tf.reduce_sum(y+p, axis=axes)+1e-6)
    return bce + 1-dice  # 標本ごとの損失
コードD.8　状態を蓄積する評価指標
import tensorflow as tf
m = tf.keras.metrics.RootMeanSquaredError()
m.update_state([0.,0.], [0.,2.])
m.update_state([0.], [4.])
print(m.result().numpy())  # sqrt(20/3)
m.reset_state()

D.11　選択・集約・報告のチェックリスト

実装前に次の項目を確認する。コンペでは公式の評価コードと集約方法を最優先する。

  • 正解ラベルの型、出力形状、クラス軸、logits/probabilityを揃える。
  • 無効ラベル、パディング、欠損、空集合、ゼロ分母の扱いを定義する。
  • microは全体のカウントから、macroはクラス別指標の単純平均、weightedは支持数による加重平均。どれを採用するか明記する。
  • F1・AUC・RMSEなどは原則として全予測を集めるか、必要な統計量を正しく蓄積して計算する。バッチごとの単純平均とは一般に異なる。Fold平均と全OOFでの計算は一致しないことがある。
  • 閾値や校正は検証集合で決め、最終テストで再調整しない。
  • サンプル重みを指標にも反映する場合、Kerasのweighted_metricsとmetricsの違いを確認する。
  • 損失に正則化項が含まれる場合、報告するデータ損失と区別する。
