19.1 学習の安定性とは何か

第18章では勾配を更新に変換する方法を学んだ。本章では、更新に使う勾配そのものが深いネットワークを通して適切な大きさに保たれるかを考える。SigmoidやTanhでは前活性化値の絶対値が極端に大きくなると飽和し、逆伝播で勾配が小さくなる。逆に勾配が大きすぎれば更新が発散する。初期化、正規化、残差接続、勾配クリッピングは、それぞれ異なる段階に働く。

第11章の式を再掲する。要素ごとの活性化関数について、$D_l=\partial J/\partial Z_l$ とすると

$$D_{l-1}=(D_lW_l^\top)\odot g'_{l-1}(Z_{l-1})$$

行列の積が何度も繰り返されるため、方向によって勾配が増幅・減衰する。平均的な分散が保たれていても、すべての方向で勾配が保たれるとは限らない。学習の安定性と汎化性能も区別しよう。

19.2 ゼロ初期化と対称性の破れ

隠れ層のニューロンがすべて同じ重みとバイアスを持ち、次層への結合も同じなら、各ニューロンは同じ計算を行い、逆伝播で同じ勾配を受ける。更新しても同じ状態にとどまり、幅を増やす意味が失われる。これを対称性の問題という。

たとえば $h_j=\tanh(w_jx+b_j)$、$\hat y=\sum_jv_jh_j$ とする。全パラメータが0なら $h_j=0$ かつ $v_j=0$ なので、両層の重みの勾配は0になる（出力バイアスがあれば更新されうる）。一般には重みを独立な乱数で初期化し、バイアスは0でよい。単一の線形回帰ではゼロ初期化でも学習可能であり、ゼロそのものが常に悪いわけではない。

コード19.1　同じ重みからは同じ勾配が生じる
import numpy as np
x = np.array([[2.]])
W = np.full((1, 3), .1)
v = np.full((3, 1), .2)
h = np.tanh(x @ W)
e = h @ v - 1
D = (e @ v.T) * (1-h*h)
dW = x.T @ D
print(dW)
assert np.allclose(dW, dW[0, 0])

19.3 分散伝播から初期化を導く

全結合層の1ユニットについて $z_j=\sum_{i=1}^{n_{in}}w_{ij}a_i$ とする。重みは平均0、分散 $\sigma_w^2$、入力と独立、異なる重み同士も独立で、入力の各成分の二次モーメントが共通と仮定する。バイアスは0とする。このとき交差項の期待値が0となるため

$$E[z_j^2]=\sum_i E[w_{ij}^2]E[a_i^2]=n_{in}\sigma_w^2 E[a^2]$$

ここで $E[z_j]=0$ なので左辺は分散でもある。入力の平均が0でない場合は $E[a^2]=\operatorname{Var}(a)+E[a]^2$ であり、分散と二次モーメントを混同しない。恒等関数に近い領域なら順伝播の二次モーメントを維持する条件は $n_{in}\sigma_w^2\approx1$。逆伝播では独立性などを近似的に仮定して $n_{out}\sigma_w^2\approx1$ となる。実際の学習中にはこれらの仮定は厳密には成立しない。

19.4 Xavier・He・LeCun初期化

Xavier（Glorot）初期化

順伝播と逆伝播の条件を折衷する。

$$\sigma_w^2=\frac{2}{n_{in}+n_{out}}$$

一様分布 $U(-r,r)$ の分散は $r^2/3$ なので $r=\sqrt{6/(n_{in}+n_{out})}$。Tanhなどの原点付近で線形に近い関数に適する出発点である。

He（Kaiming）初期化

対称な分布の $z$ について ReLU は負側を0にするため $E[\mathrm{ReLU}(z)^2]=E[z^2]/2$。よって順伝播の二次モーメントを保つには

$$\sigma_w^2=\frac2{n_{in}}$$

Leaky ReLUの負側傾きが $\alpha$ なら $2/((1+\alpha^2)n_{in})$ に一般化できる。LeCun初期化は $1/n_{in}$ を採用する。SELUと組み合わせる自己正規化には追加条件がある。

方式重みの目標分散用途の目安
Glorot2/(fan_in+fan_out)Tanh・一般的なDense
He2/fan_inReLU系
LeCun1/fan_inSELUなど
Orthogonal行列の直交性（gainで調整）深い線形層・RNNなど

畳み込みでは受容野の大きさとチャネル数を含めてfanを求める。KerasのGlorotNormal・HeNormal・LecunNormalは切断正規分布を使い、切断後の分散を補正する。以下のNumPy実験では非切断正規分布を使うため、乱数の分布は完全には一致しない。

コード19.2　Kerasで初期化方式を指定する
import tensorflow as tf
from tensorflow import keras
model = keras.Sequential([
    keras.Input(shape=(64,)),
    keras.layers.Dense(128, activation='relu', kernel_initializer='he_normal'),
    keras.layers.Dense(128, activation='tanh', kernel_initializer='glorot_uniform'),
    keras.layers.Dense(1)
])
model.summary()

19.5 深いネットワークで分布を観察する

幅64、深さ30のReLUネットワークで、初期化だけを変えた場合の活性化値と逆伝播の勾配を比較する。入力は標準正規分布、バイアスは0。損失の代わりに最終活性化に独立な上流勾配を与え、ネットワーク自体の勾配伝播を観察する。学習実験ではない。

コード19.3　活性化と勾配のRMSを測定する
import numpy as np

def probe(scale, seed=19, depth=30, width=64):
    rng = np.random.default_rng(seed)
    a = rng.normal(size=(128, width))
    activations, weights, masks = [a], [], []
    for _ in range(depth):
        W = rng.normal(size=(width, width)) * scale
        z = a @ W
        a = np.maximum(z, 0)
        weights.append(W)
        masks.append(z > 0)
        activations.append(a)
    d = rng.normal(size=a.shape)
    grad = [np.sqrt(np.mean(d*d))]
    for W, mask in zip(weights[::-1], masks[::-1]):
        d = (d * mask) @ W.T
        grad.append(np.sqrt(np.mean(d*d)))
    rms = [np.sqrt(np.mean(a*a)) for a in activations]
    return np.array(rms), np.array(grad[::-1])

scales = {'small': .03, 'Glorot': np.sqrt(1/64),
          'He': np.sqrt(2/64), 'large': .3}
for name, scale in scales.items():
    a, g = np.median([probe(scale, seed=s) for s in range(19, 24)], axis=0)
    print(name, a[-1], g[0])

He初期化は他の極端な尺度よりRMSを保ちやすいが、有限幅の乱数実験では一定にはならない。勾配の図は右端の上流勾配から左へ逆伝播した結果である。平均・標準偏差・ゼロの割合も確認すると、飽和や死んだReLUを発見しやすい。

19.6 Batch Normalization

ミニバッチ内の各特徴量について平均と分散を求め、正規化してから学習可能な尺度と平行移動を適用する。

$$\mu_B=\frac1B\sum_i x_i,\quad \sigma_B^2=\frac1B\sum_i(x_i-\mu_B)^2$$ $$\hat x_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\qquad y_i=\gamma\hat x_i+\beta$$

epsilonはゼロ除算を防ぐ。gammaとbetaにより必要に応じて尺度や位置を回復できる。Denseの入力が(B,F)なら通常axis=-1で特徴量ごとにバッチ軸を集計する。画像NHWCでは通常バッチと空間軸を集計する。

訓練時はバッチ統計量を使い、移動平均・移動分散を更新する。推論時は蓄積された統計量を使う。Kerasのmomentum $m$ は $\mu_{moving}\leftarrow m\mu_{moving}+(1-m)\mu_B$ の係数である。小バッチでは統計が不安定になりやすい。KerasのBatchNormalizationではtrainable=Falseにすると移動統計の更新を停止し、推論モードで動作する。compile後にtrainableを変更した場合は再compileする（第35章も参照）。BatchNormが最適化を助ける理由は単なる内部共変量シフトの抑制だけでは説明しきれない。

コード19.4　訓練時と推論時の統計量を確認する
import tensorflow as tf
from tensorflow import keras
bn = keras.layers.BatchNormalization(momentum=0.5)
x = tf.constant([[1., 10.], [3., 14.]])
print(bn(x, training=True).numpy())
print(bn.moving_mean.numpy())
print(bn(x, training=False).numpy())

19.7 Layer Normalization・Group Normalization・RMSNorm

LayerNormは各標本内で指定した特徴軸を集計する。典型的な系列テンソル(B,T,D)では最後のD軸を正規化し、トークンごとに平均・分散を計算する。BatchNormと異なり他の標本に依存せず、通常は訓練時・推論時に同じ計算を行う。

GroupNormはチャネルをグループに分割し、各標本のグループ内の空間・チャネル方向で統計量を求める。グループ数はチャネル数を割り切る必要がある。RMSNormは平均を引かず二乗平均平方根で尺度を調整する。

$$\mathrm{RMSNorm}(x)_j=\gamma_j\frac{x_j}{\sqrt{\frac1D\sum_k x_k^2+\epsilon}}$$
方式統計量の範囲（典型例）特徴
BatchNorm各チャネルのB,H,W推論用移動統計あり
LayerNorm各標本・各トークンのDバッチサイズに依存しない
GroupNorm各標本・各グループのH,W,C/G小バッチ画像モデルにも有用
RMSNorm各トークンのDの二次モーメント平均の減算なし
コード19.5　RMSNormを独自レイヤーとして実装する
import tensorflow as tf
from tensorflow import keras

@keras.utils.register_keras_serializable(package='Textbook')
class SimpleRMSNorm(keras.layers.Layer):
    def __init__(self, epsilon=1e-6, **kwargs):
        super().__init__(**kwargs)
        self.epsilon = epsilon
    def build(self, shape):
        self.gamma = self.add_weight(name='gamma', shape=(shape[-1],), initializer='ones')
        super().build(shape)
    def call(self, x):
        u = tf.cast(x, tf.float32)
        u = u * tf.math.rsqrt(tf.reduce_mean(tf.square(u), axis=-1, keepdims=True) + self.epsilon)
        return tf.cast(u, self.compute_dtype) * self.gamma
    def get_config(self):
        return {**super().get_config(), 'epsilon': self.epsilon}

x = tf.constant([[1., 2., 3.]])
print(SimpleRMSNorm()(x))

19.8 残差接続・勾配クリッピングと数値安定性

残差接続 $y=x+F(x)$ のヤコビ行列は $I+J_F$ となる。恒等経路が勾配の通り道を提供する。ただし勾配消失・爆発が必ずなくなるわけではない。勾配クリッピングは勾配計算後に大きさを制限する技術であり、初期化や正規化とは働く段階が異なる。

$$g'=g\min(1,c/\|g\|_2)\quad(\|g\|_2>0)$$

上限cは正とし、勾配がゼロならそのままとする。グローバルノルムはすべての勾配テンソルの要素の二乗和の平方根。要素別のclipvalueとは異なり方向を保つ。Adam等ではクリッピング後の勾配から内部状態が更新されるため、実際のパラメータ更新ノルムを直接制限するものではない。NaNやInfを修復する処理でもない。学習率・入力尺度・損失計算を点検しよう。

コード19.6　Kerasのグローバルノルム制限
from tensorflow import keras
optimizer = keras.optimizers.Adam(learning_rate=1e-3, global_clipnorm=1.0)
# model.compile(optimizer=optimizer, loss='mse')

19.9 実践：初期化と正規化の比較実験

同じ深いMLPで初期化とBatchNormの有無を比較する。人工的な二値分類データを使い、訓練データだけで標準化の統計量を求める。深さ20、幅64、ReLU、Adam、学習率0.001を固定する。各条件を3シードで実行し、検証損失の平均と標準偏差を比較する。BatchNormを追加すると学習パラメータ数も変わるため、完全に同一のモデルではない。テスト集合は方式の選択後に一度だけ評価する。

コード19.7　深いMLPの比較実験（TensorFlow）
import numpy as np
import tensorflow as tf
from tensorflow import keras
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

X, y = make_moons(n_samples=1500, noise=.25, random_state=19)
Xtr, Xrest, ytr, yrest = train_test_split(X, y, test_size=.4, stratify=y, random_state=19)
Xva, Xte, yva, yte = train_test_split(Xrest, yrest, test_size=.5, stratify=yrest, random_state=19)
scaler = StandardScaler().fit(Xtr)
Xtr, Xva, Xte = [scaler.transform(x).astype('float32') for x in (Xtr, Xva, Xte)]
ytr, yva, yte = [y.astype('float32').reshape(-1,1) for y in (ytr,yva,yte)]

def trial(init, bn, seed):
    keras.backend.clear_session()
    keras.utils.set_random_seed(seed)
    inputs = keras.Input(shape=(2,))
    x = inputs
    for _ in range(20):
        x = keras.layers.Dense(64, kernel_initializer=init, use_bias=not bn)(x)
        if bn:
            x = keras.layers.BatchNormalization()(x)
        x = keras.layers.ReLU()(x)
    model = keras.Model(inputs, keras.layers.Dense(1)(x))
    model.compile(optimizer=keras.optimizers.Adam(.001),
                  loss=keras.losses.BinaryCrossentropy(from_logits=True),
                  metrics=[keras.metrics.BinaryAccuracy(threshold=0.)])
    ds = tf.data.Dataset.from_tensor_slices((Xtr,ytr)).shuffle(len(Xtr),seed=seed).batch(32)
    h = model.fit(ds, validation_data=(Xva,yva), epochs=30, verbose=0,
                  callbacks=[keras.callbacks.TerminateOnNaN()])
    curve = np.asarray(h.history['val_loss'])
    if len(curve) != 30 or not np.all(np.isfinite(curve)):
        raise RuntimeError('Unstable trial: inspect gradients and activations')
    return model, curve

results = []
for init in ('glorot_normal','he_normal'):
    for bn in (False, True):
        curves = np.stack([trial(init,bn,s)[1] for s in (19,20,21)])
        results.append((curves[:,-1].mean(), init, bn))
        print(init,bn,curves[:,-1].mean(),curves[:,-1].std())
        plt.plot(np.arange(1,31),curves.mean(axis=0),label=f'{init}, BN={bn}')
plt.xlabel('Epoch'); plt.ylabel('Validation loss'); plt.legend(); plt.show()
_, init, bn = min(results)
model, _ = trial(init,bn,19)
print(model.evaluate(Xte,yte,return_dict=True,verbose=0))

この比較は最終エポックの検証損失を基準にする。学習が不安定な試行は失敗として記録し、成功した試行だけで都合のよい平均を算出しない。実行環境によって結果は異なる。本教材ではTensorFlowの学習結果は未計測である。

勾配の絶対値だけでは判断しにくいので、重みのノルムに対する更新量の比も確認する。ゼロの重みには分母の下限を設ける。診断時は同じ入力・同じモデル状態を使う。BatchNormをtraining=Trueで呼ぶだけでも移動統計が更新される点に注意する。

コード19.8　勾配の診断（学習モードで実際に状態が変化する）
import tensorflow as tf

def inspect_gradients(model, x, y):
    with tf.GradientTape() as tape:
        logits = model(x, training=True)
        loss = tf.reduce_mean(tf.nn.sigmoid_cross_entropy_with_logits(labels=y, logits=logits))
        if model.losses:
            loss += tf.add_n(model.losses)
    grads = tape.gradient(loss, model.trainable_variables)
    for w, g in zip(model.trainable_variables, grads):
        if g is None:
            print(w.name, 'disconnected')
            continue
        tf.debugging.assert_all_finite(g, w.name)
        rms = tf.sqrt(tf.reduce_mean(tf.square(g)))
        tf.print(w.name, 'gradient RMS:', rms)
    return loss

19.11 まとめと確認問題

初期化は情報伝播の出発点を整え、正規化は中間表現の尺度を調整し、残差接続は経路を追加し、クリッピングは更新に使う勾配を制限する。目的に応じて組み合わせる。

全重みを0にすると多層ネットワークで何が起きるか？

対称性が破れず、層によっては勾配も0になる。

fan_in=128のHe初期化の分散は？

2/128=0.015625。標準偏差は0.125。

fan_in=64、fan_out=128のGlorot一様分布の上限は？

sqrt(6/192) ≈ 0.17678。

ReLUの出力の分散は常に入力の半分か？

いいえ。対称入力なら二次モーメントが半分。平均が非ゼロになるため分散とは異なる。

BatchNormの推論時の統計量は？

通常は学習中に更新された移動平均・移動分散。

LayerNormとBatchNormの集計軸の違いは？

典型的な2次元入力ではLayerNormは標本内の特徴軸、BatchNormは特徴ごとのバッチ軸。

RMSNormは平均を0にするか？

平均を引かないので一般には0にならない。

勾配(6,8)をglobal norm 5で制限した結果は？

ノルム10なので(3,4)。

発展：probeの活性化をLeaky ReLU（α=0.1）に変更し、初期化を比較せよ。

a=np.maximum(z,0)+0.1*np.minimum(z,0) とし、masks.append(np.where(z>0,1.,0.1)) に変更する。scale=np.sqrt(2/((1+0.1**2)*64)) とGlorotを比較する。複数シードでRMSを観察し、有限幅でのばらつきも報告する。 シード19〜23の中央値による再計算例：Glorot：最終活性化RMS=2.5814e-05、入力勾配RMS=3.52763e-05、Leaky ReLU向け：最終活性化RMS=0.728592、入力勾配RMS=0.995662。
