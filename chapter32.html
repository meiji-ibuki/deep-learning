32.1 自然言語処理の問題設定

自然言語処理（NLP）は文章を計算可能な表現へ変換し、意味や構造を推定する。本章では生成ではなく識別・抽出を扱う。文章分類は文書単位、系列ラベリングはトークン単位、質問応答の抽出型は開始・終了位置を予測する。予測対象によって出力形状と損失が変わる。

タスク出力指標
感情分析(B,1) 二値ロジットF1、ROC-AUC
多クラス分類(B,K)Macro F1
多ラベル分類(B,K) ラベルごとのロジットMicro/Macro F1
固有表現抽出(B,T,K)Entity F1
抽出型質問応答開始・終了位置Exact Match、F1

32.2 テキストの正規化と分割

Unicode正規化は表記揺れを減らすが、意味のある違いも失う可能性がある。NFCは正準等価な表現を統一し、NFKCは全角英数字など互換文字も変換する。URLや数値を特殊トークンに置き換えるかはタスク依存である。否定語、絵文字、句読点は感情を表すため無条件に削除しない。原文と加工後を保存する。

同一著者・商品・記事の重複が分割をまたぐと、未知の著者・商品・記事への汎化を評価したい場合にリークや評価の過大推定が起き得る。時系列の投稿なら未来への汎化を検証する。語彙・IDF・最大長などデータ依存の前処理は訓練のみで決める。

コード32.1　Unicode正規化の比較
import unicodedata as ud
s = 'ＡＩとｶﾀｶﾅ、Cafe\u0301！'
for form in ['NFC','NFKC']:
    print(form, ud.normalize(form,s))

32.3 トークン化と日本語の形態素解析

英語では空白が手掛かりになるが、日本語には単語境界が明示されない。形態素解析は辞書や統計モデルを用いて語境界・品詞などを推定する。SudachiPyやMeCabが候補となる。文字単位は未知語に強いが系列が長くなる。サブワードは頻出部分を語彙に登録し、未知語を細分化する。BPEは頻出ペアの結合、WordPieceは語彙候補の選択、SentencePieceは原文を扱うトークナイザ実装でBPEやUnigramを利用できる。事前学習モデルには対応するトークナイザを使う。

単位長所短所
文字未知語に強い系列が長い
単語意味が明瞭未知語・辞書依存
サブワード語彙と長さの折衷境界が直感的でない
コード32.2　日本語の文字n-gram（外部辞書不要）
def ngrams(s,n):
    return [s[i:i+n] for i in range(len(s)-n+1)]
print(ngrams('猫が眠る',2))
assert ngrams('猫が眠る',2)==['猫が','が眠','眠る']

32.4 Bag of WordsとTF-IDF

Bag of Wordsは単語の出現回数をベクトル化し、順序を捨てる。TF-IDFは多くの文書に共通する語を抑制する。scikit-learnの平滑化付きIDFは次の形である。

$$idf(t)=\log\frac{1+N}{1+df(t)}+1,\quad v_{d,t}=tf(d,t)idf(t)$$

scikit-learnの既定値では非ゼロの行をL2正規化する。文字n-gramは日本語の強いベースラインとなる。語彙のfitを分割前に行わない。線形分類器は高速かつ解釈しやすく、深層学習が常に勝つわけではない。

コード32.3　TF-IDFの実測例
from sklearn.feature_extraction.text import TfidfVectorizer
texts=['猫 が 眠る','犬 が 眠る','猫 が 遊ぶ']
v=TfidfVectorizer(token_pattern=r'(?u)\b\w+\b')
a=v.fit_transform(texts).toarray()
print(v.get_feature_names_out())
print(a.round(3))

32.5 ID列・Embedding・マスキング

語彙サイズV、埋め込み次元Dの行列Eを学習する。トークンID $i$ のベクトルは $E_{i,:}$ である。One-hotベクトルとの積と等価だが、実装では行を直接参照する。Word2VecのCBOWは周辺語から中心語、Skip-gramは中心語から周辺語を予測する。静的埋め込みは同じ語に同じベクトルを割り当てるが、BERTでは文脈で変化する。

パディングIDを0、未知語IDを1とする例では、マスク $m_t=1[id_t\ne0]$ を使う。平均プーリングは有効位置数で割る。

$$h=\frac{\sum_t m_t E_{id_t}}{\max(1,\sum_t m_t)}$$
コード32.4　マスク付き平均の実装
import numpy as np
E=np.arange(20,dtype=float).reshape(5,4)
ids=np.array([[2,3,0],[4,0,0]])
m=ids!=0
h=(E[ids]*m[...,None]).sum(1)/np.maximum(1,m.sum(1,keepdims=True))
assert np.allclose(h[0],(E[2]+E[3])/2)
assert np.allclose(h[1],E[4])
print(h)

32.6 文章分類モデルと損失

Embedding＋平均プーリングは順序を捨てるが高速である。TextCNNは局所n-gramに相当する特徴を抽出し、BiGRUは前後の文脈を統合する。TransformerはAttentionによって離れた位置を直接結びつける。二値分類では1ロジット、排他的多クラスではKロジットを出力する。二値の確率は $\sigma(z)$、損失は $-y\log p-(1-y)\log(1-p)$ である。ロジットを出す場合はfrom_logits=Trueとする。

方式順序計算特性
TF-IDF＋線形n-gramのみ疎行列
平均Embeddingなし軽量
TextCNN局所並列化
BiGRU前後逐次
Transformer位置情報付きAttentionの二乗コスト

32.7 実践：IMDb感情分析のデータ準備

英語レビューの二値分類を例に、TensorFlow DatasetsのIMDbを使用する。訓練と検証は公式trainから分割し、公式testはモデル選択後に使用する。最大長256は教育用の設定であり、切り捨て率を調べて調整する。HTMLタグや句読点の処理も検証対象となる。

コード32.5　データセットの読み込みと語彙のfit（要tensorflow-datasets）
import tensorflow as tf
import tensorflow_datasets as tfds
from tensorflow import keras
keras.utils.set_random_seed(32)
train,val,test=tfds.load('imdb_reviews',split=['train[:80%]','train[80%:]','test'],as_supervised=True)
vectorizer=keras.layers.TextVectorization(max_tokens=20000,output_mode='int',output_sequence_length=256)
vectorizer.adapt(train.map(lambda x,y:x).batch(128))
train_b=train.shuffle(20000,seed=32).batch(64).prefetch(tf.data.AUTOTUNE)
val_b=val.batch(64).prefetch(tf.data.AUTOTUNE)
test_b=test.batch(64).prefetch(tf.data.AUTOTUNE)
print(vectorizer.get_vocabulary()[:12])

32.8 実践：平均EmbeddingとBiGRUの比較

同じデータ・語彙・学習予算を用い、平均EmbeddingとBiGRUを比較する。BiGRUではmask_zero=Trueでパディングを除外し、平均EmbeddingではIDから明示的なマスクを作る。平均プーリングは全位置がマスクされた文でNaNを起こす実装があるため、入力の空文字を明示的な語に置換するか、安全なプーリングを使う。ここでは安全な平均を実装する。モデル選択は検証損失で行い、テストは選択モデルだけ評価する。

コード32.6　二種類のモデルを学習する（前節に続けて実行）
class SafeMean(keras.layers.Layer):
    def call(self, inputs):
        ids,emb=inputs
        m=tf.cast(ids!=0,emb.dtype)[...,None]
        return tf.math.divide_no_nan(tf.reduce_sum(emb*m,axis=1),tf.reduce_sum(m,axis=1))
def build(kind):
    x=keras.Input(shape=(),dtype=tf.string)
    ids=vectorizer(x)
    e=keras.layers.Embedding(len(vectorizer.get_vocabulary()),64,mask_zero=(kind=='gru'))(ids)
    h=keras.layers.Bidirectional(keras.layers.GRU(32))(e) if kind=='gru' else SafeMean()([ids,e])
    z=keras.layers.Dense(1)(keras.layers.Dropout(.2)(h))
    model=keras.Model(x,z)
    model.compile(optimizer='adam',loss=keras.losses.BinaryCrossentropy(from_logits=True),metrics=[keras.metrics.BinaryAccuracy(threshold=0.)])
    return model
models={}; scores={}
for kind in ['mean','gru']:
    keras.utils.set_random_seed(32)
    m=build(kind)
    m.fit(train_b,validation_data=val_b,epochs=8,callbacks=[keras.callbacks.EarlyStopping(patience=2,restore_best_weights=True)])
    models[kind]=m
    scores[kind]=m.evaluate(val_b,return_dict=True)['loss']
best=models[min(scores,key=scores.get)]
print(best.evaluate(test_b,return_dict=True))

32.9 系列ラベリングと固有表現抽出

BIOタグではB-PERは人物名の先頭、I-PERは続き、Oは対象外である。サブワード化で一語が複数に分かれる場合、先頭だけを評価するか全サブワードへタグを伝えるかを定義する。パディングと特殊トークンは損失から除く。トークンAccuracyが高くても、固有表現の境界がずれるとEntity F1は低くなる。CRFは遷移スコアを使い系列全体を評価する。

コード32.7　有効トークンだけの損失（TensorFlow）
import tensorflow as tf
def masked_loss(y,logits):
    valid=y!=-100
    safe=tf.where(valid,y,0)
    loss=tf.nn.sparse_softmax_cross_entropy_with_logits(labels=safe,logits=logits)
    w=tf.cast(valid,loss.dtype)
    return tf.math.divide_no_nan(tf.reduce_sum(loss*w),tf.reduce_sum(w))

32.10 BERTによる転移学習

BERTはTransformer Encoderを用い、左右の文脈を参照する。事前学習ではマスクされたトークンの予測などを通じて表現を獲得する。分類では文全体の表現から分類ヘッドを学習する。事前学習済み語彙と特殊トークンのID対応を保持し、モデルが許容する位置埋め込みの範囲内で入力長を設定する。日本語では日本語または多言語に対応したモデルを選ぶ。英語用のuncasedモデルを日本語に無条件適用しない。学習率は小さめから検証し、GPUメモリに合わせてバッチサイズを調整する。

32.11 誤分類分析とKaggle提出

クラス不均衡ではMacro F1とクラス別Recallを確認する。閾値は検証データで選ぶ。誤分類を否定・皮肉・長文・未知語・ドメイン差などに分類し、改善仮説を立てる。提出時はID順と確率の定義を確認する。文字列の欠損を空欄に変換する場合は学習時にも同じ処理を適用する。

コード32.9　人工日本語データで線形ベースラインを検証
from sklearn.pipeline import make_pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import f1_score,confusion_matrix
x=['猫が好き','犬が好き','とても楽しい','本当に楽しい','猫が嫌い','犬が嫌い','とても退屈','本当に退屈']
y=[1,1,1,1,0,0,0,0]
m=make_pipeline(TfidfVectorizer(analyzer='char',ngram_range=(1,2)),LogisticRegression())
m.fit(x,y)
xt=['鳥が好き','すごく楽しい','鳥が嫌い','すごく退屈']
yt=[1,1,0,0]
pred=m.predict(xt)
print(confusion_matrix(yt,pred),f1_score(yt,pred,average='macro'))

32.12 まとめと確認問題

文章分類はデータ分割、語彙、モデル、評価を一体として設計する。人工日本語データは動作確認用であり実用性能の証拠ではない。IMDbとBERTの学習は未実行である。

問1　NFCとNFKCの違いは？

NFKCは互換文字も統一する。

問2　日本語で空白分割が不十分な理由は？

単語境界が明示されない。

問3　IDFは何を抑制するか？

多くの文書に出現する語。

問4　Embeddingの形状は？

V×D。

問5　マスクの役割は？

マスクに対応する演算でパディングを集計・状態更新などから除く。

問6　二値ロジットの損失設定は？

BinaryCrossentropy(from_logits=True)。

問7　BERTの語彙を置換しない理由は？

事前学習済みのIDと埋め込みが対応するため。

問8　Entity F1の評価単位は？

種類と境界が一致する固有表現。

問9　発展：文字n-gramとBiGRUを比較せよ。

同じ訓練・検証・テスト分割を用い、文字n-gramの語彙・IDFもBiGRUの語彙も訓練のみで適合する。検証Macro F1でモデルを選択し、長さ別・否定語別の誤分類を調べ、最終選択後にテストを評価する。
