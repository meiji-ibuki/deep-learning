11.1 学習とは何を計算することか

第8章では順伝播によって予測を求め、第10章では予測の誤りを損失として測りました。しかし、損失が大きいという情報だけでは、数千個の重みのうちどれをどちらへ動かせばよいかはわかりません。そこで必要になるのが勾配です。勾配は、各パラメータを微小に変化させたときの損失の変化率を並べたものです。

$$J(\theta)=\frac1B\sum_{i=1}^B\ell(y_i,f_\theta(x_i)),\qquad \theta\leftarrow\theta-\eta\nabla_\theta J$$

ここで $B$ はバッチサイズ、$\eta$ は学習率です。誤差逆伝播法（backpropagation）は勾配を効率よく計算する方法であり、勾配降下法はその勾配を利用してパラメータを更新する方法です。両者は別の役割を担います。

訓練ではこの処理を反復します。推論では通常、順伝播だけを行い、正解も勾配も必要ありません。検証では順伝播と損失・指標の計算を行いますが、重みは更新しません。

11.2 計算グラフと局所微分

複雑な式を小さな演算に分解し、依存関係を矢印で表したものを計算グラフと呼びます。例えば $z=wx+b$、$e=z-y$、$L=\frac12(z-y)^2$ とします。$x=2,w=3,b=1,y=5$ なら、$z=7,L=2$ です。

連鎖律を使うと、出力から入力側へ順に微分できます。$\partial L/\partial e=e=2$、$\partial e/\partial z=1$、$\partial z/\partial w=x=2$ なので、$\partial L/\partial w=4$ です。バイアスに対しては $\partial L/\partial b=2$ になります。

$$\frac{\partial L}{\partial w}=\frac{\partial L}{\partial e}\frac{\partial e}{\partial z}\frac{\partial z}{\partial w}$$

学習率0.1で同時に更新すると $w=2.6,b=0.8$、新しい予測は6、損失は0.5です。勾配は更新前の同一のパラメータから計算します。

コード11.1　一つのニューロンの学習
x,w,b,y = 2.,3.,1.,5.
z = w*x+b
e = z-y
L = .5*e**2
dw,db = e*x,e
w,b = w-.1*dw,b-.1*db
print(L, .5*(w*x+b-y)**2)  # 2.0, 0.5

11.3 分岐と勾配の加算

同じ変数が複数の演算で使われると、損失に至る経路が複数になります。その場合、各経路から戻る勾配を加算します。例えば $u=x^2,v=3x,L=u+v$ なら、$dL/dx=2x+3$ です。

スカラーの計算グラフでは、変数 $x$ を直接利用するノードが $v_1,\dots,v_k$ なら、逆伝播では次の式を使います。

$$\bar x=\sum_j \bar v_j\frac{\partial v_j}{\partial x},\qquad \bar v=\frac{\partial L}{\partial v}$$

この加算は共有パラメータ、残差接続、複数出力の損失などでも重要です。例えば同じ重みが複数の標本で使われる場合も、それぞれの寄与を集約します。

コード11.2　分岐を数値微分で確認
x=2.
f=lambda x:x*x+3*x
h=1e-5
numeric=(f(x+h)-f(x-h))/(2*h)
assert abs(numeric-(2*x+3))<1e-8
print(numeric)

11.4 多層ネットワークの逆伝播を手計算する

入力1、隠れニューロン2、出力1の回帰ネットワークを考えます。隠れ層にはReLU、出力層には恒等関数を使います。入力 $x=2$、正解 $y=1$、隠れ層の重み $(1,-1)$、バイアス $(0,0)$、出力重み $(2,3)$、出力バイアス0とします。

$$z=(2,-2),\quad a=\mathrm{ReLU}(z)=(2,0),\quad \hat y=4,\quad L=\tfrac12(4-1)^2=4.5$$

出力の勾配は $\delta_o=\hat y-y=3$。出力重みの勾配は $(6,0)$、バイアスは3です。隠れ層の活性化後の勾配は $(6,9)$、ReLUの微分を掛けると前活性化値の勾配は $(6,0)$ になります。

パラメータ勾配学習率0.01で更新
隠れ重み(12,0)(0.88,−1)
隠れバイアス(6,0)(−0.06,0)
出力重み(6,0)(1.94,3)
出力バイアス3−0.03

更新後の損失は約2.572です（予測3.268）。負領域のReLUではこの標本に関する勾配が0ですが、別の標本では正領域に入る可能性があります。

コード11.3　手計算の検算
import numpy as np
x,y=2.,1.
w=np.array([1.,-1.]); b=np.zeros(2)
v=np.array([2.,3.]); c=0.
z=x*w+b; a=np.maximum(z,0)
p=a@v+c; d=p-y
dv=a*d; dc=d
dz=d*v*(z>0); dw=x*dz; db=dz
print(dw,db,dv,dc)
w-=.01*dw; b-=.01*db; v-=.01*dv; c-=.01*dc
p=np.maximum(x*w+b,0)@v+c
print(p,.5*(p-y)**2)

11.5 行列による誤差逆伝播の一般化

第8章と同様に標本を行に並べます。層 $l$ の入力幅を $d_{l-1}$、出力幅を $d_l$ とします。順伝播は次式です。

$$Z_l=A_{l-1}W_l+b_l,\quad A_l=g_l(Z_l),\quad A_0=X$$

損失 $J$ に対する前活性化値の勾配を $D_l=\partial J/\partial Z_l$ と定義します。要素ごとの活性化関数であれば、逆伝播は次の四式で表現できます。

$$\frac{\partial J}{\partial W_l}=A_{l-1}^{\top}D_l$$ $$\frac{\partial J}{\partial b_l}=\sum_{i=1}^{B}D_{l,i,:}$$ $$\frac{\partial J}{\partial A_{l-1}}=D_lW_l^\top$$ $$D_{l-1}=(D_lW_l^\top)\odot g'_{l-1}(Z_{l-1})$$

$\odot$ は要素積です。例えば $Z_{ij}=\sum_k A_{ik}W_{kj}+b_j$ なので、$\partial J/\partial W_{kj}=\sum_i A_{ik}D_{ij}$ となります。この成分表示を行列化したものが最初の式です。

変数shape
A, dA(B, d入力)
W, dW(d入力, d出力)
b, db(d出力,)
Z, D(B, d出力)

Softmaxは要素ごとの関数ではないので、一般にはヤコビ行列との積が必要です。ただし交差エントロピーと組み合わせれば、第10章の結果を利用して簡潔に計算できます。

11.6 出力層の勾配とミニバッチ

出力層から逆伝播を開始するには、損失の微分が必要です。線形出力層を使う単一出力のMSEなら $D_L=2(\hat Y-Y)/B$、二値分類のロジット版BCEなら $D_L=(\sigma(Z_L)-Y)/B$、Softmaxと組み合わせた多クラス分類のCCEなら $D_L=(\mathrm{softmax}(Z_L)-Y)/B$ です。最後の $Y$ はOne-hot形式とします。

ここでは $J$ がバッチ平均なので、最初の $D_L$ に $1/B$ を含めています。重みの勾配を計算する際に再び $B$ で割ると誤りです。多出力MSEやマルチラベルBCEで出力軸も平均する場合、その軸の要素数でも割ります。

コード11.4　バッチ勾配と標本勾配の一致
import numpy as np
X=np.array([[1.,2.],[3.,4.],[2.,1.]])
y=np.array([[1.],[2.],[3.]])
w=np.array([[.2],[.3]])
e=X@w-y
batch=X.T@(2*e/len(X))
individual=np.array([2*X[i,:,None]*e[i] for i in range(len(X))])
np.testing.assert_allclose(batch,individual.mean(axis=0))
print(batch)

全バッチ勾配降下法、確率的勾配降下法（標本単位）、ミニバッチ勾配降下法の違いは、勾配を推定するデータの範囲にあります。ミニバッチは計算効率と更新頻度のバランスを取ります。エポックと更新ステップは区別しましょう。

11.7 数値微分・解析微分・自動微分

解析微分は式を数学的に微分する方法、数値微分は関数値の差から微分を近似する方法、自動微分は実際の演算を記録し、局所微分と連鎖律で導関数の値を計算する方法です。自動微分は数値差分ではありません。

方法特徴
解析微分式を理解するのに有用。複雑なモデルでは手作業が困難。
中央差分1パラメータにつき通常2回の関数評価。丸め誤差と近似誤差がある。
逆モード自動微分多数の入力と単一の損失に有効。通常は中間値を保存する（再計算で節約する方法もある）。
$$\frac{\partial J}{\partial \theta_j}\approx\frac{J(\theta+h e_j)-J(\theta-h e_j)}{2h}$$

順モードは入力側から微分情報を伝え、逆モードは出力側から伝えます。深層学習では多数のパラメータに対するスカラー損失の勾配が必要なので、逆モードが適しています。誤差逆伝播はニューラルネットワークにおける逆モード自動微分の代表例です。

コード11.5　中央差分の刻み幅を比較
import numpy as np
x=1.3
for h in [1e-1,1e-3,1e-5,1e-8,1e-12]:
    g=(np.exp(x+h)-np.exp(x-h))/(2*h)
    print(h,abs(g-np.exp(x)))

刻み幅を小さくしすぎると、浮動小数点の桁落ちによって誤差が増えます。勾配チェックにはfloat64を使い、ReLUの折れ点などを避けることが有効です。

11.8 NumPyで学習の一反復を実装する

ここまでの公式を組み合わせ、隠れ層1個の回帰モデルを学習させます。次章ではこの実装を任意の層数に拡張します。今回はすべての配列をfloat64で扱います。

コード11.6　順伝播・逆伝播・更新
import numpy as np
rng=np.random.default_rng(42)
X=rng.uniform(-1,1,(128,2))
y=(X[:,0:1]**2+X[:,1:2])
W1=rng.normal(0,.5,(2,8)); b1=np.zeros(8)
W2=rng.normal(0,.5,(8,1)); b2=np.zeros(1)
params=[W1,b1,W2,b2]
def loss_and_grads():
    Z=X@W1+b1; A=np.tanh(Z)
    pred=A@W2+b2
    e=pred-y
    loss=np.mean(e**2)
    D2=2*e/len(X)
    D1=(D2@W2.T)*(1-A**2)
    return loss,[X.T@D1,D1.sum(axis=0),A.T@D2,D2.sum(axis=0)]
initial,_=loss_and_grads()
history=[initial]
for step in range(500):
    loss,grads=loss_and_grads()
    for param,grad in zip(params,grads):
        assert param.shape==grad.shape
        param-=.05*grad
    history.append(loss_and_grads()[0])
final,_=loss_and_grads()
print(initial,final)
assert final<initial

ここでは全標本を使った勾配降下法です。訓練損失の低下は最適化が進んだことを示しますが、汎化性能を保証しません。実践では検証データを別途用意します。

11.9 TensorFlowのGradientTapeと学習ループ

tf.GradientTape はコンテキスト内のTensorFlow演算を記録します。学習可能な tf.Variable は通常自動的に監視されます。定数テンソルの微分が必要なら tape.watch(x) を使います。

コード11.7　手計算と自動微分の比較
import tensorflow as tf
import numpy as np
w=tf.Variable(3.,dtype=tf.float64)
b=tf.Variable(1.,dtype=tf.float64)
with tf.GradientTape() as tape:
    z=2*w+b
    loss=.5*(z-5)**2
dw,db=tape.gradient(loss,[w,b])
np.testing.assert_allclose([dw.numpy(),db.numpy()],[4.,2.])
w.assign_sub(.1*dw); b.assign_sub(.1*db)
print(w.numpy(),b.numpy())
コード11.8　ミニバッチによるカスタム学習ループ
import tensorflow as tf
import numpy as np
tf.keras.utils.set_random_seed(42)
rng=np.random.default_rng(42)
X=rng.uniform(-1,1,(256,2)).astype('float32')
y=X[:,0:1]**2+X[:,1:2]
model=tf.keras.Sequential([tf.keras.Input(shape=(2,)),
    tf.keras.layers.Dense(16,activation='tanh'),
    tf.keras.layers.Dense(1)])
opt=tf.keras.optimizers.SGD(.05)
ds=tf.data.Dataset.from_tensor_slices((X[:200],y[:200])).shuffle(200,seed=42).batch(32)
for epoch in range(40):
    metric=tf.keras.metrics.Mean()
    for xb,yb in ds:
        with tf.GradientTape() as tape:
            pred=model(xb,training=True)
            loss=tf.reduce_mean(tf.square(pred-yb))
        grads=tape.gradient(loss,model.trainable_variables)
        assert all(g is not None for g in grads)
        opt.apply_gradients(zip(grads,model.trainable_variables))
        metric.update_state(loss,sample_weight=tf.cast(tf.shape(xb)[0],tf.float32))
    if epoch%10==0:
        val=tf.reduce_mean(tf.square(model(X[200:],training=False)-y[200:]))
        print(epoch,float(metric.result()),float(val))

training=True はDropoutやBatch Normalizationを含むモデルで特に重要です。正則化項を持つモデルでは、必要に応じて model.losses を目的関数に加えます。persistent=False（既定）のTapeは一度のgradient呼び出しで消費されます。複数回必要な場合はpersistentを検討しますが、メモリ使用量が増える点に注意します。

通常のKerasの fit() はこれらの処理を抽象化しています。実装の柔軟性が必要なときにカスタムループを使います。

11.10 勾配のデバッグと学習の注意点

勾配が得られない場合、まず計算グラフが接続されているか確認します。None は接続されていないことを示す場合があり、数値として0の勾配とは異なります。

症状確認事項
勾配がNoneTape外の演算、NumPy変換、監視対象、stop_gradient
勾配が0に近い飽和、ReLUの負領域、初期化、勾配消失
勾配が巨大・NaN・Inf学習率、入力尺度、数値安定性、勾配爆発
損失が減らないラベルと出力shape、損失設定、更新の有無、学習率
コード11.9　接続されない勾配とゼロ勾配
import tensorflow as tf
w=tf.Variable(2.)
with tf.GradientTape() as tape:
    loss=tf.stop_gradient(w)**2
assert tape.gradient(loss,w) is None
with tf.GradientTape() as tape:
    loss=w*0.
assert float(tape.gradient(loss,w))==0.

Kaggleで新しいモデルを実装するときは、小さなデータで損失を十分に下げられるか試し、勾配のノルムや有限性を確認すると、実装上の不具合を切り分けやすくなります。勾配クリッピングや初期化は第19章で詳しく扱います。

11.11 まとめと確認問題

順伝播で中間値を得て、損失から逆向きに局所微分を伝え、全パラメータの勾配を求めます。更新は勾配計算と区別し、shapeと集約方法を常に確認しましょう。

問1　逆伝播と勾配降下法の違いは？

逆伝播は勾配計算、勾配降下法はパラメータ更新。

問2　x=3のとき x²+3x の微分は？

2x+3=9。

問3　分岐した経路の勾配は？

各経路の局所微分と上流勾配の積を加算する。例：x=2では4+3=7。

問4　Aのshapeが(32,10)、Dが(32,4)ならdWは？

Aの転置とDの行列積なので(10,4)。

問5　バッチ平均の勾配を二重に平均すると？

既にバッチ平均を含む勾配をさらにBで割ると、本来の1/Bになる。

問6　ReLUの負領域での局所微分は？

0。ただし原点では数学的に微分不能。

問7　自動微分と数値微分の違いは？

自動微分は連鎖律、数値微分は関数値の差による近似。

問8　Noneの勾配と0の勾配は同じか？

異なる。Noneは計算グラフの非接続や監視対象外などを示す場合があり、0は得られた微分値。

発展演習：多層ネットワークの勾配チェック

小さなTanhネットワークについて、すべてのパラメータの解析勾配と中央差分を比較してください。最大絶対誤差を報告し、刻み幅を変えて考察しましょう。

解答・実装例
コード11.10　全パラメータの勾配チェック
import numpy as np
X=np.array([[.2,.5],[-.4,.1]])
y=np.array([[.3],[-.1]])
rng=np.random.default_rng(1)
W=rng.normal(0,.3,(2,3)); b=np.zeros(3)
V=rng.normal(0,.3,(3,1)); c=np.zeros(1)
params=[W,b,V,c]
def calc():
    A=np.tanh(X@W+b); e=A@V+c-y
    D=2*e/len(X); H=(D@V.T)*(1-A*A)
    return np.mean(e*e),[X.T@H,H.sum(0),A.T@D,D.sum(0)]
_,grads=calc()
for h in [1e-3,1e-5,1e-7]:
    errors=[]
    for p,g in zip(params,grads):
        numeric=np.zeros_like(p)
        for idx in np.ndindex(p.shape):
            orig=p[idx]
            p[idx]=orig+h; plus=calc()[0]
            p[idx]=orig-h; minus=calc()[0]
            p[idx]=orig
            numeric[idx]=(plus-minus)/(2*h)
        if h==1e-5:
            np.testing.assert_allclose(numeric,g,atol=1e-8)
        errors.append(np.max(abs(numeric-g)))
    print(h,max(errors))
