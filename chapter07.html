7.1 人工ニューロンとは

第6章の線形回帰では特徴量の加重和から数値を予測し、ロジスティック回帰ではその値を確率に変換しました。人工ニューロン（artificial neuron）は、この「集約して変換する」という計算を一つの部品として抽象化したものです。生物の神経細胞に着想を得ていますが、実際の脳の精密な再現ではありません。

入力を $x_1,\ldots,x_d$、重みを $w_1,\ldots,w_d$、バイアスを $b$ とすると、まず加重和（前活性化値）$z$ を計算し、活性化関数 $g$ を適用します。

$$z=\sum_{j=1}^d w_jx_j+b=w^\top x+b,\qquad a=g(z)$$

重みは入力の影響の向きと大きさを調整します。バイアスは入力がすべて0でも出力を調整できる項です。活性化関数は出力の性質を決めます。例えば $x=(2,3),w=(0.5,-1),b=1$ なら $z=1-3+1=-1$ となります。

コード7.1　加重和を計算する
import numpy as np
x = np.array([2., 3.])
w = np.array([0.5, -1.])
b = 1.
z = x @ w + b
print(z)  # -1.0
print(max(0., z))  # ReLU: 0.0

7.2 単純パーセプトロンと閾値

単純パーセプトロンは加重和をステップ関数に通し、0または1を出力する二値分類器です。本章では境界上の値を1と定義します（文献によっては符号関数や厳密な不等号を用います）。

$$g(z)=\begin{cases}1&z\geq0\\0&z<0\end{cases}$$

閾値 $\theta$ を用いた $w^\top x\geq\theta$ という表現は、$b=-\theta$ と置けば同じです。重みが非ゼロなら、バイアスを変えると判定境界が平行移動します。ステップ関数はほとんど至るところで微分が0で、境界では微分できません。そのため通常の誤差逆伝播法でそのまま学習するには適していません。

コード7.2　バッチ単位のパーセプトロン
import numpy as np
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
def perceptron(X, w, b):
    return (X @ np.asarray(w) + b >= 0).astype(int)
print(perceptron(X, [1, 1], -1.5))  # [0 0 0 1]
# X: (4, 2), w: (2,), output: (4,)

7.3 論理ゲートを実装する

論理ゲートは二値入力から二値出力を計算します。ANDは両方が1、ORは少なくとも一方が1、NANDはANDの否定です。重みとバイアスを適切に選べば、同じ計算構造でそれぞれを表現できます。

x₁x₂ANDORNANDXOR

010111
100111
111100
ゲート重みバイアス陽性条件
AND(1, 1)−1.5x₁+x₂ ≥ 1.5
OR(1, 1)−0.5x₁+x₂ ≥ 0.5
NAND(−1, −1)1.5x₁+x₂ ≤ 1.5
NOT(−1)0.5x ≤ 0.5

for name, w, b in [('AND',[1,1],-1.5),
                   ('OR',[1,1],-0.5),
                   ('NAND',[-1,-1],1.5)]:
    print(name, perceptron(X,w,b))
print('NOT', perceptron(np.array([[0],[1]]),[-1],0.5))

7.4 決定境界と線形分離可能性

二次元入力で重みが非ゼロの場合、$w_1x_1+w_2x_2+b=0$ が決定境界となる直線です。$w$ は直線に垂直なベクトルで、加重和が正の側と境界上をクラス1とします。重みがすべて0なら出力は定数であり、通常の決定境界は存在しません。$w_2\ne0$ の場合、直線は $x_2=-\frac{w_1}{w_2}x_1-\frac{b}{w_2}$ と書けます。$w_2=0,w_1\ne0$ なら垂直線です。高次元では超平面となります。

両クラスを一つの超平面で厳密に分離できる性質を線形分離可能性と呼びます。AND・OR・NANDはいずれも線形分離可能です。

7.5 パーセプトロンの学習則

これまでは手作業で重みを設定しました。学習では教師ラベル $y\in\{0,1\}$ と予測 $\hat y$ の差を使って、誤分類した標本に対して重みを修正します。学習率 $\eta>0$ として、

$$w\leftarrow w+\eta(y-\hat y)x,\qquad b\leftarrow b+\eta(y-\hat y)$$

正例を0と誤判定すると加重和を増やし、負例を1と誤判定すると減らします。正しく分類できた場合は更新しません。例えば $w=(0,0),b=0,x=(0,1),y=0,\eta=1$ なら予測は1で、更新後は $w=(0,-1),b=-1$ です。

有限の訓練集合が厳密に線形分離可能なら、一定の正の学習率で全標本を繰り返し提示する古典的な学習則は有限回の誤りで収束します（パーセプトロン収束定理）。ただし最大マージンや確率校正、未知データでの性能を保証するものではありません。分離不能な場合は終了条件が必要です。

コード7.4　NumPyで学習則を実装する
import numpy as np
X = np.array([[0,0],[0,1],[1,0],[1,1]])
def train_perceptron(X, y, eta=1., max_epochs=20):
    w = np.zeros(X.shape[1]); b = 0.
    history = []
    for epoch in range(max_epochs):
        mistakes = 0
        for xi, yi in zip(X, y):
            pred = int(xi @ w + b >= 0)
            error = yi - pred
            w += eta * error * xi
            b += eta * error
            mistakes += int(error != 0)
        history.append(mistakes)
        if mistakes == 0:
            break
    return w, b, history
w, b, history = train_perceptron(X, np.array([0,0,0,1]))
print(w, b, history)
print((X @ w + b >= 0).astype(int))

コード7.4の実行結果は重み (2, 1)、バイアス −3、誤分類数 [2, 3, 3, 2, 1, 0] です。グラフの誤分類数は各標本を提示した瞬間の誤りを数えたものです。エポック終了時の固定モデルの誤分類数とは異なります。標本順序を変えると履歴や最終パラメータも変わり得ます。

7.6 XOR問題：単層の限界

XOR（排他的論理和）は二つの入力が異なるときだけ1となります。正例は $(0,1),(1,0)$、負例は $(0,0),(1,1)$ です。一つの直線でこれらを分離することはできません。

不等式による証明

単純パーセプトロンでXORを表現できると仮定すると、次の条件をすべて満たす必要があります。

$$\begin{aligned}b<0 &\quad (0,0)\\w_1+b\ge0 &\quad (1,0)\\w_2+b\ge0 &\quad (0,1)\\w_1+w_2+b<0 &\quad (1,1)\end{aligned}$$

中央の二式を加えると $w_1+w_2+2b\ge0$ です。したがって $w_1+w_2+b\ge-b>0$ となり、最後の条件と矛盾します。学習率や反復回数を変更しても、この表現能力の限界は解消できません。

先にコード7.4を実行してください。

コード7.5　分離不能なXORを学習してみる
y_xor = np.array([0,1,1,0])
w, b, history = train_perceptron(X, y_xor)
print(history)
print((X @ w + b >= 0).astype(int))
assert not np.array_equal((X @ w + b >= 0), y_xor)

7.7 複数のニューロンでXORを表現する

単独のニューロンでは不可能でも、複数のニューロンを組み合わせれば可能です。XORは OR と NAND の出力を AND に入力することで実現できます。

$$h_1=g(x_1+x_2-0.5),\quad h_2=g(-x_1-x_2+1.5)$$ $$\hat y=g(h_1+h_2-1.5)$$

最初の層で入力を別の特徴表現へ変換し、次の層で分類しています。この例では中間表現 $(h_1,h_2)$ において正例が $(1,1)$ に集まり、線形分離が可能になります。

入力ORNANDAND（出力）
0,0010
0,1111
1,0111
1,1100
コード7.6　行列積による二層ネットワーク
import numpy as np
X = np.array([[0,0],[0,1],[1,0],[1,1]])
W1 = np.array([[1,-1],[1,-1]])
b1 = np.array([-0.5,1.5])
H = (X @ W1 + b1 >= 0).astype(int)
W2 = np.ones((2,1)); b2 = -1.5
Y = (H @ W2 + b2 >= 0).astype(int)
print(H)
print(Y.ravel())  # [0 1 1 0]
assert np.array_equal(Y.ravel(), [0,1,1,0])

入力の形状（shape）は $(4,2)$、第1層の重みは $(2,2)$、中間表現は $(4,2)$、出力は $(4,1)$ です。重み4個とバイアス2個、次の層の重み2個とバイアス1個、合計9個のパラメータがあります。ここでは重みを設計しましたが、第8章以降ではデータから学習する方法へ進みます。

なお、活性化関数を挟まずアフィン変換だけを重ねると、$(XW_1+b_1)W_2+b_2=X(W_1W_2)+(b_1W_2+b_2)$ となり、単一のアフィン変換と同じです。非線形性が多層化の鍵です。

7.8 TensorFlowによる実装と学習への橋渡し

TensorFlowのテンソル演算でも同じ論理ゲートを再現できます。閾値判定は学習後の分類や手作業の論理回路には使えますが、勾配による学習では微分可能なシグモイドや、0以外で微分可能なReLUなどを使います。

コード7.7　TensorFlowで固定重みのXORを再現する
import tensorflow as tf
X = tf.constant([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
W1 = tf.constant([[1.,-1.],[1.,-1.]])
b1 = tf.constant([-0.5,1.5])
H = tf.cast(tf.matmul(X,W1) + b1 >= 0, tf.float32)
Y = tf.cast(tf.matmul(H,tf.ones((2,1))) - 1.5 >= 0, tf.int32)
print(tf.reshape(Y,[-1]).numpy())  # [0 1 1 0]

次の例は学習可能なモデルです。隠れ層にはtanh、出力層にはシグモイドを含めずロジットを出力し、二値交差エントロピーに直接渡します。損失内部ではロジットから安定に交差エントロピーを計算し、予測時はシグモイドによりクラス1の推定確率へ変換します。これは第5章の数値安定性の考え方に沿っています。

コード7.8　KerasでXORを学習する（発展）
import numpy as np
import tensorflow as tf
tf.keras.utils.set_random_seed(42)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=np.float32)
y = np.array([[0],[1],[1],[0]], dtype=np.float32)
model = tf.keras.Sequential([
    tf.keras.Input(shape=(2,)),
    tf.keras.layers.Dense(8, activation='tanh'),
    tf.keras.layers.Dense(1)
])
model.compile(optimizer=tf.keras.optimizers.Adam(0.03),
              loss=tf.keras.losses.BinaryCrossentropy(from_logits=True))
hist = model.fit(X, y, epochs=300, batch_size=4, verbose=0)
p = tf.sigmoid(model(X, training=False)).numpy()
print(p.ravel())
print((p >= 0.5).astype(int).ravel())
print(hist.history['loss'][-1])

この実験は4点すべてを学習に用いる表現能力の確認であり、汎化性能の評価ではありません。初期値や最適化の条件によって学習が成功しない可能性もあります。その場合は損失曲線を確認し、初期値や学習率を変えて比較しましょう。

7.9 まとめと確認問題

人工ニューロンは加重和と活性化関数からなります。単純パーセプトロンの決定境界は超平面であり、線形分離不能なXORを表現できません。非線形な中間表現を作る多層構造によって、その限界を越えられます。

問1　重みとバイアスの役割は？

重みは入力ごとの影響を調整し、バイアスは加重和を平行移動する。

問2　x=(2,1), w=(−1,3), b=−1 の出力は？

z=−2+3−1=0。本章のステップ関数では1。

問3　ORの重みが(1,1)ならバイアスの範囲は？

入力 (0,0) では b<0、入力 (0,1), (1,0) では 1+b≥0 が必要です。(1,1) の条件 2+b≥0 は後者から従うため、−1≤b<0 です。

問4　w=(2,−1), b=3 の決定境界は？

x₂=2x₁+3。クラス1は x₂≤2x₁+3 の側。

問5　正例を0と誤分類した場合の更新は？

wにηxを、bにηを加える。

問6　XORが学習できない理由は？

元の二次元特徴量では単一のアフィン決定境界で分離できないため。反復不足とは異なる。非線形特徴量の追加や多層化で表現できる。

問7　活性化関数なしに層を重ねると？

アフィン変換の合成もアフィン変換なので単層で表現できる範囲を超えない。途中に狭い層がある場合はランクが制限され、表現できる範囲がさらに狭くなることもある。

問8　ステップ関数が通常の勾配学習に不向きな理由は？

境界以外では微分が0、境界では微分不能で有用な勾配を得にくい。

発展演習：特徴量を追加してXORを解く

入力に積 $x_1x_2$ を加えた3次元特徴量を作り、単純パーセプトロンでXORを表現してください。さらに学習則で重みを求め、全4点を正しく分類できるか確認しましょう。

解答例

重みを (1,1,−2)、バイアスを −0.5 とすれば、入力順 (0,0), (0,1), (1,0), (1,1) に対する加重和は −0.5, 0.5, 0.5, −0.5 となり、XORを表現できます。元の入力空間では非線形ですが、変換後の特徴空間では線形分離可能です。コード7.9の実行結果は重み (1,1,−3)、バイアス −1、誤分類数 [3,3,4,3,1,2,1,0] で、全4点を正しく分類します。

先にコード7.4を実行してください。

コード7.9　特徴量変換とパーセプトロン学習
X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0,1,1,0])
Z = np.column_stack([X, X[:,0]*X[:,1]])
print((Z @ np.array([1,1,-2]) - 0.5 >= 0).astype(int))
w,b,h = train_perceptron(Z,y,max_epochs=100)
print(w,b,h)
assert np.array_equal((Z @ w + b >= 0).astype(int), y)
