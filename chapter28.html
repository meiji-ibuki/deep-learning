28.1 表現学習とAutoencoderの発想

第24〜27章では、画像や系列から有用な特徴を抽出するネットワークを学んだ。表現学習（representation learning）とは、手作業で特徴量を定義する代わりに、データから情報を表すベクトルを学習する考え方である。Autoencoder（自己符号化器、AE）は入力を復元する課題を通じて表現を学ぶ。入力そのものが教師信号になるため、外部のクラスラベルを必要としない。

Encoderは入力を潜在表現へ写像し、Decoderは潜在表現を入力空間へ戻す。入力をそのままコピーできるだけでは有益な特徴を得たとはいえない。ボトルネック、ノイズ、疎性などの制約によって、復元に必要な規則性を抽出させることが設計の中心である。

28.2 ネットワーク構造と再構成損失

入力幅をD、潜在次元をKとする。バッチサイズBの入力Xは(B,D)、潜在表現Zは(B,K)、復元値は(B,D)となる。KがDより小さい場合をundercomplete AEという。逆にKが大きい場合でも、制約によって有用な表現を学べることがある。

$$z=f_\theta(x),\qquad \hat x=g_\phi(z)$$ $$J(\theta,\phi)=\frac1{ND}\sum_{i=1}^N\|x_i-\hat x_i\|_2^2$$

連続値にはMSEやMAE、0〜1の画素にはSigmoid出力とBCEも選択肢となる。ただしBCEはベルヌーイ型の負の対数尤度に対応し、画素のデータ生成仮定によって適切さが異なる。標準化した連続値には通常、恒等出力を用いる。

層shapeパラメータ数（Dense）
入力(B, 64)0
Encoder(B, 16)1040
潜在(B, 2)34
Decoder(B, 16)48
復元(B, 64)1088

合計2210個のパラメータを学習する。潜在次元を小さくするほど表現の制約は強くなる傾向があるが、復元性能と下流タスクの性能は必ずしも一致しない。

コード28.1　Kerasで基本的なAutoencoderを構築
import tensorflow as tf
from tensorflow import keras
from keras import layers

encoder = keras.Sequential([
    keras.Input((64,)), layers.Dense(16, activation="relu"),
    layers.Dense(2)], name="encoder")
decoder = keras.Sequential([
    keras.Input((2,)), layers.Dense(16, activation="relu"),
    layers.Dense(64)], name="decoder")
x = keras.Input((64,))
ae = keras.Model(x, decoder(encoder(x)))
ae.compile(optimizer="adam", loss="mse")
print(ae.count_params())  # 2210
# ae.fit(X_train, X_train, validation_data=(X_val, X_val))

28.3 PCAと線形Autoencoder

主成分分析（PCA）は中心化したデータの分散が大きい方向を探す。共分散行列の固有値の降順に並べた正規直交固有ベクトルを列にもつ行列Uのうち上位K列を用いると、射影と復元は次の式になる。

$$Z=(X-\mu)U_K,\quad \hat X=ZU_K^\top+\mu$$

線形AEで中心化済みの入力、線形Encoder・Decoder、二乗再構成損失、追加の制約や正則化のないK次元のボトルネック（1≤K≤D）を仮定し、大域最適解に到達すれば、PCAと同じ最小再構成誤差を達成できる。ただしAEの潜在座標がPCAの直交した主成分そのものになるとは限らない。可逆なK次元変換をEncoderに、逆変換をDecoderに挿入しても復元は同じである。非線形AEは曲がった低次元構造を表せる可能性があるが、常にPCAを上回る保証はない。

コード28.2　SVDによるPCAと線形AEの復元の一致
import numpy as np
rng = np.random.default_rng(28)
z = rng.normal(size=(400, 2))
X = z @ rng.normal(size=(2, 6)) + 0.1*rng.normal(size=(400, 6))
mu = X.mean(axis=0)
Xc = X - mu
_, s, Vt = np.linalg.svd(Xc, full_matrices=False)
U = Vt[:2].T
pca = Xc @ U @ U.T + mu
R = np.array([[2., 1.], [0., 1.]])
Wenc = U @ R
Wdec = np.linalg.solve(R, U.T)
linear_ae = Xc @ Wenc @ Wdec + mu
np.testing.assert_allclose(pca, linear_ae, atol=1e-12)
print(np.mean((X-pca)**2))

コード28.2の実行結果：再構成MSEは0.006505。PCAと線形AEの復元値が一致することを確認した。ここでは学習による最適化ではなく、等価な重みをSVDから直接構成している。

28.4 非線形Autoencoderと潜在空間の可視化

非線形活性化を使うと、直線や平面では表せない構造を潜在表現として学べる可能性がある。例えば円弧上の点は角度という一つの変数で表せるが、直線への射影は曲率を失う。完全な円周は連続な1次元実数座標で切れ目なく一対一に表現できないため、潜在次元の選択には位相的な制約もある。

潜在空間を2次元にして散布図を描くと、似た入力が近くに位置するか観察できる。ただし距離やクラスタの意味は損失と学習条件に依存する。分類ラベルを使わずにAEを学習した後、ラベルで色分けするのは事後分析であり、テストラベルをモデル選択に使ってはいけない。

28.5 Denoising Autoencoder：ノイズ除去

Denoising AEは破損した入力$\tilde x$から元のクリーンな$x$を復元する。通常のAEと異なり、入力と教師信号は同じではない。

$$\tilde x=x+\varepsilon,\quad J=\mathbb E_{x,\varepsilon}\|x-g_\phi(f_\theta(\tilde x))\|^2$$

ノイズにはガウスノイズ、画素のマスクなどを用いる。訓練時に想定したノイズと実際のノイズが異なる場合には性能が低下する可能性がある。検証データのノイズは固定すると実験を比較しやすい。

コード28.3　Fashion-MNISTのノイズ除去と畳み込みAE
import numpy as np
import tensorflow as tf
from tensorflow import keras
from keras import layers
keras.utils.set_random_seed(28)
(x, _), (xt, _) = keras.datasets.fashion_mnist.load_data()
x = x.astype("float32")[..., None] / 255
xt = xt.astype("float32")[..., None] / 255
train, val = x[:-10000], x[-10000:]
rng = np.random.default_rng(28)
def noisy(a):
    return np.clip(a + rng.normal(0, .25, a.shape), 0, 1).astype("float32")
val_noise, test_noise = noisy(val), noisy(xt)
model = keras.Sequential([
    keras.Input((28,28,1)),
    layers.Conv2D(16,3,strides=2,padding="same",activation="relu"),
    layers.Conv2D(8,3,strides=2,padding="same",activation="relu"),
    layers.Conv2DTranspose(16,3,strides=2,padding="same",activation="relu"),
    layers.Conv2DTranspose(1,3,strides=2,padding="same",activation="sigmoid")])
model.compile(optimizer="adam",loss="mse")
ds = tf.data.Dataset.from_tensor_slices(train).shuffle(10000,seed=28).batch(128)
ds = ds.map(lambda a: (tf.clip_by_value(a+tf.random.normal(tf.shape(a),stddev=.25),0.,1.),a)).prefetch(tf.data.AUTOTUNE)
model.fit(ds,validation_data=(val_noise,val),epochs=15)
print("noisy MSE",np.mean((test_noise-xt)**2))
print("restored MSE",model.evaluate(test_noise,xt,verbose=0))
import matplotlib.pyplot as plt
pred = model.predict(test_noise[:8],verbose=0)
fig, axes = plt.subplots(3,8,figsize=(12,5))
for row, images in enumerate([test_noise, pred, xt]):
    for i in range(8):
        axes[row,i].imshow(images[i,:,:,0],cmap="gray",vmin=0,vmax=1)
        axes[row,i].axis("off")
plt.show()

28.6 Sparse Autoencoderと表現への制約

Sparse AEでは潜在ユニットの活性化を疎にする。例えば非負の係数λを用いたL1ペナルティを再構成損失へ追加する。

$$J=J_{rec}+\lambda\frac1{BK}\sum_{i,j}|z_{ij}|$$

重みのL1正則化とは異なり、ここで制約する対象は活性化値である。潜在次元が入力より大きくても、各標本が少数のユニットを使うよう誘導できる。λが大きすぎると潜在表現がほぼゼロとなり、復元性能が悪化する。Decoderの重みが大きくなることで活性化ペナルティを回避する場合もあるため、重み正則化等との併用を検討する。

コード28.4　活性化のL1ペナルティを加える
import tensorflow as tf
from tensorflow import keras
@keras.utils.register_keras_serializable(package="textbook")
class SparsePenalty(keras.layers.Layer):
    def __init__(self, strength=1e-3, **kwargs):
        super().__init__(**kwargs)
        self.strength = strength
    def call(self, z):
        self.add_loss(self.strength * tf.reduce_mean(tf.abs(z)))
        return z
    def get_config(self):
        return {**super().get_config(), "strength": self.strength}

inputs = keras.Input((64,))
z = keras.layers.Dense(128, activation="relu")(inputs)
z = SparsePenalty()(z)
outputs = keras.layers.Dense(64)(z)
model = keras.Model(inputs, outputs)
model.compile(optimizer="adam", loss="mse")

28.7 再構成誤差による異常検知

正常データでAEを訓練し、未知データの再構成誤差を異常スコアにする方法がある。正常パターンを復元しやすく、異常パターンを復元しにくいという仮定に基づく。

$$s(x)=\frac1D\sum_j(x_j-\hat x_j)^2,\qquad \hat y=\mathbf1[s(x)>\tau]$$

閾値τは独立した正常検証データの分位点などで決める。99パーセンタイルを使っても、将来の誤検知率が必ず1%になるわけではない。分布変化や検証標本数の影響を受ける。高容量のAEが異常まで復元すること、正常な希少パターンが誤検知されることにも注意する。

コード28.5　線形AEによる異常検知の数値実験
import numpy as np
from sklearn.metrics import roc_auc_score
rng = np.random.default_rng(28)
def normal(n):
    return rng.normal(size=(n,1)) @ np.array([[1.,2.,-1.]]) + rng.normal(0,.1,(n,3))
train, val, test = normal(1000), normal(500), normal(500)
anomaly = normal(500) + rng.choice([-1.,1.],size=(500,1))*np.array([[1.,0.,1.]])
mu = train.mean(0)
_,_,vt = np.linalg.svd(train-mu,full_matrices=False)
u = vt[:1].T
def score(x):
    recon = (x-mu) @ u @ u.T + mu
    return np.mean((x-recon)**2,axis=1)
sv, sn, sa = score(val), score(test), score(anomaly)
threshold = np.quantile(sv,.99)
auc = roc_auc_score(np.r_[np.zeros(len(sn)),np.ones(len(sa))],np.r_[sn,sa])
print(threshold, (sn>threshold).mean(), (sa>threshold).mean(), auc)

実測結果：閾値 0.02875、正常テストの誤検知率 0.4%、異常検出率 100.0%、ROC-AUC 1.0000。人工的に真の正常信号方向 [1,2,-1] と直交する変化（推定した主成分とは厳密には直交しない）を追加した容易な課題であり、実データへの一般化を保証しない。

28.8 Variational Autoencoder（VAE）の基本原理

通常のAEが入力を一つの潜在ベクトルへ変換するのに対し、VAEは入力ごとに潜在変数の確率分布を推定する。標準的な例では対角ガウス分布$q_\phi(z|x)=\mathcal N(\mu(x),\operatorname{diag}(\sigma^2(x)))$を近似事後分布とし、事前分布を$p(z)=\mathcal N(0,I)$とする。

$$z=\mu+\exp(\tfrac12\log\sigma^2)\odot\epsilon,\quad \epsilon\sim\mathcal N(0,I)$$

この再パラメータ化により、乱数と学習パラメータを分離して勾配を伝えられる。標本xごとに最小化する負のELBOは次式である。これは負の対数周辺尤度の上界であり、差は近似事後分布と真の事後分布のKLダイバージェンスである。

$$J=\mathbb E_{q_\phi}[-\log p_\theta(x|z)]+D_{KL}(q_\phi(z|x)\|p(z))$$ $$D_{KL}=\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2)$$

第5章のKLダイバージェンスがここで再登場する。第1項は復元、第2項は潜在分布を事前分布に近づける役割を持つ。復元項は観測モデルによって定まり、任意のMSEとKLを尺度を考えず足すと意味が変わる。β-VAEはKL項の係数を調整する変種である。KLがほぼゼロとなり潜在変数が使われなくなるposterior collapseにも注意する。本書では生成モデル固有の応用には深入りしない。

コード28.6　VAEのKL項と再パラメータ化の数値計算
import numpy as np
mu = np.array([[0., 0.], [1., -1.]])
logvar = np.zeros_like(mu)
kl = .5*np.sum(mu**2 + np.exp(logvar)-1-logvar,axis=-1)
np.testing.assert_allclose(kl,[0.,1.])
rng = np.random.default_rng(28)
z = mu + np.exp(.5*logvar)*rng.normal(size=mu.shape)
print(kl,z)

28.9 実践：手書き数字の非線形次元削減

scikit-learnの8×8手書き数字データを使い、PCAと非線形AEの2次元表現を比較する。画素を16で割る固定変換は訓練データ以外にも適用できる。PCAのfitとAEの学習は訓練集合のみを使用し、検証損失でEarly Stoppingを行う。テスト集合で再構成MSEを比較し、潜在座標を色分けする。ラベルは分割と可視化のみに使う。

コード28.7　PCAと非線形AEの比較実験（独立して実行可能）
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.decomposition import PCA
from tensorflow import keras
from keras import layers
keras.utils.set_random_seed(28)
X,y=load_digits(return_X_y=True)
X=(X/16).astype("float32")
Xtr,Xte,ytr,yte=train_test_split(X,y,test_size=.2,stratify=y,random_state=28)
Xtr,Xva,ytr,yva=train_test_split(Xtr,ytr,test_size=.25,stratify=ytr,random_state=28)
pca=PCA(n_components=2).fit(Xtr)
zp=pca.transform(Xte)
encoder=keras.Sequential([keras.Input((64,)),layers.Dense(32,activation="relu"),layers.Dense(2)])
decoder=keras.Sequential([keras.Input((2,)),layers.Dense(32,activation="relu"),layers.Dense(64,activation="sigmoid")])
inputs=keras.Input((64,))
ae=keras.Model(inputs,decoder(encoder(inputs)))
ae.compile(optimizer="adam",loss="mse")
ae.fit(Xtr,Xtr,validation_data=(Xva,Xva),epochs=150,batch_size=32,verbose=0,
       callbacks=[keras.callbacks.EarlyStopping(patience=15,restore_best_weights=True)])
za=encoder.predict(Xte,verbose=0)
print("PCA MSE",np.mean((Xte-pca.inverse_transform(zp))**2))
print("AE MSE",ae.evaluate(Xte,Xte,verbose=0))
fig,axes=plt.subplots(1,2,figsize=(10,4))
for ax,z,name in zip(axes,[zp,za],["PCA","Autoencoder"]):
    sc=ax.scatter(z[:,0],z[:,1],c=yte,cmap="tab10",vmin=-.5,vmax=9.5,s=12)
    ax.set_title(name)
fig.colorbar(sc,ax=axes,ticks=range(10)); plt.show()
fig,axes=plt.subplots(3,8,figsize=(12,5))
for row,images in enumerate([Xte,pca.inverse_transform(zp),ae.predict(Xte,verbose=0)]):
    for i in range(8):
        axes[row,i].imshow(images[i].reshape(8,8),cmap="gray",vmin=0,vmax=1)
        axes[row,i].axis("off")
plt.show()

比較結果は実行環境で確認すること。PCAとAEは学習パラメータ数や最適化方法が異なるため、非線形性だけを分離した比較ではない。潜在次元を2、4、8と変え、検証誤差で選択する発展実験も可能である。テスト結果で選び直さない。

28.10 表現学習の活用と限界

潜在表現を別のモデルの入力とする場合、Encoderを固定して分類器を学習する方法と、下流タスクでEncoderも微調整する方法がある。再構成が重視する情報と予測対象に必要な情報は一致しないことがある。例えば画像の背景は復元に重要でも、分類には不要な場合がある。ラベルが少ない状況では自己教師あり事前学習が有用なこともあるが、下流タスクで検証する必要がある。

手法学習目標主な用途・注意点
PCA線形射影の再構成誤差高速な基準モデル、線形構造
通常のAE入力の再構成非線形次元削減、恒等写像に注意
Denoising AE破損入力から元データを復元ノイズ耐性、ノイズ分布に依存
Sparse AE再構成と活性化の疎性特徴抽出、係数の調整が必要
VAE負のELBO確率的潜在表現、事前分布の制約
対照学習正例の表現を近づける等再構成を必要としない表現学習

Kaggleでは、まず単純な特徴量やPCAを基準とし、AEの潜在表現を追加した場合のOOF性能を比較する。各FoldのEncoderはそのFoldの訓練データだけで学習する。異常検知では再構成誤差だけでなく、Isolation Forestや距離ベースの基準モデルも比較候補となる。

28.11 まとめと確認問題

Autoencoderは復元課題を通じて潜在表現を学ぶ。制約の種類によって学習する情報が変わり、復元性能と下流タスクの性能は区別して評価する。線形AEとPCAの関係、再構成誤差による異常検知、VAEの確率的な潜在表現を理解しておこう。

問1　AEの教師信号は何か？

通常は入力そのもの。Denoising AEでは破損前の入力。

問2　入力幅64、潜在幅2、バッチ32の潜在shapeは？

(32,2)。

問3　線形AEがPCAと同じ誤差を達成する条件は？

線形変換、中心化、二乗損失、同じ潜在次元、大域最適解など。

問4　潜在座標はPCAと必ず一致するか？

一致しない。可逆変換の自由度がある。

問5　Sparse AEのL1は何に適用するか？

潜在活性化値。

問6　異常検知の閾値はどのデータで設定するか？

独立した検証データ。テストデータで調整しない。

問7　VAEの再パラメータ化の目的は？

乱数を分離して学習パラメータへ勾配を伝える。

問8　再構成誤差が小さいほど分類性能も良いか？

保証されない。下流タスクで検証する。

問9　発展：コード28.5の異常方向を正常部分空間に平行な方向へ変更せよ。

[1,2,-1]方向の変化を加えると射影で復元できるため、異常スコアが増えにくい。ROC-AUCを再計算し、仮定の限界を確認する。 コード28.5の異常方向だけを置換した再実行ではROC-AUC=0.519184、異常検出率=1.000%。推定主成分には標本誤差があるため、完全に変化が消えるとは限らない。
