H.2　強化学習：MDPと価値関数

マルコフ決定過程（MDP）は状態 $s$、行動 $a$、遷移確率 $P(s'|s,a)$、報酬 $r$、割引率 $\gamma$ で定義される。マルコフ性とは次状態と報酬の条件付き分布が、過去の履歴ではなく現在の状態・行動で決まる性質である。部分観測の場合は履歴や信念状態が必要になる。

$$G_t=\sum_{k=0}^{\infty}\gamma^k R_{t+k+1},\quad V^\pi(s)=E_\pi[G_t|S_t=s]$$

無限期間では通常、報酬が有界かつ $0\le\gamma<1$ と仮定する。有限エピソードでは終端後の報酬を0として $\gamma=1$ も扱える。方策 $\pi(a|s)$ は行動分布、$Q^\pi(s,a)$ は行動価値である。Bellman最適方程式：

$$Q^*(s,a)=E[r+\gamma\max_{a'} Q^*(s',a')|s,a]$$

終端では将来価値をゼロとする。教師あり学習と異なり、探索によって訓練データ自体が変わる。報酬設計と実際の目的のずれにも注意する。

H.3　Q-learningと深層強化学習

TD誤差 $\delta=r+\gamma(1-d)\max_{a'}Q(s',a')-Q(s,a)$ を使い、$Q(s,a)\leftarrow Q(s,a)+\alpha\delta$ と更新する。$d$ は真の終端フラグであり、単なる時間制限と区別する。DQNではQ表をニューラルネットに置換し、経験再生とターゲットネットワークで学習を安定化する。初期状態分布がパラメータに依存しないエピソード型問題で $J(\theta)=E[G_0]$ とすると、方策勾配の一形式は $\nabla_\theta J=E[\sum_t\gamma^t\nabla_\theta\log\pi_\theta(A_t|S_t)G_t]$ である。微分と期待値の交換が可能であることを仮定する。Actor-Criticでは価値推定で分散を抑える。PPOは方策比のクリップを用いる代表例である。

コードH.1　一次元環境のQ-learning（表形式）
import numpy as np
rng = np.random.default_rng(42)
Q = np.zeros((6,2))
returns = []
for ep in range(500):
    state, total = 0, 0.
    for step in range(40):
        a = rng.integers(2) if rng.random() < .2 else np.argmax(Q[state])
        nxt = int(np.clip(state + (1 if a else -1),0,5))
        done = nxt == 5
        r = 1. if done else -.05
        target = r + (0 if done else .95*Q[nxt].max())
        Q[state,a] += .15*(target-Q[state,a])
        total += r
        state = nxt
        if done: break
    returns.append(total)
print('greedy actions:',Q[:5].argmax(axis=1))
assert np.all(Q[:5].argmax(axis=1)==1)

実行結果

greedy actions: [1 1 1 1 1]

H.4　自己教師あり学習と対照学習

ラベルなしデータから代理課題を作る。画像の異なる拡張を同一対象とする対照学習、マスクされた入力の復元、時系列の未来表現予測などがある。学習したEncoderを下流タスクへ転移する（第35章）。SimCLRでは正例ペア $(i,j)$ に対し、正規化した表現の内積を用いる。

$$\ell_{i,j}=-\log\frac{\exp(\operatorname{sim}(z_i,z_j)/\tau)}{\sum_{k\ne i}\exp(\operatorname{sim}(z_i,z_k)/\tau)}$$

温度 $\tau>0$ は分布の鋭さを制御する。正例を壊す拡張、意味的に同じ対象を負例にする偽負例に注意。BYOLなど負例を明示的に使わない方法もある。表現の評価には固定Encoderの線形評価と全層微調整を区別する。

コードH.2　対照損失の計算（4表現・対称平均）
import numpy as np
z = np.array([[1.,0.],[.9,.1],[0.,1.],[.1,.9]])
z /= np.linalg.norm(z,axis=1,keepdims=True)
s = z@z.T/.2
np.fill_diagonal(s,-np.inf)
p = np.exp(s-s.max(axis=1,keepdims=True))
p /= p.sum(axis=1,keepdims=True)
positive = [1,0,3,2]
print(-np.log(p[np.arange(4),positive]).mean())

実行結果

0.0255968011296918

H.5　メタ学習とFew-shot学習

タスクごとにsupport集合で適応し、query集合で評価する。N-way K-shotはNクラス各K例のsupportを指す。学習時と評価時のタスクを分離する。未知クラスへの適応を評価する設定ではクラスも分離する。Prototypical Networksではクラス中心 $c_k=|S_k|^{-1}\sum_{x\in S_k}f_\theta(x)$ を作り、距離の負値をlogitとして分類する。MAMLは初期値を学習し、内側更新 $\theta'_i=\theta-\alpha\nabla L_{S_i}(\theta)$ の後の外側目的 $\sum_i L_{Q_i}(\theta'_i)$ を最小化する。厳密なMAMLは勾配による内側更新を通じて微分するため、一般に二階微分を含む。

コードH.3　プロトタイプ分類（固定特徴の例）
import numpy as np
support = np.array([[[0.,0.],[0.,1.]],[[4.,4.],[4.,5.]]])
query = np.array([[.2,.4],[3.9,4.8]])
centers = support.mean(axis=1)
d = ((query[:,None,:]-centers[None,:,:])**2).sum(axis=-1)
print(d.argmin(axis=1))

実行結果

[0 1]

H.6　継続学習と破滅的忘却

タスクAの学習後、Bだけで更新するとAの性能が落ちることがある。Replayは過去例を混ぜ、EWCは重要な重みの変化を抑制する。

$$L=L_B+\frac\lambda2\sum_j F_j(\theta_j-\theta^*_{A,j})^2$$

$\lambda\ge 0$ とし、$F_j$ はFisher情報行列の対角成分の推定値などから求める。タスク識別子が既知か未知かで難度が異なる。各時点の全既習タスクの性能行列 $R_{t,i}$ を記録し、大きいほど良い評価指標について、最終平均性能と忘却 $\max_{t=i,...,T}R_{t,i}-R_{T,i}$ を評価する。Replayの保管制約、個人情報、分布変化を考慮する。

コードH.4　逐次学習の性能行列から忘却を算出
import numpy as np
R = np.array([[.9,np.nan,np.nan],[.7,.85,np.nan],[.6,.8,.88]])
print('final average:',R[-1].mean())
print('forgetting:',np.nanmax(R,axis=0)-R[-1])

実行結果

final average: 0.7599999999999999
forgetting: [0.3  0.05 0.  ]

H.7　連合学習とプライバシー

FedAvgではサーバーがモデルを配布し、各クライアントがローカル学習を行い、サンプル数で重み付けして集約する。

$$\theta^{t+1}=\sum_{k\in C_t}\frac{n_k}{\sum_{j\in C_t}n_j}\theta_k^{t+1}$$

参加クライアントのサンプル数の総和が正で、同じ形状・対応関係のパラメータを集約することを仮定する。非IIDデータでは更新方向が異なるため、ローカル更新回数や参加率の影響が大きい。通信量、端末差、離脱、群別性能を測る。生データを送らないこと自体はプライバシー保証ではない。更新からの情報漏洩に対し、Secure Aggregationや差分プライバシーを検討する。

コードH.5　サンプル数重み付き集約
import numpy as np
weights = np.array([[1.,2.],[3.,0.],[2.,4.]])
n = np.array([20,60,20])
print(np.average(weights,axis=0,weights=n))

実行結果

[2.4 1.2]

H.8　ニューラルアーキテクチャ探索（NAS）

探索対象は層数、チャネル数、接続、演算の種類など。探索空間・探索戦略・評価戦略を分離する。Random Search、進化的探索、強化学習、微分可能NASなどがある。DARTSは候補演算をsoftmax重み付き和として連続緩和し、重みと構造変数を最適化する。通常は離散化後に再学習して評価し、代理性能と最終性能が一致するとは限らない。

$$\min_{a}\ L_{val}(w^*(a),a),\quad w^*(a)=\arg\min_w L_{train}(w,a)$$

速度・メモリ・精度の多目的探索ではPareto前線を用いる。評価機器を固定し、探索に消費した計算資源も報告する。第36章、第38章参照。

コードH.6　Pareto非支配候補の抽出
import numpy as np
# 人工的な候補の (latency, error)、両方とも小さいほど良い
v = np.array([[2,.25],[3,.18],[4,.19],[5,.12],[8,.10],[9,.13]])
keep = np.array([not np.any(np.all(v<=x,axis=1)&np.any(v<x,axis=1)) for x in v])
print(v[keep])

実行結果

[[2.   0.25]
 [3.   0.18]
 [5.   0.12]
 [8.   0.1 ]]

H.9　不確実性推定と予測区間

Aleatoric不確実性はデータに内在する不確実性（観測ノイズなど）、Epistemic不確実性はモデル知識の不足に対応する。両者の分離は仮定に依存する。異分散回帰では平均 $\mu$ と対数分散 $s$ を出力し、Gaussian NLL $\frac12[s+(y-\mu)^2e^{-s}]$（定数省略）を最小化する。Deep Ensembleでは各モデルの平均と分散を用いる。次式は等重み混合分布に対して厳密な分散であり、真の予測分布の分散の推定として用いる。

$$\operatorname{Var}(Y|x)\approx\frac1M\sum_m\sigma_m^2+\frac1M\sum_m(\mu_m-\bar\mu)^2$$

MC Dropoutは推論時にDropoutを有効にした反復予測で近似するが、Batch Normalizationまで訓練モードにしない設計が必要。分類ではNLL、Brier score、信頼度曲線を確認する（第22章）。Conformal predictionは交換可能性の下で周辺被覆率を保証する。学習済み予測器を固定し、学習から分離した校正集合の絶対残差を使う。校正点と将来の評価点が交換可能で、$0<\alpha<1$ として、$k=\lceil(n+1)(1-\alpha)\rceil$ 番目の順序統計量を半幅とする（$k>n$ なら無限大）。個々の入力に対する条件付き保証ではない。

コードH.7　Split conformalの校正と独立評価
import numpy as np
rng = np.random.default_rng(42)
x = rng.uniform(-2,2,3000)
y = 2*x + rng.normal(size=len(x))*(.2+abs(x))
# 既知の平均関数を使う教育例。校正と評価を分離
r = np.abs(y[:1000]-2*x[:1000])
k = int(np.ceil((len(r)+1)*.9))
q = np.sort(r)[k-1]
covered = np.abs(y[1000:]-2*x[1000:])<=q
print('half width:',round(q,3),'coverage:',covered.mean())

実行結果

half width: 2.208 coverage: 0.897

H.10　その他の研究方向と評価の注意

方向概要評価の焦点
ドメイン一般化未知ドメインでの性能を高めるドメイン単位の分割
能動学習ラベル取得対象を選ぶ同じラベル予算

H.11　学習ロードマップと参考資料

まず教師あり学習のベースラインを確立し、課題の制約に応じて発展手法を一つずつ追加する。数式の復習は付録A、実験の設計は第39章を参照。

Q-learningと教師あり回帰の違いは？

目標値が次状態の価値推定に依存し、行動がデータ分布を変える。

連合学習だけでプライバシーを保証できるか？

できない。更新の漏洩リスクと追加の保護機構を検討する。

90% conformal区間は全入力で90%被覆するか？

交換可能性の下の周辺保証であり、条件付き保証ではない。
