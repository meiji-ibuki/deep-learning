31.1 画像認識タスクの違い

第30章では画像全体に一つのラベルを付けた。本章では位置と領域を予測する。物体検出は物体ごとに矩形とクラスを返し、セマンティックセグメンテーションは画素ごとにクラスを返す。インスタンスセグメンテーションは同じクラスの別個体を区別する。パノプティックセグメンテーションは個体と背景領域を統合して扱う。

タスク出力形状の例用途
分類(B,K)画像カテゴリ
検出画像ごとに可変個数の矩形部品検査
意味領域(B,H,W,K)道路・背景
個体領域個体ごとのマスク個体数・面積

31.2 Bounding Boxと座標変換

本章では矩形を $(x_1,y_1,x_2,y_2)$ とし、左上と右下を表す。原点は左上、xは右、yは下へ増加する。連続座標または半開区間を採用するため幅は $x_2-x_1$ であり、+1は不要である。COCO形式は左上と幅・高さ、YOLO形式のラベルは通常画像幅・高さで正規化した中心座標と幅・高さを使う。

$$c_x=(x_1+x_2)/2,\quad c_y=(y_1+y_2)/2,\quad w=x_2-x_1,\quad h=y_2-y_1$$

入力をリサイズする際は画像と矩形に同じ変換を施す。letterboxで余白を入れる場合は $x'=sx+p_x$ のように平行移動も記録する。推論時は逆変換を施して元画像の座標に戻す。左右反転なら $(x'_1,x'_2)=(W-x_2,W-x_1)$ となる。変換後は範囲外をクリップし、面積0の矩形を除く。

コード31.1　座標形式の変換
import numpy as np

def xyxy_to_yolo(box, width, height):
    x1,y1,x2,y2 = np.asarray(box, float)
    return np.array([(x1+x2)/(2*width), (y1+y2)/(2*height),
                     (x2-x1)/width, (y2-y1)/height])

def yolo_to_xyxy(box, width, height):
    x,y,w,h = np.asarray(box, float)
    return np.array([(x-w/2)*width,(y-h/2)*height,
                     (x+w/2)*width,(y+h/2)*height])
b = [20,30,100,90]
assert np.allclose(yolo_to_xyxy(xyxy_to_yolo(b,200,120),200,120),b)

31.3 IoUと位置回帰の損失

Intersection over Union（IoU）は予測領域Pと正解領域Gの重なりを測る。矩形でも画素マスクでも定義は同じである。ただし和集合が空の場合は定義できず、評価仕様で扱いを定める。コード31.2では0を返す。

$$\operatorname{IoU}(P,G)=\frac{|P\cap G|}{|P\cup G|}$$

例えば両方の面積が100、交差が60なら和集合は140、IoUは約0.429である。矩形の交差幅は $\max(0,\min(x_2^P,x_2^G)-\max(x_1^P,x_1^G))$。高さも同様に求める。IoUが0のとき通常のIoU損失は離れた矩形に有用な勾配を与えにくい。GIoUは両矩形を覆う最小矩形Cを利用する。

$$GIoU=IoU-\frac{|C|-|P\cup G|}{|C|},\qquad L=1-GIoU$$

DIoUは中心間距離、CIoUはさらに縦横比を考慮する。Smooth L1も座標回帰に使われる。分類損失と位置損失の重みはモデル設計に依存する。

コード31.2　IoUのNumPy実装
import numpy as np

def iou(a,b):
    a,b = np.asarray(a,float),np.asarray(b,float)
    inter = np.maximum(0,np.minimum(a[2:],b[2:])-np.maximum(a[:2],b[:2])).prod()
    area = lambda x: np.maximum(0,x[2:]-x[:2]).prod()
    union = area(a)+area(b)-inter
    return inter/union if union>0 else 0.0
assert np.isclose(iou([0,0,10,10],[4,0,14,10]),3/7)
assert iou([0,0,1,1],[2,2,3,3]) == 0

31.4 候補の割り当てと検出モデル

検出器は複数の候補位置についてクラスと矩形を予測する。anchor-based方式では既定の矩形を基準に中心やサイズの差分を回帰する。anchor-free方式では特徴マップの位置から直接距離や中心を予測する。正例・負例の割り当てはIoUや中心位置、動的なマッチングなどを用いる。背景候補が多いため、Focal Lossは容易な例の寄与を抑える。

$$FL(p_t)=-\alpha_t(1-p_t)^\gamma\log p_t$$

ここでp_tは正解クラスに割り当てた確率（二値分類なら正例でp、負例で1−p）、α_tは非負のクラス重み、γ≥0は焦点化係数である。上式は0<p_t<1で定義し、端点は極限で扱う。γ=0かつα_t=1なら通常の交差エントロピーに戻る（付録D）。

Faster R-CNNはRegion Proposal Networkで候補を作り、領域ごとの特徴から分類・回帰する二段階方式である。SSDや多くのYOLO系は一段階方式で、特徴マップから直接候補を予測する。FPNは異なる解像度の特徴を組み合わせ、小物体と大物体の検出に対応する。DETRは物体クエリと集合予測を使い、一対一マッチングにより通常のNMSを不要にする設計を採る。YOLO系でも実装・世代ごとに割り当てや後処理は異なる。

方式特徴検討点
Faster R-CNN候補領域を精査計算量
SSD / YOLO系密な候補予測小物体・後処理
DETR系集合予測学習・解像度の設計

31.5 Non-Maximum Suppression（NMS）

同一物体に複数の候補が集中する場合、スコア順に候補を選び、選ばれた矩形とIoUが閾値を超える候補を除く。通常はクラスごとに実行する。閾値が低すぎると隣接する別個体を消し、高すぎると重複が残る。Soft-NMSは候補を即時除去せずスコアを減衰させる。スコア閾値とNMS閾値は別の設定である。

コード31.3　クラス内NMS（前節のiouを利用）
def nms(boxes,scores,threshold=.5):
    order = np.argsort(-np.asarray(scores),kind='stable').tolist()
    keep = []
    while order:
        i = order.pop(0)
        keep.append(i)
        order = [j for j in order if iou(boxes[i],boxes[j]) <= threshold]
    return keep
boxes = np.array([[0,0,10,10],[1,1,11,11],[20,20,30,30]])
assert nms(boxes,[.9,.8,.7]) == [0,2]
print(nms(boxes,[.9,.8,.7]))

31.6 検出の評価：APとmAP

第22章のPrecision・Recallを検出に拡張する。同一クラスの予測をスコア降順に並べ、各画像内で未対応の正解矩形とIoUを比較する。閾値以上のIoUを持つ未対応の正解のうち、原則として最大IoUの正解に一対一で対応した予測をTP、重複や誤検出をFPとする。見逃しはFNとなる。正解数をNとすると、順位kまでのRecallは累積TP/Nである。

$$P_k=\frac{TP_k}{k},\quad R_k=\frac{TP_k}{N}$$

APはPrecision–Recall曲線を要約する。COCOでは101個のRecall点で補間Precisionを平均し、主要指標はIoU 0.50〜0.95を0.05刻みで平均する。クラス、面積区分、最大検出数、crowdやignoreの扱いも定義されている。AP50と主要APを混同しない。以下は単一クラスで正解3個、スコア順のTP/FPが1,0,1,0,1という教育用例で、完全なCOCO評価器ではない。101点補間APは約0.756436となる。

コード31.4　101点補間APの計算（マッチング済みの例）
import numpy as np

def ap101(tp,n_gt):
    tp = np.asarray(tp,int)
    if n_gt <= 0:
        return np.nan
    r = np.cumsum(tp)/n_gt
    p = np.cumsum(tp)/np.arange(1,len(tp)+1)
    return np.mean([p[r>=t].max(initial=0) for t in np.linspace(0,1,101)])
print(ap101([1,0,1,0,1],3))
assert ap101([1,1,1],3) == 1

31.7 セグメンテーションのラベルと前処理

意味領域の正解は高さH、幅Wの整数クラスID行列であり、予測は各画素のKクラスロジットである。マスクを通常の画像のようにbilinear補間するとクラスIDが混ざるため、整数ラベルにはnearest neighborを使用する。画像とマスクの幾何変換は同期させ、明るさや色変換は画像だけに適用する。無効画素はignore IDとして損失と評価から除外する。以下のPetデータでは元のID 1・2・3を0・1・2に変換する（物体・背景・境界の順）。図31.7の模式例のID順とは異なる。背景クラスと未注釈を区別する。

コード31.5　Oxford-IIIT Petのデータ準備（tensorflow-datasetsが必要）
import tensorflow as tf
import tensorflow_datasets as tfds
from tensorflow import keras
keras.utils.set_random_seed(31)
raw = tfds.load('oxford_iiit_pet:3.*.*',split=['train[:80%]','train[80%:]','test'])
def prep(item):
    x = tf.image.resize(item['image'],(128,128))/255.0
    y = tf.image.resize(item['segmentation_mask'],(128,128),method='nearest')
    y = tf.cast(tf.squeeze(y,-1),tf.int32)-1
    return x,y

def augment(x,y):
    flip = tf.random.uniform(()) < .5
    return tf.cond(flip,lambda:(tf.image.flip_left_right(x),tf.reverse(y,[1])),lambda:(x,y))
train = raw[0].shuffle(1000,seed=31).map(prep).map(augment).batch(16).prefetch(tf.data.AUTOTUNE)
valid = raw[1].map(prep).batch(16).prefetch(tf.data.AUTOTUNE)
test = raw[2].map(prep).batch(16).prefetch(tf.data.AUTOTUNE)

31.8 U-NetとEncoder–Decoder構造

分類CNNは解像度を縮小し意味的な特徴を抽出するが、領域予測では画素位置に対応する出力が必要になる。U-NetはEncoderで解像度を縮小し、Decoderで復元する。同じ解像度のEncoder特徴を連結するskip connectionにより、境界や局所的な情報を利用できる。第19章の残差加算とは異なり、典型的なU-Netではチャネル方向に連結する。FCNは全畳み込み型の予測、DeepLab系は膨張畳み込みと多尺度文脈、Mask R-CNNは個体ごとのマスク予測を扱う。

コード31.6　小型U-Net（前節に続けて実行）
L = keras.layers
def block(x,n):
    for _ in range(2):
        x = L.Conv2D(n,3,padding='same',activation='relu')(x)
    return x
inp = keras.Input((128,128,3))
a = block(inp,32)
b = block(L.MaxPooling2D()(a),64)
c = block(L.MaxPooling2D()(b),128)
for skip,n in [(b,64),(a,32)]:
    c = L.Conv2DTranspose(n,2,strides=2,padding='same')(c)
    c = block(L.Concatenate()([c,skip]),n)
model = keras.Model(inp,L.Conv2D(3,1)(c))
model.compile(optimizer=keras.optimizers.Adam(1e-3),
    loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=[keras.metrics.SparseCategoricalAccuracy(),
             keras.metrics.MeanIoU(num_classes=3,sparse_y_pred=False)])
model.fit(train,validation_data=valid,epochs=25,callbacks=[
    keras.callbacks.EarlyStopping(monitor='val_loss',patience=5,restore_best_weights=True)])
model.evaluate(test)

31.9 画素単位の損失と評価指標

多クラスの画素分類ではSparse Categorical Crossentropyが基本である。二値領域ならBCEを用いる。背景が大部分を占める場合、画素Accuracyは高くても物体領域を全く検出できないことがある。Dice係数は重なりを次のように定義する。

$$D=\frac{2TP}{2TP+FP+FN},\qquad IoU=\frac{TP}{TP+FP+FN},\qquad D=\frac{2IoU}{1+IoU}$$

学習時は離散化せず確率を使うsoft Diceを定義する。εは分母0を避けるための小値である。離散DiceとIoUの関係式は分母が正の場合に成立する。下例はバッチ全体と空間軸で集計しクラス平均を取る方式で、CEと組み合わせる。評価ではデータセット全体の混同行列からクラスごとのIoUを求め、その平均をmIoUとする。正解・予測とも存在しないクラスの扱いは評価仕様に従う。

コード31.7　多クラスCE＋soft Dice（任意の代替損失、無効画素なしを前提）
def ce_dice(y_true,logits):
    y = tf.one_hot(tf.cast(y_true,tf.int32),3)
    p = tf.nn.softmax(logits,axis=-1)
    ce = tf.reduce_mean(tf.keras.losses.sparse_categorical_crossentropy(y_true,logits,from_logits=True))
    inter = tf.reduce_sum(y*p,axis=[0,1,2])
    denom = tf.reduce_sum(y+p,axis=[0,1,2])
    return ce + 1-tf.reduce_mean((2*inter+1e-6)/(denom+1e-6))
コード31.8　混同行列とmIoU（NumPy）
import numpy as np

def segmentation_metrics(y,p,k,ignore=-1):
    y,p = np.asarray(y).ravel(),np.asarray(p).ravel()
    valid = y != ignore
    y,p = y[valid],p[valid]
    assert np.all((0<=y)&(y<k)) and np.all((0<=p)&(p<k))
    cm = np.bincount(k*y+p,minlength=k*k).reshape(k,k)
    tp = cm.diagonal()
    union = cm.sum(0)+cm.sum(1)-tp
    iou = np.divide(tp,union,out=np.full(k,np.nan),where=union>0)
    return cm,iou,np.nanmean(iou)
y = np.array([0]*90+[1]*10)
p = np.zeros_like(y)
cm,per_class,miou = segmentation_metrics(y,p,2)
print(cm,per_class,miou)
assert np.isclose(miou,.45)

31.10 推論・誤差分析と提出

検証画像を元画像・正解・予測の三列で比較する。境界のずれ、小物体の欠落、クラス混同、背景の誤検出を分けて数える。検出の場合はサイズ別APやスコア分布も調べる。マスク推論ではlogitsをargmaxする前に元解像度へ補間する方法と、離散マスクをnearestで拡大する方法がある。検証で採用方法を固定する。コンペでは矩形の座標形式やマスクのRLE仕様を必ず確認する。以下は列優先・1始まりの二値RLE例であり、COCOの圧縮RLEとは異なる。

コード31.10　二値RLEの往復検証
import numpy as np

def encode(mask):
    a = np.asarray(mask).ravel(order='F')
    if not np.all((a == 0) | (a == 1)):
        raise ValueError('mask must be binary')
    a = a.astype(np.uint8)
    edges = np.flatnonzero(np.diff(np.r_[0,a,0]))+1
    edges[1::2] -= edges[::2]
    return ' '.join(map(str,edges))

def decode(text,shape):
    a = np.zeros(np.prod(shape),dtype=np.uint8)
    v = list(map(int,text.split()))
    if len(v) % 2:
        raise ValueError('RLE requires start-length pairs')
    end = 0
    for s,n in zip(v[::2],v[1::2]):
        if s < 1 or n < 1 or s-1 < end or s-1+n > a.size:
            raise ValueError('invalid or overlapping run')
        a[s-1:s-1+n]=1
        end = s-1+n
    return a.reshape(shape,order='F')
m = np.array([[0,1,0],[1,1,0]],dtype=np.uint8)
assert np.array_equal(m,decode(encode(m),m.shape))
print(encode(m))

31.11 まとめと確認問題

検出は位置とクラス、セグメンテーションは画素領域を扱う。データ拡張、座標復元、評価仕様の一貫性が重要である。掲載したU-Netは教育用の小型モデルであり、TensorFlow学習は未実行。検出器の学習全体ではなく、検出の構成要素をNumPyで実装する範囲とした。

問1　分類と検出の違いは？

検出は個体ごとの位置も予測する。

問2　IoUの分母は？

和集合の面積。

問3　NMSで別個体が消える原因は？

重なりが閾値を超える場合。

問4　AP50とCOCO主要APの違いは？

後者は複数のIoU閾値で平均する。

問5　マスクのリサイズ方法は？

整数ラベルはnearest neighbor。

問6　U-Netのスキップ接続の目的は？

高解像度の局所情報を復元に活用する。

問7　背景90%をすべて背景と予測したときのmIoUは？

2クラスなら(0.9+0)/2=0.45。

問8　RLEの注意点は？

走査順・開始番号・空マスクの仕様。

問9　発展：CEとCE＋Diceを比較せよ。

同一分割・シード・学習予算で、同じ初期重みからCEとCE＋Diceの各モデルを学習し、共通指標の検証mIoU（大きいほど良い）で停止・選択する。クラス別IoUも比較し、モデル選択後のみテストを評価する。損失の尺度が異なるため、両モデルのval_lossの大小を直接比較しない。
