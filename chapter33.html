33.1 時系列予測の問題設定

時系列とは時間順に観測されたデータである。売上、電力需要、気温、センサー値などでは、近い時刻の観測値が互いに依存しやすい。表形式データと異なり、行を無作為に分割すると将来の情報が訓練に混入することがある。

予測起点を $t$、過去の長さを $L$、予測期間を $H$ とする。入力 $X_t=(x_{t-L+1},\ldots,x_t)$ から、将来の目的変数 $Y_t=(y_{t+1},\ldots,y_{t+H})$ を推定する。予測時点で既知の情報のみを条件とすることが根本原則である。

設定入力と出力例
単変量過去の目的変数 → 将来の目的変数電力需要
多変量複数の観測特徴量 → 一つまたは複数の目的変数気象と需要
単一ステップH=1翌時刻
多段階H>1翌24時間

33.2 トレンド・季節性・自己相関

加法分解では $y_t=T_t+S_t+e_t$ と書く。トレンド $T_t$ は長期変化、季節成分 $S_t$ は周期的な変動、残差 $e_t$ はそれらで説明できない部分である。変動幅が水準に比例するなら乗法分解や対数変換も候補となる。

弱定常性は平均・分散が時間に依存せず、共分散がラグだけに依存する性質である。差分 $\Delta y_t=y_t-y_{t-1}$ や季節差分 $y_t-y_{t-s}$ が役立つことがあるが、深層モデルに定常性が常に必要なわけではない。差分予測は元の尺度に戻して評価する。

$$\hat\rho(k)=\frac{\sum_{t=k}^{N-1}(y_t-\bar y)(y_{t-k}-\bar y)}{\sum_{t=0}^{N-1}(y_t-\bar y)^2}$$

自己相関（ACF）はラグごとの線形依存を調べる。トレンドが残ると周期の解釈が難しくなるので、訓練期間だけを用いて原系列と差分系列を比較する。

33.3 前処理と特徴量エンジニアリング

タイムスタンプの昇順、重複、欠測、時間帯、観測間隔を確認する。等間隔モデルではリサンプリングが必要になることもある。欠測補完は未来の観測値を利用しない方法（前方補完など）を基本とし、欠測フラグを残す。先頭の欠測は訓練から推定した値または除外で処理する。

目的時刻の特徴量を作るとき、ラグ $y_{t-1}$ と移動平均 $\frac1w\sum_{j=1}^{w}y_{t-j}$ は過去だけに依存する。曜日・時刻は未来も既知だが、未来の実測気温や売上は未知である。予報値を使うなら当時入手できた予報の履歴を利用する。

$$h_{sin}=\sin(2\pi h/24),\quad h_{cos}=\cos(2\pi h/24)$$
コード33.1　因果的なラグ特徴量
import pandas as pd
import numpy as np
s = pd.Series([10.,12.,11.,14.,13.])
f = pd.DataFrame({'target':s,'lag1':s.shift(1),
                  'mean3':s.shift(1).rolling(3).mean()})
assert f.loc[3,'mean3']==11
print(f)
特徴量未来に利用できるか
時刻・曜日・確定済み祝日可能
実測気温未来の実測は不可
公開予定の販促確定済みなら可能
中心化移動平均未来を含むため通常不可

33.4 スライディングウィンドウとテンソル形状

連続した過去 $L$ 点を一サンプルにする。バッチサイズ $B$、特徴量数 $F$ の入力は $(B,L,F)$、単一目的の多段階出力は $(B,H)$ とする。窓を1時刻ずつずらすとサンプルは増えるが独立ではない。

コード33.2　人工データと時系列窓の構築（以降の実践で共通）
import numpy as np
rng = np.random.default_rng(33)
t = np.arange(1200)
y = (20 + .008*t + 3*np.sin(2*np.pi*t/24)
     + 1.2*np.cos(2*np.pi*t/168) + rng.normal(0,.7,len(t)))
L, H = 72, 24
# i は予測起点（最後に観測済みの時刻）
origins = np.arange(L-1, len(y)-H)
X = np.stack([y[i-L+1:i+1] for i in origins])[...,None]
Y = np.stack([y[i+1:i+H+1] for i in origins])
# 目的値が各期間に完全に含まれる窓だけを採用
train = origins+H < 720
val = (origins+1 >= 720) & (origins+H < 960)
test = origins+1 >= 960
assert X.shape == (len(origins), L, 1)
assert Y.shape == (len(origins), H)
assert (origins[train]+H).max() < (origins[val]+1).min()
print(X.shape, Y.shape, train.sum(), val.sum(), test.sum())

この例は外部ファイル不要の人工需要データである。入力72時間、出力24時間とし、目的値が分割境界を跨ぐ窓を除外する。検証・テスト窓の入力には、予測起点までに観測済みの前期間の履歴を含めてよい。

33.5 時系列分割・バックテストとリーク防止

訓練→検証→テストを時刻順に設定する。標準化の平均と分散は訓練期間のみで推定する。拡張窓（expanding window）は訓練期間を徐々に広げ、固定長のrolling windowは古いデータを捨てる。後者は分布変化が大きい場合に候補となる。

複数ステップ予測では訓練ラベルの終了時刻が検証起点より後にならないようにする。ラベル確定の遅延も考慮する。TimeSeriesSplitのgapは行数単位であり、行が連続した予測起点ならH−1行を空けることで訓練ラベルの最終時刻が検証起点以下になる（等間隔、遅延なしの場合）。

コード33.3　予測起点に対する交差検証（コード33.2に続ける）
from sklearn.model_selection import TimeSeriesSplit
idx = np.flatnonzero(train)
cv = TimeSeriesSplit(n_splits=3, test_size=48, gap=H-1)
for a,b in cv.split(idx):
    tr,va = idx[a],idx[b]
    assert origins[tr[-1]]+H <= origins[va[0]]
    print(origins[tr[-1]],origins[va[0]])

固定起点で24時間を一括予測する場合、途中の実測値で入力を更新してはいけない。一方、毎時点で観測値が届く運用ならrolling-origin評価が適切である。本章は後者を採用する。

33.6 ベースラインと評価指標

深層学習を始める前に、直近値予測 $\hat y_{t+h}=y_t$、季節ナイーブ予測 $\hat y_{t+h}=y_{t+h-s}$（$1\le h\le s$）、線形回帰を比較する。季節ナイーブは周期性の強いデータで特に重要である。

$$MAE=\frac1{NH}\sum_{i,h}|y_{i,h}-\hat y_{i,h}|,\quad RMSE=\sqrt{\frac1{NH}\sum_{i,h}(y_{i,h}-\hat y_{i,h})^2}$$

MAPEはゼロ付近で不安定になる。MASEは訓練期間のナイーブ予測の平均絶対誤差（季節系列では季節ナイーブを使うこともある）でMAEを割り、異なるスケールの系列を比較する。分母がゼロなら定義できない。全期間平均だけでなくホライズン別の誤差も確認する。

コード33.4　ベースライン比較（コード33.2に続ける）
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error
# コード33.2の変数を使う。検証期間のみで比較。
mu, sigma = y[:720].mean(), y[:720].std()
Xs = (X-mu)/sigma
Ys = (Y-mu)/sigma
ridge = Ridge(alpha=1.).fit(Xs[train].reshape(-1,L),Ys[train])
preds = {'Last':np.repeat(X[val,-1,0,None],H,axis=1),
         'Seasonal':X[val,-H:,0],
         'Ridge':ridge.predict(Xs[val].reshape(-1,L))*sigma+mu}
for name,pred in preds.items():
    print(name,mean_absolute_error(Y[val],pred))

33.7 多段階予測の設計

再帰型は1ステップモデルを繰り返し適用する。計算を共有できるが誤差が入力に戻る。直接型はホライズン別のモデルを構築する。Multi-output型は一度にH点を予測し、出力間で表現を共有する。本章のRidgeと深層モデルはMulti-output型である。

方式利点注意点
再帰型任意の長さに拡張誤差蓄積・学習時との入力分布差
直接型各時点に最適化モデル数が増える
Multi-output一括推論・共有表現固定ホライズン
コード33.5　再帰予測の最小例（説明用）
import numpy as np
history = [1.,2.,3.]
forecast = []
for _ in range(4):
    pred = np.mean(history[-3:])
    forecast.append(pred)
    history.append(pred)  # 将来の実測値は使わない
print(forecast)

33.8 LSTM・GRU・TCN・Transformerの実装

LSTMとGRUは隠れ状態を時間方向に更新する（第26章）。TCNは因果畳み込みと膨張畳み込みによって長い受容野を確保する。ストライド1で各層に1つの畳み込みがある場合、受容野は $R=1+(k-1)\sum_l d_l$ となる。カーネル3、膨張率1,2,4,8,16,32では127点である。TransformerはAttentionで遠い時刻の関係を直接扱えるが、位置情報が必要で特徴次元を固定した場合、Attentionの系列長に対する計算量は通常 $O(L^2)$ である。

以下は同じ入力と出力を持つ教育用モデル。TCNは残差付き、Transformerは学習可能な位置埋め込みを用いる。入力窓の全時刻が予測起点で観測済みなので窓内Self-Attentionに因果マスクは不要である（各位置で将来を予測する場合は別）。

コード33.6　4モデルの構築（TensorFlow、コード33.2・33.4に続ける）
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def build(kind):
    x = keras.Input((L,1))
    if kind in ('LSTM','GRU'):
        h = getattr(layers,kind)(32)(x)
    elif kind == 'TCN':
        h = layers.Dense(32)(x)
        for rate in [1,2,4,8,16,32]:
            z = layers.Conv1D(32,3,padding='causal',
                              dilation_rate=rate,activation='relu')(h)
            h = layers.Add()([h,z])
        h = layers.Cropping1D((L-1,0))(h)
        h = layers.Flatten()(h)
    elif kind == 'Transformer':
        h = layers.Dense(32)(x)
        # 位置ごとに異なる学習可能なバイアス
        class Position(layers.Layer):
            def build(self,shape):
                self.pos = self.add_weight(shape=(L,32),
                    initializer='random_normal',trainable=True)
            def call(self,z):
                return z+self.pos
        h = Position()(h)
        z = layers.MultiHeadAttention(4,8)(h,h)
        h = layers.LayerNormalization()(h+z)
        z = layers.Dense(64,activation='relu')(h)
        h = layers.LayerNormalization()(h+layers.Dense(32)(z))
        h = layers.GlobalAveragePooling1D()(h)
    else:
        raise ValueError(kind)
    model = keras.Model(x,layers.Dense(H)(h))
    model.compile(optimizer='adam',loss='mse')
    return model

33.9 実践：学習・モデル選択・テスト評価

検証MAEを比較し、最良モデルだけをテスト期間で評価する。Early Stoppingの監視値は標準化尺度の検証MSE、選択指標は元尺度のMAEとする。異なる目的であることを理解し、実務では選択指標に合わせて監視値を決める。各モデルの学習予算と乱数を固定するが、パラメータ数は異なるので厳密な容量比較ではない。

コード33.7　深層モデルの比較（コード33.2・33.4・33.6に続ける）
models = {}
scores = {k:mean_absolute_error(Y[val],v) for k,v in preds.items()}
for kind in ['LSTM','GRU','TCN','Transformer']:
    keras.utils.set_random_seed(33)
    model = build(kind)
    model.fit(Xs[train],Ys[train],validation_data=(Xs[val],Ys[val]),
        epochs=30,batch_size=32,verbose=0,callbacks=[
        keras.callbacks.EarlyStopping(patience=5,restore_best_weights=True)])
    pred = model.predict(Xs[val],verbose=0)*sigma+mu
    scores[kind] = mean_absolute_error(Y[val],pred)
    models[kind] = model
winner = min(scores,key=scores.get)
print(scores,winner)
if winner=='Last':
    final = np.repeat(X[test,-1,0,None],H,axis=1)
elif winner=='Seasonal':
    final = X[test,-H:,0]
elif winner=='Ridge':
    final = ridge.predict(Xs[test].reshape(-1,L))*sigma+mu
else:
    final = models[winner].predict(Xs[test],verbose=0)*sigma+mu
print('test MAE',mean_absolute_error(Y[test],final))

33.10 確率予測と予測区間

点予測だけでは需要の不確実性がわからない。分位点回帰では分位点 $q$ に対してピンボール損失を最小化する。

$$\ell_q(y,\hat y)=\max(q(y-\hat y),(q-1)(y-\hat y))$$

0<q<1とする。例えば0.1と0.9分位点による区間は名目80%の予測区間である。実際の被覆率が80%になる保証はないので検証する。分位点の交差にも注意し、区間幅と被覆率の両方を評価する。

コード33.8　ピンボール損失と被覆率
import numpy as np
def pinball(y,p,q):
    e=np.asarray(y)-np.asarray(p)
    return np.maximum(q*e,(q-1)*e).mean()
assert np.isclose(pinball([2],[1],.9),.9)
assert np.isclose(pinball([1],[2],.9),.1)
y0=np.array([1,2,3,4])
lo=np.array([0,1,2,5]); hi=lo+2
print(np.mean((lo<=y0)&(y0<=hi)))

33.11 Kaggle形式の推論と提出

複数店舗・商品の系列では系列IDでグループ化し、窓が系列境界を跨がないようにする。分割は各系列の時刻を整合させる。未来のカレンダーは使えても未来の売上は使えない。固定起点のコンペではテスト期間の目的値を逐次参照できない。

以下は人工系列の最終時刻を起点とする24時間先予測を、IDと予測値の表に変換する例である。実際の競技ではsample_submissionのID・列名・並びを照合する。ここでは学習済みRidgeを使うが、競技の運用に合わせて検証後に利用可能な全履歴で再学習することも検討する。

コード33.9　固定起点の提出表（コード33.2・33.4に続ける）
import pandas as pd
last = ((y[-L:]-mu)/sigma).reshape(1,L)
p = ridge.predict(last).ravel()*sigma+mu
sample = pd.DataFrame({'id':np.arange(len(y),len(y)+H)})

33.12 まとめと確認問題

予測起点・利用可能情報・予測期間を最初に定義し、時間分割とベースラインを設計してから深層モデルへ進む。

問1　無作為分割の危険は？

未来の情報が訓練に混入する。

問2　季節差分とは？

周期sだけ前の観測値を引く。

問3　移動平均にshiftを使う理由は？

予測対象時刻の実測を含めないため。ただし多段階予測では予測起点より後の実測値も使わない。

問4　L=72、H=24、F=1の形状は？

入力(B,72,1)、出力(B,24)。

問5　gap=23の理由は？

予測起点が1時刻間隔でラベル確定の遅延がない場合、24ステップ先の訓練ラベルが検証起点を越えないため。

問6　季節ナイーブの利点は？

周期性を低コストで利用できる。

問7　再帰予測の問題は？

予測誤差が次の入力に伝播する。

問8　TCNの膨張率の役割は？

少ない層で受容野を広げる。

問9　発展：実運用の検証を設計せよ。

例えば毎時更新の24時間予測なら、起点までに確定した観測と当時の予報だけを使い、各分割で訓練ラベルが検証起点までに確定するようにする。24時間固定起点の運用なら途中の実測で入力を更新しない。季節ナイーブと比較し、全体・ホライズン別MAEを複数期間で評価する。
