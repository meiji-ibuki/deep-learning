1.1 人工知能・機械学習・深層学習の関係

人工知能（Artificial Intelligence; AI）とは、認識、推論、計画、意思決定など、知的な働きをコンピュータで実現しようとする技術・研究領域の総称です。必ずしもデータから学ぶ仕組みを備えているとは限りません。人間が用意した規則に従って推論するシステムや、探索によって最善の手を選ぶプログラムも、その範囲に含まれます。

そのなかで、機械学習（Machine Learning; ML）は、データや経験を利用して、ある課題に対する性能を改善する方法を扱います。そして機械学習の一領域として、多層のニューラルネットワークによる表現の学習を中心に据えるのが、深層学習（Deep Learning; DL）です。

深層学習が機械学習を置き換えたわけではありません。住宅価格のような表形式データでは、線形回帰や勾配ブースティング決定木が優れた性能を示す場合もあります。画像や音声など、入力に複雑な構造があるときには深層学習が有力な選択肢になります。課題に合った道具を選ぶことが、本書を通じて身につけたい姿勢です。

1.2 データから学ぶということ

家の広さから価格を予測する課題を考えます。次の表は説明のために作った架空のデータです。広さを入力 $x$、価格を目標値 $y$ と呼びます。

物件広さ（m²）価格（万円）
A401800
B602600
C803400
D（未知）70？

三つの事例を見ると、広さが20 m²増えるごとに価格が800万円増えています。そこで、価格を「広さ×40＋200」と予測する規則を考えられます。70 m²なら3000万円です。この規則のように、入力から出力を計算する仕組みをモデル（model）と呼びます。

一般にはモデルを $\hat{y}=f_\theta(x)$ と書きます。$\hat{y}$ は予測値、$\theta$ はモデルが持つ調整可能な数値（パラメータ）です。今回の例なら、40と200がそれにあたります。データに合わせてパラメータを調整することを学習（training）、学習済みのモデルに新たな入力を渡して出力を求めることを推論（inference）と呼びます。

予測の誤りを数値で測る

実際のデータは、これほどきれいに直線上に並びません。駅からの距離、築年数、地域なども価格に影響するからです。そこで予測値と正解のずれを数値化する損失関数（loss function）を用意します。たとえば平均二乗誤差は、$n$ 件のデータについて次のように定義されます。

$$L=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2$$

予測が正解から離れるほど二乗誤差は大きくなります。この値を小さくする方向へパラメータを調整するのが最適化です。具体的な計算方法は第4章、第10章、第11章で学びます。ここでは、学習が魔法ではなく、目標を数値として定めたうえで行う調整であることを押さえてください。

1.3 深層学習は何が違うのか

猫を見分ける際、人間は写真を構成する一つひとつの画素の値を意識しているわけではありません。輪郭や模様、顔の形など、複数の手がかりを組み合わせています。従来の機械学習では、このような手がかりを人間が設計してモデルに与えることがよくありました。入力を予測に役立つ形に加工する作業を特徴量エンジニアリングと呼びます。

深層学習では、入力を段階的に変換する複数の層を設け、予測に有用な内部表現そのものを学習できるようにします。このような仕組みを表現学習（representation learning）と呼びます。画像なら初期の層が輪郭や色の変化に反応し、後の層がより複雑な模様や部位に対応することがあります。ただし、実際の内部表現は必ずしも人間が解釈できる概念と一対一には対応しません。

ニューラルネットワークと「深さ」

典型的な多層ニューラルネットワークは、入力を重み付きで組み合わせ、非線形な変換などを施す計算単位を積み重ねたモデルです。出力層が線形（恒等活性化）の場合もあります。深層学習の「深い」とは、こうした学習可能な変換が多段に重なることを指します。何層以上なら深層学習と呼ぶかについて、普遍的な境界はありません。

層を重ねることで複雑な関数を表現できますが、層が多いほど常に性能が高くなるわけではありません。データ量、計算資源、最適化の難しさ、過学習などとの兼ね合いが必要です。第7章から第12章で、各計算単位の仕組みを一つずつ分解します。

1.4 機械学習の五つの学習方式

モデルを学習させる方法は、どのような情報を学習の手がかりとするかによって異なります。ここでは代表的な五つの方式を整理します。これらは完全に排他的な分類ではなく、一つのシステムが複数の方式を組み合わせることもあります。

教師あり学習（Supervised Learning）

入力と目標値の組を使って、入力から目標値を予測する規則を学習します。分類の正解カテゴリはラベルとも呼ばれます。住宅価格予測なら実際の価格、画像分類なら画像に付された動物名が正解です。Kaggleの予測コンペで中心となる方式です。

教師なし学習（Unsupervised Learning）

外部から与えられた正解ラベルを使わず、データの構造や分布を捉えます。たとえば購買履歴が似た顧客をグループに分けるクラスタリングや、多数の特徴を少数の軸へ圧縮する次元削減があります。発見したグループにどのような意味があるかは、人間が別途検討する必要があります。

半教師あり学習（Semi-supervised Learning）

ラベル付きデータとラベルなしデータを組み合わせて学習します。典型的には前者が少量、後者が多量です。たとえばラベル付き画像で学んだモデルを使い、ラベルなし画像のうち高い確信度で予測したものを擬似ラベル付きデータとして再学習に利用します。誤った擬似ラベルが増幅される危険があるため、検証が必要です。

自己教師あり学習（Self-supervised Learning）

データ自体から学習の目標を作ります。文章の一部を隠し、残りから隠した単語を予測する課題や、同じ画像から作った異なる変換画像の表現を近づける課題などが例です。人が付けた正解ラベルを必要とせず、事前学習に利用できます。自己教師あり学習は教師なし学習の一種として整理されることもあります。

強化学習（Reinforcement Learning）

環境と相互作用する主体（エージェント）が、行動の結果として報酬を受け取り、将来にわたる累積報酬を大きくする行動方針を学びます。ゲームやロボット制御などが例です。各時点に正解の行動が与えられるとは限らず、試行錯誤と将来の結果を考慮する点が教師あり学習と異なります。本書では概要にとどめます。

方式学習の手がかり代表例
教師あり入力と正解の組画像分類、価格予測
教師なしデータの構造クラスタリング、次元削減
半教師あり一部の正解とラベルなしデータ擬似ラベル
自己教師ありデータから作る学習目標マスク予測、対照学習
強化学習行動に対する報酬ゲーム、制御

1.5 回帰と分類 ―― 何を予測するのか

教師あり学習の代表的な問題は、予測対象によって回帰（regression）と分類（classification）に分けられます。回帰では価格や気温などの数値を予測します。一方、分類では所属するカテゴリを予測します。分類モデルは、多くの場合、各カテゴリに属する確率やスコアを出力し、それを判断規則によってカテゴリへ変換します。

タスク予測例代表的な評価指標
回帰来月の売上 120万円MAE、RMSE
二値分類迷惑メールか否かAccuracy、ROC-AUC、F1
多クラス分類猫・犬・鳥のいずれかAccuracy、Log Loss
マルチラベル分類写真に猫と犬が同時にいるF1、mAP

多クラス分類では通常、一つの入力に一つの正解カテゴリが対応します。マルチラベル分類では複数のカテゴリが同時に成立します。数値で表されたラベルでも、たとえば猫=0、犬=1、鳥=2という番号なら回帰ではなく分類です。番号の大小に意味があるとは限らないためです。物体検出やセグメンテーションなどの複合的なタスクは、第31章で扱います。

1.6 学習の目的は、未知のデータに対応すること

過去の問題の解答をすべて暗記した学生が、新しい問題にも答えられるとは限りません。機械学習も同じです。学習に使ったデータに対して正確な予測をすることと、まだ見たことのないデータに対して正確な予測をすることは、区別しなければなりません。後者の能力を汎化性能（generalization performance）と呼びます。

モデルが複雑すぎたり、訓練データが少なすぎたりすると、データに含まれる偶然のばらつきまで学んでしまうことがあります。これが過学習（overfitting）です。反対に、モデルの表現力が不足していたり、学習が不十分だったりするために、データの規則性を十分に捉えられない状態を未学習（underfitting）と呼びます。

訓練・検証・テストデータ

汎化性能を測るためには、学習に使わなかったデータが必要です。一般的にはデータを次の三つに分けます。訓練データでパラメータを調整し、検証データでモデルや学習条件を選び、最後にテストデータで性能を評価します。テストの結果を見ながら何度もモデルを修正すれば、そのテストも事実上、検証に使ったことになります。

たとえば売上を予測する際、予測時点では得られない将来の実測売上を、入力や前処理の学習に使ってはいけません。予測時点で既知の祝日や予定などの将来情報は、利用条件を満たせば特徴量にできます。このように本来利用できない情報が学習や評価に入り込むことをデータリーク（data leakage）と呼びます。データ分割と評価設計については第6章、第22章、第39章で詳しく扱います。

1.7 はじめてのTensorFlow ―― 予測する直線を学習する

ここまでの話を、実際のプログラムで確かめてみましょう。第2章で実行環境を整える予定ですので、今はコードを眺めるだけでも構いません。実行する場合はTensorFlow 2系が利用できるPython環境（Colabなど）を用意してください。

第1.2節の住宅価格の例を小さく作り直します。面積を100 m²単位、価格を1000万円単位に換算すると、入力と目標値はそれぞれ [0.4, 0.6, 0.8]、[1.8, 2.6, 3.4] です。モデルは入力を一つ受け取り、出力を一つ返す全結合層（Dense）だけで構成します。これは深層モデルではなく、深層学習の道具を使った線形回帰です。

コード1.1　TensorFlow / Python
import numpy as np
import tensorflow as tf

# データ：面積（100 m²単位）、価格（1000万円単位）
x = np.array([[0.4], [0.6], [0.8]], dtype=np.float32)
y = np.array([[1.8], [2.6], [3.4]], dtype=np.float32)

tf.keras.utils.set_random_seed(42)
model = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),
    tf.keras.layers.Dense(1)
])
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.05),
    loss="mean_squared_error"
)
history = model.fit(x, y, epochs=1000, verbose=0)

# 70 m²の物件を予測し、万円単位に戻す
new_x = np.array([[0.7]], dtype=np.float32)
pred = model.predict(new_x, verbose=0)
w, b = model.layers[0].get_weights()
print(f"重み: {w[0, 0]:.3f}, バイアス: {b[0]:.3f}")
print(f"予測価格: {pred[0, 0] * 1000:.0f} 万円")

期待される結果（目安）

重みが4、バイアスが0.2に近づき、70 m²の価格が3000万円付近になることを期待します。数値は実行環境や最適化の進み方によって異なります。ここでは正確な実行ログではなく、理論上の目標値を示しています。

コード役割
Input(shape=(1,))一件あたり一つの数値を受け取る。
Dense(1)入力を重みとバイアスで変換し、一つの値を出力する。
compile()最適化方法と損失関数を指定する。
fit()訓練データを使ってパラメータを繰り返し更新する。
predict()学習済みモデルで新たな入力を予測する。
コード1.2　学習曲線の描画（コード1.1に続けて実行）
import matplotlib.pyplot as plt

plt.plot(range(1, len(history.history["loss"]) + 1), history.history["loss"])
plt.xlabel("Epoch")
plt.ylabel("Training loss (MSE)")
plt.yscale("log")
plt.grid(alpha=0.3)
plt.show()

横軸は学習の繰り返し回数（エポック）、縦軸は訓練損失です。損失がどの程度減少したかを確認してください。さらにエポック数を10や100に変更して、重みや予測価格がどう変わるかを観察しましょう。学習回数を増やせば必ず未知のデータへの性能も高くなる、というわけではありません。

この実験の限界

わずか三件の架空データから規則を学ばせる教材であり、実際の住宅価格の予測精度を検証したものではありません。70 m²の理論上の価格を求められても、それだけで汎化性能が確認できたとはいえません。

1.8 Kaggleで求められる力と、本書の歩き方

Kaggleはデータ分析や機械学習のコンペティションに参加できるプラットフォームです。典型的な予測コンペでは、正解付きの訓練データと、正解が非公開のテストデータが提供されます。参加者はテストデータに対する予測を指定の形式で提出し、主催者が定めた評価指標によって比較されます。

多くのコンペでは公開リーダーボード（Public Leaderboard）と最終順位に用いられる非公開部分（Private Leaderboard）が設けられています。公開スコアへの過度な最適化を避け、手元で信頼できる検証方法を構築することが大切です。コンペごとにルールや提出方式は異なります。

本書は、Pythonの基本文法に触れたことがある読者を想定します。数学は第3章から第5章で必要なところから学び直します。TensorFlowとKerasを用いる実装だけでなく、なぜその方法を選ぶのか、どのような場合に失敗するのかまで理解することが目標です。

1.9 本章のまとめと確認問題

  • 人工知能は広い研究領域であり、深層学習は機械学習の一領域である。
  • 学習はモデルのパラメータを調整すること、推論は学習済みモデルで出力を求めること。
  • 深層学習では多層の変換により有用な内部表現を学べる。
  • 学習方式は利用する学習信号によって区別される。
  • 回帰は数値、分類はカテゴリを予測する課題である。
  • 未知のデータでの性能を測り、過学習とデータリークを避けることが重要である。

確認問題

問1　AIと機械学習と深層学習の違いを説明せよ。

AIは知的機能の実現を目指す広い領域、機械学習はデータや経験から性能を改善する方法、深層学習は多層ニューラルネットワークによる表現学習を中心とする機械学習の一領域です。

問2　ラベルのない顧客データを購買傾向でグループ化する学習方式は何か。

教師なし学習です。正解グループが与えられず、データの構造を利用してグループを発見するクラスタリングに相当します。

問3　商品価格の予測、商品のカテゴリ判定、画像に含まれる複数の動物の判定はそれぞれ何か。

順に回帰、分類（排他的なカテゴリが3種類以上なら多クラス分類）、マルチラベル分類（動物の種類ごとの有無を予測する場合）です。位置も予測するなら物体検出になります。

問4　訓練データで100%正解したモデルが優れているとは限らない理由は何か。

訓練データを暗記しただけの過学習の可能性があるためです。独立した検証・テストデータで汎化性能を確認する必要があります。

問5　コード1.1で学習するパラメータは何か。換算後の理論値も答えよ。

Dense層の重みとバイアスです。入力を100 m²単位、価格を1000万円単位にしたので、理論値は重み4、バイアス0.2です。

発展演習

コード1.1の訓練データに [1.0]、価格 [4.5] を追加し、予測された重みとバイアスがどのように変化するか調べてください。追加したデータは従来の直線上にはないため、すべての点を同時に誤差ゼロにすることはできません。

考え方と理論上の解

最小二乗法で求める直線は重み4.45、バイアス−0.04です。入力の平均は0.7、目標値の平均は3.075であり、傾きは偏差積の和0.89を入力の偏差平方和0.20で割った値です。70 m²の予測価格は3075万円となります。最適化で得られる値はこれらに近づくことが期待されますが、完全に一致するとは限りません。
