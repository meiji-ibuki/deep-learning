10.1 損失関数の役割

第8章でモデルの出力を、第9章で活性化関数を学びました。しかし、予測値が得られただけでは、重みをどちらに更新すべきかは決まりません。損失関数（loss function）は、予測と正解のずれを数値化し、最適化の目標を定める関数です。

住宅価格の真値が3,000万円、予測が3,200万円なら、誤差は200万円です。誤差をそのまま平均すると正負が打ち消し合うため、絶対値や二乗などを用います。分類では、正解クラスにどれほど高い確率を割り当てたかを評価します。

$$\hat y_i=f_\theta(x_i),\qquad J(\theta)=\frac1N\sum_{i=1}^N\ell(y_i,\hat y_i)$$

$\ell$ は1標本の損失、$J$ はデータ全体の平均損失、$\theta$ は学習可能なパラメータです。ミニバッチではそのバッチの平均を使って勾配を推定します。正則化項 $\lambda R(\theta)$ を加えたものを目的関数と呼ぶ場合もあります。

評価指標（metric）は性能を測る物差しです。学習に使う損失と一致する必要はありません。例えばAccuracyは閾値をまたぐと離散的に変化するため、通常は交差エントロピーを最小化します。

10.2 回帰の損失関数：MSE・MAE・RMSE

残差を $e_i=\hat y_i-y_i$ と定義します。平均二乗誤差（MSE）、平均絶対誤差（MAE）、二乗平均平方根誤差（RMSE）は次のように定義されます。

$$\mathrm{MSE}=\frac1N\sum_i e_i^2,\quad \mathrm{MAE}=\frac1N\sum_i |e_i|$$ $$\mathrm{RMSE}=\sqrt{\frac1N\sum_i e_i^2}$$

MSEは大きな誤差を強く罰します。MAEは誤差に比例するため外れ値の影響が比較的小さく、RMSEは目的変数と同じ単位で解釈できます。固定された同一データ上でMSEとRMSEの最小解は一致しますが、ミニバッチごとのRMSE平均は全データのRMSEとは一般に異なります。

例えば残差が $[1,-2,3]$ のとき、MSEは $14/3$、MAEは2、RMSEは約2.160です。微分はMSEで $2e_i/N$、MAEで $\operatorname{sign}(e_i)/N$（ゼロ以外）となります。MAEの原点は微分不能ですが、実装では劣勾配の一つを選びます。

コード10.1　回帰損失を手計算と照合
import numpy as np
y = np.array([2., 4., 6.])
pred = np.array([3., 2., 9.])
e = pred - y
mse = np.mean(e**2)
mae = np.mean(np.abs(e))
rmse = np.sqrt(mse)
print(mse, mae, rmse)
assert np.isclose(mse, 14/3) and np.isclose(mae, 2)

10.3 Huber Lossと外れ値への耐性

Huber Lossは小さな誤差には二乗、大きな誤差には線形の罰則を適用します。閾値 $\delta>0$ は目的変数の単位に依存します。

$$\ell_\delta(e)=\begin{cases}\frac12e^2 & |e|\le\delta\\ \delta(|e|-\frac12\delta)& |e|>\delta\end{cases}$$ $$\ell'_\delta(e)=\begin{cases}e & |e|\le\delta\\ \delta\operatorname{sign}(e)& |e|>\delta\end{cases}$$

境界でも値と一階微分が連続します。大きな残差による勾配の影響が上限 $\delta$ に抑えられるため、ラベルに異常値が混じる場合の候補になります。ただし、大きな値が業務上重要なら、無条件に外れ値を抑えるべきではありません。

定数モデルを $[1,2,3,4,20]$ に当てはめるとMSEの最小点は平均6、MAEの最小点は中央値3です。Huber（δ=1）の最小点は3.0となります。各残差を[−1,1]に切り詰めた勾配の合計が0になるためです。有限な二次モーメントの下でMSEの期待損失を最小化する値は条件付き平均、有限な一次絶対モーメントの下でMAEの最小解は条件付き中央値です（モデルの表現力に制約がない場合）。

コード10.2　外れ値の影響を確認
import numpy as np
y = np.array([1., 2., 3., 4., 20.])
grid = np.linspace(0, 10, 10001)
e = grid[:, None] - y[None, :]
huber = np.where(abs(e) <= 1, .5*e**2, abs(e)-.5)
for name, loss in [('MSE', e**2), ('MAE', abs(e)), ('Huber', huber)]:
    print(name, grid[np.argmin(loss.mean(axis=1))])

10.4 二値分類とBinary Cross Entropy

二値分類の正解 $y\in\{0,1\}$、正例確率 $p$ に対して、二値交差エントロピー（BCE）を定義します。

$$\ell(y,p)=-y\log p-(1-y)\log(1-p)$$

正例なら $-\log p$、負例なら $-\log(1-p)$ です。正解への確信が高いほど損失は小さく、誤った確信には大きな罰則が課されます。第5章のベルヌーイ分布の負の対数尤度と同じ式です。自然対数を用います。式は0<p<1で有限であり、端点は極限で定義します（正解に確率0を割り当てれば損失は無限大）。

ロジット $z$ から $p=\sigma(z)$ とすると、連鎖律より $\partial\ell/\partial z=p-y$ となります。実際に $\partial\ell/\partial p=(p-y)/(p(1-p))$ と $dp/dz=p(1-p)$ を掛けると分母が消えます。これは出力層の逆伝播で頻出する式です。

コード10.3　BCEとロジット勾配
import numpy as np
z = np.array([-2., 0., 2.])
y = np.array([0., 1., 1.])
p = 1/(1+np.exp(-z))
loss = -y*np.log(p) - (1-y)*np.log1p(-p)
print(loss, p-y)
print(loss.mean())

10.5 多クラス分類とCategorical Cross Entropy

互いに排他的な $K$ クラスを分類するときはSoftmaxで確率分布を作ります。One-hotラベル $y_k$ と予測確率 $p_k$ の交差エントロピーは次式です。

$$p_k=\frac{\exp z_k}{\sum_j\exp z_j},\qquad \ell=-\sum_{k=1}^{K}y_k\log p_k$$

正解クラスを $c$ とすれば $\ell=-\log p_c$ です。例えば正解がクラスB、確率が $(0.2,0.7,0.1)$ なら損失は約0.357です。Sparse Categorical Cross Entropyは整数クラスIDから同じ損失を計算します。Sparseは疎な入力特徴量という意味ではありません。

形式正解の例予測のshapeKerasの損失
One-hot[0,1,0](B,K)CategoricalCrossentropy
整数ID1(B,K)SparseCategoricalCrossentropy

バッチ全体ではOne-hotは通常 $(B,K)$、整数IDは $(B,)$ です。Softmaxと交差エントロピーを組み合わせたロジットの勾配は $\partial\ell/\partial z_k=p_k-y_k$ です。Softmaxのヤコビ行列 $\partial p_j/\partial z_k=p_j(\mathbf1_{j=k}-p_k)$ を用いて導出できます。

コード10.4　One-hotと整数IDの等価性
import numpy as np
p = np.array([[.2,.7,.1], [.8,.1,.1]])
y = np.array([1,0])
onehot = np.eye(3)[y]
a = -(onehot*np.log(p)).sum(axis=1)
b = -np.log(p[np.arange(len(y)), y])
np.testing.assert_allclose(a,b)
print(a, a.mean())

10.6 マルチラベル分類と出力層の設計

一枚の画像に犬と猫が同時に写るような場合、クラスは排他的ではありません。各ラベルに個別のSigmoid出力を用い、BCEをラベル方向に集約します。各出力の確率の和は1でなくても構いません。これはラベル間の統計的独立性を保証するものではありません。

タスク出力shape出力の意味損失
回帰(B,D)連続値MSE / MAE / Huber
二値分類(B,1)正例ロジットBCE
多クラス分類(B,K)クラス別ロジットCCE / Sparse CCE
マルチラベル(B,K)ラベル別ロジットBCE

分類の表は出力層に活性化を付けず、損失に from_logits=True を指定する設計です。確率を出力する設計も可能ですが、その場合はFalseにします。ラベルのdtype、shape、クラスIDの範囲を必ず確認しましょう。

クラス不均衡では重み付き損失を用いることがあります。正例に大きな重みを付けると勾配への寄与が増えますが、予測確率の校正や閾値にも影響します。Focal Lossについては第31章および付録Dを参照してください。

10.7 Logitsと数値安定性

確率を明示的に計算してから対数を取ると、浮動小数点の丸めによって $\log 0$ が発生することがあります。BCEをロジットから計算する場合、次の等価式が安定です。

$$\ell(y,z)=\max(z,0)-yz+\log(1+\exp(-|z|))$$

多クラス分類では $\ell=\operatorname{logsumexp}(z)-z_c$ とし、最大値 $m$ を引いて指数演算を行います。

$$\operatorname{logsumexp}(z)=m+\log\sum_k\exp(z_k-m)$$
コード10.5　極端なロジットでも安定な計算
import numpy as np
z = np.array([-1000., 0., 1000.])
y = np.array([1., 1., 0.])
loss = np.maximum(z,0) - y*z + np.log1p(np.exp(-abs(z)))
print(loss)  # [1000., 0.693..., 1000.]
assert np.isfinite(loss).all()
a = np.array([1000.,1001.,999.])
m = a.max()
print(m + np.log(np.exp(a-m).sum()) - a[1])

注意：SigmoidやSoftmaxを適用済みの確率に対し、さらに from_logits=True として扱うのは誤りです。逆に、未変換のロジットにFalseを指定するのも誤りです。

10.8 損失の集約・評価指標・Kaggleでの選択

損失には標本内の集約とバッチ内の集約があります。例えば多出力MSEは通常、各標本の出力軸を平均してから標本方向を平均します。標本重みを付ける場合、$\sum_i w_i\ell_i/\sum_i w_i$ と $\sum_i w_i\ell_i/B$ は異なる定義です。Kerasの既定の sum_over_batch_size と重み合計による正規化（Keras 3の mean_with_sample_weight）を混同しないようにしましょう。ここでは標本ごとにスカラー損失を持つ場合を想定します。

コンペの評価指標が必ずしも微分可能とは限りません。AccuracyやF1、AUCを直接最適化する代わりにBCEなどを代理損失として用い、検証データ上で本来の評価指標を計算します。RMSEはfoldのRMSEを単純平均するより、OOF予測全体から計算する方が全標本を同じ重みで評価できます。

評価指標学習損失の候補注意点
RMSEMSE単位・外れ値
MAEMAE / Huber中央値・δ
Log LossBCE / CCE確率校正
Accuracy / F1BCE / CCE閾値は検証データで選択
ROC-AUCBCE順位の評価と確率の評価は異なる
コード10.6　集約方法の違い
import numpy as np
loss = np.array([1., 4., 9.])
w = np.array([1., 1., 3.])
print(np.mean(w*loss))       # 10.666...
print(np.average(loss, weights=w))  # 6.4
# foldのサイズが異なる場合
squared = [np.array([1., 9.]), np.array([4.])]
print(np.sqrt(np.concatenate(squared).mean()))
print(np.mean([np.sqrt(a.mean()) for a in squared]))

損失の値を比較する際は、同じ損失関数・集約・データを使います。MSEとMAEの値が小さい方を直接選ぶことはできません。学習損失と検証指標の両方を記録しましょう。

10.9 TensorFlowによる実装と比較実験

まず固定された予測値を用いてKerasの損失を検算します。reduction="none" は標本ごとの損失を返しますが、通常は出力軸の集約は行われます。

コード10.7　Kerasの損失と勾配
import tensorflow as tf
import numpy as np
y = tf.constant([[1.], [0.]])
z = tf.Variable([[2.], [-1.]])
loss_fn = tf.keras.losses.BinaryCrossentropy(from_logits=True)
with tf.GradientTape() as tape:
    loss = loss_fn(y, z)
g = tape.gradient(loss, z)
np.testing.assert_allclose(g.numpy(), (tf.sigmoid(z)-y).numpy()/2, atol=1e-6)
print(loss.numpy(), g.numpy())
labels = tf.constant([1,0])
logits = tf.constant([[0.,2.,1.],[2.,0.,1.]])
a = tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True)(labels, logits)
b = tf.keras.losses.CategoricalCrossentropy(from_logits=True)(tf.one_hot(labels,3), logits)
np.testing.assert_allclose(a.numpy(), b.numpy(), atol=1e-6)

実践：外れ値を含む回帰問題

同じデータ分割、構造、初期値、学習率、エポック数でMSE・MAE・Huberを比較します。訓練ラベルにのみ人工的な異常値を追加し、検証・テストは通常の分布に保ちます。この設定は訓練データのラベル汚染を想定した実験であり、実世界で常に成り立つ条件ではありません。

コード10.8　損失関数の比較実験
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error
rng = np.random.default_rng(42)
X = rng.uniform(-2,2,(1200,1)).astype('float32')
y = (2*X + .5 + rng.normal(0,.2,X.shape)).astype('float32')
X_dev,X_te,y_dev,y_te = train_test_split(X,y,test_size=.2,random_state=42)
X_tr,X_va,y_tr,y_va = train_test_split(X_dev,y_dev,test_size=.25,random_state=42)
y_bad = y_tr.copy()
idx = rng.choice(len(y_bad),size=len(y_bad)//10,replace=False)
y_bad[idx] += 10
losses = {'MSE':tf.keras.losses.MeanSquaredError(),
          'MAE':tf.keras.losses.MeanAbsoluteError(),
          'Huber':tf.keras.losses.Huber(delta=1.)}
scores = {}
for name, loss in losses.items():
    tf.keras.backend.clear_session()
    tf.keras.utils.set_random_seed(42)
    model = tf.keras.Sequential([tf.keras.Input(shape=(1,)),tf.keras.layers.Dense(1)])
    model.compile(optimizer=tf.keras.optimizers.Adam(.02),loss=loss,
                  metrics=[tf.keras.metrics.MeanAbsoluteError(name='mae')])
    hist = model.fit(X_tr,y_bad,validation_data=(X_va,y_va),epochs=60,batch_size=32,verbose=0)
    pred = model.predict(X_va,verbose=0)
    scores[name] = (mean_absolute_error(y_va,pred),model.get_weights())
    plt.plot(np.arange(1, len(hist.history['val_mae'])+1), hist.history['val_mae'],label=name)
    print(name, scores[name][0], np.sqrt(mean_squared_error(y_va,pred)))
plt.xlabel('Epoch'); plt.ylabel('Validation MAE'); plt.legend(); plt.show()
best = min(scores,key=lambda k:scores[k][0])
model = tf.keras.Sequential([tf.keras.Input(shape=(1,)),tf.keras.layers.Dense(1)])
model.set_weights(scores[best][1])
print('Selected:',best,'Test MAE:',mean_absolute_error(y_te,model.predict(X_te,verbose=0)))

比較には共通の検証MAEを使います。訓練損失の絶対値は直接比較しません。次に汚染率やHuberのδを変更し、複数の乱数シードでも結果を確認しましょう。テストデータは選択完了後の評価にのみ使います。TensorFlow実測結果は掲載していません。

10.10 まとめと確認問題

損失関数は学習の目的を決めます。出力の意味、正解ラベルの形式、数値安定性、評価指標との関係を一体として設計しましょう。

問1　残差が1と−3の場合のMSE・MAE・RMSEは？

MSE=(1²+(-3)²)/2=5、MAE=(1+3)/2=2、RMSE=√5≈2.2361。

問2　MSEとMAEの外れ値への反応の違いは？

標本損失の残差に関する微分は二乗誤差で2e、絶対誤差でsign(e)（e≠0）。後者の微分の絶対値は1であり、損失そのものが一定なのではない。

問3　δ=1、残差3のHuber Lossは？

1×(3−0.5)=2.5。

問4　正例に確率0.8を与えたBCEは？

−log(0.8) ≈ 0.2231。

問5　整数IDとOne-hotのどちらにSparse CCEを使う？

整数ID。

問6　マルチラベル分類にSoftmaxが通常不適切なのは？

複数ラベルが同時に正例となり、確率和1という制約が不要だから。

問7　出力層が線形でBCEを使う場合の設定は？

from_logits=True。

問8　F1を競うコンペでBCEを使ってもよいか？

よい。検証データでF1を測り、必要に応じ閾値を選ぶ。

発展演習：BCEの勾配チェック

安定なロジット版BCEを中央差分で微分し、解析解と比較してください。第4章の数値微分を復習します。

解答・実装例
コード10.9　BCEの勾配チェック
import numpy as np
z = np.linspace(-8,8,101)
y = (z > 0).astype(float)
f = lambda z: np.logaddexp(0,z)-y*z
h = 1e-5
numeric = (f(z+h)-f(z-h))/(2*h)
analytic = 1/(1+np.exp(-z))-y
np.testing.assert_allclose(numeric,analytic,atol=1e-8)
print(np.max(abs(numeric-analytic)))

独立検算（float64）：h=1e-05で最大絶対誤差3.96e-11。刻み幅を小さくし過ぎると丸め誤差の影響が増えることがあります。
