35.1 転移学習の問題設定

第30章では画像分類に事前学習済みCNNを利用した。本章ではその背後にある学習戦略を一般化する。転移学習（transfer learning）とは、あるデータや課題で獲得した知識を別の課題に再利用することである。元の課題をソース、目的の課題をターゲットと呼ぶ。

入力 $x$ を特徴抽出器 $f_\theta$ で表現 $z$ に変換し、予測器 $g_\phi$ で出力する。

$$z=f_\theta(x),\qquad \hat y=g_\phi(z)$$

ソースで得た $\theta_s$ をターゲットの初期値として利用すれば、ランダム初期化から学習するより少ない教師データで有用な特徴を使える場合がある。ただし分布や課題が異なると負の転移（negative transfer）が起きることもある。転移の有効性は検証データで判断する。

35.2 特徴抽出とファインチューニング

特徴抽出では $\theta=\theta_s$ を固定し、新しいヘッドだけを最適化する。ファインチューニングでは特徴抽出器の一部または全部も更新する。

$$\min_\phi L_t(\theta_s,\phi),\qquad \min_{\theta,\phi}L_t(\theta,\phi)$$

後者の初期値は前者で学習したヘッドと事前学習済み重みであることが多い。初期のランダムなヘッドによる大きな勾配で有用な表現を壊す危険を減らすためである。

方式更新する部分利点と制約
Scratch全層ソース依存なし、データと計算が必要
Linear probe線形ヘッド表現から線形モデルで予測できる程度を評価
特徴抽出ヘッドのみ高速、表現の適応は不可
部分FT上位ブロックとヘッド過学習と適応の折衷
全層FT全層柔軟、計算量と忘却リスク

35.3 事前学習済みモデルの選択

モデルの選択では事前学習のデータ、入力サイズ・色順・正規化、出力特徴の次元、利用条件、推論コストを調べる。画像ではImageNetで学習したMobileNetV2やResNet、文章では第32章のBERT、音声では波形やスペクトログラムに対応したエンコーダが候補となる。目的データと近い事前学習が常に最良とは限らない。

データが少なくソースと近い場合は固定特徴から開始し、データが多い場合や分布が異なる場合は部分FTから全層FTへ比較範囲を広げる。入力の正規化はモデルごとの仕様に従う。MobileNetV2では0〜255の画素を−1〜1へ写すが、別のモデルに同じ処理を無条件に適用してはいけない。

35.4 実践：データ準備とベースライン

ここからはCIFAR-10の小標本を使う連続した実習である。訓練は各クラス200枚、検証は各クラス100枚、公式テストは最後まで保持する。画像を96×96に拡大してMobileNetV2へ渡す。拡大は情報を増やす処理ではない。コード35.1〜35.3を順番に実行する。データと重みの初回取得にネット接続が必要である。

コード35.1　データ分割と入力パイプライン
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
keras.utils.set_random_seed(35)
(x,y),(xt,yt)=keras.datasets.cifar10.load_data()
y=y.ravel(); yt=yt.ravel()
rng=np.random.default_rng(35)
tr=[]; va=[]
for c in range(10):
    ids=rng.permutation(np.flatnonzero(y==c))
    tr.extend(ids[:200]); va.extend(ids[200:300])
assert not set(tr)&set(va)
def dataset(x,y,train=False):
    ds=tf.data.Dataset.from_tensor_slices((x,y))
    if train: ds=ds.shuffle(len(y),seed=35)
    return ds.batch(32).prefetch(tf.data.AUTOTUNE)
train=dataset(x[tr],y[tr],True)
val=dataset(x[va],y[va])
test=dataset(xt,yt)
def build(weights,freeze):
    base=keras.applications.MobileNetV2(input_shape=(96,96,3),
        include_top=False,weights=weights)
    base.trainable=not freeze
    inp=keras.Input((32,32,3))
    z=layers.Resizing(96,96)(inp)
    z=layers.RandomFlip('horizontal')(z)
    z=layers.Rescaling(1/127.5,offset=-1)(z)
    z=base(z,training=False) if freeze else base(z)
    z=layers.GlobalAveragePooling2D()(z)
    z=layers.Dropout(.2)(z)
    return keras.Model(inp,layers.Dense(10)(z)),base
def fit_stage(model,lr,epochs):
    model.compile(optimizer=keras.optimizers.Adam(lr),
        loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
        metrics=['accuracy'])
    return model.fit(train,validation_data=val,epochs=epochs,
        callbacks=[keras.callbacks.EarlyStopping(monitor='val_loss',
            patience=3,restore_best_weights=True)])

35.5 実践：特徴抽出と段階的な凍結解除

比較対象は同じ骨格をランダム初期化したモデルと、ImageNet重みを固定したモデルである。次に後段ブロックを解凍する。解凍前のヘッド学習済み重みを保存しておくことで、検証性能が悪化した場合に戻せる。下記の学習率やエポック数は出発点であり、検証集合だけで選ぶ。

コード35.2　Scratchと固定特徴の比較
scratch,_=build(None,False)
h_scratch=fit_stage(scratch,1e-3,20)
model,base=build('imagenet',True)
h_probe=fit_stage(model,1e-3,10)
probe_weights=model.get_weights()
probe_loss=float(model.evaluate(val,verbose=0)[0])
scratch_loss=float(scratch.evaluate(val,verbose=0)[0])
print('validation loss',scratch_loss,probe_loss)
コード35.3　部分FT・検証による選択・最終評価
base.trainable=True
for layer in base.layers:
    layer.trainable=False
for layer in base.layers[-30:]:
    if not isinstance(layer,layers.BatchNormalization):
        layer.trainable=True
h_ft=fit_stage(model,1e-5,10)  # 再compile、新しいoptimizer
ft_loss=float(model.evaluate(val,verbose=0)[0])
if ft_loss>probe_loss:
    model.set_weights(probe_weights)
    base.trainable=False
    model.compile(optimizer=keras.optimizers.Adam(1e-3),
        loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
        metrics=['accuracy'])
selected=model if min(ft_loss,probe_loss)<=scratch_loss else scratch
print('final test',selected.evaluate(test,verbose=0))
selected.save('chapter35_selected.keras')

実験比較では同一データ・指標を使い、探索予算や計算時間も記録する。上のコードは教育用の単一シードであり、実務では複数シードで再評価する。テスト結果を見て再選択しない。

35.6 層別学習率とカスタム学習

新しいヘッドと事前学習済み層で異なる学習率を使う層別学習率（discriminative learning rates）は、下位表現を保ちつつ上位を適応させる方法である。

$$\theta_{l,t+1}=\theta_{l,t}-\eta_l\nabla_{\theta_l}L$$

Adamで勾配を単に定数倍しても、一次・二次モーメントの正規化により学習率を変えた効果とは一般に一致しない。別々のoptimizerを使う方法を示す。下記はコード35.1の後に独立して実行する小さな例で、ヘッドを先に学習してから解凍する。各optimizerには固定した変数集合を渡す。

コード35.4　二つのoptimizerを使うカスタム学習
m,b=build('imagenet',True)
fit_stage(m,1e-3,5)
b.trainable=True
for layer in b.layers:
    layer.trainable=False
for layer in b.layers[-30:]:
    if not isinstance(layer,layers.BatchNormalization):
        layer.trainable=True
v_base=list(b.trainable_variables)
base_ids={id(v) for v in v_base}
v_head=[v for v in m.trainable_variables if id(v) not in base_ids]
assert v_base and v_head
opt_b=keras.optimizers.Adam(1e-5)
opt_h=keras.optimizers.Adam(1e-4)
loss_fn=keras.losses.SparseCategoricalCrossentropy(from_logits=True)
for epoch in range(3):
    for xb,yb in train:
        with tf.GradientTape() as tape:
            loss=loss_fn(yb,m(xb,training=True))
        grads=tape.gradient(loss,v_base+v_head)
        n=len(v_base)
        opt_b.apply_gradients(zip(grads[:n],v_base))
        opt_h.apply_gradients(zip(grads[n:],v_head))
    vloss=keras.metrics.Mean()
    for xb,yb in val:
        vloss.update_state(loss_fn(yb,m(xb,training=False)),
                           sample_weight=tf.cast(tf.shape(yb)[0],tf.float32))
    print(epoch,float(vloss.result()))

35.7 Batch Normalizationと状態管理

第19章のBatch Normalization（BN）は学習可能な $\gamma,\beta$ と移動平均・移動分散を持つ。固定した重みが変わらなくても、学習モードで状態が更新される層が存在する。Kerasの trainable は重み更新の可否、training は順伝播の動作モードであり、通常は別概念である。BNでは trainable=False が推論モードにも結びつく特例がある。

小標本FTではBN統計を保持するため、上のモデルでは事前学習済みbaseを training=False で呼び出し、BN層を固定する。これでも解凍した畳み込み層の勾配は伝わる。一方、ヘッドのDropoutや入力拡張は学習中だけ有効となる。ターゲットが大きく異なり十分なデータがあるならBNの再適応も比較候補だが、評価データを統計の更新に使わない。

コード35.5　凍結した重みと状態を検査する（コード35.2の固定段階で実行）
check,enc=build('imagenet',True)
before=[v.numpy().copy() for v in enc.weights]
check.compile(optimizer='adam',loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True))
xb,yb=next(iter(train))
check.train_on_batch(xb,yb)
for old,v in zip(before,enc.weights):
    np.testing.assert_array_equal(old,v.numpy())
print('encoder weights and BN state unchanged')

35.8 ドメインシフトとドメイン適応

ソースとターゲットの分布が異なる現象をドメインシフトと呼ぶ。共変量シフトは $p_s(x)\ne p_t(x)$ だが $p_s(y|x)=p_t(y|x)$ と仮定する。ラベルシフトはクラス事前確率の変化（典型的なラベルシフトでは $p_s(x|y)=p_t(x|y)$ を仮定）、概念シフトは条件付き分布の変化である。実際には複数が混在し得る。

共変量シフトの仮定とターゲット分布がソース分布に対して絶対連続であり、期待損失が有限の場合、重要度重み $w(x)=p_t(x)/p_s(x)$ を用いると

$$R_t(f)=\mathbb E_s[w(x)\ell(f(x),y)]$$

となる。密度比の推定誤差や極端な重みには注意が必要である。ドメイン適応の代表例には特徴統計の整合（CORAL）、ドメイン識別器を用いた敵対的学習（DANN）、高信頼予測を教師として再学習する擬似ラベルがある。CORALは共分散 $C_s,C_t$ の差 $\|C_s-C_t\|_F^2$ を縮めるが、クラスの意味まで一致する保証はない。擬似ラベルは誤りを増幅し得る。ターゲットのラベル付き検証集合を確保するのが望ましい。

35.9 自己教師あり学習と表現の再利用

自己教師あり学習は、観測データから教師信号を作る事前学習である。画像の異なる拡張を同一対象として扱う対照学習、マスクした入力の復元、時系列の未来表現の予測などがある。第28章のAEも入力自体を教師とする表現学習である。教師なし・自己教師あり・半教師ありを区別する。

対照学習の一例では、正例ペア $(i,j)$ の正規化埋め込みの類似度を高める。

$$L_i=-\log\frac{\exp(\operatorname{sim}(z_i,z_j)/\tau)}{\sum_{k\ne i}\exp(\operatorname{sim}(z_i,z_k)/\tau)}$$

$\tau>0$ は温度である。分母は正例を含む自己以外の候補の和である。負例の選び方や拡張が意味を保つことが重要で、同じクラスの別サンプルを負例とする問題もある。学習後は投影ヘッドを外し、エンコーダを下流分類へ転用する。

コード35.6　対照損失のNumPy実装（実行済み）
import numpy as np
from scipy.special import logsumexp
rng=np.random.default_rng(35)
a=rng.normal(size=(8,16)); b=a+rng.normal(0,.1,a.shape)
def contrastive(a,b,tau=.2):
    if a.ndim != 2 or a.shape != b.shape or len(a) == 0 or tau <= 0:
        raise ValueError("paired nonempty matrices and positive temperature required")
    z=np.concatenate([a,b]); z/=np.maximum(np.linalg.norm(z,axis=1,keepdims=True),1e-12)
    logits=z@z.T/tau
    np.fill_diagonal(logits,-np.inf)
    pos=(np.arange(len(z))+len(a))%len(z)
    return np.mean(logsumexp(logits,axis=1)-logits[np.arange(len(z)),pos])
print('matched',contrastive(a,b),'shuffled',contrastive(a,b[::-1]))
assert contrastive(a,b)<contrastive(a,b[::-1])

35.10 少数データでの比較実験

転移の効果を外部ダウンロードなしで確認するため、手書き数字の画像を0〜4（ソース）と5〜9（ターゲット）に分ける。ソースでPCAを学習して固定し、ターゲットの少数ラベルで線形分類器を学習する。比較対象は生画素とターゲットのみで適合したPCAである。これは深層学習の性能比較ではなく、固定表現の転移を理解するための線形実験である。

コード35.7　固定表現の転移を比較する数値実験（実行済み）
import numpy as np
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
X,y=load_digits(return_X_y=True); X=X/16
source=X[y<5]; target=X[y>=5]; labels=y[y>=5]
Xtr,Xte,ytr,yte=train_test_split(target,labels,test_size=.4,
    stratify=labels,random_state=35)
source_pca=PCA(10,random_state=35).fit(source)
results=[]
for k in (5,10,20,40):
    for seed in range(10):
        rng=np.random.default_rng(seed)
        ids=np.concatenate([rng.choice(np.flatnonzero(ytr==c),k,replace=False)
                            for c in range(5,10)])
        a,b=Xtr[ids],ytr[ids]
        local=PCA(10,random_state=35).fit(a)
        for name,transform in [('Raw',lambda x:x),('Source PCA',source_pca.transform),
                               ('Target PCA',local.transform)]:
            clf=LogisticRegression(max_iter=1000).fit(transform(a),b)
            results.append((k,seed,name,clf.score(transform(Xte),yte)))

この結果は固定したテスト集合で事前に定めた三方式を記述的に比較したもので、テストを使ったモデル選択は行わない。誤差棒は訓練標本抽出の変動であり、独立したテスト集合に対する信頼区間ではない。PCAは教師なしの線形表現なので、実際のCNNの転移性能へ直接一般化できない。

35.12 まとめと確認問題

転移学習は、事前学習で獲得した表現をターゲットのデータ量と分布に応じて再利用する技術である。固定特徴から始め、検証性能に基づいて段階的に解凍する。次章ではこの比較をさらに体系的なハイパーパラメータ探索へ発展させる。

問1　特徴抽出とFTの違いは？

前者はエンコーダ固定、後者は一部または全部を更新する。

問2　新しいヘッドを先に学習する理由は？

初期の大きな誤差信号で有用な表現を壊す危険を抑える。

問3　解凍後にcompileが必要な理由は？

更新対象の変化を学習処理に反映するため。

問4　training=Falseは勾配を止めるか？

止めない。主に順伝播の動作を指定する。

問5　Adamで勾配を0.1倍すれば学習率も0.1倍か？

一般には違う。モーメントによる正規化がある。

問6　負の転移を判定するには？

同じ分割・評価条件でScratchと比較する。

問7　擬似ラベルの危険は？

誤予測を教師として再学習し誤りを増幅する可能性。

問8　対照学習の温度を下げると？

類似度の差に敏感になる。小さすぎると学習が不安定になることもある。

問9　発展：5 FoldのFTを設計せよ。

開発データを5つの外側Foldに分け、各外側訓練集合の内部で検証集合を確保する。各Foldで同じ事前学習済み重みから開始し、内側検証で停止時点・解凍範囲を選ぶ。外側検証でOOF予測を作り、選択終了後に独立テストで最終モデルを評価する。
