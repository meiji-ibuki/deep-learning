8.1 多層ニューラルネットワークの構造

多層パーセプトロン（multilayer perceptron; MLP）は、複数の全結合層を順に接続したフィードフォワードニューラルネットワークです。現代のMLPは通常、ステップ関数ではなくReLUなどを用います。情報が入力から出力へ一方向に流れる計算を順伝播（forward propagation）と呼びます。

入力層は特徴量を受け取る場所であり、通常は学習可能な重みを持ちません。隠れ層は入力を中間表現へ変換し、出力層はタスクに必要な値を返します。全結合とは、ある層の各ユニットが直前の層のすべての出力を受け取ることです。

本書では重みを持つ層の数を深さと数え、上図を3層ネットワーク（隠れ層2層）と呼びます。入力層も数える流儀があるため、層数だけでなく構造を明記しましょう。各層のユニット数を幅と呼びます。

8.2 全結合層と行列演算

第3章の行列積を使えば、複数のニューロンと複数の標本を一度に処理できます。バッチサイズを $B$、第 $l$ 層の幅を $d_l$、入力特徴量数を $d_0$ とします。標本を行に並べるKerasの流儀に合わせ、$A^{(0)}=X$ と定義します。

$$Z^{(l)}=A^{(l-1)}W^{(l)}+b^{(l)},\qquad A^{(l)}=g_l(Z^{(l)})$$

重み $W^{(l)}$ は $(d_{l-1},d_l)$、バイアス $b^{(l)}$ は $(d_l,)$ です。バイアスはバッチ軸にブロードキャストされます。活性化関数を適用しても、ReLUのような要素ごとの関数ならshapeは変わりません。

テンソルshape意味
$X$(B, 2)入力
$W^{(1)}$(2, 4)第1層の重み
$b^{(1)}$(4,)各ユニットのバイアス
$A^{(1)}$(B, 4)第1層の出力
$W^{(2)}$(4, 2)第2層の重み
$A^{(2)}$(B, 2)第2層の出力
$W^{(3)}$(2, 1)出力層の重み
$A^{(3)}$(B, 1)予測値
コード8.1　shapeを追跡する
import numpy as np
X = np.ones((5, 2))
W = np.ones((2, 4))
b = np.array([0., 1., 2., 3.])
Z = X @ W + b
A = np.maximum(0, Z)
print(Z.shape, A.shape)  # (5, 4) (5, 4)
print(A[0])  # [2. 3. 4. 5.]

8.3 順伝播を手計算する

入力2、隠れ層2、出力1の小さなネットワークを考えます。隠れ層はReLU（$g(z)=\max(0,z)$）、出力層は恒等関数とします。

$$X=\begin{pmatrix}2&1\\0&3\end{pmatrix},\quad W^{(1)}=\begin{pmatrix}1&-1\\2&1\end{pmatrix},\quad b^{(1)}=(0,1)$$ $$Z^{(1)}=\begin{pmatrix}4&0\\6&4\end{pmatrix},\quad A^{(1)}=\begin{pmatrix}4&0\\6&4\end{pmatrix}$$

第1標本の第2ユニットは $2(-1)+1(1)+1=0$ です。第2層の重みとバイアスを次のように選ぶと、予測値は2と−1になります。

$$W^{(2)}=\begin{pmatrix}0.5\\-1\end{pmatrix},\quad b^{(2)}=0,\quad \hat Y=\begin{pmatrix}2\\-1\end{pmatrix}$$

このように各層は前の層の出力だけを使って計算できます。途中の値を保存すると、後の誤差逆伝播でも利用できます。

コード8.2　手計算とNumPyの照合
import numpy as np
X = np.array([[2., 1.], [0., 3.]])
W1 = np.array([[1., -1.], [2., 1.]])
b1 = np.array([0., 1.])
W2 = np.array([[0.5], [-1.]])
b2 = np.array([0.])
Z1 = X @ W1 + b1
A1 = np.maximum(0., Z1)
yhat = A1 @ W2 + b2
print(Z1, A1, yhat, sep="\n")
assert np.allclose(yhat, [[2.], [-1.]])

8.4 非線形性と表現能力

活性化関数を挟まずに全結合層を重ねても、表現できる関数の種類は増えません。

$$ (XW_1+b_1)W_2+b_2=X(W_1W_2)+(b_1W_2+b_2) $$

右辺は一つのアフィン変換です。隠れ層の幅が狭ければ、行列のランク制約により、むしろ表現できる変換が限られることもあります。非線形活性化関数を挟むことで、一般に単一のアフィン変換では表せない関数も表現できます。ただし重みの設定によってはアフィン関数になる場合もあります。

ReLUで折れ曲がる関数を作る

例えば $f(x)=\text{ReLU}(x)+\text{ReLU}(-x)$ は絶対値 $|x|$ を表します。2個の隠れユニットはそれぞれ正側と負側を担当し、出力層が合成します。さらに $f(x)=\text{ReLU}(x)-2\text{ReLU}(x-1)+\text{ReLU}(x-2)$ とすると、0から2の間だけ盛り上がる三角形の関数になります。

コード8.3　アフィン変換の合成と非線形変換
import numpy as np
rng = np.random.default_rng(42)
X = rng.normal(size=(8, 3))
W1 = rng.normal(size=(3, 4)); b1 = rng.normal(size=4)
W2 = rng.normal(size=(4, 2)); b2 = rng.normal(size=2)
linear = (X @ W1 + b1) @ W2 + b2
merged = X @ (W1 @ W2) + b1 @ W2 + b2
assert np.allclose(linear, merged)
nonlinear = np.maximum(X @ W1 + b1, 0) @ W2 + b2
print(np.allclose(nonlinear, merged))  # False

ReLUネットワークは入力空間を複数の領域に分け、各領域でアフィン関数として振る舞います。層を重ねると領域の構造が複雑になり得ます。ただし、すべての重みの設定で領域数が増えるわけではありません。

8.5 深さ・幅・パラメータ数

全結合層には入力数と出力数の積だけ重みがあり、出力数だけバイアスがあります。したがって総パラメータ数は次の式で求められます（全層でバイアスを使用する場合）。

$$P=\sum_{l=1}^{L}(d_{l-1}+1)d_l$$
構造重みバイアス合計
2 → 48412
4 → 28210
2 → 1213
合計18725

他の層の幅を固定して幅を増やすと、一度に保持できる中間特徴の数が増え、深さを増やすと変換を段階的に組み合わせられます。一方で、パラメータ数・計算量・中間活性化のメモリも増えます。全結合層の順伝播の積和演算量はおおむね $O(Bd_{l-1}d_l)$ です。float32の重みだけなら1要素4バイトですが、学習時は勾配、オプティマイザの状態、中間活性化も必要です。

コード8.4　パラメータ数を計算する
def count_params(widths):
    return sum((a + 1) * b for a, b in zip(widths[:-1], widths[1:]))
assert count_params([2, 4, 2, 1]) == 25
for width in [8, 32, 128, 512]:
    print(width, count_params([20, width, 1]))

幅や深さはハイパーパラメータです。大きくすれば必ず検証精度が上がるわけではありません。第6章の汎化性能の考え方に沿って、検証データで比較します。

8.6 出力層とタスクの対応

出力層は予測対象に合わせて設計します。隠れ層の活性化と出力層の活性化は役割が異なります。例えば回帰では負の値も出力できる恒等関数が一般的ですが、二値分類ではロジットをSigmoidで確率に変換します。

タスク出力shape出力の扱い代表的損失
単一値回帰(B, 1)恒等関数MSE / MAE
二値分類(B, 1)ロジット → SigmoidBinaryCrossentropy
多クラス分類(B, C)ロジット → SoftmaxSparseCategoricalCrossentropy（整数ラベル）
マルチラベル分類(B, C)各ロジット → SigmoidBinaryCrossentropy
多出力回帰(B, K)恒等関数MSE / MAE

多クラス分類のクラスは排他的で、Softmaxの出力の和は1です。マルチラベル分類では複数のラベルが同時に成立するため、各ラベルの周辺確率の推定値を個別に計算します。ラベル同士の統計的独立性を意味するわけではありません。ロジットを損失関数へ直接渡す場合は from_logits=True とし、出力層にSigmoidやSoftmaxを重ねないようにします。

8.7 万能近似定理と深層化の意味

万能近似定理（universal approximation theorem）は、一定の条件を満たす活性化関数を用いた隠れ層1層のネットワークでも、十分な幅があればコンパクト集合上の連続関数を任意の精度で一様近似できる、という存在定理です。ReLUも適切な定理の条件を満たします。

$$\forall \varepsilon>0,\quad \exists m,\theta: \sup_{x\in K}|f(x)-f_\theta(x)|<\varepsilon$$

ここで $K$ は有限次元の実数空間のコンパクト集合、$f$ はその上の実数値連続関数、$m$ は隠れ層の幅、$\theta$ は重みとバイアスです。出力層は恒等関数とします。この定理は必要な幅が小さいこと、有限データから学習できること、勾配降下法が適切な解に到達すること、未知データで汎化することを保証しません。

区分線形関数による近似

1次元では、ReLUの折れ曲がりを足し合わせて折れ線を作れます。昇順の節点 $t_0\lt t_1\lt\cdots\lt t_m$ に対し、$s_i$ を区間 $[t_i,t_{i+1}]$ の傾きとします。節点 $t_i$ で傾きが $s_{i-1}$ から $s_i$ に変わるなら、その差をReLUの係数にします。

$$f_m(x)=a+s_0x+ \sum_{i=1}^{m-1}(s_i-s_{i-1})\max(0,x-t_i)$$

ここで $a=f_m(t_0)-s_0t_0$ です。この式には直接の線形項がありますが、$x=\text{ReLU}(x)-\text{ReLU}(-x)$ と書けば通常の1隠れ層MLPでも表現できます。以下は $\sin x$ の折れ線近似で、万能近似定理の一般的な証明ではなく直感を示す例です。

コード8.5　ReLU基底による折れ線近似
import numpy as np
x = np.linspace(0, 2*np.pi, 1001)
for m in [4, 12, 32]:
    t = np.linspace(0, 2*np.pi, m+1)
    y = np.sin(t)
    slopes = np.diff(y) / np.diff(t)
    basis = np.maximum(x[:, None] - t[None, 1:-1], 0)
    approx = y[0] + slopes[0]*(x-t[0]) + basis @ np.diff(slopes)
    print(m, np.max(np.abs(approx - np.sin(x))))
    assert np.allclose(approx, np.interp(x, t, y))

コード8.5の1001点上の最大絶対誤差は、4・12・32区間でそれぞれ約0.21051、0.03292、0.00479です（連続区間全体の厳密な最大値ではありません）。

ではなぜ深くするのでしょうか。関数によっては階層的に部品を再利用する方が、浅いネットワークより少ないユニットやパラメータで表現できます。画像なら輪郭から形状へという階層的な特徴の組み合わせが一例です。ただし深くするほど最適化が難しくなる場合もあり、第19章で初期化や正規化を学びます。

8.8 NumPyによる汎用的な順伝播

層数を固定せず、重みとバイアスのリストを順に処理する関数を作ります。最後の層だけ恒等関数を使い、各層のshapeを確認できるようにします。このコードは順伝播のみで、重みを学習する処理は第12章で扱います。

コード8.6　任意の層数に対応するNumPy実装
import numpy as np
def forward(X, params):
    A = np.asarray(X)
    if A.ndim != 2:
        raise ValueError("X must be a 2D batch")
    activations = [A]
    for i, (W, b) in enumerate(params):
        if W.ndim != 2 or A.shape[1] != W.shape[0] or b.shape != (W.shape[1],):
            raise ValueError(f"shape mismatch at layer {i+1}")
        Z = A @ W + b
        A = np.maximum(Z, 0) if i < len(params)-1 else Z
        activations.append(A)
    return A, activations
rng = np.random.default_rng(42)
widths = [3, 8, 4, 1]
params = [(rng.normal(size=(a,b))*np.sqrt(2/a), np.zeros(b))
          for a,b in zip(widths[:-1], widths[1:])]
X = rng.normal(size=(5, 3))
pred, acts = forward(X, params)
print([a.shape for a in acts])  # [(5, 3), (5, 8), (5, 4), (5, 1)]

コード8.7はコード8.6に続けて実行します。注意したいのは、1標本でもバッチ軸を残して X[0:1] のように入力することです。また、回帰の予測値と正解のshapeを一致させないと、ブロードキャストによる誤った損失計算が発生します。

コード8.7　バッチ軸と損失のshapeを確認する
one, _ = forward(X[0:1], params)
assert one.shape == (1, 1)
y = np.arange(5, dtype=float).reshape(-1, 1)
assert pred.shape == y.shape
mse = np.mean((pred-y)**2)
print(mse)
print((pred-y.ravel()).shape)  # (5, 5): 意図しない計算

実践：非線形な回帰問題

次は人工データ $y=|x|+\epsilon$ を使い、線形モデルとMLPを比較します。第6章の手順に沿って訓練・検証・テストに分割し、検証損失によって最良エポックの重みを復元します。テストデータは最後の評価だけに用います。入力範囲の外側への外挿能力はこの実験では評価しません。

コード8.9　線形モデルとMLPを比較する
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
tf.keras.utils.set_random_seed(42)
rng = np.random.default_rng(42)
X = rng.uniform(-2, 2, size=(1200, 1)).astype("float32")
y = (np.abs(X) + rng.normal(0, .08, X.shape)).astype("float32")
Xt, Xtest, yt, ytest = train_test_split(X, y, test_size=.2, random_state=42)
Xtr, Xv, ytr, yv = train_test_split(Xt, yt, test_size=.25, random_state=42)
grid = np.linspace(-2, 2, 200, dtype="float32")[:, None]
models, histories = {}, {}
for name, widths in [("linear", []), ("MLP", [16, 16])]:
    net = tf.keras.Sequential([tf.keras.Input(shape=(1,))] +
        [tf.keras.layers.Dense(w, activation="relu") for w in widths] +
        [tf.keras.layers.Dense(1)])
    net.compile(optimizer=tf.keras.optimizers.Adam(.01), loss="mse", metrics=["mae"])
    hist = net.fit(Xtr, ytr, validation_data=(Xv, yv), epochs=150,
                   batch_size=32, verbose=0, callbacks=[
        tf.keras.callbacks.EarlyStopping(monitor="val_loss", patience=15,
                                       restore_best_weights=True)])
    models[name], histories[name] = net, hist.history
    print(name, net.evaluate(Xtest, ytest, verbose=0, return_dict=True))
plt.scatter(Xtest.ravel(), ytest.ravel(), s=8, alpha=.25, label="test")
for name, net in models.items():
    plt.plot(grid.ravel(), net(grid, training=False).numpy().ravel(), label=name)
plt.plot(grid.ravel(), np.abs(grid.ravel()), "--", label="true")
plt.legend(); plt.xlabel("x"); plt.ylabel("y"); plt.show()
for name, h in histories.items():
    plt.plot(np.arange(1, len(h["val_loss"])+1), h["val_loss"], label=name)
plt.xlabel("epoch"); plt.ylabel("validation MSE"); plt.legend(); plt.show()

一様分布 $x\sim U(-2,2)$ に対し、独立で平均0のノイズを仮定した母集団MSEの最適な直線は、対称性から傾き0、切片 $E[|x|]=1$ です。傾きは $\operatorname{Cov}(x,|x|)/\operatorname{Var}(x)=0$ です。ノイズなしの場合の最小MSEは $\operatorname{Var}(|x|)=1/3$ です。一方MLPは絶対値を表現できるので、適切に学習できればより小さな誤差が期待できます。実際の学習結果は実行環境や初期値によって異なるため、上図は理論上の比較であり、実測値ではありません。

分類モデルへの変更

出力層と損失を変更すれば、同じ隠れ層を分類にも利用できます。次の例はscikit-learnのアヤメデータを用いた3クラス分類です。標準化は訓練データだけで学習します。

コード8.10　多クラス分類のMLP
import tensorflow as tf
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import numpy as np
tf.keras.utils.set_random_seed(42)
X, y = load_iris(return_X_y=True)
Xtr, Xv, ytr, yv = train_test_split(X, y, test_size=.2, stratify=y, random_state=42)
scaler = StandardScaler().fit(Xtr)
Xtr = scaler.transform(Xtr).astype("float32")
Xv = scaler.transform(Xv).astype("float32")
net = tf.keras.Sequential([
    tf.keras.Input(shape=(4,)),
    tf.keras.layers.Dense(16, activation="relu"),
    tf.keras.layers.Dense(3)
])
net.compile(optimizer="adam", loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
            metrics=["accuracy"])
net.fit(Xtr, ytr, epochs=100, batch_size=16, verbose=0)
print(net.evaluate(Xv, yv, verbose=0, return_dict=True))
p = tf.nn.softmax(net(Xv, training=False), axis=-1).numpy()
assert np.allclose(p.sum(axis=1), 1)
print(p[:3], np.argmax(p[:3], axis=1))

この例は固定した構成の検証を目的としています。検証結果を使って構造を繰り返し調整する場合、独立したテストデータまたは適切な交差検証が必要です。Kaggleではまず単純なベースラインを作り、幅・深さ・学習率などを一つずつ変え、同じ分割で比較しましょう。表形式データでは決定木系モデルの方が適する場合もあります。

8.10 まとめと確認問題

MLPはアフィン変換と非線形変換を組み合わせた関数です。順伝播では各層のshapeを追い、出力層はタスクに合わせて選びます。万能近似定理は表現可能性の保証であり、学習成功や汎化の保証ではありません。

問1　入力層と隠れ層の違いは？

入力層は特徴量を受け取り、隠れ層は学習可能な重みなどを用いて中間表現を作る。

問2　入力(32, 10)を幅64のDenseに渡すと？

バイアスを使う通常のDenseでは重み(10,64)、バイアス(64,)、出力(32,64)。

問3　構造10→64→32→1のパラメータ数は？

全層でバイアスを使う場合、11×64 + 65×32 + 33 = 2817。

問4　活性化関数なしで層を重ねると？

全結合層と恒等関数のみならアフィン変換の合成になるため、非線形関数は表せない。

問5　ReLU(x)−ReLU(x−1)はどんな関数か？

x≤0で0、0≤x≤1でx、x≥1で1。

問6　排他的な5クラス分類の出力は？

5ロジットを出力し、整数ラベルならSparseCategoricalCrossentropy(from_logits=True)。推論時はSoftmax。

問7　万能近似定理は最適化の成功を保証するか？

保証しない。適切なパラメータが存在することと、データから発見できることは別。

問8　幅を2倍にするとパラメータ数も必ず2倍か？

いいえ。隣接する隠れ層の幅も2倍なら、その間の重みは4倍になる。

発展演習：三角形の関数をMLPで作る

入力1、隠れ層3、出力1のReLUネットワークで、x=0と2で0、x=1で1、その外側で0になる関数を表現してください。重みを手で設定し、NumPyで確かめましょう。

解答・実装例

隠れ層はReLU(x), ReLU(x−1), ReLU(x−2)、出力重みは(1,−2,1)です。出力バイアスは0です。区間ごとの式は x≤0 で0、0≤x≤1 で x、1≤x≤2 で 2−x、x≥2 で0となり、傾きは順に0,1,−1,0です。

コード8.11　三角形の関数を検証する
import numpy as np
x = np.array([-1., 0., .5, 1., 1.5, 2., 3.])[:, None]
H = np.maximum(x @ np.ones((1,3)) + np.array([0., -1., -2.]), 0)
y = H @ np.array([[1.], [-2.], [1.]])
print(y.ravel())
assert np.allclose(y.ravel(), [0,0,.5,1,.5,0,0])
