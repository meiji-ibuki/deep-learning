9.1 活性化関数の役割

第8章では、全結合層を重ねるだけではアフィン変換のままであることを確認しました。活性化関数（activation function）は、加重和 $z$ を中間表現 $a$ に変換する関数です。

$$z=\sum_j w_jx_j+b,\qquad a=g(z)$$

隠れ層では非線形性によって複雑な関数を表現します。出力層では予測値の範囲や意味を決めます。さらに、学習時には $g'(z)$ が逆伝播の勾配に掛け合わされます。したがって、関数の形状だけでなく導関数にも注目する必要があります。

恒等関数 $g(z)=z$ は回帰の出力に便利ですが、隠れ層すべてに使用すると表現力が制限されます。ステップ関数は第7章のパーセプトロンで用いましたが、ほぼ至る所で微分が0、原点では微分不能なので通常の勾配学習には不向きです。

9.2 SigmoidとTanh

Sigmoidは実数を0と1の間に変換します。二値分類の確率表現に適していますが、隠れ層では飽和が問題になります。

$$\sigma(z)=\frac{1}{1+e^{-z}},\quad \sigma'(z)=\sigma(z)(1-\sigma(z))$$

導関数は最大でも0.25です。入力が大きな正または負の値になると出力は端に近づき、勾配はほぼ0になります。Tanhは出力が−1から1の間で、原点に関して点対称（奇関数）です。

$$\tanh z=2\sigma(2z)-1,\quad (\tanh z)'=1-\tanh^2 z$$

Tanhは原点付近では勾配が1に近く、RNNの内部状態にも使われます。ただし両端ではやはり飽和します。

コード9.1　出力と微分を数値で比較する
import numpy as np
z = np.array([-5., -2., 0., 2., 5.])
s = np.exp(-np.logaddexp(0, -z))
t = np.tanh(z)
print(np.column_stack([z, s, s*(1-s), t, 1-t*t]))

9.3 ReLUとDying ReLU

ReLU（Rectified Linear Unit）は、正の入力をそのまま通し、負の入力を0にします。計算が簡潔で、正の領域で勾配が1になるため、MLPやCNNの隠れ層で広く利用されます。

$$g(z)=\max(0,z),\qquad g'(z)=\begin{cases}0&z<0\\1&z>0\end{cases}$$

原点では数学的に微分不能です。TensorFlowのReLUは原点の勾配として0を採用します。負の領域の出力が0になることは疎な表現を作る一方、すべての訓練標本に対して前活性化値が負になると、そのユニットを通る局所勾配が0になり、重みが更新されにくくなります。これをDying ReLUと呼びます。単に一部の出力が0であることとは区別してください。

コード9.2　負領域の割合と完全に停止したユニットを区別する
import numpy as np
Z = np.array([[-2., 1., -1.], [-3., -1., 2.], [-1., 2., 3.]])
A = np.maximum(Z, 0)
print((A == 0).mean())  # 5/9
print(np.all(Z < 0, axis=0))  # [True, False, False]

対処法として、学習率を見直す、He初期化を用いる、Leaky ReLUなどへ変更する方法があります。ミニバッチだけの観察で恒久的な停止とは断定しないようにしましょう。

9.4 Leaky ReLU・PReLU・ELU

ReLUの負領域にも勾配を残す方法がLeaky ReLUです。$\alpha$ は通常小さな正の定数で、PReLUではこの値自体を学習します。

$$g(z)=\begin{cases}z&z\ge0\\\alpha z&z<0\end{cases}$$

ELU（Exponential Linear Unit）は負領域を指数関数で滑らかに飽和させます。

$$g(z)=\begin{cases}z&z\ge0\\\alpha(e^z-1)&z<0\end{cases}$$

負領域の導関数はLeaky ReLUで $\alpha$、ELUで $\alpha e^z$ です。ELUは $\alpha=1$ のとき原点でも微分可能ですが、入力が大きな負の値の場合は飽和します。PReLUでは追加の学習パラメータとshapeに注意します。

9.5 GELU・Swish（SiLU）・Softplus

GELUは標準正規分布の累積分布関数 $\Phi$ を用い、入力を滑らかに重み付けします。Transformerのフィードフォワード部分などで利用されます。

$$\mathrm{GELU}(z)=z\Phi(z),\quad g'(z)=\Phi(z)+z\phi(z)$$

$\phi$ は標準正規分布の確率密度関数です。Swishは $z\sigma(\beta z)$ で、$\beta=1$ の場合をSiLUと呼びます。

$$\mathrm{SiLU}(z)=z\sigma(z),\quad g'(z)=\sigma(z)+z\sigma(z)(1-\sigma(z))$$

どちらも負の領域に小さな負の出力があり、単調増加ではありません。滑らかさは利点になり得ますが、常にReLUより高性能とは限りません。SoftplusはReLUの滑らかな近似で、正の値が必要な出力にも使えます。

$$\mathrm{Softplus}(z)=\log(1+e^z),\quad g'(z)=\sigma(z)$$
コード9.3　NumPyとSciPyで滑らかな関数を実装する
import numpy as np
from scipy.special import ndtr, expit
z = np.linspace(-5, 5, 401)
gelu = z * ndtr(z)
silu = z * expit(z)
softplus = np.logaddexp(0, z)
print(gelu[200], silu[200], softplus[200])

9.6 Softmaxと出力層の設計

Softmaxは他の関数と異なり、ベクトル全体を変換します。排他的な多クラス分類において、各要素を正の値に変換し、合計を1にします。

$$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$$

指数演算のオーバーフローを避けるため、最大値 $m=\max_j z_j$ を引いてから指数を計算します。全要素に同じ定数を足しても結果は変わりません。導関数はスカラーではなくヤコビ行列になります。

$$\frac{\partial p_i}{\partial z_j}=p_i(\delta_{ij}-p_j)$$

$\delta_{ij}$ は添字が等しいとき1、それ以外で0です。他のロジットを固定してあるクラスのロジットを上げると、他クラスの確率は下がります（K≥2、有限のロジット）。マルチラベル分類では各ラベルを個別のSigmoidで表現するため、合計を1にする必要はありません。各出力は周辺確率を表し、ラベル間の統計的独立性を仮定する必要はありません。

コード9.4　安定したSoftmaxとヤコビ行列
import numpy as np
def softmax(z):
    z = np.asarray(z, dtype=float)
    e = np.exp(z - z.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)
p = softmax([1000, 1001, 1002])
J = np.diag(p) - np.outer(p, p)
print(p)  # [0.09003, 0.24473, 0.66524]
assert np.allclose(J.sum(axis=0), 0)
assert np.allclose(p.sum(), 1)
タスク出力（推論時）損失の例
回帰LinearMSE / MAE
二値分類Sigmoid（1個）BinaryCrossentropy
多クラス分類Softmax（K個）SparseCategoricalCrossentropy（整数ラベル）
マルチラベル分類Sigmoid（K個）BinaryCrossentropy

分類の学習では、出力層をLinearにしてロジットを返し、損失関数の from_logits=True を指定する方法が数値安定性の面で有用です。すでにSigmoidやSoftmaxを適用した出力にこの設定を使ってはいけません。

9.7 勾配消失と学習の安定性

第4章の連鎖律を思い出しましょう。単純なスカラーの連鎖 $a_l=g(w_la_{l-1}+b_l)$ では、入力までの勾配は次式になります。

$$\frac{da_L}{da_0}=\prod_{l=1}^{L}g'(z_l)w_l$$

重みを1と仮定すると、Sigmoidの導関数の積は最大でも $0.25^L$ です。10層なら上限は約 $9.54\times10^{-7}$ となります。深い層から浅い層へ勾配が届きにくい現象が勾配消失です。逆に積が大きくなると勾配爆発が生じます。実際のネットワークでは行列の積となり、重みや初期化、正規化、残差接続も影響します。ReLUでも常に勾配が保たれるわけではありません。

コード9.5　連鎖律による勾配の縮小を確認する
import numpy as np
for depth in [1, 5, 10, 20]:
    print(depth, 0.25**depth, 0.8**depth, 1.2**depth)

9.8 活性化関数の使い分け

まず標準的な選択でベースラインを作り、検証データで比較するのが実践的です。アーキテクチャの既定値や事前学習済みモデルの設定を尊重しましょう。

関数出力範囲主な用途・注意点
Step0, 1論理ゲート。勾配学習には不向き
Sigmoid(0, 1)二値・マルチラベル分類。飽和
Tanh(−1, 1)RNNなど。飽和
ReLU[0, ∞)MLP、CNNの基準。負領域は勾配0
Leaky ReLU / PReLU実数（α > 0の場合）負領域に勾配を残す
ELU(−α, ∞)負領域が滑らかに飽和（α > 0）
GELU / SiLU下限あり、上限なしTransformerなど。滑らかな非単調関数
Softplus(0, ∞)正の連続値
Softmax(0, 1)（K≥2）排他的多クラス分類
Linear実数制約のない回帰

正の回帰値にはSoftplus、0〜1に制約される回帰にはSigmoidなども候補ですが、境界付近の飽和や対象の分布を考慮します。評価指標と出力変換を混同しないことも重要です。例えばROC-AUCの計算には順位が重要で、分類閾値は別途検証データから決定します。

9.9 TensorFlowによる実装と比較実験

Kerasでは活性化をDenseの引数として指定する方法と、独立したレイヤーとして挿入する方法があります。後者はPReLUなどパラメータを持つ関数にも適しています。

コード9.6　Kerasで活性化関数を指定する
import tensorflow as tf
from tensorflow import keras
model = keras.Sequential([
    keras.Input(shape=(10,)),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(32),
    keras.layers.LeakyReLU(negative_slope=0.1),
    keras.layers.Dense(16, activation=tf.nn.gelu),
    keras.layers.Dense(1),
])
model.summary()
コード9.7　GradientTapeで活性化関数の導関数を確かめる
import tensorflow as tf
z = tf.Variable([-3., -1., 0., 1., 3.])
for fn in [tf.nn.sigmoid, tf.nn.tanh, tf.nn.relu, tf.nn.gelu, tf.nn.silu]:
    with tf.GradientTape() as tape:
        a = fn(z)
        total = tf.reduce_sum(a)
    print(fn.__name__, a.numpy(), tape.gradient(total, z).numpy())

要素ごとの関数なので、和を微分すると各要素の導関数が得られます。Softmaxに同じ方法を適用すると合計1の微分になるため、個別の偏微分を求めるには tape.jacobian() が必要です。

実践：同じ分類課題で活性化関数を比較する

二つの半月型クラスを分類する人工データを使います。データ分割・ネットワーク幅・初期化方式・学習率・学習回数を固定し、活性化だけを変更します。乱数シードを複数使うのは、初期値やバッチ順の偶然を減らすためです。ここでは検証損失を比較し、テスト集合は最終選択後の評価に残します。

コード9.8　活性化関数の比較実験（Colab等で実行）
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
X, y = make_moons(n_samples=2000, noise=0.25, random_state=42)
X_dev, X_test, y_dev, y_test = train_test_split(
    X, y, test_size=.2, stratify=y, random_state=42)
X_tr, X_va, y_tr, y_va = train_test_split(
    X_dev, y_dev, test_size=.25, stratify=y_dev, random_state=42)
scaler = StandardScaler().fit(X_tr)
X_tr, X_va, X_test = [scaler.transform(a).astype("float32")
                     for a in (X_tr, X_va, X_test)]
y_tr, y_va, y_test = [a.astype("float32")[:, None]
                     for a in (y_tr, y_va, y_test)]
activations = {"sigmoid": "sigmoid", "tanh": "tanh", "relu": "relu",
               "gelu": tf.nn.gelu, "silu": tf.nn.silu}
def build(act, seed):
    tf.keras.backend.clear_session()
    tf.keras.utils.set_random_seed(seed)
    model = tf.keras.Sequential([tf.keras.Input(shape=(2,))] + [
        tf.keras.layers.Dense(32, activation=act,
            kernel_initializer="glorot_uniform") for _ in range(4)] + [
        tf.keras.layers.Dense(1)])
    model.compile(optimizer=tf.keras.optimizers.Adam(.001),
        loss=tf.keras.losses.BinaryCrossentropy(from_logits=True),
        metrics=[tf.keras.metrics.BinaryAccuracy(threshold=0.0)])
    return model
scores = {}
for name, act in activations.items():
    curves = []
    for seed in [11, 22, 33]:
        model = build(act, seed)
        hist = model.fit(X_tr, y_tr, validation_data=(X_va, y_va),
                         epochs=50, batch_size=64, verbose=0)
        curves.append(hist.history["val_loss"])
    curves = np.array(curves)
    scores[name] = curves[:, -1].mean()
    plt.plot(np.arange(1, curves.shape[1]+1), curves.mean(axis=0), label=name)
    print(name, scores[name], curves[:, -1].std())
plt.xlabel("Epoch")
plt.ylabel("Validation BCE")
plt.legend(); plt.show()
best = min(scores, key=scores.get)
model = build(activations[best], 44)
model.fit(np.concatenate([X_tr, X_va]), np.concatenate([y_tr, y_va]),
          epochs=50, batch_size=64, verbose=0)
print("Final test:", model.evaluate(X_test, y_test, verbose=0))

結果の読み方：初期の損失低下速度、最後の検証損失、シード間のばらつきを確認しましょう。初期化を固定した比較は活性化の影響を調べるための一条件であり、各関数に最適な初期化を使った場合とは異なります。次にReLUでHe初期化を試すなど、一度に一条件ずつ変えてください。実行環境によって結果は異なり、本教材ではTensorFlow実測値を掲載していません。

9.10 まとめと確認問題

活性化関数は非線形性、勾配の伝達、出力の意味を決めます。隠れ層と出力層では選択の目的が異なり、性能は実験によって判断します。

問1　Stepが勾配学習に不向きな理由は？

原点を除く導関数が0で、原点では微分不能だから。

問2　Sigmoidの導関数の最大値は？

0.25。s=σ(z)とするとs(1−s)=1/4−(s−1/2)²なので、z=0（s=0.5）で最大となる。

問3　ReLUの原点での微分は？

数学的には未定義。TensorFlowでは0を採用する。

問4　Dying ReLUと単なるゼロ出力の違いは？

全訓練標本で負領域に入り、学習が進みにくくなる状態を指す。

問5　Leaky ReLUの負領域の導関数は？

α。

問6　Softmaxに定数を足すと？

全ロジットに同じ定数を足しても確率は不変。

問7　マルチラベル分類ではどの関数を使う？

各ラベルにSigmoid。学習ではロジットとBCEの組み合わせも可。

問8　ロジットを返す二値分類で正例判定の閾値を確率0.5にしたい場合は？

ロジットの閾値0を使用する。σ(0)=0.5であり、σは狭義単調増加。閾値と等しい場合の扱いは実装に合わせる（Keras BinaryAccuracyは閾値を超える場合に1）。

発展演習：GELUの導関数を検証する

中央差分を使い、解析的導関数と比較してください。刻み幅を変えて誤差を観察しましょう。

解答・実装例
コード9.9　GELUの勾配チェック
import numpy as np
from scipy.special import ndtr
x = np.linspace(-4, 4, 101)
f = lambda z: z * ndtr(z)
analytic = ndtr(x) + x*np.exp(-x*x/2)/np.sqrt(2*np.pi)
for h in [1e-2, 1e-4, 1e-6, 1e-8]:
    numeric = (f(x+h)-f(x-h))/(2*h)
    print(h, np.max(np.abs(analytic-numeric)))
assert np.allclose(analytic, (f(x+1e-4)-f(x-1e-4))/2e-4, atol=1e-7)

独立検算（float64）：h=0.01で最大絶対誤差1.3e-05、h=0.0001で最大絶対誤差1.3e-09、h=1e-06で最大絶対誤差3.26e-10、h=1e-08で最大絶対誤差3.87e-08。刻み幅を小さくし過ぎると丸め誤差の影響が増えることがあります。
