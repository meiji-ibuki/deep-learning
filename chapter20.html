20.1 過学習と汎化性能

第19章では深いネットワークの学習を安定化させた。だが、訓練損失を小さくすることと、未知の標本で正確に予測することは異なる。訓練集合を $D$、未知の標本の分布を $P$ とすると、経験リスクと期待リスクはそれぞれ

$$\hat R(\theta)=\frac1N\sum_{i=1}^N\ell(f_\theta(x_i),y_i),\qquad R(\theta)=\mathbb E_{(x,y)\sim P}[\ell(f_\theta(x),y)]$$

である。期待リスクは直接観測できないため、同じ対象分布から独立に得た検証集合で近似する。ただし繰り返しのモデル選択による偏りには注意する。訓練損失が低い一方で検証損失が悪化する現象は過学習の典型例である。両方が高い場合はモデルの表現力不足や最適化の失敗も疑う。分布シフトやラベル品質の差でもギャップが生じるので、ギャップだけで断定しない。

二乗誤差では、真の回帰関数を $f$ とすると、独立な平均ゼロの観測ノイズの下で期待予測誤差はバイアスの二乗、予測の分散、不可避なノイズ分散に分解できる。正則化はしばしばバイアスを増やす代わりに分散を減らす。深層学習ではモデル規模と汎化の関係は単純なU字型に限らない。

20.2 L1・L2正則化の数学

正則化はモデルに制約や事前の仮定を加えて、未知データへの性能を改善する技法の総称である。重みを直接罰する場合は、データ損失にペナルティを加える。

$$J(\theta)=\hat R(\theta)+\lambda\Omega(\theta)$$

L1では $\Omega(w)=\sum_j|w_j|$、L2では本書の導出上 $\Omega(w)=\frac12\sum_jw_j^2$ とする。正則化係数λは非負とする。L1の劣勾配は非ゼロ点で符号、ゼロ点で区間 $[-1,1]$。L2の勾配は $w$ である。KerasのL2は半分を掛けない定義なので係数を比較する際は注意する。

直交した単純な回帰の一座標を $\frac12(w-a)^2+\lambda|w|$ とすると、最小解は $\operatorname{sign}(a)\max(|a|-\lambda,0)$ となる（ソフト閾値）。L2（ペナルティ $\lambda w^2/2$）なら $w=a/(1+\lambda)$。L1は疎性を促すが、通常の勾配法で必ず厳密なゼロになるとは限らない。近接勾配法ではソフト閾値を明示的に適用する。

確率的には、ガウス事前分布とL2、ラプラス事前分布とL1がMAP推定で対応する。ただし尤度の合計・平均によって係数のスケールは変わる。

コード20.1　Kerasの重み正則化
import tensorflow as tf
from tensorflow import keras
model = keras.Sequential([
    keras.Input(shape=(10,)),
    keras.layers.Dense(32, activation="relu",
        kernel_regularizer=keras.regularizers.L2(1e-4)),
    keras.layers.Dense(1)
])
model.compile(optimizer="adam", loss="mse")
# model.losses に正則化損失が含まれる
print(model.losses)

20.3 Weight DecayとAdamW

素のSGDでL2ペナルティを加えると $w_{t+1}=w_t-\eta(g_t+\lambda w_t)=(1-\eta\lambda)w_t-\eta g_t$ となる。これは同じ係数のWeight Decayと一致する。しかしMomentumやAdamでは勾配の変換が介在するため一般には一致しない。AdamWは減衰を適応的勾配更新から分離する（第18章）。

バイアスや正規化層のスケールを減衰対象から除外する設計もあるが、普遍的な規則ではない。対象を明示して比較する。L2とAdamWを意図せず併用しない。学習率の変更は一更新あたりの減衰量にも影響する。

コード20.2　AdamWの設定例（名前による除外は対象変数名を確認）
optimizer = keras.optimizers.AdamW(
    learning_rate=1e-3, weight_decay=1e-4)
# 必要なら optimizer の build より前に設定する
optimizer.exclude_from_weight_decay(var_names=["bias", "beta", "gamma"])

20.4 Dropoutと確率的な正則化

Dropoutは訓練時にユニットの出力を確率的にゼロにする。ドロップ率を $p$（$0\le p<1$）、保持率を $q=1-p$ とすると、inverted dropoutは

$$m_i\sim\mathrm{Bernoulli}(q),\quad \tilde h_i=\frac{m_i h_i}{q},\quad \mathbb E[\tilde h_i\mid h_i]=h_i$$

であり、条件付き分散は $h_i^2p/q$。推論時は通常マスクを使わず、そのまま出力する。期待値が一致しても非線形ネットワーク全体の予測期待値が一致するとは限らない。高すぎるドロップ率は情報を失わせる。Batch Normalizationとの位置関係にも注意する。

コード20.3　Dropoutの期待値を検証
import numpy as np
rng = np.random.default_rng(42)
h = np.array([1., 2., 3.])
q = 0.75
m = rng.binomial(1, q, size=(100000, 3))
out = m * h / q
print(out.mean(axis=0), out.var(axis=0))
np.testing.assert_allclose(out.mean(axis=0), h, atol=.03)

20.5 Early Stoppingとモデル選択

Early Stoppingは検証性能が改善しなくなった時点で訓練を打ち切り、過度の適合を防ぐ。patienceは改善がなくても待つエポック数、min_deltaは改善とみなす変化量である。学習率低下を併用する場合、低下後に改善を観察する余裕を持たせる。検証集合への繰り返しの選択も過学習を起こしうるため、最終評価用のテスト集合は隔離する。

callbacks = [

        mode="min", save_best_only=True),
    keras.callbacks.EarlyStopping(monitor="val_loss", mode="min",
        patience=12, min_delta=0., restore_best_weights=True)
]

20.6 データ拡張とMixup

データ拡張はラベルを保つ変換、または変換に対応してラベルも更新する処理により、学習分布を広げる。画像の左右反転や平行移動、音声の小さな時間シフトなどが例である。ただし文字・左右の意味を持つ医用画像・時系列の未来方向など、変換でラベルが変わる場合は使えない。検証・テストには通常ランダム拡張を適用しない。分割後に拡張し、同一原標本の派生が別集合へ漏れないようにする。

Mixupは二標本を混合する（α>0）。$\lambda\sim\mathrm{Beta}(\alpha,\alpha)$ として $\tilde x=\lambda x_i+(1-\lambda)x_j,\ \tilde y=\lambda y_i+(1-\lambda)y_j$。分類ではOne-hotベクトルを混合したソフトラベルを使う。CutMixは画像の領域を置換し、実際の置換面積に応じてラベルを混合する。意味の異なる表形式特徴の線形混合が妥当とは限らない。

コード20.5　Mixupの実装
import numpy as np
rng = np.random.default_rng(42)

def mixup(x, y, alpha, rng):
    # x, y は浮動小数点配列。y は one-hot など
    idx = rng.permutation(len(x))
    lam = rng.beta(alpha, alpha)
    return lam*x + (1-lam)*x[idx], lam*y + (1-lam)*y[idx]

x = np.array([[1., 0.], [0., 1.]])
y = np.eye(2)
xm, ym = mixup(x, y, .4, rng)
np.testing.assert_allclose(ym.sum(axis=1), 1.)

20.7 Label Smoothingとその他の手法

Label Smoothingは正解One-hotベクトルを一様分布と混合する。$K$ クラス、平滑化係数 $\varepsilon\in[0,1]$ なら $y'_k=(1-\varepsilon)y_k+\varepsilon/K$。正解クラスへの過度な確信を抑えるが、確率校正が必ず改善するわけではない。クラス間の微細な区別が弱くなる場合もある。

ほかに入力ノイズ、重み制約、Stochastic Depthなどがある。Batch Normalizationは主に学習の安定化を目的とするが、バッチ統計の揺らぎが正則化的に働く場合もある。

コード20.6　Label Smoothing
loss = keras.losses.CategoricalCrossentropy(
    from_logits=True, label_smoothing=0.1)
# 整数ラベルの場合は one-hot に変換する
labels = tf.one_hot([0, 2, 1], depth=3)

20.8 NumPyによる正則化の比較実験

少数の標本から高次多項式を推定する例で、L2の効果を分離して観察する。ニューラルネットワークではないが、同じ目的関数の考え方を検証できる。切片は罰しない。この実験ではL2項に1/2を付けない規約を使用する。訓練・検証・テストを独立に生成し、検証MSEのみでλを選ぶ。Legendre基底を使い数値条件を改善する。

$$w_\lambda=\arg\min_w\left(\frac1N\|\Phi w-y\|^2+\lambda\|w_{1:}\|^2\right)$$
コード20.7　L2強度の選択と独立テスト評価
import numpy as np
from numpy.polynomial.legendre import legvander
rng = np.random.default_rng(20)
def sample(n):
    x = rng.uniform(-1, 1, n)
    return x, np.sin(3*x) + rng.normal(0, .2, n)
xtr, ytr = sample(20)
xva, yva = sample(200)
xte, yte = sample(200)
def phi(x): return legvander(x, 15)
A = phi(xtr)
P = np.eye(A.shape[1]); P[0, 0] = 0
lambdas = [0., 1e-5, 1e-3, 1e-2, .1, 1.]
models, scores = [], []
for lam in lambdas:
    w = np.linalg.lstsq(np.vstack([A, np.sqrt(len(A)*lam)*P]),
                        np.r_[ytr, np.zeros(A.shape[1])], rcond=None)[0]
    models.append(w)
    scores.append([np.mean((phi(x)@w-y)**2) for x,y in [(xtr,ytr),(xva,yva)]])
best = int(np.argmin(np.array(scores)[:,1]))
print('selected lambda:', lambdas[best])
print('test MSE:', np.mean((phi(xte)@models[best]-yte)**2))

20.9 TensorFlowによる比較実験

少数の訓練標本を用いた二値分類で、L2・Dropout・Early Stoppingを比較する。評価は正則化項を含まない検証BCEとする。正則化項を含むval_lossを異なる手法間で比較すると不公平になる場合がある。初期重みとデータ分割を共通化し、乱数シードを複数用いる。テストは設定を選んだ後だけ使う。

コード20.8　Kerasによる比較実験（未実行）
import numpy as np
import tensorflow as tf
from tensorflow import keras
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
X, y = make_moons(n_samples=1000, noise=.3, random_state=20)
Xtr, Xrest, ytr, yrest = train_test_split(X, y, train_size=160,
    stratify=y, random_state=20)
Xva, Xte, yva, yte = train_test_split(Xrest, yrest, test_size=.5,
    stratify=yrest, random_state=21)
scaler = StandardScaler().fit(Xtr)
Xtr, Xva, Xte = [scaler.transform(a).astype('float32') for a in (Xtr,Xva,Xte)]
ytr, yva, yte = [a.astype('float32').reshape(-1,1) for a in (ytr,yva,yte)]
configs = {'base':(0.,0.,False), 'l2':(1e-3,0.,False),
           'dropout':(0.,.3,False), 'early':(0.,0.,True)}
def make_model(l2, drop):
    model = keras.Sequential([keras.Input(shape=(2,)),
        keras.layers.Dense(64, activation='relu', kernel_regularizer=keras.regularizers.L2(l2)),
        keras.layers.Dropout(drop),
        keras.layers.Dense(64, activation='relu', kernel_regularizer=keras.regularizers.L2(l2)),
        keras.layers.Dense(1)])
    model.compile(optimizer=keras.optimizers.Adam(1e-3),
        loss=keras.losses.BinaryCrossentropy(from_logits=True),
        metrics=[keras.metrics.BinaryCrossentropy(from_logits=True, name='bce')])
    return model
scores = {k:[] for k in configs}
trained = {}
for seed in (20,21,22):
    keras.utils.set_random_seed(seed)
    initial = make_model(0.,0.).get_weights()
    for name,(l2,drop,early) in configs.items():
        keras.utils.set_random_seed(seed)
        model = make_model(l2,drop)
        model.set_weights(initial)
        cb = [keras.callbacks.EarlyStopping(monitor='val_bce', mode='min',
                patience=15, restore_best_weights=True)] if early else []
        model.fit(Xtr,ytr,validation_data=(Xva,yva),epochs=150,
                  batch_size=32,callbacks=cb,verbose=0)
        scores[name].append(model.evaluate(Xva,yva,return_dict=True,verbose=0)['bce'])
        if seed == 20: trained[name] = model
best = min(scores, key=lambda k: np.mean(scores[k]))
for k,v in scores.items(): print(k, np.mean(v), np.std(v))
print('selected:', best)
print('test:', trained[best].evaluate(Xte,yte,return_dict=True,verbose=0))

テスト評価はあらかじめ定めたseed=20のモデルで行う。各手法の強度候補も探索する場合は検証集合で選び、比較予算をそろえる。厳密な再現性は実行環境にも依存する。上記はTensorFlow未実行のため結果を掲載していない。

20.11 まとめと確認問題

正則化はモデルの汎化を改善するための手段であり、強ければ強いほど良いわけではない。学習・評価時の処理差と、比較条件の統一が重要である。

訓練損失が減り検証損失が増える場合は？

過学習を疑う。分布の差も確認する。

L2の半二乗ペナルティの勾配は？

λw。KerasのL2では係数に2が付く。

AdamWとAdam＋L2は同じか？

一般には異なる。減衰を適応的更新から分離するため。

Dropout率0.2の保持時の倍率は？

1/0.8=1.25。

Early Stoppingでテスト損失を監視してよいか？

不可。検証集合を使う。

4クラスでε=0.1の正解ラベルは？

正解0.925、他は各0.025。

Mixupで整数クラスIDを直接混合するか？

しない。One-hot等の確率表現を使用する。

正則化強度の比較に共通の評価指標が必要な理由は？

正則化項の大小を含む損失は予測性能だけを測らないため。

発展：多項式回帰の次数とλの候補を変え、検証MSEを比較せよ。

次数3・8・15とλ候補を組み合わせ、検証MSEの最小値を選ぶ。最終テストは選択後のみ。複数の分割で結果のばらつきを調べる。 コード20.7と同じ分割で18候補を比較した再計算例：次数3、λ=0.01、検証MSE=0.054263、テストMSE=0.056792。
