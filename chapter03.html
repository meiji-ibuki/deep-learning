3.1 線形代数はなぜ必要なのか

第2章では、住宅の面積や築年数をNumPyの配列に格納しました。本章ではその背後にある数学を学びます。深層学習では、一つの予測を作るための加重和も、数千件の画像を同時に処理する計算も、基本的には数値の集合に対する演算です。線形代数はその演算を簡潔に記述するための言語です。

例えば面積を $x_1$、築年数を $x_2$ とし、仮の住宅価格（万円）を $40x_1-10x_2+200$ とします。面積60㎡、築年数5年なら2550万円です。係数40と−10は重み、200はバイアスです。ここでは学習済みと仮定した値であり、実際の市場価格を推定したものではありません。

この計算をベクトルと内積で表現できるようになると、複数の出力や複数の住宅にも同じ規則を適用できます。第7章以降で登場する人工ニューロンは、この加重和を出発点とします。

3.2 スカラー・ベクトル・行列・テンソル

スカラーは一つの数値、ベクトルは順序を持つ数値の列、行列は行と列からなる数値の表です。深層学習の実装でいうテンソルは、それらを多次元配列に一般化したものです。数学の厳密なテンソルの定義とは区別し、本書では主に計算上の意味で用います。

種類軸の数（ndim）形状の例意味の例
スカラー0()損失値
ベクトル1(3,)3特徴量
行列2(4, 3)4件×3特徴量
3階テンソル3(8, 20, 5)8系列×20時点×5特徴量
4階テンソル4(32, 64, 64, 3)32枚のRGB画像

ベクトルの次元は成分数を指すことがありますが、配列のndimは軸の数です。例えば100次元ベクトルもndimは1です。またテンソルのrank（軸数）と行列のrank（独立な行・列の数）は異なる意味です。

コード3.1　配列の階数・形状・要素数
import numpy as np
for a in [np.array(7), np.array([1, 2, 3]),
          np.zeros((4, 3)), np.zeros((32, 64, 64, 3))]:
    print(a.ndim, a.shape, a.size)

形状 (32,64,64,3) の要素数は32×64×64×3=393216です。float32なら各要素4バイトで、配列本体は約1.5 MiBになります。学習時には中間結果や勾配も保持するため、必要メモリは入力だけでは決まりません。

3.3 ベクトルの基本演算と幾何学

ベクトルは特徴量の集合としても、座標空間の矢印としても解釈できます。以下では列ベクトルを数学上の標準表記とします。

$$\boldsymbol u=\begin{pmatrix}2\\1\end{pmatrix},\quad \boldsymbol v=\begin{pmatrix}1\\2\end{pmatrix}$$

加算は対応する成分同士を足します。スカラー倍は各成分を同じ数で掛けます。差 u−v は v の終点から u の終点への移動を表します。

$$u+v=(3,3)^\top,\quad 2u=(4,2)^\top,\quad u-v=(1,-1)^\top$$
コード3.2　ベクトルの加減算とスカラー倍
import numpy as np
u = np.array([2, 1])
v = np.array([1, 2])
print(u + v)  # [3 3]
print(u - v)  # [ 1 -1]
print(2 * u)  # [4 2]

NumPyの1次元配列には行・列の区別がありません。数学の列ベクトルに対応する2次元配列が必要な場合は u[:, None] を使い、shapeを (2,1) にします。

3.4 内積・ノルム・距離

内積：二つのベクトルを一つの数にする

本章では実数ベクトルの標準内積を扱います。同じ成分数のベクトルの対応する要素を掛けて合計します。角度を用いる等式では両ベクトルが非ゼロであることを仮定します。

$$u^\top v=\sum_{i=1}^d u_i v_i=\|u\|_2\|v\|_2\cos\theta$$

例えば $u=(2,1)^\top,v=(1,2)^\top$ の内積は4です。角度が直角なら内積は0、鈍角なら負です（どちらも非ゼロの場合）。住宅価格の重み付き和も内積です。Attentionではベクトル同士の関連性を計算するためにも内積が使われます。

ノルム：ベクトルの大きさ

$$\|x\|_1=\sum_i|x_i|,\qquad \|x\|_2=\sqrt{\sum_i x_i^2},\qquad \|x\|_\infty=\max_i |x_i|$$

例えば $(3,4)^\top$ のL1ノルムは7、L2ノルムは5、L∞ノルムは4です。二点間のユークリッド距離は差のL2ノルムです。

コサイン類似度

$$\operatorname{cos}(u,v)=\frac{u^\top v}{\|u\|_2\|v\|_2}$$

大きさを取り除いて方向の近さを測ります。値は−1から1で、非ゼロベクトルに対して定義されます。文章や画像の埋め込み比較に利用できます。ゼロベクトルを扱う際は除算の前に検査します。単位の異なる特徴量で距離を測る場合には、尺度の調整も必要です。

コード3.3　内積・ノルム・類似度
import numpy as np
u = np.array([2., 1.])
v = np.array([1., 2.])
print(u @ v)  # 4.0
print(np.linalg.norm(u-v))  # sqrt(2)
print(np.linalg.norm([3, 4], ord=1))  # 7
print(np.linalg.norm([3, 4], ord=2))  # 5
print((u @ v) / (np.linalg.norm(u)*np.linalg.norm(v)))  # 0.8

ノルムは第20章の正則化にもつながります。ただしL2正則化では通常、L2ノルムそのものではなくその二乗を罰則として使用します。

3.5 行列の演算と転置

$m$ 行 $n$ 列の行列を $A\in\mathbb R^{m\times n}$ と書きます。$a_{ij}$ は第 $i$ 行第 $j$ 列の要素です。数学では通常1から添字を数え、Pythonでは0から数えます。

$$A=\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix},\quad A^\top=\begin{pmatrix}1&4\\2&5\\3&6\end{pmatrix}$$

転置は行と列を交換する操作です。加減算やアダマール積（要素積）は同じ位置の要素に適用します。行列積とは異なるので区別してください。

コード3.4　転置と要素積
import numpy as np
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.full((2, 3), 2)
print(A.T)
print(A + B)
print(A * B)
print(A[1, 2])  # 6
print(np.array([1, 2, 3]).T.shape)  # (3,)

2次元行列では .T が転置になります。3階以上の配列の .T はすべての軸の順序を逆転させます。バッチを維持しながら最後の二軸だけを入れ替えるなら np.swapaxes(A, -1, -2) などを使います。

3.6 行列積とニューラルネットワーク

行列積 $C=AB$ は、左の行列の各行と右の行列の各列の内積を並べたものです。$A\in\mathbb R^{m\times n}$、$B\in\mathbb R^{n\times p}$ のとき、結果は $C\in\mathbb R^{m\times p}$ となります。

$$c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}$$

内側の次元が一致しなければ計算できません。外側の次元が結果になります。

一般に $AB\ne BA$ です。順序を交換すると計算自体が不可能なこともあります。一方、結合則 $(AB)C=A(BC)$ と分配則 $A(B+C)=AB+AC$ は適切な形状の行列について成立します。

一括予測を行列積で表す

住宅3件の特徴量を行に並べた行列 $X$ と、2種類の出力を計算する重み行列 $W$ を考えます。第1出力は仮の価格、第2出力は別の仮想スコアとします。

$$X=\begin{pmatrix}40&10\\60&5\\80&2\end{pmatrix},\quad W=\begin{pmatrix}40&0.5\\-10&-1\end{pmatrix},\quad b=(200,10)$$ $$Z=XW+b=\begin{pmatrix}1700&20\\2550&35\\3380&48\end{pmatrix}$$

ここで $b$ は各行へ加算されます。数学では厳密には $\boldsymbol 1 b$（$\boldsymbol 1$ は3行1列、$b$ は1行2列）を足すと書けますが、配列ライブラリのブロードキャストを利用すれば簡潔に表現できます。

コード3.5　バッチ行列積による一括予測
import numpy as np
X = np.array([[40, 10], [60, 5], [80, 2]], dtype=np.float32)
W = np.array([[40, .5], [-10, -1]], dtype=np.float32)
b = np.array([200, 10], dtype=np.float32)
Z = X @ W + b
print(Z)
assert Z.shape == (3, 2)
assert np.allclose(Z, [[1700, 20], [2550, 35], [3380, 48]])

KerasのDense層は基本的にこのアフィン変換に活性化関数を組み合わせたものです。入力が $d$ 特徴量、出力が $h$ 個の場合、重みは $(d,h)$、バイアスは $(h,)$、バイアスを使う場合の学習パラメータ数は $dh+h$ です（use_bias=False なら $dh$）。これはサンプル数に依存しません。

3.7 線形変換・基底・行列のランク

行列はベクトルを別のベクトルへ写す変換として理解できます。線形変換 $T$ は $T(au+bv)=aT(u)+bT(v)$ を満たします。標準基底 $e_1=(1,0)^\top,e_2=(0,1)^\top$ の変換先を列に並べると変換行列になります。

$$T(x)=Ax,\quad A=\begin{pmatrix}2&1\\0&1\end{pmatrix}$$

この変換は $e_1$ を $(2,0)^\top$、$e_2$ を $(1,1)^\top$ に移します。したがって単位正方形は平行四辺形へ変わります。

線形独立とは、ベクトルのうちどれも他のベクトルの線形結合で表せないことです（集合が空でない場合、同値にゼロベクトルを作る係数がすべて0の場合のみ）。空間を張る線形独立なベクトルの集合を基底と呼びます。

行列のランクは独立な列の最大数（独立な行の最大数とも等しい）です。例えば $\begin{pmatrix}1&2\\2&4\end{pmatrix}$ は第2列が第1列の2倍で、ランク1です。二次元の情報を一次元の直線上に押しつぶす変換になります。

単位行列・逆行列・行列式

単位行列 $I$ は $Ix=x$ を満たします。正方行列 $A$ の逆行列 $A^{-1}$ が存在する場合、$A^{-1}A=AA^{-1}=I$ です。正方行列が可逆であること、フルランクであること、行列式が0でないことは同値です。2×2の行列式は $ad-bc$ で、絶対値は面積の拡大率です。

コード3.6　ランク・行列式・連立方程式
import numpy as np
A = np.array([[2., 1.], [0., 1.]])
B = np.array([[1., 2.], [2., 4.]])
print(np.linalg.matrix_rank(B))  # 1
print(np.linalg.det(A))  # 2.0
print(np.linalg.solve(A, [5., 1.]))  # [2. 1.]
print(np.allclose(A @ np.linalg.inv(A), np.eye(2)))

連立方程式を解く場合は通常、逆行列を明示的に計算するより np.linalg.solve を使います。ほぼ特異な行列では誤差が増幅されるため、ランクや条件数の確認が有用です。

なおバイアスを加える $Ax+b$ は厳密にはアフィン変換です。非線形な活性化関数を挟まないアフィン変換の重ね合わせは、結局一つのアフィン変換にまとめられます。深層学習で非線形性が重要な理由の一つです。

3.8 テンソルの軸とブロードキャスト

データをまとめて計算する場合、先頭の軸は一般にバッチ軸です。RGB画像のバッチをchannels-last形式で表すと $(B,H,W,C)$ となります。系列データなら $(B,T,D)$ などがよく使われます。軸の意味はモデルによって異なるため、shapeだけでなく意味も記録しましょう。

データshape軸の意味
表形式(32, 10)バッチ、特徴量
画像(32, 64, 64, 3)バッチ、高さ、幅、チャネル
系列(32, 20, 8)バッチ、時点、特徴量

ブロードキャストでは末尾から軸を比較し、軸の長さが等しいか、どちらかが1なら適合します。不足する先頭軸は長さ1として扱います。物理的に同じ配列を何度も複製する必要はありません。

特に注意したいのは $(B,1)$ と $(B,)$ の引き算です。結果は $(B,B)$ になってしまい、各サンプル同士を比較するつもりが全組み合わせの比較になります。エラーにならず学習が進むこともあるので、意図した形状を確認します。

コード3.7　ブロードキャストの落とし穴
import numpy as np
y = np.array([1., 2., 3.])
pred = np.array([[1.1], [1.9], [3.2]])
print((pred-y).shape)  # (3, 3): 意図と異なる
err = pred-y[:, None]
assert err.shape == (3, 1)
print(np.mean(err**2))  # 0.02

バッチ行列積

NumPyの @ は両オペランドが2階以上なら最後の二軸を行列として扱い、先頭側の軸をブロードキャストします。例えば $(B,T,D)@(D,H)$ は $(B,T,H)$ になります。系列の各時点で同じ重みを用いる計算です。

コード3.8　系列データに対する行列積
import numpy as np
X = np.ones((4, 5, 3), dtype=np.float32)
W = np.ones((3, 2), dtype=np.float32)
Z = X @ W
print(Z.shape)  # (4, 5, 2)
assert np.all(Z == 3)
print(X.mean(axis=1).shape)  # (4, 3)
print(X.mean(axis=1, keepdims=True).shape)  # (4, 1, 3)

3.9 固有値・固有ベクトルと次元削減

正方行列 $A$ に対し、ゼロでないベクトル $v$ が $Av=\lambda v$ を満たすとき、$v$ を固有ベクトル、$\lambda$ を固有値と呼びます。変換によって向きが同一直線上に保たれ、大きさや符号だけが変わる特別な方向です。固有値0の場合はゼロに写ります。

$$A=\begin{pmatrix}3&1\\1&3\end{pmatrix},\quad A\begin{pmatrix}1\\1\end{pmatrix}=4\begin{pmatrix}1\\1\end{pmatrix},\quad A\begin{pmatrix}1\\-1\end{pmatrix}=2\begin{pmatrix}1\\-1\end{pmatrix}$$

固有値は $\det(A-\lambda I)=0$ を解くことで求められます。この例では $(3-\lambda)^2-1=0$ より2と4です。一般の実行列には複素固有値が現れることもあり、常に独立な固有ベクトルが十分に存在するわけではありません。実対称行列では直交する固有ベクトルの基底を取れます。

コード3.9　対称行列の固有値分解
import numpy as np
A = np.array([[3., 1.], [1., 3.]])
values, V = np.linalg.eigh(A)
print(values)  # [2. 4.]
print(V)       # 各列が固有ベクトル（符号は任意）
assert np.allclose(A @ V, V @ np.diag(values))

主成分分析（PCA）への応用

標本数 $N>1$ の中心化したデータ行列 $X_c$ の標本共分散行列 $S=X_c^\top X_c/(N-1)$ は実対称行列です。最大固有値に対応する単位固有ベクトル（最大固有値が重複すれば方向は一意ではありません）は、データを射影したときの分散が最大になる方向です。上位の固有ベクトルだけを残すことで、情報の一部を保ちながら次元を減らせます。

コード3.10　PCAの基本計算
import numpy as np
X = np.array([[1., 1.], [2., 3.], [3., 2.], [4., 4.]])
Xc = X - X.mean(axis=0)
S = Xc.T @ Xc / (len(X)-1)
values, V = np.linalg.eigh(S)
W = V[:, -1:]  # 最大固有値の方向
Z = Xc @ W
print(Z.shape)  # (4, 1)
assert values.sum() > 0  # 全分散が正であることを確認
print(values[-1] / values.sum())  # 寄与率 0.9

PCAは教師なしの次元削減であり、予測に重要な方向と分散が大きい方向が一致するとは限りません。実践では前処理の平均と主成分を訓練データでのみ求めます。特異値分解（SVD） $X=U\Sigma V^\top$ は長方形行列にも適用でき、PCAの数値計算や低ランク近似に使われます。固有値分解やSVDを毎回手書きする必要はありませんが、意味を理解しておくと表現学習の理解に役立ちます。

3.10 TensorFlowで線形代数を実践する

最後にNumPyで扱った計算をTensorFlowで再現します。学習はまだ行いません。重みの値を固定し、Dense層の出力が行列積と一致することを確認します。第2章で用意したTensorFlow環境で実行してください。

コード3.11　行列積とDense層の比較
import tensorflow as tf
X = tf.constant([[40., 10.], [60., 5.], [80., 2.]])
W = tf.constant([[40., .5], [-10., -1.]])
b = tf.constant([200., 10.])
Z = tf.matmul(X, W) + b
layer = tf.keras.layers.Dense(2, activation=None)
layer.build((None, 2))
layer.set_weights([W.numpy(), b.numpy()])
Y = layer(X)
tf.debugging.assert_near(Y, Z)
print(Y.numpy())
print(layer.count_params())  # 6
演算NumPyTensorFlow
行列積A @ Btf.matmul(A, B)
要素積A * BA * B
転置A.T（2次元）tf.transpose(A)
形状変更np.reshape(A, shape)tf.reshape(A, shape)
L2ノルムnp.linalg.norm(v)（ベクトル）tf.norm(v)
軸に沿う合計np.sum(A, axis=0)tf.reduce_sum(A, axis=0)

TensorFlowのmatmulは通常2階以上のテンソルを対象とします。1次元ベクトルの内積なら tf.reduce_sum(u*v)、行列とベクトルの積なら tf.linalg.matvec(A,v) も使えます。NumPyと同名の演算であっても引数の条件が異なることがあります。

実装では、入力と重みのshape、dtype、出力のshapeを順に確認する習慣をつけましょう。float32は深層学習で一般的な型です。ただし数値的に厳しい線形代数の計算ではfloat64が有用なこともあります。浮動小数点演算の比較には厳密な等号ではなく許容誤差を用います。

3.11 まとめと確認問題

本章では数値配列の形状、内積、行列積、線形変換、固有値を学びました。特に重要なのは、数式を見てどの軸が縮約され、どの軸が出力に残るかを判断できることです。

キーワード確認すべきこと
内積対応する成分を掛けて合計する
ノルム大きさ・距離・正則化の基礎
行列積内側の次元が一致し外側が残る
ランク独立な行・列の数
ブロードキャスト末尾から軸を比較する
固有値特別な方向の伸縮率
Denseバッチ行列積＋バイアス＋活性化関数
問1　shape (16, 28, 28, 1) のndimと要素数は？

4階、16×28×28×1 = 12544要素です。

問2　u=(3,4)、v=(−4,3) の内積とL2ノルムを求めよ。

内積は−12+12=0、両方のL2ノルムは5です。直交しています。

問3　形状 (7,3) と (3,5) の行列積の結果は？

(7,5) です。逆順の積は内側の次元が一致せず計算できません。

問4　入力12特徴量、出力8、バイアスありのDense層のパラメータ数は？

12×8+8=104です。バッチサイズには依存しません。

問5　形状 (64,1) と (64,) の差の形状は？

(64,64) です。サンプルごとの差が目的なら、後者を (64,1) に変換してから差を計算します。

問6　行列 [[1,2],[2,4]] のランクと行列式は？

ランク1、行列式0です。逆行列は存在しません。

問7　対角行列 diag(2,5) の固有値と固有方向は？

2と5です。対応する方向はそれぞれ x 軸と y 軸です。

発展演習：バッチ計算と1件ずつの計算を比較する

乱数で100件×4特徴量の入力、4×3の重み行列、3要素のバイアスを作成してください。行列積とPythonのforループでそれぞれ予測を計算し、出力が一致することを検証しましょう。さらに入力を (10,10,4) に変形してバッチ行列積を行い、結果を (100,3) に戻して比較してください。

解答例
コード3.12　発展演習の解答
import numpy as np
rng = np.random.default_rng(42)
X = rng.normal(size=(100, 4))
W = rng.normal(size=(4, 3))
b = rng.normal(size=3)
Y = X @ W + b
Y_loop = np.stack([x @ W + b for x in X])
Y_seq = (X.reshape(10, 10, 4) @ W + b).reshape(100, 3)
assert np.allclose(Y, Y_loop)
assert np.allclose(Y, Y_seq)
print(Y.shape)

同じ計算を異なる形状や実装で表現できることが確認できます。実際の実行速度はデータサイズ、ライブラリ、ハードウェアに依存します。

独立検算：各出力を4項の積和とバイアス加算だけで計算し、行列積と比較しました。出力形状は (100,3)、最大絶対誤差は 8.88e-16（float64、検証環境での値）です。丸め誤差のため厳密な等号ではなく許容誤差で比較します。
