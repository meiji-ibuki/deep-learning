27.1 系列データとAttentionの発想

第26章のRNNは状態を時刻順に更新する。離れた時点の情報は多数の更新を通過するため、学習が難しくなることがある。Attentionは、必要な情報を他の位置から直接取得する仕組みである。たとえば文章「花が咲いた。彼女はそれを眺めた。」の「それ」を処理する際、前方の「花」に大きな重みを与えられる。これは説明のための例であり、実際のモデルが必ずその対応を学ぶとは限らない。

Attentionは重み付き和である。重みは入力に依存して変化するため、固定された畳み込みカーネルとは異なる。Self-Attentionでは同一系列内の要素を参照し、Cross-Attentionでは別の系列を参照する。Transformerはこの仕組みを中心に、位置情報、全結合変換、残差接続、正規化を組み合わせる。

27.2 Query・Key・Valueとshape

検索を例にすると、Queryは探したい情報、Keyは照合用の索引、Valueは取り出す情報に相当する。ただし実際にはいずれも学習可能な線形変換（バイアス付きならアフィン変換）で得られるベクトルであり、人間が意味を指定するわけではない。

$$Q=X_qW_Q,\quad K=X_kW_K,\quad V=X_kW_V$$

バッチサイズをB、Queryの長さをT、参照系列の長さをS、モデル幅をDとする。以下では1ヘッドのQueryとKeyの幅を$d_k$、Valueの幅を$d_v$とする。

テンソルshape意味
Xq(B,T,D)問い合わせ側
Xk(B,S,D)参照側
Q(B,T,dk)問い合わせ
K(B,S,dk)照合用
V(B,S,dv)取り出す情報
QKᵀ(B,T,S)全位置間のスコア
出力(B,T,dv)重み付き和

27.3 Scaled Dot-Product Attention

QueryとKeyの内積をスコアとし、参照位置Sの方向にSoftmaxを適用する。

$$A=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right),\qquad O=AV$$

QueryとKeyの全成分が互いに独立で平均0・分散1と仮定すると内積の分散は$d_k$になる。平方根で割ることでスコアの尺度を抑え、Softmaxが極端に飽和することを防ぎやすくする。実際の学習済みベクトルが独立とは限らないため、これは設計の動機である。

具体例として、Q=K=[[1,0],[0,1],[1,1]]、V=[[2,0],[0,2],[1,1]]とする。第1行のスコアは(1,0,1)/√2、重みは約(0.401,0.198,0.401)、出力は約(1.203,0.797)となる。各行の重みの合計は1であるが、列の合計は一般に1ではない。

コード27.1　安定なSoftmaxとAttention
import numpy as np

def attention(q, k, v, mask=None):
    scores = q @ np.swapaxes(k, -1, -2) / np.sqrt(q.shape[-1])
    if mask is not None:
        mask = np.broadcast_to(mask, scores.shape)
        if not np.all(mask.any(axis=-1)):
            raise ValueError("Each query must have a valid key")
        scores = np.where(mask, scores, -np.inf)
    exp = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights = exp / exp.sum(axis=-1, keepdims=True)
    return weights @ v, weights

q = k = np.array([[1., 0.], [0., 1.], [1., 1.]])
v = np.array([[2., 0.], [0., 2.], [1., 1.]])
out, a = attention(q, k, v)
print(a.round(3), out.round(3))
np.testing.assert_allclose(a.sum(axis=-1), 1)

27.4 Self-Attention・Cross-Attention・マスク

Self-AttentionはQ・K・Vの元が同じ系列である。Cross-AttentionではQを問い合わせ側、KとVを参照側から得る。例えばエンコーダ・デコーダではデコーダの状態がエンコーダの出力を参照する。

パディングマスクは無効なKeyを除外する。因果マスクは現在より未来のKeyを除外する。両者は論理積で合成できる。マスクはSoftmaxの前にスコアへ適用する。Softmax後に単に0を掛けると、重みの合計が1にならない。全Keyが無効な行は別途扱う必要があり、上の教育用実装では例外とした。KerasのMultiHeadAttentionではTrueが参照可能を意味する。

コード27.2　因果マスクの検証
# コード27.1に続けて実行
causal = np.tril(np.ones((3, 3), dtype=bool))
y, w = attention(q, k, v, causal)
assert np.all(w[~causal] == 0)
np.testing.assert_allclose(w.sum(-1), 1)
print(w.round(3))

27.5 Multi-Head Attention

単一のAttentionでは一つの重み行列で情報を混合する。複数のヘッドを用いると、それぞれ独立した射影を通じて異なる関係を学習できる。特定のヘッドが特定の文法や意味に対応する保証はない。

$$H_i=\operatorname{Attention}(XW_i^Q,XW_i^K,XW_i^V),\quad O=\operatorname{Concat}(H_1,\ldots,H_h)W^O$$

典型的には$d_k=d_v=D/h$とする。D=128、h=4なら各ヘッドの幅は32。Kerasのkey_dimはモデル全体ではなく1ヘッドのQuery・Keyの幅を指定する。value_dimを省略するとkey_dimと同じになる。典型的な等分割ではDがhで割り切れることを仮定する。バイアスを除けば、D幅の入出力で各射影の総幅もDの場合、パラメータ数は$4D^2$となる。

コード27.3　KerasによるMulti-Head Attention
import tensorflow as tf
from tensorflow import keras
x = tf.random.normal((2, 10, 128))
mha = keras.layers.MultiHeadAttention(num_heads=4, key_dim=32)
y, weights = mha(x, x, return_attention_scores=True)
print(y.shape, weights.shape)  # (2,10,128), (2,4,10,10)

27.6 位置情報の付与

位置情報もマスクもないSelf-Attentionは、入力の並び替えに対して出力も同じように並び替わる（置換同変性）。順序そのものを区別するため、位置情報を追加する。原型Transformerは正弦・余弦の位置エンコーディングを採用した。

$$PE_{p,2i}=\sin(p/10000^{2i/D}),\qquad PE_{p,2i+1}=\cos(p/10000^{2i/D})$$

埋め込みと位置ベクトルのshapeを一致させて加算する。学習可能な位置埋め込みは訓練時に設定した最大長を超える扱いに注意する。相対位置バイアスやRoPEは位置間の関係を別の形で取り込む手法である。RoPEではQとKの成分対を位置依存の角度で回転させる。

コード27.4　正弦波位置エンコーディング
import numpy as np

def sinusoidal(length, d):
    pos = np.arange(length)[:, None]
    angle = pos / 10000 ** (2 * np.arange((d+1)//2) / d)
    pe = np.zeros((length, d))
    pe[:, 0::2] = np.sin(angle)
    pe[:, 1::2] = np.cos(angle[:, :d//2])
    return pe

pe = sinusoidal(20, 16)
assert pe.shape == (20, 16)

27.7 Transformerブロックと全体構造

EncoderブロックはSelf-Attentionと位置ごとのFeed Forward Network（FFN）を持つ。FFNは各位置に同じ重みで独立に作用する。Attentionが位置間の情報交換を担い、FFNが各位置の特徴を非線形変換する。残差接続とLayer Normalizationは学習を安定させる。

$$\mathrm{FFN}(x)=g(xW_1+b_1)W_2+b_2$$

原論文のPost-Normは$\mathrm{LN}(x+F(x))$、Pre-Normは$x+F(\mathrm{LN}(x))$である。本章の実装はPre-Normを採用する。Decoderブロックは因果Self-Attentionと、原型のエンコーダ・デコーダ構成ではCross-Attentionを持つ。Encoder-onlyは分類など、Decoder-onlyは自己回帰的な系列予測、Encoder–Decoderは入力系列から出力系列への変換に適する。

27.8 計算量とRNN・CNNとの比較

標準的なSelf-Attentionではスコアのshapeが(B,h,T,T)なので、系列長Tを2倍にするとスコア要素数は4倍になる。QKᵀとAVの計算量は概ね$O(T^2D)$、FFNの中間幅がDに比例する場合、射影やFFNは$O(TD^2)$程度になる。RNNは系列方向の逐次依存があるが、Attentionは訓練時に複数位置を並列計算できる。ただし自己回帰推論は逐次的である。

方式位置間の接続系列長に対する特徴
RNN隣接状態を経由逐次処理
CNN局所カーネル受容野の拡大が必要
Self-Attention全位置を直接参照標準形では二乗のスコア要素数

例えばT=1024、B=8、h=8、float32の場合、スコアだけで256 MiBになる。実際には勾配や中間値も必要である。FlashAttentionなどは厳密なAttentionを効率的に計算し、中間行列の保存やメモリ転送を削減するが、標準的な全位置間の演算を単純に線形時間へ変えるわけではない。局所Attentionや疎なAttentionは参照範囲を制限する別の方法である。

27.9 KerasによるEncoderブロックの実装

以下は固定長系列を対象としたPre-Normブロックである。パディングを含む場合はAttentionのマスクに加え、最後のプーリングでも無効位置を除外する。Dropoutは訓練時だけ有効にする。ここでは標準レイヤーのみを組み合わせ、Functional APIで構築する。

コード27.5　Functional APIによるEncoderブロック
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def encoder_block(x, d=32, heads=4, ff=64, dropout=0.1):
    z = layers.LayerNormalization(epsilon=1e-5)(x)
    z = layers.MultiHeadAttention(num_heads=heads, key_dim=d//heads)(z, z)
    x = layers.Add()([x, layers.Dropout(dropout)(z)])
    z = layers.LayerNormalization(epsilon=1e-5)(x)
    z = layers.Dense(ff, activation="gelu")(z)
    z = layers.Dense(d)(z)
    return layers.Add()([x, layers.Dropout(dropout)(z)])

inputs = keras.Input(shape=(16, 32))
x = encoder_block(inputs)
model = keras.Model(inputs, x)
model.summary()

27.10 実践：離れた位置の関係を分類する

人工系列の先頭と末尾の整数が一致するかを分類する。正例・負例をそれぞれ確率1/2で生成し、途中の位置にはランダムな整数を置く。位置埋め込みを持つTransformerとGRUを比較する。先頭と末尾を直接比較するルールなら解ける課題なので、ここでの目的は高精度な解法探しではなく、モデルの学習挙動の観察である。モデルのパラメータ数も記録し、同じデータ・学習予算で比較する。ただし単一シードの実験は結論を一般化できない。

コード27.6　GRUとTransformerによる系列分類の比較
# コード27.5の encoder_block を使用
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(27)
N, T, V, D = 3000, 32, 16, 32
X = rng.integers(0, V, size=(N,T), dtype=np.int32)
y = rng.integers(0, 2, size=N, dtype=np.int32)
X[:, -1] = np.where(y == 1, X[:, 0],
                    (X[:, 0]+rng.integers(1,V,size=N)) % V)
Xtr, Xtmp, ytr, ytmp = train_test_split(X,y,test_size=.4,
    random_state=27,stratify=y)
Xva, Xte, yva, yte = train_test_split(Xtmp,ytmp,test_size=.5,
    random_state=27,stratify=ytmp)

def make_model(kind):
    inp = keras.Input((T,), dtype="int32")
    x = layers.Embedding(V, D)(inp)
    if kind == "Transformer":
        # 位置IDを追加の入力として明示する
        pos = keras.Input((T,), dtype="int32", name="positions")
        x = layers.Add()([x, layers.Embedding(T,D)(pos)])
        for _ in range(2):
            x = encoder_block(x, d=D)
        x = layers.LayerNormalization()(x)
        x = layers.Flatten()(x)
        x = layers.Dense(32, activation="relu")(x)
        ins = [inp, pos]
    else:
        x = layers.GRU(32)(x)
        ins = inp
    return keras.Model(ins, layers.Dense(1)(x))

def data(x, kind):
    return [x, np.tile(np.arange(T,dtype=np.int32),(len(x),1))] if kind == "Transformer" else x

for kind in ["GRU", "Transformer"]:
    keras.utils.set_random_seed(27)
    model = make_model(kind)
    model.compile(optimizer=keras.optimizers.Adam(1e-3),
        loss=keras.losses.BinaryCrossentropy(from_logits=True),
        metrics=[keras.metrics.BinaryAccuracy(threshold=0.0)])
    h = model.fit(data(Xtr,kind),ytr[:,None],validation_data=(data(Xva,kind),yva[:,None]),
        epochs=30,batch_size=64,verbose=0,callbacks=[keras.callbacks.EarlyStopping(
        monitor="val_loss",patience=5,restore_best_weights=True)])
    print(kind, model.count_params(), model.evaluate(data(Xte,kind),yte[:,None],return_dict=True))
    import matplotlib.pyplot as plt
    plt.plot(range(1, len(h.history["val_loss"])+1), h.history["val_loss"],label=kind)
plt.xlabel("Epoch"); plt.ylabel("Validation loss"); plt.legend(); plt.show()

比較ではFlattenによる分類ヘッドも含めて構造が異なるため、Attentionだけの効果を分離した実験ではない。改善案として同じ分類ヘッド、パラメータ予算、複数シードを用いた比較を行う。テスト結果を見て設定を調整しない。学習結果は実行環境で確認すること（本教材ではTensorFlowの実測値を掲載しない）。

27.11 まとめと確認問題

Attentionは入力に応じて参照位置の重みを決定し、Valueの加重和を求める。TransformerはAttentionだけでなく、位置情報・FFN・残差接続・正規化を統合した構造である。

問1　QとKの内積を計算する目的は？

問い合わせと参照位置の関連度を得る。

問2　Softmaxを適用する軸は？

Keyの位置に対応する最後の軸。

問3　√dkで割る理由は？

内積の分散増大を抑え、Softmaxの飽和を緩和する。

問4　T=20、S=30のスコアのshapeは？

1標本1ヘッドでは(20,30)。

問5　D=128、8ヘッドの典型的なkey_dimは？

16。

問6　因果マスクの役割は？

未来の位置を参照できないようにする。

問7　位置情報が必要な理由は？

マスクなしのSelf-Attention自体は置換同変であり、順序を直接表現しないため。

問8　Tを3倍にするとスコア要素数は？

9倍。

問9　発展：コード27.1のAttentionの置換同変性を検証せよ。

Q,K,Vの行に同じ置換を適用し、出力が元の出力の同じ置換と一致することをnp.testing.assert_allcloseで確認する。位置情報や因果マスクは使用しない。例えばコード27.1の実行後に perm = np.array([2,0,1]) とし、out2, a2 = attention(q[perm], k[perm], v[perm]) を計算する。np.testing.assert_allclose(out2, out[perm]) および np.testing.assert_allclose(a2, a[np.ix_(perm,perm)]) が成立する。独立検算の出力最大絶対誤差は 0。
