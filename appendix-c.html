C.1 実行環境・テンソルの生成

参照章：第2章・第13章

TensorFlow 2系とKeras 3をTensorFlowバックエンドで使う。以下の例は原則として独立実行できる。テンソルは値を直接書き換えず、変数は状態を保持する。

API・主要引数用途・注意点
tf.constant / convert_to_tensorPython・NumPyの値をテンソルに変換。dtypeを明示できる
tf.Variable / assign / assign_add更新可能な変数。学習対象かどうかはtrainableで指定
tf.zeros / ones / fill形状を指定して生成
tf.range / linspace等間隔の値を生成
tf.shape / Tensor.shape / tf.rank動的形状／静的形状／軸数
tf.cast型変換。整数化では小数部が失われる
tf.random.normal / uniform乱数。再現性にはseedも管理
keras.utils.set_random_seedPython・NumPy・バックエンドの乱数を設定
コードC.1　実装例
import tensorflow as tf
from tensorflow import keras
keras.utils.set_random_seed(42)
x = tf.constant([[1, 2], [3, 4]], dtype=tf.float32)
w = tf.Variable(tf.ones((2, 1)))
w.assign_add(tf.ones_like(w))
print(x.shape, tf.shape(x).numpy(), tf.matmul(x, w).numpy())
実装時の注意

期待形状は (2, 1)。GPU演算の完全再現性はシードだけでは保証されない。必要なら tf.config.experimental.enable_op_determinism() を検討する。

C.2 形状変換・添字・集約・行列演算

参照章：第3章・第13章

バッチ軸を先頭に置くことが多い。reshapeは要素順を変えず、transposeは軸を入れ替える。

API・主要引数用途・注意点
tf.reshape / expand_dims / squeeze形状変換。squeezeは長さ1の軸だけを除く
tf.transposepermで軸順を指定
tf.concat / stack既存軸で連結／新しい軸を生成
tf.gather / gather_nd添字で抽出
tf.boolean_mask / where条件抽出／条件選択（whereは条件だけを渡すと真の位置の添字を返す）
tf.reduce_sum / reduce_mean / reduce_maxaxisとkeepdimsを指定
tf.math.reduce_std / reduce_logsumexp標準偏差／安定なlog-sum-exp
tf.matmul / einsum行列積／添字表記の縮約
tf.nn.softmax / sigmoid確率への変換。softmaxは軸に注意
tf.math.divide_no_nan分母ゼロのとき0を返す
コードC.2　実装例
import tensorflow as tf
x = tf.reshape(tf.range(24, dtype=tf.float32), (2, 3, 4))
y = tf.transpose(x, (0, 2, 1))
z = tf.reduce_mean(x, axis=1, keepdims=True)
a = tf.ones((2, 4, 5))
b = tf.matmul(x, a)
print(y.shape, z.shape, b.shape)
tf.debugging.assert_shapes([(b, (2, 3, 5))])
実装時の注意

期待形状：(2,4,3)、(2,1,4)、(2,3,5)。ブロードキャストによる意図しない巨大配列に注意。

C.3 モデル構築と基本レイヤー

参照章：第7章・第8章・第14章

Sequentialは直列構造、Functionalは分岐・結合・複数入出力、Modelサブクラスは独自の処理に適する。Inputのshapeはバッチ軸を除く。

API・主要引数用途・注意点
keras.Input(shape=...)シンボリック入力
keras.Sequential層を順番に積む
keras.Model(inputs, outputs)Functionalモデルを作る
layers.Dense(units, activation)最後の軸を全結合変換
layers.Flatten / Reshapeバッチ軸を維持して形状変換
layers.Activation / ReLU / LeakyReLU活性化関数を独立した層にする
layers.Add / Concatenate要素加算／軸方向の結合
model.summary / count_params構造とパラメータ数の確認
model.get_layer / trainable_variables層や学習可能変数の参照
コードC.3　実装例
from tensorflow import keras
from tensorflow.keras import layers
x = keras.Input((12,), name='features')
h = layers.Dense(32, activation='relu')(x)
h = layers.Add()([h, layers.Dense(32)(h)])
y = layers.Dense(3)(h)
model = keras.Model(x, y)
model.summary()
assert model.output_shape == (None, 3)
実装時の注意

Keras 3のFunctional構築中はKerasTensorに任意のtf演算を直接適用せず、keras.opsまたはLayerを使う。

C.4 CNN・系列・Attentionレイヤー

参照章：第24章・第25章・第26章・第27章

画像はchannels_last設定ではNHWC、系列は(B,T,D)。出力形状とマスクの伝播を確認する。

API・主要引数用途・注意点
layers.Conv2D(filters, kernel_size, strides, padding)画像の局所特徴抽出
layers.Conv1D / Conv3D系列／3次元データ
layers.DepthwiseConv2D / SeparableConv2Dチャネル別畳み込み／深さ方向分離畳み込み
layers.MaxPooling2D / AveragePooling2D空間サイズを縮小
layers.GlobalAveragePooling2D空間軸を平均し(B,C)へ（keepdims=Falseの場合）
layers.Conv2DTranspose / UpSampling2D学習可能な拡大／補間等による拡大
layers.Embedding(input_dim, output_dim)整数IDをベクトル化。mask_zero=Trueなら0をマスク
layers.SimpleRNN / LSTM / GRU系列の状態更新。return_sequencesで全時点を返す
layers.Bidirectional順方向・逆方向の系列処理
layers.MultiHeadAttention(num_heads, key_dim)query・value・keyを受け取る。key_dimは各ヘッドの次元
コードC.4　実装例
import tensorflow as tf
from tensorflow.keras import layers
x = tf.zeros((4, 32, 32, 3))
h = layers.Conv2D(16, 3, padding='same')(x)
h = layers.MaxPooling2D(2)(h)
print(h.shape)
s = layers.Embedding(100, 32)(tf.ones((4, 10), tf.int32))
z = layers.GRU(16, return_sequences=True)(s)
a = layers.MultiHeadAttention(2, key_dim=8)(z, z, use_causal_mask=True)
print(z.shape, a.shape)
実装時の注意

期待形状は (4,16,16,16)、(4,10,16)、(4,10,16)。未来の観測値が利用できない予測では双方向RNNの入力範囲に注意。

C.5 前処理・正則化・初期化・正規化

参照章：第16章・第19章・第20章

訓練データだけでadaptを実行する。交差検証では各Fold内で前処理を学習する。

API・主要引数用途・注意点
layers.Normalization / adapt平均・分散を学習して標準化
layers.Rescaling定数によるスケーリング
layers.StringLookup / IntegerLookup語彙と整数IDの対応
layers.TextVectorizationテキストから整数列などへ
layers.RandomFlip / RandomRotation / RandomZoom訓練時の画像拡張
layers.BatchNormalization訓練時はバッチ統計、推論時は移動統計を用いる。trainable=Falseでは推論モードになる
layers.LayerNormalization / GroupNormalization特徴軸／グループ内で正規化
layers.Dropout / SpatialDropout2D訓練時に要素／特徴マップをランダムに除去
keras.initializers.HeNormal / GlorotUniformReLU系／一般的な初期化
keras.regularizers.L1 / L2 / L1L2損失へ正則化項を追加
コードC.5　実装例
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
x_train = tf.constant([[1., 2.], [3., 6.], [5., 10.]])
norm = layers.Normalization(axis=-1)
norm.adapt(x_train)
model = keras.Sequential([keras.Input((2,)), norm,
    layers.Dense(16, activation='relu', kernel_initializer='he_normal',
                 kernel_regularizer=keras.regularizers.L2(1e-4)),
    layers.BatchNormalization(), layers.Dropout(0.2), layers.Dense(1)])
print(model(x_train, training=False).shape)
実装時の注意

DropoutとBatchNormalizationはtraining引数の影響を受ける。L2正則化とAdamWのdecoupled weight decayは同じとは限らない。

C.6 損失関数と評価指標

参照章：第10章・第15章・第22章

損失は最適化対象、指標は評価対象。分類の出力形式とラベル形式を一致させる。

API・主要引数用途・注意点
losses.MeanSquaredError / MeanAbsoluteError / Huber回帰。Huberは大きな残差の影響を抑える
losses.BinaryCrossentropy(from_logits=...)二値・マルチラベル分類
losses.SparseCategoricalCrossentropy整数ラベルによる多クラス分類
losses.CategoricalCrossentropyOne-hotまたは確率ラベル
metrics.Mean / MeanAbsoluteError / RootMeanSquaredError集約・回帰評価
metrics.BinaryAccuracy / SparseCategoricalAccuracy分類精度。logits二値ならthreshold=0
metrics.AUC(curve="ROC" or "PR")有限個の閾値による曲線下面積の近似。logitsの場合はfrom_logits=True
metrics.Precision / Recall閾値を超える値を陽性として適合率・再現率を評価
Metric.update_state / result / reset_state状態を蓄積・取得・初期化
コードC.6　実装例
import tensorflow as tf
from tensorflow import keras
y = tf.constant([0, 2])
z = tf.constant([[3., 0., -1.], [0., 1., 2.]])
loss = keras.losses.SparseCategoricalCrossentropy(from_logits=True)
m = keras.metrics.SparseCategoricalAccuracy()
m.update_state(y, z)
print(loss(y, z).numpy(), m.result().numpy())
m.reset_state()
実装時の注意

期待Accuracyは1.0。BinaryAccuracyのthresholdは厳密な超過判定（等しい値は陰性）。PR-AUCとscikit-learnのAverage Precisionは定義・近似方法が異なる。sample_weightを指標にも反映したい場合はcompileのweighted_metricsを使う。

C.7 最適化・学習率スケジュール

参照章：第18章・第21章・第38章

optimizerは勾配から変数を更新する。スケジュールは通常optimizerの更新ステップに基づく。

API・主要引数用途・注意点
optimizers.SGD(learning_rate, momentum, nesterov)確率的勾配降下法
optimizers.Adam / AdamW適応学習率／分離型weight decay
optimizers.RMSprop / Adagrad勾配二乗の履歴を利用
clipnorm / global_clipnorm / clipvalue個別ノルム／全体ノルム／要素クリップ
schedules.ExponentialDecay / CosineDecay指数／コサイン減衰
schedules.PiecewiseConstantDecay境界ステップごとの学習率
optimizer.apply_gradients勾配と変数の組を渡す
optimizer.iterations更新ステップ数
コードC.7　実装例
import tensorflow as tf
from tensorflow import keras
lr = keras.optimizers.schedules.CosineDecay(1e-3, decay_steps=100)
opt = keras.optimizers.AdamW(learning_rate=lr, weight_decay=1e-4,
                            global_clipnorm=1.0)
w = tf.Variable(2.)
for _ in range(3):
    with tf.GradientTape() as tape:
        loss = (w - 1.) ** 2
    opt.apply_gradients([(tape.gradient(loss, w), w)])
print(w.numpy(), opt.iterations.numpy())
実装時の注意

スケジュールとReduceLROnPlateauを同時に使うと学習率を書き換えられない場合がある。異なる変数集合にはoptimizerを作り直す必要がある場合がある。

コードC.8　実装例
import numpy as np
from tensorflow import keras
rng = np.random.default_rng(42)
x = rng.normal(size=(120, 4)).astype('float32')
y = (x[:, 0] > x[:, 1]).astype('float32')[:, None]

実装時の注意

独立した人工データを使用する最小例。検証データで選択し、テストは最終確認にだけ使用する。

C.9 tf.dataと入力パイプライン

参照章：第16章・第30章・第33章・第38章

Datasetは要素の遅延処理を組み合わせる。要素仕様はelement_specで確認する。

API・主要引数用途・注意点
Dataset.from_tensor_slices配列の先頭軸から要素を作る
Dataset.from_generatorgeneratorから構築。output_signatureを指定
Dataset.map各要素の変換。num_parallel_callsで並列化
Dataset.shuffleバッファからランダム抽出
Dataset.batch / padded_batch固定形状／可変長をパディングしてバッチ化
Dataset.cacheメモリまたはファイルにキャッシュ。初回は入力を末尾まで走査して確定させる
Dataset.prefetch(tf.data.AUTOTUNE)次バッチの準備を重ねる
Dataset.repeat / take / skip反復・先頭取得・先頭除外
Dataset.zip / concatenate対応要素を組にする／順に連結
tf.io.read_file / tf.io.decode_jpegファイル読み込み・画像復号
コードC.9　実装例
import tensorflow as tf
x = tf.reshape(tf.range(40, dtype=tf.float32), (10, 4))
y = tf.range(10)
ds = tf.data.Dataset.from_tensor_slices((x, y))
ds = ds.map(lambda a, b: (a / 40., b), num_parallel_calls=tf.data.AUTOTUNE)
ds = ds.cache().shuffle(10, seed=42).batch(4).prefetch(tf.data.AUTOTUNE)
print(ds.element_spec)
for i, (a, b) in enumerate(ds):
    if i == 0:
        print(a.shape, b.shape)
実装時の注意

検証・推論では通常shuffleしない。キャッシュ確定前に走査を中断すると部分キャッシュが破棄されることがある。ランダム拡張をcacheの前に置くと拡張結果が固定される。repeatで無限化した場合はsteps_per_epochが必要。

C.10 自動微分・カスタム学習・グラフ実行

参照章：第11章・第17章・第23章

GradientTapeは記録された微分可能な演算から勾配を求める。通常のTensorはwatchが必要。

API・主要引数用途・注意点
tf.GradientTape / watch演算記録と監視対象指定
tape.gradient / jacobian勾配／ヤコビ行列
tf.stop_gradient勾配を遮断
tf.function(input_signature=...)グラフ化。再トレースを抑える
tf.TensorSpec入力形状・型の仕様
tf.debugging.assert_all_finiteNaN・Infを検査
tf.clip_by_global_norm勾配全体のノルム制限
Layer.build / add_weight / callカスタム層の構築・変数生成・順伝播
Model.train_stepfitの学習ステップをカスタマイズ
コードC.10　実装例
import tensorflow as tf
from tensorflow import keras
m = keras.Sequential([keras.Input((2,)), keras.layers.Dense(1)])
opt = keras.optimizers.Adam()
loss_fn = keras.losses.MeanSquaredError()
@tf.function(input_signature=[tf.TensorSpec((None, 2), tf.float32),
                              tf.TensorSpec((None, 1), tf.float32)])
def step(x, y):
    with tf.GradientTape() as tape:
        pred = m(x, training=True)
        loss = loss_fn(y, pred)
        if m.losses:
            loss += tf.add_n(m.losses)
    grads = tape.gradient(loss, m.trainable_variables)
    tf.debugging.assert_all_finite(loss, 'nonfinite loss')
    opt.apply_gradients(zip(grads, m.trainable_variables))
    return loss
print(step(tf.ones((4, 2)), tf.zeros((4, 1))).numpy())
実装時の注意

NumPy演算へ途中変換すると勾配が切れることがある。None勾配は未接続などの原因を調べる。グラフ内部のデバッグ出力はtf.printを使う。
