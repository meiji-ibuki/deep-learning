30.1 画像分類の問題設定

画像分類では画像全体に対してカテゴリを予測する。単一ラベル分類では各画像が一つのクラスに属し、多ラベル分類では複数の属性を同時に持つ。第24・25章のCNNを利用し、今回はデータから提出までの実務的な流れを学ぶ。

問題出力損失
二値1ロジットBCE
多クラスKロジットSparse Categorical CE
多ラベルKロジット（個別にsigmoid）BCE

単一ラベル多クラスではsoftmaxで確率の和を1にする。多ラベルでは各クラスにsigmoidを使う。画像の位置を予測する物体検出とは異なる。

30.2 画像の検査とデータ分割

画像は高さH、幅W、チャネルCのテンソルで表現する。RGBは3チャネル、グレースケールは1チャネルである。ファイルの破損、EXIF方向、重複、クラス頻度、解像度、撮影条件を確認する。同一人物や同じ撮影系列はグループとして分割し、類似画像のリークを避ける。テストは最後までモデル選択に使わない。

コード30.1　画像ファイルの監査（任意の画像フォルダ）
from pathlib import Path
from PIL import Image
from collections import Counter
sizes = Counter()
for path in Path("images").rglob("*"):
    if path.suffix.lower() not in {".jpg", ".jpeg", ".png"}:
        continue
    try:
        with Image.open(path) as im:
            sizes[im.size] += 1
            im.verify()
    except (OSError, ValueError) as e:
        print(path, e)
print(sizes.most_common(10))

30.3 リサイズと入力値の正規化

バッチ化には原則として同じ形状が必要である。縦横比を無視したリサイズは物体を変形させる。中央切り抜きは周辺情報を失う。縦横比を保って縮放しパディングすると余白が入る。対象に応じて選ぶ。画素値0〜255を0〜1へ変換するなら $$x'=x/255$$ とする。事前学習モデルの指定が異なる場合はそちらを優先する。MobileNetV2は0〜255から−1〜1への変換を要求する。二重正規化を避ける。

30.4 データ拡張とラベルの保存

通常の学習用拡張は訓練時にだけランダムに適用し、ラベルが変わらない変換を選ぶ。左右反転は自然画像で有効でも、文字・左右を識別する画像では不適切な場合がある。色変換も色そのものが分類対象なら避ける。Mixup・CutMixは第20章参照。検証時は固定した前処理を使う。

変換期待する効果注意
平行移動位置変化への頑健性対象が画面外に出る
回転姿勢変化数字6と9等
明るさ照明変化診断情報の消失
左右反転向きの変化文字・左右ラベル
コード30.2　CIFAR-10の分割とtf.data（以下の実践コードの共通準備）
import numpy as np
import tensorflow as tf
from tensorflow import keras
from sklearn.model_selection import train_test_split
keras.utils.set_random_seed(30)
(x, y), (xt, yt) = keras.datasets.cifar10.load_data()
y, yt = y.ravel(), yt.ravel()
tr, va = train_test_split(np.arange(len(y)), test_size=.2,
                          stratify=y, random_state=30)
def dataset(a, b, training=False):
    ds = tf.data.Dataset.from_tensor_slices((a,b))
    if training:
        ds = ds.shuffle(len(b), seed=30)
    return ds.batch(64).prefetch(tf.data.AUTOTUNE)
train = dataset(x[tr], y[tr], True)
valid = dataset(x[va], y[va])
test = dataset(xt, yt)
classes = ['airplane','automobile','bird','cat','deer','dog',
           'frog','horse','ship','truck']
def augment():
    return keras.Sequential([keras.layers.RandomFlip('horizontal'),
        keras.layers.RandomTranslation(.08,.08),
        keras.layers.RandomRotation(.05)])

30.5 CNNによる基準モデル

基準モデルは小さなCNNから始める。Conv2Dで局所特徴を抽出し、プーリングで空間サイズを縮小する。Global Average Poolingは各チャネルの平均を取り、空間サイズが1×1より大きく、後続の全結合層の出力幅が同じならFlattenに比べパラメータを減らす。出力は10ロジットとする。

$$L=-\log\frac{\exp z_y}{\sum_k\exp z_k}$$
コード30.3　基準CNNの学習（前節に続けて実行）
def compile_model(model, lr):
    model.compile(optimizer=keras.optimizers.Adam(lr),
        loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
        metrics=['accuracy'])
def fit_model(model, epochs):
    return model.fit(train, validation_data=valid, epochs=epochs,
        callbacks=[keras.callbacks.EarlyStopping(patience=5,
                    restore_best_weights=True)], verbose=2)
inp = keras.Input((32,32,3))
a = augment()(inp)
a = keras.layers.Rescaling(1/255)(a)
for filters in (32,64):
    a = keras.layers.Conv2D(filters,3,padding='same',activation='relu')(a)
    a = keras.layers.MaxPooling2D()(a)
a = keras.layers.Conv2D(128,3,padding='same',activation='relu',name='last_conv')(a)
a = keras.layers.GlobalAveragePooling2D()(a)
out = keras.layers.Dense(10)(a)
cnn = keras.Model(inp,out)
compile_model(cnn,1e-3)
history = fit_model(cnn,30)

30.6 転移学習とFine-tuning

ImageNetで学習した特徴抽出器を再利用する。最初に基盤を凍結して分類ヘッドを学習し、その後一部の層を小さな学習率で更新する。trainableを変えたら再compileする。Batch Normalizationの移動統計を壊さないため基盤をtraining=Falseで呼び出す。この引数だけでは重みの更新は止まらないため、下例ではBatch Normalization層のtrainableもFalseにする。CIFAR-10を96×96に拡大しても元の情報量は増えないが、基盤の入力条件に合わせられる。重み取得には初回ネット接続または事前キャッシュが必要。

コード30.4　MobileNetV2による転移学習（共通準備と学習関数を使用）
base = keras.applications.MobileNetV2(input_shape=(96,96,3),
    include_top=False, weights='imagenet')
base.trainable = False
inp = keras.Input((32,32,3))
a = augment()(inp)
a = keras.layers.Resizing(96,96)(a)
a = keras.layers.Rescaling(1/127.5, offset=-1)(a)
a = base(a, training=False)
a = keras.layers.GlobalAveragePooling2D()(a)
out = keras.layers.Dense(10)(a)
transfer = keras.Model(inp,out)
compile_model(transfer,1e-3)
fit_model(transfer,15)
base.trainable = True
for layer in base.layers[:-30]:
    layer.trainable = False
for layer in base.layers:
    if isinstance(layer,keras.layers.BatchNormalization):
        layer.trainable = False
compile_model(transfer,1e-5)
fit_model(transfer,15)

30.7 クラス不均衡への対処

多数クラスが90%なら、常に多数クラスを予測してもAccuracyは90%となる。Macro F1は各クラスのF1を等しく平均する。訓練部分の頻度から重みを計算する方法では $$w_k=N/(K n_k)$$ を用い、損失を重み付けする（すべてのクラスの訓練標本数が正の場合）。少数クラスの過剰サンプリングとの併用は過補正に注意する。確率の校正も変化しうる。

コード30.5　クラス重みの計算
counts = np.bincount(y[tr], minlength=10)
assert np.all(counts > 0)
weights = {i: float(len(tr)/(10*n)) for i,n in enumerate(counts)}
print(weights)
# 必要な場合は model.fit(..., class_weight=weights) を使用

30.8 評価と誤分類分析

検証データで混同行列、クラス別Recall・Precision、Macro F1を確認する。誤分類画像を抽出して、ラベル誤り、背景への依存、遮蔽、小さな対象などの傾向を調べる。以下は外部ダウンロード不要の手書き数字データをロジスティック回帰で分類した実測例である。Accuracy=0.9667、Macro F1=0.9667。CNNの結果ではない。

コード30.6　実測値の再現
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, accuracy_score, f1_score
X,Y = load_digits(return_X_y=True)
a,b = train_test_split(np.arange(len(Y)), test_size=.25,
                       stratify=Y, random_state=30)
m = LogisticRegression(max_iter=2000).fit(X[a]/16,Y[a])
pred = m.predict(X[b]/16)
print(confusion_matrix(Y[b],pred))
print(accuracy_score(Y[b],pred), f1_score(Y[b],pred,average='macro'))

30.9 Grad-CAMによる注目領域の可視化

クラスcのロジットに対する特徴マップAの勾配を空間平均し、チャネルの重みとする。

$$\alpha_k^c=\frac1{HW}\sum_{i,j}\frac{\partial z_c}{\partial A^k_{ij}},\qquad L^c=\operatorname{ReLU}(\sum_k\alpha_k^c A^k)$$

ヒートマップはモデルが使った正の寄与の粗い近似であり、因果的説明や物体の正確な領域を保証しない。ロジットを使い、推論モードで計算する。

コード30.8　基準CNNのGrad-CAM
import tensorflow as tf
import matplotlib.pyplot as plt
grad_model = keras.Model(cnn.inputs,
    [cnn.get_layer('last_conv').output,cnn.output])
image = x[va[:1]]
with tf.GradientTape() as tape:
    maps, logits = grad_model(image, training=False)
    c = tf.argmax(logits[0])
    score = tf.gather(logits[0],c)
g = tape.gradient(score,maps)
w = tf.reduce_mean(g,axis=(1,2),keepdims=True)
h = tf.nn.relu(tf.reduce_sum(maps*w,axis=-1))[0]
h = tf.math.divide_no_nan(h,tf.reduce_max(h))
h = tf.image.resize(h[...,None],(32,32))[...,0]
plt.imshow(image[0]); plt.imshow(h,cmap='jet',alpha=.4)
plt.axis('off'); plt.show()

30.10 Test Time Augmentationとモデル選択

TTAは同一画像を複数のラベル保存変換で推論し、確率を平均する。$$\bar p(y|x)=\frac1M\sum_{m=1}^M p(y|T_m(x))$$ ロジット平均とは異なる。計算量は概ね推論回数に比例するため、検証で効果とコストを確認する。ここでは左右反転のみを候補とし、検証で基準CNN・転移モデルとTTAの有無を比較する。EarlyStoppingにも同じ検証集合を使うため、そのスコアは独立な最終評価ではない。独立テストは選択後に一度評価する。

コード30.9　検証によるモデル・TTA選択と最終評価
from sklearn.metrics import log_loss, accuracy_score
def probabilities(model, images, tta=False):
    def predict(a):
        return tf.nn.softmax(model.predict(a,batch_size=64,verbose=0),axis=-1).numpy()
    p = predict(images)
    return (p+predict(images[:,:,::-1,:].copy()))/2 if tta else p
candidates = [(m,t) for m in (cnn,transfer) for t in (False,True)]
scores = [log_loss(y[va],probabilities(m,x[va],t),labels=np.arange(10))
          for m,t in candidates]
best_model,use_tta = candidates[int(np.argmin(scores))]
pt = probabilities(best_model,xt,use_tta)
print('test accuracy',accuracy_score(yt,pt.argmax(axis=1)))
print('test log loss',log_loss(yt,pt,labels=np.arange(10)))

30.11 Kaggle形式の推論と提出

実際のコンペではsample_submissionのIDと列順を基準に画像を読み込む。下例はIDが拡張子を含むファイル名で、クラスごとの確率列を要求する仮想コンペを想定する。実際の規約に従って変更する。学習時と同じRGB・サイズ・正規化を守り、モデル内部に正規化があるため外側では0〜255を維持する。大規模データはバッチ単位で処理する。

コード30.10　確率提出CSV（外部ファイルが必要）
import pandas as pd
from pathlib import Path
from PIL import Image, ImageOps
sample = pd.read_csv('sample_submission.csv')
assert sample['id'].is_unique
parts = []
for start in range(0,len(sample),64):
    batch = []
    for name in sample['id'].iloc[start:start+64]:
        with Image.open(Path('test_images')/str(name)) as im:
            im = ImageOps.exif_transpose(im).convert('RGB').resize((32,32), resample=Image.Resampling.BILINEAR)
            batch.append(np.asarray(im))
    parts.append(probabilities(best_model,np.stack(batch),use_tta))
pred = np.concatenate(parts)
assert np.isfinite(pred).all() and np.allclose(pred.sum(1),1,atol=1e-5)
assert set(sample.columns)=={'id',*classes}
for i,c in enumerate(classes): sample[c]=pred[:,i]
sample.to_csv('submission.csv',index=False)

30.12 まとめと確認問題

画像分類では、分割・入力仕様・拡張・モデル選択・誤分類分析を一つのパイプラインとして管理する。掲載したCIFAR-10のTensorFlow学習コードは未実行であり、性能値は実行後に確認する。

問1　多ラベル分類の出力は？

各ラベルに個別にsigmoidを適用した確率。ラベル間の統計的独立性を仮定する必要はない。

問2　分割で同一人物を分けない理由は？

人物固有情報のリークを防ぐ。

問3　MobileNetV2の入力範囲は？

−1〜1。

問4　拡張を検証にランダム適用しない理由は？

評価条件を固定するため。

問5　基盤の凍結解除後に必要な操作は？

再compile。

問6　不均衡でAccuracyだけでは不十分な理由は？

少数クラスの失敗が隠れる。

問7　Grad-CAMの限界は？

因果関係を証明しない。

問8　TTAで平均するものは？

本章では確率。

問9　発展：入力解像度の効果を比較せよ。

同一分割・シードでコード30.4の基盤のinput_shapeとResizingを96、128、160などにそろえて変更し、各条件でモデルを新規構築する。検証損失・同一バッチサイズでの推論時間（ウォームアップ後）・メモリを記録する。テストは選択後に利用する。
