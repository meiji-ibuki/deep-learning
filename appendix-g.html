G.1　解釈可能性の基本

予測の根拠を調べる目的は、モデル改善、異常な依存関係の発見、説明責任、運用監視である。説明はモデルの振る舞いについての仮説であり、現実世界の因果関係の証明ではない。まず説明する出力（確率・logit・回帰値）と対象データを定義する。

分類問い代表手法
大域的全体で何を利用するかPermutation Importance、PDP
局所的この予測はなぜかSHAP、LIME、IG、Grad-CAM
モデル固有内部構造を利用できるか重み、勾配、Attention
モデル非依存予測関数だけで調べられるかPermutation、PDP、Kernel SHAP、LIME

忠実度（元モデルを説明できるか）、安定性（小変化で説明が激変しないか）、理解しやすさは異なる尺度である。説明が人間に納得しやすくても忠実とは限らない。第23章、第36章参照。

G.2　Permutation Importance

学習済みモデルを固定し、検証集合の特徴量 $j$ をシャッフルする。大きいほど良いスコア $S$ なら重要度は $I_j=S(f,X,y)-\frac1R\sum_r S(f,X^{\pi_r(j)},y)$。損失なら差の向きを反転する。再学習は不要で、反復間の標準偏差は置換に伴う変動を示す（信頼区間ではない）。

相関する特徴量は互いを代替できるので個別重要度が低くなる場合がある。関連列を同じ順列で一括置換する方法もあるが、他の列との依存は壊れる。時系列では無制約なシャッフルが不自然になることにも注意する。

コードG.1　独立検証データでの重要度
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(42)
X = rng.normal(size=(1500, 3))
y = 2*X[:,0] + X[:,1]**2 + rng.normal(0,.3,len(X))
Xtr,Xva,ytr,yva = train_test_split(X,y,test_size=.3,random_state=42)
m = RandomForestRegressor(n_estimators=80,random_state=42).fit(Xtr,ytr)
r = permutation_importance(m,Xva,yva,n_repeats=15,random_state=42,scoring='r2')
print('R2:', round(m.score(Xva,yva),3))
print('importance:', r.importances_mean.round(3))

実行結果

R2: 0.963
importance: [1.059e+00 6.510e-01 1.000e-03]

G.3　PDP・ICE・ALE

特徴量 $j$ の値を $z$ に置き換えると、ICEは $f(z,x_{i,-j})$、PDPは $\frac1n\sum_i f(z,x_{i,-j})$ である。ICEは個別曲線、PDPはその平均。交互作用があると平均によって個別の異質性が見えにくくなる場合がある。中心化ICEでは各個体について同じ基準特徴値での予測を引く。

ALE（Accumulated Local Effects）は観測された特徴値の区間ごとに局所差分を平均し、積み上げて中心化する。相関が強い場合にPDPより非現実的な組合せを減らせるが、疎な区間では不安定になる。

コードG.2　PDPとICEの描画
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.inspection import PartialDependenceDisplay
import matplotlib.pyplot as plt
rng = np.random.default_rng(7)
X = rng.normal(size=(600,2))
y = X[:,0]*(1+X[:,1]) + .2*rng.normal(size=len(X))
m = RandomForestRegressor(n_estimators=60,random_state=7).fit(X[:400],y[:400])
PartialDependenceDisplay.from_estimator(m,X[400:],[0],kind='both',subsample=30,random_state=7)
plt.show()

G.4　SHAPとShapley値

特徴量集合 $N$、部分集合 $S$ に対する価値関数 $v(S)$ を定義する。Shapley値は追加する順序全体での限界寄与の平均である。

$$\phi_j=\sum_{S\subseteq N\setminus\{j\}}\frac{|S|!(|N|-|S|-1)!}{|N|!}[v(S\cup\{j\})-v(S)]$$

効率性より $v(N)=v(\emptyset)+\sum_j\phi_j$。欠けた特徴を背景データで補う方法や条件付き期待値を使う方法では帰属が変わる。出力尺度（確率、logit等）を必ず確認する。Tree SHAPは木モデルに特化し、Kernel SHAPは予測関数への問い合わせで近似する。Deep SHAPも近似であり任意の層に対応するとは限らない。

例えば $f(x)=x_1+x_2+2x_1x_2$、基準 $(0,0)$、入力 $(1,2)$ なら、相互作用4を両特徴に均等配分し、寄与は3と4となる。

コードG.3　小規模Shapley値を全順序で計算
import numpy as np
from itertools import permutations
x = np.array([1.,2.])
f = lambda a: a[0]+a[1]+2*a[0]*a[1]
phi = np.zeros(2)
orders = list(permutations(range(2)))
for order in orders:
    z = np.zeros(2)
    for j in order:
        before = f(z)
        z[j] = x[j]
        phi[j] += (f(z)-before)/len(orders)
assert np.isclose(phi.sum(), f(x)-f(np.zeros(2)))
print(phi)

実行結果

[3. 4.]

G.5　LIMEと局所代理モデル

説明対象 $x$ の近傍に摂動点 $z$ を生成し、距離に応じた重み $\pi_x(z)$ で簡単な代理モデル $g$ を学習する。

$$\arg\min_g \sum_z\pi_x(z)(f(z)-g(z))^2+\Omega(g)$$

表形式では疎な線形回帰、画像ではスーパーピクセル、文章では単語の有無などを使う。係数は局所近似であり、全体の傾向ではない。係数の比較には特徴量の尺度も考慮する。乱数、距離、近傍幅、摂動分布に敏感である。

コードG.5　重み付き局所線形近似（LIMEの教育用簡略版）
import numpy as np
from sklearn.linear_model import Ridge
rng = np.random.default_rng(42)
x = np.array([1.,2.])
z = x + rng.normal(0,.15,(1000,2))
f = lambda a: a[:,0]**2 + a[:,0]*a[:,1]
w = np.exp(-np.sum((z-x)**2,axis=1)/.2**2)
g = Ridge(alpha=.001).fit(z,f(z),sample_weight=w)
print('local slopes:',g.coef_.round(2))
print('weighted R2:',round(g.score(z,f(z),sample_weight=w),3))

実行結果

local slopes: [3.99 0.99]
weighted R2: 0.998

G.6　Saliency MapとIntegrated Gradients

ここでのSaliencyは入力勾配 $\partial F_c/\partial x_i$ を可視化する。絶対値は感度の強さを表すが、正負や実際の寄与を失う。勾配飽和により重要な特徴でも勾配が小さい場合がある。

$$IG_i(x)=(x_i-x'_i)\int_0^1\frac{\partial F_c(x'+\alpha(x-x'))}{\partial x_i}d\alpha$$

IGは基準入力 $x'$ から入力への直線経路で勾配を積分する。経路上で連鎖律と微積分の基本定理を適用できる場合（例：連続微分可能なモデル）、厳密な積分では $\sum_i IG_i=F_c(x)-F_c(x')$ が成り立つ。数値積分では近似的に一致する。黒画像などの基準が意味的に中立とは限らない。複数の基準で感度を確認する。

コードG.6　NumPyによるIGと完全性の確認
import numpy as np
x = np.array([2.,3.]); b = np.zeros(2)
f = lambda z: z[0]**2*z[1]
a = np.linspace(0,1,1001)
z = b + a[:,None]*(x-b)
g = np.column_stack([2*z[:,0]*z[:,1],z[:,0]**2])
ig = (x-b)*((g[:-1]+g[1:])/2).mean(axis=0)
print(ig, 'residual:',ig.sum()-(f(x)-f(b)))
assert abs(ig.sum()-(f(x)-f(b))) < 1e-4

実行結果

[8.000004 4.000002] residual: 6.000000006167738e-06
コードG.7　TensorFlowで単一画像のIG（logit出力モデル）
import tensorflow as tf

def integrated_gradients(model, image, baseline, class_id, steps=64):
    # image, baseline: (H,W,C), model output: (batch,classes)
    # バッチ内の各入力が独立に処理される推論モデルを仮定
    if steps < 1:
        raise ValueError("steps must be positive")
    image = tf.cast(image,tf.float32)
    baseline = tf.cast(baseline,tf.float32)
    a = tf.linspace(0.,1.,steps+1)[:,None,None,None]
    path = baseline + a*(image-baseline)
    with tf.GradientTape() as tape:
        tape.watch(path)
        scores = model(path,training=False)[:,class_id]
        total = tf.reduce_sum(scores)
    grad = tape.gradient(total,path)
    return (image-baseline)*tf.reduce_mean((grad[:-1]+grad[1:])/2,axis=0)

G.7　Grad-CAMと画像の領域説明

対象クラスのlogit $y^c$ と畳み込み特徴マップ $A^k$ に対し、勾配を空間平均する。

$$\alpha_k^c=\frac1{HW}\sum_{i,j}\frac{\partial y^c}{\partial A_{ij}^k},\quad L^c=\operatorname{ReLU}(\sum_k\alpha_k^c A^k)$$

ヒートマップは対象クラスを支持する領域を粗く示す。負の寄与はReLUで除かれる。元画像へ補間して重ねるが、境界の精密なセグメンテーションではない。第30章参照。

コードG.8　Grad-CAM関数（Functional CNN、単一画像・logit出力）
import tensorflow as tf

def gradcam(model, image_batch, layer_name, class_id):
    probe = tf.keras.Model(model.inputs,[model.get_layer(layer_name).output,model.output])
    with tf.GradientTape() as tape:
        maps, logits = probe(image_batch,training=False)
        score = logits[0,class_id]
    grads = tape.gradient(score,maps)
    weights = tf.reduce_mean(grads[0],axis=(0,1))
    cam = tf.nn.relu(tf.reduce_sum(maps[0]*weights,axis=-1))
    return tf.math.divide_no_nan(cam,tf.reduce_max(cam))

G.8　Attentionの可視化と系列データ

Attention行列 $A=\operatorname{softmax}(QK^\top/\sqrt{d_k})$ の行はQuery、列はKeyに対応する。各ヘッドの推論時の重みはKey方向に正規化され、重みが高いことは対応するValueの混合係数が大きいことを示すが、最終出力への寄与や因果的な重要性とは限らない。Valueの方向、残差接続、後続層、ヘッド間の相互作用も関係する。

文章ではトークンとサブワードの対応、paddingの除外を確認する。時系列では予測起点より後の未知の観測値へのAttentionを許さない。既知の入力窓内では双方向の参照が可能な場合もある。第27章参照。

コードG.9　KerasでAttention重みを取得
import tensorflow as tf
mha = tf.keras.layers.MultiHeadAttention(num_heads=2,key_dim=4)
x = tf.random.normal((1,5,8),seed=42)
y, weights = mha(x,x,return_attention_scores=True,use_causal_mask=True,training=False)
print(y.shape,weights.shape)  # (1,5,8), (1,2,5,5)

G.9　反実仮想・特徴除去・説明の検証

反実仮想説明は予測を変える近傍入力を探索する。例えば $\min_{x'} \lambda L(f(x'),y^*)+d(x,x')$ を、変更可能な特徴や実現可能性の制約下で解く。予測が変わっても現実に介入した結果が同じとは限らない。

画像の遮蔽、文章の単語削除、特徴群の除去による性能変化は説明の検証に役立つ。ただし分布外の入力が生まれるので、複数の置換方法とランダム除去との比較が必要。パラメータのランダム化によって説明が変化するかも確認する。

検証方法注意
忠実度上位特徴の除去・挿入分布外入力
安定性seed・背景・入力微小変化真の予測変化と区別
局所近似近傍の重み付き誤差近傍分布に依存
公平性群別の性能・説明分布説明だけで公平性を保証しない
再現性モデル版・対象・尺度・背景を保存同じ条件で再計算

G.11　実践チェックリストと参考資料

  • 説明の対象クラス・出力尺度・モデル版を固定する。
  • 検証集合を用い、背景データは原則として学習集合から選ぶ。
  • 正解・誤分類・低信頼度の例を偏りなく抽出する。
  • 相関、分布外摂動、基準値、seedによる変化を確認する。
  • 説明から得た仮説を独立評価・アブレーションで検証する。

確認問題

重要度が低い特徴は不要か？

相関特徴による代替や交互作用があり得る。特徴群の除去と再学習で確認する。

IGの合計が出力差と異なる場合は？

積分ステップ、対象出力、基準値、推論モードを確認する。

Attentionが高い単語が予測原因と断言できるか？

できない。Valueや後続層の影響も検討し、介入実験で仮説を検証する。
