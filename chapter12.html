12.1 スクラッチ実装の設計

第11章では一つのネットワークについて勾配を導きました。本章ではそれを再利用可能な部品に分け、任意の幅・深さの全結合ネットワークを組み立てます。目的は高速なライブラリを作ることではなく、Kerasの fit() が隠している仕事を理解することです。

以下のコードはPython 3とNumPyを使い、上から順に同じNotebookで実行します。Matplotlibは可視化にのみ必要です。完全版のPythonファイルも配布します。

部品責務
Layer順伝播・入力への勾配・自分のパラメータの勾配
Lossスカラーの損失と出力に対する勾配
Sequential層を順方向・逆方向に呼び出す
Optimizer勾配を使ってパラメータを更新する

各層は直前の順伝播の中間値を保存します。逆伝播が終わるまでは別の入力で順伝播しないことが、この簡易設計の約束です。分岐や重み共有は対象外です。

12.2 全結合層と重みの初期化

入力 $X$ のshapeを $(B,d)$、出力幅を $h$ とします。重み $W$ は $(d,h)$、バイアス $b$ は $(h,)$ です。順伝播は $Z=XW+b$。上流から受け取る勾配 $D$ は $(B,h)$ です。

$$dW=X^\top D,\quad db=\sum_{i=1}^B D_{i,:},\quad dX=DW^\top$$

同一層のユニットが同一の入出力側の重みとバイアスを持つなど、対称な状態では同じ更新を受け、対称性が破れません。乱数で初期化し、入力・出力幅に応じて分散を調整します。ここではGlorot型の非切断正規分布（分散 $2/(d+h)$）と、ReLU向けHe型の非切断正規分布（分散 $2/d$）を使います。バイアスは0で構いません。第19章で理論を詳しく扱います。

コード12.1　Denseクラス
import numpy as np
class Dense:
    def __init__(self, n_in, n_out, rng, relu_next=False):
        scale=np.sqrt(2/n_in) if relu_next else np.sqrt(2/(n_in+n_out))
        self.W=rng.normal(0,scale,(n_in,n_out)); self.b=np.zeros(n_out)
    def forward(self,x):
        self.x=x
        return x@self.W+self.b
    def backward(self,d):
        self.dW=self.x.T@d; self.db=d.sum(axis=0)
        return d@self.W.T
    def parameters(self):
        return [(self.W,self.dW),(self.b,self.db)]

backward は更新せず、勾配を保存して入力側へ返します。すべての勾配がそろってから更新するため、古い重みと新しい重みが混在しません。

12.3 活性化層とSequentialモデル

ReLUの局所微分は正領域で1、負領域で0です（原点は本実装では0と定めます）。Tanhは出力 $a$ を保存すれば $1-a^2$ で微分できます。どちらも上流勾配と要素ごとの積を取ります。

コード12.2　活性化層とモデル
class ReLU:
    def forward(self,x):
        self.mask=x>0
        return np.maximum(x,0)
    def backward(self,d):
        return d*self.mask

class Tanh:
    def forward(self,x):
        self.a=np.tanh(x)
        return self.a
    def backward(self,d):
        return d*(1-self.a**2)

class Sequential:
    def __init__(self,layers):
        self.layers=layers
    def forward(self,x):
        for layer in self.layers: x=layer.forward(x)
        return x
    def backward(self,d):
        for layer in reversed(self.layers): d=layer.backward(d)
        return d
    def parameters(self):
        return [pair for layer in self.layers if isinstance(layer,Dense)
                for pair in layer.parameters()]

Sequentialは各層の内部計算を知る必要がありません。共通のforward/backwardというインターフェースで合成します。学習パラメータを持つ層はここではDenseだけです。KerasではLayerやModelがさらに変数の追跡・保存・自動微分を担当します。

12.4 損失関数を実装する

回帰では全要素の平均二乗誤差を採用します。出力が複数ある場合も正しく平均化するため、標本数ではなく要素数 $N=Bh$ で割ります。

$$J=\frac1N\sum_{ij}(z_{ij}-y_{ij})^2,\quad \frac{\partial J}{\partial z}=\frac{2(z-y)}N$$

分類では整数ラベルを受け取るSoftmaxと交差エントロピーの融合実装を作ります。最大ロジットを引いてから指数を計算することでオーバーフローを防ぎ、確率を対数に戻す操作を避けます。

$$\log p_{ik}=z_{ik}-\log\sum_j e^{z_{ij}},\quad D_{ik}=\frac{p_{ik}-\mathbf1[y_i=k]}B$$
コード12.3　MSEとSoftmax交差エントロピー
class MSE:
    def forward(self,z,y):
        assert z.shape==y.shape and z.size>0
        self.e=z-y
        return np.mean(self.e**2)
    def backward(self):
        return 2*self.e/self.e.size

class SoftmaxCE:
    def forward(self,z,y):
        assert z.ndim==2 and y.shape==(len(z),)
        assert np.issubdtype(y.dtype,np.integer) and np.all((y>=0)&(y<z.shape[1]))
        shifted=z-z.max(axis=1,keepdims=True)
        logp=shifted-np.log(np.exp(shifted).sum(axis=1,keepdims=True))
        self.p=np.exp(logp); self.y=y.copy()
        return -logp[np.arange(len(y)),y].mean()
    def backward(self):
        d=self.p.copy(); d[np.arange(len(self.y)),self.y]-=1
        return d/len(self.y)

分類の最後のDenseは活性化なしです。損失にSoftmaxを内包しているため二重適用しません。確率が必要な推論時には安定したSoftmaxを別途計算します。損失関数で既に平均化したため、Denseの逆伝播で再びバッチサイズで割りません。

12.5 SGDとMomentum

SGDは現在の勾配で更新します。Momentumは過去の勾配を蓄積した速度を使います。本章では $v_t=\beta v_{t-1}+g_t$、$\theta_t=\theta_{t-1}-\eta v_t$ という定義を採用します（指数移動平均型の定義とは学習率の尺度が異なります）。

コード12.4　オプティマイザ
class SGD:
    def __init__(self,lr=.05): self.lr=lr
    def step(self,pairs):
        for p,g in pairs: p-=self.lr*g

class Momentum:
    def __init__(self,lr=.03,beta=.9):
        self.lr=lr; self.beta=beta; self.v={}
    def step(self,pairs):
        for p,g in pairs:
            v=self.v.setdefault(id(p),np.zeros_like(p))
            v*=self.beta; v+=g; p-=self.lr*v

Momentumの状態はパラメータ配列ごとに保持します。配列を作り直さずインプレースで更新し、異なるモデルを学習するときはオプティマイザも新しく作ります。勾配の更新と重みの更新を分離したため、後からAdam等を追加できます。

12.6 数値微分による勾配チェック

実装の正しさを確認するには、学習曲線だけでは不十分です。中央差分で各パラメータを微小に変化させ、解析勾配と比較します。

$$g_j^{num}=\frac{J(\theta+he_j)-J(\theta-he_j)}{2h}$$

検査にはfloat64を使い、ReLUの折れ点を避けるためTanhの小さなモデルを使います。パラメータを必ず元に戻し、解析勾配は先にコピーしておきます。数値微分はパラメータ数に比例して順伝播が必要なため、学習そのものには使いません。

コード12.5　全パラメータの検査
def gradient_check(model,loss_fn,x,y,h=1e-5):
    loss_fn.forward(model.forward(x),y)
    model.backward(loss_fn.backward())
    pairs=[(p,g.copy()) for p,g in model.parameters()]
    errors=[]
    for p,g in pairs:
        numeric=np.zeros_like(p)
        for idx in np.ndindex(p.shape):
            old=p[idx]
            try:
                p[idx]=old+h; plus=loss_fn.forward(model.forward(x),y)
                p[idx]=old-h; minus=loss_fn.forward(model.forward(x),y)
            finally: p[idx]=old
            numeric[idx]=(plus-minus)/(2*h)
        np.testing.assert_allclose(numeric,g,atol=1e-7,rtol=1e-5)
        errors.append(float(np.max(np.abs(numeric-g))))
    return errors
コード12.6　二種類の損失で検査
rng=np.random.default_rng(1)
model=Sequential([Dense(2,3,rng),Tanh(),Dense(3,2,rng)])
x=rng.normal(size=(4,2)); y=np.array([0,1,1,0])
print(gradient_check(model,SoftmaxCE(),x,y))
print(gradient_check(model,MSE(),x,np.eye(2)[y]))

実行結果：交差エントロピーの最大絶対誤差は約 $7.03\times10^{-12}$、MSEは約 $9.43\times10^{-12}$。いずれも許容誤差を満たしました。検査後は再度順伝播してキャッシュを作り直してください。

12.7 ミニバッチ学習と検証

1エポックは訓練データを一巡することです。各エポックでインデックスをシャッフルし、最後の端数バッチも処理します。バッチごとに順伝播、損失、逆伝播、更新を行います。検証データは更新に使いません。

コード12.7　学習ループ
def fit(model,loss_fn,opt,x,y,xv,yv,epochs=100,batch_size=32,seed=0):
    rng=np.random.default_rng(seed); history=[]
    for epoch in range(epochs):
        order=rng.permutation(len(x))
        for start in range(0,len(x),batch_size):
            idx=order[start:start+batch_size]
            loss_fn.forward(model.forward(x[idx]),y[idx])
            model.backward(loss_fn.backward())
            pairs=model.parameters()
            if not all(np.isfinite(g).all() for _,g in pairs):
                raise FloatingPointError('non-finite gradient')
            opt.step(pairs)
        # epoch終了時の同じ重みで両方を測る
        train=float(loss_fn.forward(model.forward(x),y))
        val=float(loss_fn.forward(model.forward(xv),yv))
        history.append((train,val))
    return np.array(history)

エポック終了時の同じ重みで全訓練データと検証データの損失を計算するため、曲線を比較できます。大規模データでは評価もバッチ化し、標本数（または要素数）に応じた加重平均を取ります。ここでは簡潔さを優先して全件評価します。

12.8 実践1：非線形回帰

入力を区間 $[-2,2]$ から生成し、$y=\sin(2x)+\epsilon$ を予測します。ノイズの標準偏差は0.05です。240標本を訓練、80標本を検証に使い、Tanhの隠れ層を24ユニットとします。データは独立に生成されているため、この例では生成順の分割で構いません。

コード12.8　回帰モデル
def regression():
    rng=np.random.default_rng(42)
    x=rng.uniform(-2,2,(320,1)); y=np.sin(2*x)+rng.normal(0,.05,x.shape)
    model=Sequential([Dense(1,24,rng),Tanh(),Dense(24,1,rng)])
    history=fit(model,MSE(),Momentum(.015,.9),x[:240],y[:240],x[240:],y[240:],epochs=150)
    return x,y,model,history
x,y,model,history=regression()
print(history[0],history[-1])

第1エポックの訓練MSEは0.38429、最終訓練MSEは0.00459、最終検証MSEは0.00418です。これは検証値であり、独立テストによる評価ではありません。

コード12.9　予測曲線を描く
import matplotlib.pyplot as plt
grid=np.linspace(-2,2,300)[:,None]
plt.scatter(x[:,0],y[:,0],s=8,alpha=.3)

12.9 実践2：非線形分類

第7章のXOR型の問題を連続値へ拡張します（ここでは同符号を1とするXNOR型のラベル付けです）。平面の第一・第三象限をクラス1、残りをクラス0とします。単一の直線では分離できません。400標本を訓練、100標本を検証、100標本をテストに使います。ReLUを二層に配置し、出力は2クラスのロジットです。

コード12.10　分類モデル
def classification():
    rng=np.random.default_rng(7)
    x=rng.uniform(-1,1,(600,2)); y=(x[:,0]*x[:,1]>0).astype(int)
    model=Sequential([Dense(2,24,rng,True),ReLU(),Dense(24,16,rng,True),ReLU(),Dense(16,2,rng)])
    history=fit(model,SoftmaxCE(),Momentum(.025,.9),x[:400],y[:400],x[400:500],y[400:500],epochs=100)
    acc=np.mean(model.forward(x[500:]).argmax(axis=1)==y[500:])
    return x,y,model,history,acc
x,y,model,history,accuracy=classification()
print(history[-1],accuracy)

最終検証交差エントロピーは0.03178、テストAccuracyは99.0%でした。固定シードの一実験であり、他のデータにおける性能を保証しません。

12.10 デバッグとKerasへの橋渡し

スクラッチ実装ではshapeの誤り、二重平均、古いキャッシュ、非有限値が代表的な失敗です。まず少数の標本で学習できるか確認し、勾配チェックを行い、次にデータ分割を適切に設定します。

症状対策
損失が減らない勾配チェック、学習率、ラベルのshape、初期化
NaN・Inf入力の有限性、安定した損失、学習率を確認
訓練のみ改善検証分割、過学習、データリークを確認
結果が再現しない初期化・シャッフルの乱数シードを固定

KerasではDense、Activation、Sequential、Loss、Optimizerが対応する部品です。自動微分でbackwardの手書きが不要になります。一方、shape・損失の集約・訓練と検証の区別は引き続き自分で判断しなければなりません。

本実装はCPU上の小規模な教育用モデルです。GPU、分岐、重み共有、Dropout、Batch Normalization、モデル保存、分散学習には対応していません。実際のコンペではTensorFlowを使います。

12.11 まとめと確認問題

学習可能なネットワークを部品に分解し、順伝播・逆伝播・更新・検証を一つのシステムとして実装しました。

問1　Denseの重みのshapeは？

入力幅d、出力幅hなら(d,h)。

問2　なぜ重みを乱数で初期化するか？

ユニット間の対称性を破るため。バイアスは通常0でもよい。

問3　逆伝播前に別の入力をforwardすると？

キャッシュが上書きされ、勾配が誤る。

問4　MSEの平均化はどこで行うか？

forwardでは全要素の平均を取り、backwardでは2倍した誤差を全要素数で割る。

問5　なぜSoftmax前に最大値を引くか？

確率を変えず指数のオーバーフローを防ぐ。

問6　最後の端数バッチはどうするか？

そのまま処理し、実際のバッチサイズで平均化する。

問7　Momentumの状態を別モデルに流用すべきか？

いいえ。モデルごとに新規作成する。

問8　勾配チェックが通れば汎化性能も保証されるか？

保証されない。勾配チェックは選んだ入力・パラメータ近傍での微分実装の検査である。

発展演習：学習アルゴリズムの比較

同じ回帰データ・初期値・バッチ順序でSGDとMomentumを比較し、検証損失をグラフ化してください。学習率を変えて結果を考察しましょう。

解答・実装例
コード12.12　条件を統制した比較
import matplotlib.pyplot as plt
rng=np.random.default_rng(42)
x=rng.uniform(-2,2,(320,1)); y=np.sin(2*x)+rng.normal(0,.05,x.shape)
for name,opt in [('SGD',SGD(.015)),('Momentum',Momentum(.015,.9))]:
    r=np.random.default_rng(123)
    model=Sequential([Dense(1,24,r),Tanh(),Dense(24,1,r)])
    h=fit(model,MSE(),opt,x[:240],y[:240],x[240:],y[240:],epochs=100,seed=0)
    plt.plot(np.arange(1,len(h)+1),h[:,1],label=name)
    print(name, h[-1,1])
plt.xlabel('epoch'); plt.ylabel('validation MSE'); plt.yscale('log'); plt.legend(); plt.show()

同じ学習率でもMomentumは蓄積により更新幅が異なります。最適な学習率を個別に探索する比較も行いましょう。検証MSEを比較し、最終性能は別のテストデータで評価します。

独立再実行結果（100エポック後の検証MSE）：学習率0.005ではSGD 0.27518、Momentum 0.01042、0.015では0.07803、0.00612、0.03では0.01332、0.00400。これはこのデータ・初期値・バッチ順での結果であり、一般的な優劣を意味しません。
