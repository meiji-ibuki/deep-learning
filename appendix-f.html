F.1　診断の基本手順

最初の異常を見つけることが重要である。最後に出た例外が根本原因とは限らない。完全なトレースバック、乱数seed、入力のshape・dtype、ライブラリ版、実行端末を記録し、変更は一度に一つだけにする。第23章参照。

症状・エラー例原因候補診断修正・対策
例外発生入力契約違反・環境最初の自作コード行と例外型最小再現を作る
例外なしで精度低いラベルずれ・分割・設計小標本への過適合テストデータと損失の契約を点検
再現しない乱数・並列・状態seed・環境・分割を記録再現条件を固定

F.3　Shape・軸・ブロードキャスト

shapeは要素数だけでなく軸の意味を表す。軸を入れ替える場合はreshapeではなくtranspose等を使う。画像は通常(B,H,W,C)、系列は(B,T,D)、表形式は(B,D)。Noneは未確定の次元を示す。

症状・エラー例原因候補診断修正・対策
Matrix size-incompatible内積の軸が不一致両辺のshape内側の次元を合わせる
expected ndim=4, found ndim=3チャネルまたはバッチ軸不足各軸の意味必要な軸だけexpand_dims
cannot reshape array要素数不一致sizeの積変換先の要素数を一致
Concatenate shape mismatch連結軸以外が異なる各枝の出力shape空間サイズや系列長を揃える
Add shape mismatch残差枝の幅が違うmainとskipのshape1×1 ConvやDenseで射影
lossが不自然に小さい意図しないbroadcast損失前のshape予測と教師のshapeを明示
Negative dimension sizeカーネルが入力より大きい出力サイズ公式padding・kernel・strideを調整
Attention mask mismatchquery/key軸が違うB,Tq,Tkを確認broadcast可能なマスクへ

import numpy as np

F.6　NaN・Infと数値安定性

NaNをゼロに置き換える前に発生箇所を特定する。入力、logits、loss、gradient、更新後の重みの順に調べる。数値安定化は目的関数を変えない方法を優先する。

症状・エラー例原因候補診断修正・対策
初回lossがNaN欠損・log(0)・不正ラベルisfiniteと値域欠損方針・安定な損失を選ぶ
途中からlossがInf学習率過大・勾配爆発勾配norm・更新norm学習率を下げ、必要ならclip
exp overflow大きなlogits最大値確認maxを引くsoftmax・logsumexp
0除算分散ゼロ・空マスク分母と有効数ゼロ分母時の定義を決める
FP16で異常表現範囲不足FP32で比較mixed policyとloss scalingを確認
正規化後NaN標準偏差ゼロ列ごとの分散定数列除去または安全なscale
コードF.6　安定なsoftmaxの数値実験
import numpy as np
z = np.array([1000., 1001., 1002.])
with np.errstate(over='ignore', invalid='ignore'):
    naive = np.exp(z) / np.exp(z).sum()
p = np.exp(z-z.max()); p /= p.sum()
assert np.isnan(naive).any()
assert np.isfinite(p).all() and np.isclose(p.sum(), 1)
print(p)
コードF.7　非有限値を発生演算で検出（意図的な異常例）

finally:
    tf.debugging.disable_check_numerics()

F.7　勾配・学習停滞・過学習

少数標本への過適合テストは、拡張・強い正則化を外して小さな訓練集合を覚えられるか調べるもの。成功しても汎化の保証ではない。第19章・第23章参照。

症状・エラー例原因候補診断修正・対策

一部の勾配がNone未使用の枝・stop_gradient変数とlossの依存意図した未使用枝・勾配遮断か確認（通常、凍結変数はtrainable_variablesに含まれない）
勾配がほぼゼロ飽和・初期化層別normと活性化初期化・活性化・正規化を見直す
lossが横ばい学習率・教師ずれ少数標本テスト入力とラベル、更新量を確認

accuracyが多数派率不均衡・閾値混同行列・PR曲線重み・評価指標・閾値を検証
コードF.8　変数ごとの勾配診断
import tensorflow as tf
m = tf.keras.Sequential([tf.keras.Input((4,)), tf.keras.layers.Dense(1)])
x = tf.ones((8,4)); y = tf.zeros((8,1))
with tf.GradientTape() as tape:
    loss = tf.reduce_mean(tf.square(m(x, training=True)-y))
g = tape.gradient(loss, m.trainable_variables)
for v, grad in zip(m.trainable_variables, g):
    if grad is None:
        raise RuntimeError(f'Disconnected: {v.name}')
    tf.debugging.assert_all_finite(grad, v.name)
    print(v.name, tf.linalg.global_norm([grad]).numpy())

F.8　GPU・メモリ・実行速度

OOMは重みだけでなく活性化、勾配、optimizer状態、一時領域にも依存する。メモリgrowthは割当方式を変えるだけで、演算自体に必要な容量を削減しない。

症状・エラー例原因候補診断修正・対策
ResourceExhaustedError / OOMバッチ・解像度・系列長過大最小batchで比較batch・解像度を下げる
Foldを重ねるとOOM旧モデル参照残存GPU使用量をFoldごとに記録参照削除・clear_session・必要時再起動
GPU利用率が低い入力供給ボトルネックProfilerで待ち時間prefetch・並列map
GPUがCPUより遅い小規模・転送負荷warmup後の時間batchを調整し実測
Physical devices cannot be modified初期化後に設定変更設定実行順新規プロセスで先に設定
推論OOM全データ一括推論batchと出力容量分割推論・逐次保存
コードF.9　GPU割当設定（容量削減ではない）
import tensorflow as tf
# 新規プロセスで、GPU初期化より前に実行
for gpu in tf.config.list_physical_devices('GPU'):
    tf.config.experimental.set_memory_growth(gpu, True)
print(tf.config.list_physical_devices('GPU'))

F.10　モデル保存・転移学習

Keras 3では全モデル保存に.keras、単一ファイルの重み保存に.weights.h5を使う（構成は別途必要。コンパイル済みモデルではoptimizer状態が含まれる場合もある）。SavedModelへの推論用出力はmodel.exportを利用する。信頼できないモデルの安全設定を安易に解除しない。

コードF.11　保存前後の予測一致テスト
import tempfile
from pathlib import Path
import tensorflow as tf
m = tf.keras.Sequential([tf.keras.Input((2,)), tf.keras.layers.Dense(1)])

    restored = tf.keras.models.load_model(path)

import pandas as pd
import numpy as np

assert list(out.columns) == list(sample.columns)
assert np.isfinite(out.target).all() and out.target.between(0,1).all()
