22.1　評価と検証の目的

評価指標（metric）は目的への適合度を測る尺度であり、損失関数は学習時に最適化する量である。例えばAUCを評価する場合でもBCEを学習損失として使用できる。訓練データは重みの学習、検証データはモデルや閾値の選択、テストデータは選択後の性能推定に使う。テストを繰り返し参照すれば実質的に検証データとなる。

評価の対象は、モデル単体ではなく前処理・推論・後処理まで含む手続きである。実運用で患者単位の予測を行うなら患者単位で分割し、未来を予測するなら過去から未来への順序を保つ。標本が独立同分布という仮定が崩れると、ランダム分割は楽観的になり得る。

22.2　回帰の評価指標

残差を $e_i=\hat y_i-y_i$ とする。回帰指標は誤差の大きさ、単位、外れ値への感度が異なる。

$$\mathrm{MAE}=\frac1N\sum_i|e_i|,\quad \mathrm{RMSE}=\sqrt{\frac1N\sum_i e_i^2}$$ $$R^2=1-\frac{\sum_i e_i^2}{\sum_i(y_i-\bar y)^2}$$

RMSEは大きな誤差を強く罰する。MAEとRMSEは目的変数と同じ単位を持つ。決定係数は平均予測を基準にした相対的改善で、負にもなり得る。正解が一定なら数式上は定義できない（ライブラリの有限値処理に注意）。MAPEはゼロ付近で不安定であり、RMSLEは非負の値を前提とする。

指標方向用途・注意
MAE小典型的な絶対誤差
RMSE小大誤差を重視
R²大平均予測との比較
MAPE小ゼロ付近に注意
RMSLE小非負・相対的な誤差
コード22.1　回帰指標の計算
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
y = np.array([1., 2., 3., 4.])
pred = np.array([1., 2., 4., 6.])
print(mean_absolute_error(y, pred))
print(np.sqrt(mean_squared_error(y, pred)))
print(r2_score(y, pred))

22.3　混同行列と二値分類指標

二値分類では陽性を1とする。予測確率を閾値以上なら1に変換し、混同行列（confusion matrix）で誤りの種類を数える。

真値＼予測01
0TNFP
1FNTP
$$\mathrm{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}$$ $$\mathrm{Precision}=\frac{TP}{TP+FP},\quad \mathrm{Recall}=\frac{TP}{TP+FN}$$ $$\mathrm{Specificity}=\frac{TN}{TN+FP},\quad F_1=\frac{2TP}{2TP+FP+FN}$$

分母が0の場合の扱いはあらかじめ定める。陽性率1%のデータで全件陰性と予測するとAccuracyは99%だがRecallは0。Balanced AccuracyはRecallとSpecificityの平均である。誤検出と見逃しの費用が異なる場合、閾値を検証データで調整する。

コード22.2　混同行列と閾値探索
import numpy as np
from sklearn.metrics import confusion_matrix, f1_score
y = np.array([0,0,1,0,1,0,1,1])
p = np.array([.08,.19,.32,.45,.55,.67,.81,.94])
thresholds = np.unique(np.r_[0, p, 1])
best = max(thresholds, key=lambda t: f1_score(y, p >= t, zero_division=0))
print(best, confusion_matrix(y, p >= best, labels=[0,1]))

22.4　ROC曲線とPR曲線

ROC曲線は閾値を動かしたときの偽陽性率 $FPR=FP/(FP+TN)$ と真陽性率 $TPR=Recall$ の関係である。ROC-AUCは陽性のスコアが陰性より高い確率（同点は半分）と解釈できる。ランダム順位の期待値は0.5。両クラスが存在する必要がある。

PR曲線はRecallに対するPrecisionを描く。陽性が少ないとき、少数の偽陽性でもPrecisionが低下するため、ROCと併用すると有用である。母集団でスコアとラベルが独立ならPR曲線の基準は陽性率。有限標本のランダム順位のAPの期待値は厳密には陽性率と一致しない場合がある。Average Precision（AP）はRecallが増加する順に、その増分でPrecisionを重み付けした値であり、台形積分によるPR-AUCやKerasのAUC(curve="PR")の近似値とは一般に一致しない。

$$AP=\sum_n(R_n-R_{n-1})P_n$$

ここではRecallが増える順で記述した。順位指標は順位と同点関係を保存する狭義単調増加変換で変わらないが、確率の正しさは保証しない。

コード22.3　ROCとPRの計算・描画
import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import (roc_curve, precision_recall_curve,
    roc_auc_score, average_precision_score)
rng = np.random.default_rng(22)
y = np.r_[np.zeros(950, dtype=int), np.ones(50, dtype=int)]
s = rng.normal(y * 1.7, 1)
fpr, tpr, _ = roc_curve(y, s)
p, r, _ = precision_recall_curve(y, s)
print(roc_auc_score(y,s), average_precision_score(y,s))
fig, ax = plt.subplots(1,2)
ax[0].plot(fpr,tpr); ax[0].set(xlabel='FPR',ylabel='TPR')
ax[1].plot(r,p); ax[1].set(xlabel='Recall',ylabel='Precision')
plt.show()

22.5　確率予測とキャリブレーション

確率予測では、0.8と予測された事例の約80%が陽性であることが望ましい。この性質を校正（calibration）という。Log LossとBrier Scoreは確率予測の評価に使われる。

$$\mathrm{Brier}=\frac1N\sum_i(p_i-y_i)^2$$ $$\mathrm{LogLoss}=-\frac1N\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$$

信頼度図は予測確率を区間に分け、区間内の平均予測確率と実際の陽性率を比較する。区間数や標本数に依存する。温度スケーリングではロジットを正の温度 $T$ で割る。二値分類では順位は保たれるが確率が変わる。校正用データはモデルの重みの学習に使ったデータと分離し、テストで最終評価する。

コード22.4　確率予測の評価
from sklearn.metrics import log_loss, brier_score_loss
from sklearn.calibration import calibration_curve
y = [0,0,1,1,0,1]
p = [.1,.4,.4,.8,.6,.9]
print(log_loss(y,p), brier_score_loss(y,p))
observed, predicted = calibration_curve(y,p,n_bins=3)
print(predicted, observed)

22.6　多クラス・マルチラベル分類

多クラス分類では各クラスを陽性とみなすOne-vs-Restの指標を集約できる。Macroはクラスごとの単純平均、Weightedは真の標本数で重み付けした平均、MicroはTP・FP・FNを全クラスで合算してから計算する。単一ラベル多クラス分類で全クラスを対象とし、各標本に予測ラベルが1個ある場合、Micro-F1はAccuracyと一致する。

マルチラベル分類では各ラベルのスコアを個別に閾値判定する方法が一般的である。ラベル間の統計的独立性を仮定する必要はない。Subset Accuracyは全ラベルが一致した標本だけを正解とするため厳しい。Hamming Lossはラベル単位の誤り率。多クラスAUCではOvR/OvOおよび平均方式を明示する。

集約重視する単位
Macro各クラスを等しく
Weighted頻出クラスの影響が大きい
Micro各判定を等しく
Samplesマルチラベルの各標本
コード22.5　多クラスの評価
from sklearn.metrics import classification_report, f1_score
y = [0,0,0,0,1,1,2]
p = [0,0,0,1,1,0,0]
print(classification_report(y,p,zero_division=0))
for average in ['macro','micro','weighted']:
    print(average, f1_score(y,p,average=average,zero_division=0))

22.7　交差検証と分割方法

K-FoldではデータをK個の部分集合に分割し、各回で1個を検証、残りを訓練に使う。各モデルは独立に初期化する。Stratified K-Foldはクラス比率をなるべく保つ。Group K-Foldは同一グループを訓練と検証にまたがせない。StratifiedGroupKFoldは両方を考慮するが、完全な層化が可能とは限らない。時系列では未来の情報を使わないようTimeSeriesSplit等で分割し、必要に応じgapを設ける。

分割適用例注意
KFold独立な回帰標本順序に注意
StratifiedKFold分類少数クラスの件数
GroupKFold患者・ユーザーグループの重複禁止
TimeSeriesSplit未来予測時刻順・ラベル確定時点
コード22.6　分割方法の検証
import numpy as np
from sklearn.model_selection import GroupKFold, TimeSeriesSplit
X = np.arange(24).reshape(-1,1)
groups = np.repeat(np.arange(8),3)
for tr, va in GroupKFold(4).split(X,groups=groups):
    assert not set(groups[tr]) & set(groups[va])
for tr, va in TimeSeriesSplit(n_splits=4,gap=1).split(X):
    assert tr.max() + 1 < va.min()

22.8　OOF予測と評価値の集約

OOF（Out-of-Fold）予測は、各標本をその標本を訓練に含めないモデルで予測した結果である。元の行番号に書き戻すことで、全標本に対する評価やスタッキング用特徴量を得られる。通常のK-Foldでは全件が一度ずつ予測されるが、時系列分割では最初の訓練区間にOOFがない。欠損を0で埋めて評価してはならない。

$$\mathrm{RMSE}_{OOF}=\sqrt{\frac{\sum_k n_k\mathrm{RMSE}_k^2}{\sum_k n_k}}$$

FoldのRMSEの単純平均とは異なる。AUCやF1も非線形であり、Fold平均と全OOF評価は異なる。特にAUCではFold間でスコア尺度が違うと全OOFの順位が影響を受ける。Fold別スコア・平均・ばらつき・OOFを併記する。Fold間の訓練データは重複するため標準偏差を独立試行の信頼区間とみなさない。

22.9　データリークとモデル選択

前処理のfit、特徴選択、欠損補完、標準化、Target Encoding、データ拡張、閾値調整はすべて分割境界を意識する。検証Foldを使ってEarly Stoppingを行う場合、そのFoldでの評価はエポック選択の影響を受ける。厳密な性能推定には外側Foldと内側検証を分離するNested CV、または独立テストを使用する。Kaggleの公開Leaderboardも繰り返し調整すると過適合し得る。

失敗例対策
全データで標準化Fold内の訓練のみでfit
同一人物が両側に存在Group分割
未来の集計値を特徴量に使用予測時点までの情報に限定
同じ検証で多数候補を選択外側評価または独立テスト
提出順序の不一致IDで照合しテンプレート順に整列

22.10　実践：Kerasによる交差検証

乳がん診断の公開学習用データを題材に二値分類のOOFを作る（医療用途のモデルではない）。外側の5-foldでは各検証Foldをモデル選択に使わず、内側の訓練データからEarly Stopping用の集合を取り出す。標準化は内側訓練だけで適応する。テストは最初に分離し、固定した手続きのFoldモデルの確率平均で評価する。実際のKaggleではテストにラベルがないことが多く、提出テンプレートとIDを照合する。

コード22.7　Kerasによるリーク対策済みOOFとテスト予測
import numpy as np
import tensorflow as tf
from tensorflow import keras
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, StratifiedKFold
from sklearn.metrics import roc_auc_score, average_precision_score, log_loss
X, y = load_breast_cancer(return_X_y=True)
X = X.astype('float32')
y = y.astype('int32')  # 1 = benign
X, Xte, y, yte = train_test_split(X,y,test_size=.2,stratify=y,random_state=22)
cv = StratifiedKFold(5,shuffle=True,random_state=22)
oof = np.full(len(y), np.nan)
test_preds, scores = [], []
for k,(tr,va) in enumerate(cv.split(X,y)):
    a,b = train_test_split(tr,test_size=.2,stratify=y[tr],random_state=22+k)
    keras.backend.clear_session()
    keras.utils.set_random_seed(22+k)
    norm = keras.layers.Normalization(axis=-1)
    norm.adapt(X[a])
    model = keras.Sequential([
        keras.Input(shape=(X.shape[1],)),norm,
        keras.layers.Dense(32,activation='relu'),
        keras.layers.Dense(16,activation='relu'),
        keras.layers.Dense(1,activation='sigmoid')])
    model.compile(optimizer=keras.optimizers.Adam(.001),
                  loss='binary_crossentropy')
    model.fit(X[a],y[a,None],validation_data=(X[b],y[b,None]),
              epochs=100,batch_size=32,verbose=0,
              callbacks=[keras.callbacks.EarlyStopping(
                  monitor='val_loss',patience=10,restore_best_weights=True)])
    assert np.isnan(oof[va]).all()
    oof[va] = model.predict(X[va],verbose=0).ravel()
    scores.append(roc_auc_score(y[va],oof[va]))
    test_preds.append(model.predict(Xte,verbose=0).ravel())
assert np.isfinite(oof).all()
pte = np.mean(test_preds,axis=0)
print('fold AUC',scores,np.mean(scores),np.std(scores,ddof=1))
print('OOF',roc_auc_score(y,oof),average_precision_score(y,oof),log_loss(y,oof))
print('test AUC',roc_auc_score(yte,pte))
np.savez('chapter22_predictions.npz',oof=oof,test=pte)

上記のTensorFlow学習は制作環境で未実行であり、実測スコアは掲載しない。陽性ラベルの意味に注意する。閾値が必要な場合は内側検証で決めるか、OOFで決めた閾値の性能を独立テストで評価する。

22.11　まとめと確認問題

評価は指標の選択と分割設計の両方が重要である。モデル比較の前に、予測対象・予測時点・評価単位を決め、前処理から後処理まで検証境界を守る。

問1　誤差が1,1,4のMAEとRMSEを求めよ。

MAE=2、RMSE=√6。

問2　TP=8, FP=2, FN=4のPrecisionとRecallは？

Precision=8/(8+2)=0.8、Recall=8/(8+4)=2/3。F1=16/(16+2+4)=8/11。

問3　陽性率1%で全件陰性と予測すると？

Accuracyは99%、Recallは0。

問4　ROC-AUCが高ければ確率も正しいか。

保証されない。校正やLog Lossも確認する。

問5　MacroとMicroの違いは？

Macroはクラス別平均、Microは判定数を合算して計算。

問6　同一ユーザーの複数行を分割するには？

GroupKFoldなどでユーザーを分離。

問7　時系列の初期区間にOOFがない場合は？

有効なOOFのある区間だけを評価。

問8　検証データで標準化をfitしてよいか。

不可。訓練の統計量を再利用する。

問9　発展：Fold Aが2標本でRMSE=1、Fold Bが8標本でRMSE=3のときOOF RMSEを求め、単純平均と比較せよ。

√((2×1²+8×3²)/10)=√7.4≈2.720294。単純平均2とは異なる。
