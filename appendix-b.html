B.1 配列の生成・属性・型

参照章：第2章・第3章・第12章

ndarrayは同じdtypeの要素を持つ多次元配列である。形状と型を最初に確認する。

操作用途・注意点
np.array / asarrayリスト等から配列化。asarrayはコピーを省く場合がある
zeros / ones / full / empty初期化。emptyの値は未初期化
arange / linspace刻み幅指定／点数指定。浮動小数の刻みにはlinspaceが便利
shape / ndim / size / dtype / nbytes形状・軸数・要素数・型・要素バッファのバイト数
astype / np.iinfo / np.finfo型変換と表現範囲。整数のオーバーフローに注意
コードB.1　実行例
import numpy as np
x = np.arange(12, dtype=np.float32).reshape(3, 4)
print(x.shape, x.ndim, x.size, x.dtype, x.nbytes)
assert x.nbytes == 48
print(np.linspace(0, 1, 5))
実行結果
(3, 4) 2 12 float32 48
[0.   0.25 0.5  0.75 1.  ]
実装時の注意

学習入力はfloat32を基本とし、数値微分など精度が必要な処理ではfloat64を検討する。ラベルの整数型はモデルの損失関数に合わせる。

B.2 添字・抽出・コピー

参照章：第3章・第12章・第16章

基本スライスで得られる配列はビュー、整数配列・真偽値配列による高度な添字はコピーを返す。

操作用途・注意点
x[i, j] / x[:, j]要素／列。整数添字で軸が消える
x[1:3] / x[..., 0]範囲／末尾軸の抽出
x[mask] / np.where条件抽出／条件による値の選択
np.take_along_axis各行などで異なる位置の値を取得
copy / shares_memory明示コピー／メモリ共有の確認
np.ix_行・列の直積を抽出
コードB.2　実行例
import numpy as np
x = np.arange(12).reshape(3, 4)
v = x[:, 1:3]
c = x[:, [1, 2]]
assert np.shares_memory(x, v)
assert not np.shares_memory(x, c)
print(x[x % 2 == 0])
print(x[np.ix_([0, 2], [1, 3])])
実行結果
[ 0  2  4  6  8 10]
[[ 1  3]
 [ 9 11]]
実装時の注意

x[[0,0]] += 1 は同じ位置への加算を二回保証しない。重複添字の累積にはnp.add.atを使う。

B.3 形状変換・結合・軸操作

参照章：第3章・第13章・第24章・第27章

reshapeは要素数を保つ。メモリ配置によってビューまたはコピーになる。transposeは軸を並べ替える。両者は交換できない。

操作用途・注意点
reshape / ravel / flatten形状変更／一次元化（flattenはコピー）
transpose / moveaxis / swapaxes軸の並べ替え
expand_dims / squeeze長さ1の軸の追加／除去
concatenate / stack既存軸に連結／新しい軸を作る
split / array_split整数で分割数を指定する場合、splitは等分割、array_splitは不均等分割も可能
repeat / tile要素の反復／配列全体の反復
コードB.3　実行例
import numpy as np
x = np.zeros((8, 28, 28, 3))
y = x.transpose(0, 3, 1, 2)
assert y.shape == (8, 3, 28, 28)
a = np.ones((2, 3))
assert np.concatenate([a, a], axis=0).shape == (4, 3)
assert np.stack([a, a], axis=0).shape == (2, 2, 3)
実行結果
実装時の注意
squeeze()はバッチサイズ1の軸まで消すことがある。axisを指定する。NHWCとNCHWの変換はtransposeで行う。
B.4 ブロードキャスト・要素演算
参照章：第3章・第8章・第12章
末尾の軸から比較し、各次元が等しいか一方が1なら演算できる。存在しない先頭軸は1とみなす。
操作用途・注意点
+, -, *, /, **要素ごとの演算
np.newaxis / None長さ1の軸を追加
np.broadcast_to指定形状にブロードキャストした読み取り専用ビュー
maximum / minimum / clip要素ごとの最大・最小・範囲制限
exp / log / log1p / expm1指数・対数。小さい値での桁落ち対策
isfinite / isnan / isinf非有限値の検出
コードB.4　実行例
import numpy as np
x = np.arange(12).reshape(3, 4)
b = np.array([10, 20, 30, 40])
assert (x + b).shape == (3, 4)
w = np.array([1, 2, 3])[:, None]
assert (x * w).shape == (3, 4)
print(x + b)

実行結果
[[10 21 32 43]
 [14 25 36 47]
 [18 29 40 51]]

実装時の注意
(N,1) と (N,) の差は (N,N) になる。回帰の予測値と正解値を同じ形状に揃えてから損失を計算する。
B.5 集約・統計・数値安定性
参照章：第5章・第9章・第10章・第19章
axisは集約で消える軸を指定する。keepdims=Trueで長さ1の軸を残せば再利用しやすい。
操作用途・注意点
sum / mean / std / var合計・平均・標準偏差・分散。ddofの既定値は0
min / max / argmin / argmax極値とその位置
median / quantile / percentile中央値・分位点（0〜1／0〜100）
nanmean / nanstdNaNを除く集約。全欠損には注意
sort / argsort / argpartition整列／順序添字／部分選択
cumsum / diff / unique累積和・差分・ユニーク値
コードB.5　実行例
import numpy as np
x = np.array([[1000., 1001., 1002.], [3., 2., 1.]])
z = x - x.max(axis=1, keepdims=True)
p = np.exp(z) / np.exp(z).sum(axis=1, keepdims=True)
assert np.allclose(p.sum(axis=1), 1)
print(p)

実行結果
[[0.09003057 0.24472847 0.66524096]
 [0.66524096 0.24472847 0.09003057]]

実装時の注意
softmaxでは最大値を引く。標準化の平均・分散は訓練データのみから推定する。
B.6 行列演算・乱数・バッチ処理
参照章：第3章・第12章・第18章・第27章
@は行列積、*は要素積。バッチ付き行列積では末尾2軸が行列、前方がバッチ軸となる。
操作用途・注意点
matmul / @ / dot行列積。dotは高次元でmatmulと異なり、一次元同士では内積になる
einsum添字表記による縮約
linalg.solve / lstsq連立方程式／最小二乗。逆行列の明示計算を避ける
linalg.norm / svd / eighノルム・特異値分解・対称行列等の固有値分解
default_rng / normal / integers乱数生成器・正規乱数・整数乱数
permutation / choice順列・標本抽出
コードB.6　実行例
import numpy as np
rng = np.random.default_rng(42)
x = rng.normal(size=(10, 4))
w = rng.normal(size=(4, 3))
assert np.allclose(x @ w, np.einsum('ni,ij->nj', x, w))
y = np.arange(len(x))
order = rng.permutation(len(x))
for start in range(0, len(x), 4):
    idx = order[start:start+4]
    print(x[idx].shape, y[idx])

実行結果
(4, 4) [6 0 2 8]
(4, 4) [3 4 1 5]
(2, 4) [9 7]

実装時の注意
特徴量とラベルには同じ順列を適用する。シード固定だけではGPU等の完全再現を保証しない。
B.7 pandasの基本・入出力・抽出
参照章：第2章・第16章・第29章・第39章
DataFrameは行・列にラベルを持つ。NumPyと異なり、演算時にラベルで整列する場合がある。
操作用途・注意点
read_csv / read_parquet / to_csv読み込みと保存。CSV提出ではindex=False
head / info / describe / dtypesデータ概観・型・分布の確認
loc / ilocラベル指定／整数位置指定。locのラベル範囲は原則として終点を含む（ラベルの順序・重複に注意）
query / isin / between条件抽出
rename / assign / drop列名変更・列追加・削除
sort_values / reset_index並べ替え・行ラベルの再設定
to_numpy配列化。混合型ではobject等になることがある
コードB.7　実行例
import pandas as pd
from io import StringIO
df = pd.read_csv(StringIO('id,score,group\n10,80,A\n20,50,B\n30,90,A\n'))
print(df.loc[df['score'] >= 80, ['id', 'score']])
df.loc[df['score'] < 60, 'score'] = 60
assert df.iloc[1]['score'] == 60
print(df.to_csv(index=False))

実行結果
   id  score
0  10     80
2  30     90
id,score,group
10,80,A
20,60,B
30,90,A


実装時の注意
連鎖代入 df[mask][col] = value は避け、locで一度に代入する。pandasのバージョンによりコピーの挙動が異なる。Copy-on-Write有効時の連鎖代入は元のDataFrameを更新しない。
B.8 欠損値・型変換・カテゴリ処理
参照章：第16章・第29章
欠損は0と同義ではない。欠損の発生理由を考え、訓練データから補完規則を作る。
操作用途・注意点
isna / notna / dropna欠損検出・除去
fillna / ffill / bfill指定値・直前値・直後値による補完
to_numeric / to_datetime数値・日時変換。errors="coerce"で不正値を欠損に
astype / convert_dtypes型変換・nullable型への推定変換
get_dummies / CategoricalOne-hot化・カテゴリ型
map / replace / str値の変換・文字列処理
duplicated / drop_duplicates重複検出・除去
コードB.8　実行例
import pandas as pd
train = pd.DataFrame({'age':[20, None, 40], 'city':['A','B','A']})
valid = pd.DataFrame({'age':[None, 100], 'city':['C','A']})
median = train['age'].median()
vocab = {c:i+1 for i,c in enumerate(train['city'].dropna().unique())}
def transform(df):
    return pd.DataFrame({'age':df['age'].fillna(median),
                         'city_id':df['city'].map(vocab).fillna(0).astype('int32')})
print(transform(valid))
assert transform(valid).iloc[0].tolist() == [30, 0]

実行結果
     age  city_id
0   30.0        0
1  100.0        1

実装時の注意
この例では未知カテゴリと欠損を同じ予約IDへ割り当てる。区別が必要なら別のIDを予約する。Embeddingではinput_dimを最大ID+1以上にする。時系列のbfillは未来情報を使う可能性がある。
B.9 集約・結合・整形
参照章：第16章・第29章・第40章
groupbyは分割・処理・結合。aggはグループ単位、transformは原則として元の行に対応する結果を返す。
操作用途・注意点
groupby / agg / transformグループ集約・行単位への展開
value_counts / nunique頻度・異なる値の個数
merge / joinキー・インデックスで結合
concat縦・横方向に結合
pivot / pivot_table横持ち変換。pivot_tableは集約可能
melt / explode縦持ち変換・リスト要素の行展開
rank / cut / qcut順位・区間分割・分位点分割
コードB.9　実行例
import pandas as pd
sales = pd.DataFrame({'id':[1,2,3], 'shop':['A','A','B'], 'price':[10,20,30]})
summary = sales.groupby('shop', as_index=False).agg(avg=('price','mean'), n=('id','size'))
result = sales.merge(summary, on='shop', how='left', validate='many_to_one')
assert len(result) == len(sales)
print(result)

実行結果
   id shop  price   avg  n
0   1    A     10  15.0  2
1   2    A     20  15.0  2
2   3    B     30  30.0  1

実装時の注意
結合キーの重複で行数が増えることがある。validateとindicatorで検査する。pandasでは欠損キー同士も一致しうる。目的変数集約は訓練行自身の目的変数を参照しないOOF等で作り、検証・テストには訓練側で作った集計を適用する。時系列では未来の目的変数も参照しない。
B.10 日時・時系列特徴量
参照章：第22章・第33章
予測時点より前の情報だけで特徴量を作る。グループごとの時間順に並べることが前提。同時刻に複数行がある場合は、利用可能時刻や集約規則を先に定義する。
操作用途・注意点
to_datetime / dt日時変換・年月日や曜日の抽出
shift / diff / pct_changeラグ・差分・変化率
rolling / expanding / ewm移動窓・累積窓・指数加重
resample / asfreq時間間隔の変更・集約
merge_asof近い時刻で結合。結合時刻キーを昇順に並べ、directionとtoleranceを指定。未来情報を避ける場合は通常backwardを使う
date_range / Timedelta日時列・時間差
コードB.10　実行例
import pandas as pd
df = pd.DataFrame({'shop':['A']*4+['B']*4, 'date':list(pd.date_range('2025-01-01', periods=4))*2, 'y':[1,2,3,4,10,20,30,40]})
df = df.sort_values(['shop','date'])
df['lag1'] = df.groupby('shop')['y'].shift(1)
df['past_mean'] = df.groupby('shop')['y'].transform(lambda s:s.shift(1).rolling(2).mean())
assert df.loc[df['shop']=='B','lag1'].isna().sum() == 1
print(df)

実行結果
  shop       date   y  lag1  past_mean
0    A 2025-01-01   1   NaN        NaN
1    A 2025-01-02   2   1.0        NaN
2    A 2025-01-03   3   2.0        1.5
3    A 2025-01-04   4   3.0        2.5
4    B 2025-01-01  10   NaN        NaN
5    B 2025-01-02  20  10.0        NaN
6    B 2025-01-03  30  20.0       15.0
7    B 2025-01-04  40  30.0       25.0

実装時の注意
rollingの前にshiftを適用し当日の目的変数を除く。複数ステップ先を一括予測する場合は予測起点以降の実測値も利用できない。
B.11 学習用データと提出ファイルの検査
参照章：第16章・第22章・第29章・第39章・第40章
分割を先に決め、補完・標準化・カテゴリ辞書を訓練側でfitする。検証・テストは同じ規則でtransformする。
操作用途・注意点
reindex列順や行順を明示的に揃える
select_dtypes数値列などを抽出
memory_usage(deep=True)メモリ使用量の概算
np.testing.assert_allclose浮動小数の許容誤差付き検査
pd.testing.assert_frame_equal表の値・型・ラベルの照合
assert / isfinite形状・欠損・値域の検査
コードB.11　実行例
import numpy as np
import pandas as pd
train = pd.DataFrame({'x':[1.,2.,3.], 'z':[5.,5.,5.]})
valid = pd.DataFrame({'z':[5.], 'x':[4.]})
mu = train.mean()
sigma = train.std(ddof=0).replace(0, 1)
X = ((valid.reindex(columns=train.columns)-mu)/sigma).to_numpy(dtype=np.float32)
assert X.shape == (1,2) and np.isfinite(X).all()
sample = pd.DataFrame({'id':[3,1], 'target':[0.,0.]})
pred = pd.DataFrame({'id':[1,3], 'target':[0.2,0.8]})
sub = sample[['id']].merge(pred, on='id', how='left', validate='one_to_one')
assert sub['id'].equals(sample['id']) and sub['target'].notna().all()
assert len(pred) == len(sample) and np.isfinite(sub['target']).all()
assert sub['target'].between(0, 1).all()  # この例は確率提出
print(sub.to_csv(index=False))

実行結果
id,target
3,0.8
1,0.2


実装時の注意
提出列の名前・順番・行数・ID・値域はコンペごとの規約に従う。交差検証では前処理をFoldごとに作り直す。
