E.2　計算量とパラメータ数の読み方

以下は標本1件・層1個の概算。$d$ は入力幅、$h$ は隠れ幅、$T$ は系列長、$k$ はカーネル幅、$C_i,C_o$ は入出力チャネル、$H,W$ は出力空間寸法。MAC（積和）を数え、バイアス加算・活性化・正規化は省略する。FLOPsはMACの約2倍と数える流儀もある。

演算パラメータ（バイアス除外）MAC概算注意
Densedhdh位置ごとなら位置数を掛ける
Conv2Dk²CiCoHWk²CiCo出力サイズを使う
Depthwise＋Pointwisek²Ci+CiCoHW(k²Ci+CiCo)depth multiplier=1
SimpleRNNh(d+h)Th(d+h)時間方向に逐次
LSTM4h(d+h)4Th(d+h)3ゲートと候補状態の計4変換
GRU3h(d+h)3Th(d+h)reset_afterでバイアス数が変わる
Self-Attention4d²4Td²+2T²dQ・K・Vの全ヘッド合計幅と出力幅がd、FFNなし
Transformer FFN2dm2Tdm中間幅m
GCNdhNdh+Eh疎隣接、Nノード、Eは自己ループ等を含む隣接行列の非零要素数。特徴変換を先に行う場合

例えば $k=3,C_i=32,C_o=64$ の通常畳み込みは18,432重み、分離畳み込みは2,336重み。約7.9倍の削減だが、実時間の高速化率とは一致しない。メモリ帯域や演算カーネルの効率も測る（第38章）。

コードE.1　畳み込みのパラメータ比較
import numpy as np
ci, co, k = 32, 64, 3
standard = k*k*ci*co
separable = k*k*ci + ci*co
print(standard, separable, standard/separable)
assert standard == 18432 and separable == 2336

E.3　表形式データとMLP

表形式では列の順序に空間的な意味がないことが多く、CNNを無条件に使う理由はない。カテゴリのEmbeddingは未知カテゴリ用IDを用意し、語彙を訓練Foldで確定する。第29章参照。

モデル強み弱み選定条件
線形・ロジスティック回帰高速・説明容易非線形は特徴設計が必要初期基準
GBDT非線形・相互作用に強い高次元の密な表現は不得手な場合中小規模表データ
MLP柔軟な関数近似標準化・正則化が重要連続特徴・大規模データ
Embedding付きMLP高基数カテゴリを密表現未知カテゴリ・希少カテゴリカテゴリと数値の混合
Tabular Transformer特徴間相互作用を学習計算・調整コスト十分なデータと予算

E.4　CNNと画像バックボーン

画像モデルは局所性と重み共有を利用する。分類用バックボーンとタスク固有ヘッドを区別する。第25章・第30章参照。

モデル設計の核長所制約
LeNet小型Conv＋Pooling教育用・軽量複雑な大画像には不足
AlexNet深いCNN・ReLU歴史的基準大きな全結合部
VGG3×3畳み込みの反復構造が単純大きな重み・計算
GoogLeNetInception複数受容野分岐構造
ResNet残差接続深層化しやすい幅・解像度で負荷増
DenseNet特徴連結特徴再利用活性化メモリ
MobileNetV2分離畳み込み・逆残差端末向け候補実機の演算最適化依存
EfficientNet複合スケーリング精度と予算の調整入力解像度・派生型に依存
ConvNeXt現代化CNN強力な画像特徴大型型は高負荷
ViTパッチ＋Self-Attention大域的関係事前学習・トークン数の影響

E.5　系列モデル：RNN・LSTM・GRU・TCN

系列長とオンライン性を重視する。双方向モデルは入力窓全体が利用可能な分類や予測に適するが、予測起点より後の観測値を入力に含めてはならない。第26章・第33章参照。

モデル状態・受容野利点制約
SimpleRNN隠れ状態小型長期依存・逐次計算
LSTMセル状態＋ゲート長期依存を扱いやすいゲート計算・逐次性
GRU隠れ状態＋ゲートLSTMより少ない重み（同幅）最良精度とは限らない
BiRNN両方向の状態文脈を両側から利用各出力時点より後の入力も利用する
TCN因果・膨張畳み込み時刻並列・受容野設計受容野外の情報なし
コードE.2　系列演算のMAC概算
import numpy as np
T, d, h = 256, 64, 64
for name, mac in [('RNN', T*h*(d+h)), ('LSTM', 4*T*h*(d+h)),
                  ('GRU', 3*T*h*(d+h)), ('Attention', 4*T*d*d+2*T*T*d)]:
    print(name, mac)

E.6　Attention・Transformer

TransformerはAttentionと位置情報、FFN、残差・正規化から成る。密なSelf-Attentionのスコア行列はヘッドごとに $T\times T$。FlashAttentionなどは中間行列の実体化を避けるが、通常の密Attentionの演算量そのものを線形にはしない。第27章参照。

構造適用注意
Encoder-only（BERT等）分類・系列ラベリング双方向文脈、パディングマスク
Encoder-decoder入力系列から出力系列Cross-Attention、出力側因果マスク
Decoder-only自己回帰的系列予測因果マスク、逐次推論
ViT画像分類パッチサイズと系列長
局所Attention長系列窓外の情報伝播を設計

E.7　Autoencoderと表現学習

基本的なAutoencoderの目的は入力の再構成であり、分類性能を直接最大化するものではない。再構成誤差の閾値は正常な検証データなどで設定する。第28章参照。

モデル学習目的利点注意
PCA線形射影の再構成高速・比較基準非線形構造
Undercomplete AE低次元から再構成非線形表現恒等写像・過学習
Denoising AE汚染入力から原入力頑健性ノイズ分布
Sparse AE再構成＋疎性選択的特徴疎性強度
VAE再構成＋KL確率的潜在表現再構成と分布制約のトレードオフ

モデル出力長所注意
YOLO系箱・クラス一段検出・実時間候補解像度・実装差

E.10　転移学習と実装上の比較

Keras Applicationsのバックボーンは入力の前処理が異なる。例えばResNet50は専用前処理、MobileNetV2は通常−1〜1への変換、ConvNeXtとEfficientNetB0は標準設定で前処理を含み、通常は0〜255の画素値を入力する。事前学習重みの有無・入力サイズ・分類ヘッドの有無を記録する。第35章参照。

E.11　公平な比較実験と選定チェックリスト

同じ分割、前処理の適合範囲、評価指標、探索予算を固定する。前処理方式自体は各モデルの入力契約に合わせる。精度だけでなく学習時間、推論の中央値・95パーセンタイル、最大メモリ、モデル保存容量を記録する。バッチサイズ、端末、精度型、ウォームアップを明記する。モデル選択には検証集合、最終報告には独立テストを使う。

コードE.5　同一Foldでの比較（手書き数字を平坦化した教育例）
from sklearn.datasets import load_digits
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.neural_network import MLPClassifier
X,y = load_digits(return_X_y=True)
cv = list(StratifiedKFold(3, shuffle=True, random_state=42).split(X,y))
models = {'Linear': make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)),
          'GBDT': HistGradientBoostingClassifier(max_iter=50, random_state=42),
          'MLP': make_pipeline(StandardScaler(), MLPClassifier(hidden_layer_sizes=(32,), solver='lbfgs', max_iter=1000, random_state=42))}
for name, model in models.items():
    s = cross_val_score(model,X,y,cv=cv,scoring='accuracy')
    print(name, s.mean(), s.std())

この比較は固定設定であり、探索予算やモデルの最適精度を比較する実験ではない。画像の空間構造を利用するCNNは含めていない。

選定チェックリスト

  • 入力の構造を利用する帰納バイアスがあるか。
  • 単純なベースラインを超えるか。
  • データリークを防いだ分割か。
  • 事前学習・外部データが規約上許可されているか。
  • 精度の改善幅に対して計算費用が妥当か。
  • 推論環境で実測したか。
