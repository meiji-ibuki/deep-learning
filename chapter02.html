2.1 Pythonとライブラリの役割

第1章では、データから予測の規則を学ぶという考え方を学びました。実際のコンペでは、モデルを作る前にデータを読み込み、形状や欠損を調べ、数値へ変換する必要があります。学習後には結果を評価し、予測をファイルへ書き出します。本章では、この一連の仕事を担う道具を整理します。

Pythonはプログラムを記述する言語です。ライブラリは、繰り返し必要になる処理をまとめた部品群です。TensorFlowはテンソル演算や自動微分、学習を担い、Kerasはモデルの構築を扱う高水準APIです。本書では主に tf.keras を使用します。

2.3 CPU・GPU・TPUの違い

CPUは多様な処理を柔軟に実行する汎用プロセッサです。GPUは多数の演算を並列に実行することに強く、行列積を頻繁に行う深層学習で活用されます。TPUはテンソル演算に特化したアクセラレータです。GPUやTPUを選択しただけで必ず速くなるわけではなく、データ転送やモデルの大きさ、対応演算が性能を左右します。

資源適する処理注意
CPU前処理、小規模モデル大規模行列演算では時間がかかることがある
GPUCNN、大規模行列演算VRAM不足、転送コスト
TPU対応する大規模テンソル演算専用の実行設定・対応演算

GPUメモリ不足（OOM）が発生した場合、まずバッチサイズや画像サイズを小さくします。GPUの認識と実際の演算配置は別の問題です。TPUの利用方法と分散学習は第38章で扱います。

2.4 NumPy ―― 数値を配列として扱う

Pythonのリストは異なる型を混在できますが、NumPyの ndarray は通常、同一の型の数値を多次元配列として扱います。深層学習ではデータの件数と特徴量の数を常に意識します。shape は各軸の長さ、ndim は軸の数、dtype は要素の型です。

コード2.3　配列の作成と属性
import numpy as np
x = np.array([[40, 10], [60, 5], [80, 2]], dtype=np.float32)
print(x.shape, x.ndim, x.dtype)  # (3, 2) 2 float32
print(x[0])                    # [40. 10.]
print(x[:, 0])                 # [40. 60. 80.]
print(x[1:, 1])                # [5. 2.]
コード2.4　集約・ブロードキャスト・行列積
print(x.mean(axis=0))  # [60.  5.6666665] 付近
print(x.mean(axis=1))  # [25. 32.5 41.]
scaled = x / np.array([100, 10], dtype=np.float32)
print(scaled)
w = np.array([[40], [-10]], dtype=np.float32)
print(x @ w + 200)  # shape (3, 1)

axis=0の平均では行方向を縮約するため列ごとの平均が得られます。axis=1の平均では列方向を縮約するため行ごとの平均が得られます。単位の異なる面積と築年数の平均には、この例では実務的意味はありません。軸の説明のための演算です。

配列の形状が異なっていても、末尾の軸から比較し、長さが等しいか片方が1であれば演算を拡張できる仕組みをブロードキャストといいます。上の除算では2要素の配列が各行に適用されます。* は要素積、@ は行列積です。

コード2.5　形状の変更とコピー
a = np.arange(6)
print(a.reshape(2, 3))
print(a.reshape(-1, 1).shape)  # (6, 1)
print(a[:, None].shape)       # (6, 1)
b = a[:3].copy()
b[0] = 99
print(a)  # 元の配列を変更しない
操作結果・用途
reshape要素数を保った形状変更
transpose / .T軸の入れ替え
astype型変換
concatenate既存の軸に沿って結合
stack新しい軸に沿って結合
copy独立した配列を作成

画像のバッチはTensorFlowの一般的なchannels-last形式では (件数, 高さ, 幅, チャネル) となります。色画像ならチャネルは通常3です。形状の扱いは第3章、第13章でも詳しく学びます。なおNumPyのndarrayの基本スライスはビューを返し、元配列を変更したくない場合はcopyを使います。

2.7 scikit-learn ―― 分割・前処理・評価

TensorFlowでモデルを学習する場合も、分割や評価にはscikit-learnが便利です。ここでは小さなデータを訓練・検証に分け、数値列の欠損補完と標準化、カテゴリ列のOne-hot Encodingを行います。標準化は訓練データの平均を引き、標準偏差で割る変換です。StandardScalerは分母を標本数とする分散を使い、分散が0の特徴量のスケールを1として扱います。

コード2.9　訓練・検証データの前処理
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder

X = df[["area", "age", "region"]]
y = df["price"]
X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=2, random_state=42)
num = Pipeline([("impute", SimpleImputer(strategy="median")),
                ("scale", StandardScaler())])
prep = ColumnTransformer([
    ("num", num, ["area", "age"]),
    ("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False),
     ["region"])
])
Xtr = prep.fit_transform(X_train).astype(np.float32)
Xva = prep.transform(X_val).astype(np.float32)
print(prep.get_feature_names_out())
print(Xtr.shape, Xva.shape)

fitは変換規則を学び、transformはその規則を適用します。検証データに対してfit_transformを行うと、検証データの情報を使って変換規則を決めることになります。未知カテゴリにはhandle_unknownを指定しています。この例は独立な観測を仮定した練習であり、時系列や同一人物のデータを無条件にランダム分割してはいけません。

コード2.10　平均絶対誤差による評価
from sklearn.metrics import mean_absolute_error
baseline = np.full(len(y_val), y_train.mean())
print(mean_absolute_error(y_val, baseline))

訓練データの平均値を予測するだけのモデルも、比較の基準（ベースライン）として有用です。ただし訓練MAEを最小化する定数は中央値であり、平均値は訓練MSEを最小化します。平均絶対誤差（MAE）は予測と正解の差の絶対値の平均で、ここでは万円単位です。詳細は第6章・第22章で扱います。

2.8 TensorFlowで学習を実行する

ここまでに得た数値配列をTensorFlowへ渡します。テンソルはスカラーやベクトル、行列を含む多次元配列として扱われる計算対象です。まず型と形状を確認し、続いて小さなモデルを学習します。第1章と同様にモデルの詳細は後の章で扱います。

コード2.11　前処理済みデータを使う学習
import tensorflow as tf
import matplotlib.pyplot as plt
from sklearn.metrics import mean_absolute_error

tf.keras.utils.set_random_seed(42)
t = tf.convert_to_tensor(Xtr)
print(t.shape, t.dtype)
model = tf.keras.Sequential([
    tf.keras.Input(shape=(Xtr.shape[1],)),
    tf.keras.layers.Dense(8, activation="relu"),
    tf.keras.layers.Dense(1)
])
model.compile(optimizer="adam", loss="mse")
# 価格を1000万円単位に換算
history = model.fit(Xtr, y_train.to_numpy(np.float32) / 1000,
                    epochs=200, verbose=0,
                    validation_data=(Xva, y_val.to_numpy(np.float32) / 1000))
pred = model.predict(Xva, verbose=0).ravel() * 1000
print("MAE:", mean_absolute_error(y_val, pred))
plt.plot(range(1, len(history.history["loss"]) + 1), history.history["loss"], label="train")
plt.plot(range(1, len(history.history["val_loss"]) + 1), history.history["val_loss"], label="validation")
plt.xlabel("Epoch")
plt.ylabel("MSE (scaled price)")
plt.legend()
plt.show()

学習時の目標値を小さな数値に換算し、評価時に元の単位へ戻しています。予測値のshapeは (件数, 1) なのでravelで一次元化します。ここでは訓練4件・検証2件しかないため、精度の優劣を論じることはできません。学習結果がベースラインより悪くても不思議ではなく、本節の目的は処理全体を動かすことです。乱数シードを固定してもハードウェアやライブラリの違いによる結果の差は残り得ます。

2.10 まとめと確認問題

本章では実行環境の準備から、配列操作、表の調査、可視化、データ分割、前処理、モデル学習、予測ファイルの作成までを一通り経験しました。今後はそれぞれの処理の原理を数学的に理解していきます。

shape=(32, 10) の配列は何を表し得るか。

32件のデータと10個の特徴量。軸の意味はデータの設計によって決まります。

x.mean(axis=0) と axis=1 の違いは何か。

前者は行方向を縮約し列ごとの平均、後者は列方向を縮約し行ごとの平均を求めます。

検証データで標準化のfitをしないのはなぜか。

検証データの統計量を学習処理に利用してしまうためです。訓練でfitし検証にtransformを適用します。

GPUが認識されない場合、必ず学習できないか。

いいえ。CPUで対応する演算を実行できます。

Notebookで再起動して全セルを実行する理由は何か。

過去の実行状態に依存せず、先頭から再現可能であることを確認するためです。

提出CSVでindex=Falseを指定する理由は何か。

pandasの行インデックスが不要な列として書き出されるのを防ぐためです。

発展演習

住宅データの面積だけを使うモデルと、面積・築年数・地域を使うモデルを比較してください。同じ分割を使い、前処理はそれぞれ訓練データでfitします。検証MAEと学習曲線を記録し、特徴量を増やすことで必ず性能が上がるか考察しましょう。

解答の方針

同じ行インデックスで分割したデータを用い、面積だけの前処理器と全特徴量の前処理器を別々に作成します。モデルの入力次元を変更して学習し、同じ検証データでMAEを比較します。わずか2件の検証結果から一般的な結論を出すことはできません。

独立検算（線形回帰による参考比較、TensorFlowの学習結果ではありません）：同じ分割・標準化済み面積列でMAEは 102.86 万円、全特徴量で 475.00 万円、平均値ベースラインは 900.00 万円です。訓練4件では全特徴量の回帰係数は一意に決まらない場合があります。ニューラルネットワークの比較では乱数シード・学習回数・評価条件をそろえ、学習曲線も記録してください。
