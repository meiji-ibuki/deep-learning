24.1 画像データとCNNの基本思想

画像は画素の格子であり、隣接画素の関係に意味がある。全結合層に平坦化して渡すことも可能だが、局所的な構造を直接利用する設計ではない。CNNは小さなフィルタを空間上で繰り返し適用し、局所結合と重み共有を実現する。

本章ではKerasのchannels_last形式（TensorFlowで一般的なNHWC）を用いる。これは $(B,H,W,C)$ である。Bは標本数、Hは高さ、Wは幅、Cはチャネル数。グレースケールは通常C=1、RGBはC=3である。バッチ軸を除いた画像のshapeは $(H,W,C)$。

同じフィルタで位置を変えて特徴を検出するため、平行移動に対する同変性を持つ（境界処理やストライドの影響を除く）。同変性は入力の移動に応じて出力も移動する性質であり、不変性（出力が変わらない）とは異なる。プーリングや全体集約は位置への感度を下げるが、任意の移動に対する完全な不変性は保証しない。

24.2 畳み込み演算を手計算する

深層学習で一般に畳み込みと呼ぶ演算は、カーネルを反転しない相互相関である。数学的な畳み込みとは反転の有無が異なるが、学習可能なカーネルの表現力は同じである。

$$Y_{i,j}=\sum_{u=0}^{k_h-1}\sum_{v=0}^{k_w-1}X_{i+u,j+v}K_{u,v}+b$$

入力の左上の2×2領域とカーネルを要素ごとに掛け、その合計を出力の左上に置く。次に右へ1画素移動する。バイアスはここでは0とする。

コード24.1　相互相関の手計算を確認
import numpy as np
X = np.array([[1, 2, 0, 1], [0, 1, 3, 2], [2, 0, 1, 0], [1, 2, 0, 1]])
K = np.array([[1, 0], [-1, 1]])
Y = np.array([[np.sum(X[i:i+2,j:j+2]*K)
               for j in range(3)] for i in range(3)])
print(Y)
assert Y[0,0] == 2

出力値は特徴への反応の強さを表す。学習前に特定のフィルタを手で設定することも可能だが、CNNでは通常、損失を小さくするよう重みを学習する。

24.3 ストライド・パディング・膨張率

ストライド $s$ はカーネルの移動間隔、パディング $p$ は入力周辺への追加領域、膨張率（dilation）$d$ はカーネル要素間の間隔である（$s,d,k$ は正の整数）。実効カーネル幅は $k_{eff}=d(k-1)+1$。

$$H_{out}=\left\lfloor\frac{H+p_{top}+p_{bottom}-k_{eff}}{s}\right\rfloor+1$$

幅方向も同様。validは追加パディングなし。TensorFlowのsameでは出力サイズは $\lceil H/s\rceil$ で、必要なパディング総量は $\max((H_{out}-1)s+k_{eff}-H,0)$。奇数なら下・右側に余分な1画素を配置する。sameはストライド1の場合に入力と同じ空間サイズを維持する。

入力カーネルstridepadding出力
3231valid30
3231same32
3232same16
323（d=2）1valid28

Keras Conv2Dではstrideとdilationの両方を1より大きくする組み合わせはサポートされない。サイズが小さすぎると出力が成立しないので各層のshapeを確認する。

24.4 複数チャネル・特徴マップ・パラメータ数

RGB画像では各フィルタが全入力チャネルにまたがる。フィルタを $C_{out}$ 個用意すると、各フィルタが一枚の特徴マップを生成する。

$$Y_{b,i,j,o}=b_o+\sum_{u,v,c}X_{b,is_h+u,js_w+v,c}K_{u,v,c,o}$$

この式はパディング済み入力・膨張率1の場合。Kerasのカーネルshapeは $(k_h,k_w,C_{in},C_{out})$（通常のgroups=1）。

通常のgroups=1かつバイアスありの場合、$$P=(k_hk_wC_{in}+1)C_{out}$$

3×3、入力3、出力16なら448パラメータ。入力32×32×3を全結合16ユニットに接続すると49,168個である。ただし出力の形と役割が異なるため、同じ計算量の比較ではない。畳み込みの積和演算数は概算で $H_{out}W_{out}C_{out}k_hk_wC_{in}$（1標本）。重みが少なくても大きな特徴マップは計算とメモリを消費する。

24.5 活性化・プーリング・全体集約

Convの直後にReLUなどを適用して非線形特徴を作る。Max Poolingは局所領域の最大値、Average Poolingは平均値を出力する。通常はチャネルごとに処理し、学習可能な重みを持たない。

Global Average Pooling（GAP）は空間軸を平均し $(B,H,W,C)$ を $(B,C)$ に変換する。Flattenは $(B,HWC)$ に変換し位置ごとの値を保存する。例えば8×8×64から10クラスへ接続すると、Flattenでは40,970個、GAPでは650個のDenseパラメータになる。GAPは分類に便利だが、位置が重要な検出・セグメンテーションでは空間情報を保持する必要がある。

24.6 受容野と階層的な特徴抽出

受容野とは、ある出力に影響し得る入力領域。層を重ねると局所特徴を組み合わせ、より広い範囲を参照できる。理論受容野 $r$ と入力上の間隔 $j$ は初期値 $r_0=j_0=1$ として、

$$r_l=r_{l-1}+(k_{eff,l}-1)j_{l-1},\qquad j_l=j_{l-1}s_l$$

3×3 Conv（stride1）、2×2 Pool（stride2）、3×3 Conv（stride1）では受容野は3→4→8、間隔は1→2→2となる。実際の勾配で測る有効受容野は理論値の内部でも均一ではない。

浅い層はエッジや色の変化に反応する場合があり、深い層はそれらを組み合わせる。ただし個々の特徴が人間に解釈可能な概念に必ず対応するわけではない。

24.7 NumPyによる畳み込み層の実装

以下ではNHWCのバッチ入力、複数チャネル・複数フィルタ、正の整数strideおよびsame/validに対応する順伝播を実装する（膨張率1、groups=1、ゼロパディング）。コード24.2〜24.4は順に実行する。窓ごとのテンソル積にはeinsumを使用する。教育用の実装なのでGPUや高速化は対象外とする。

コード24.2　汎用Conv2Dの順伝播
import numpy as np

def conv2d(x, w, b, stride=1, padding="valid"):
    B, H, W, C = x.shape
    kh, kw, cin, cout = w.shape
    assert C == cin and b.shape == (cout,)
    assert stride >= 1 and padding in ("same", "valid")
    if padding == "same":
        oh, ow = (H+stride-1)//stride, (W+stride-1)//stride
        ph = max((oh-1)*stride+kh-H, 0)
        pw = max((ow-1)*stride+kw-W, 0)
        x = np.pad(x, ((0,0),(ph//2,ph-ph//2),
                      (pw//2,pw-pw//2),(0,0)))
    oh = (x.shape[1]-kh)//stride+1
    ow = (x.shape[2]-kw)//stride+1
    assert oh > 0 and ow > 0
    out = np.empty((B,oh,ow,cout), dtype=np.result_type(x,w,b))
    for i in range(oh):
        for j in range(ow):
            patch = x[:,i*stride:i*stride+kh,j*stride:j*stride+kw,:]
            out[:,i,j,:] = np.einsum("buvc,uvco->bo",patch,w)+b
    return out

rng = np.random.default_rng(24)
x = rng.normal(size=(2,5,6,3))
w = rng.normal(size=(3,3,3,4))
b = np.zeros(4)
assert conv2d(x,w,b,2,"same").shape == (2,3,3,4)
assert conv2d(x,w,b).shape == (2,3,4,4)

逆伝播の考え方

パディングなし・stride1の場合、各出力位置から上流勾配 $D_{b,i,j,o}$ が与えられると、

$$\frac{\partial L}{\partial K_{u,v,c,o}}=\sum_{b,i,j}X_{b,i+u,j+v,c}D_{b,i,j,o}$$

バイアスの勾配はバッチ・空間軸の合計。入力の勾配には重なった窓からの寄与を加算する。第11章の分岐と勾配の加算と同じ原理である。

コード24.3　valid・stride1の逆伝播と数値微分
def conv_backward(x,w,d):
    kh,kw,_,_ = w.shape
    dx = np.zeros_like(x)
    dw = np.zeros_like(w)
    for i in range(d.shape[1]):
        for j in range(d.shape[2]):
            patch = x[:,i:i+kh,j:j+kw,:]
            dw += np.einsum("buvc,bo->uvco",patch,d[:,i,j,:])
            dx[:,i:i+kh,j:j+kw,:] += np.einsum(
                "bo,uvco->buvc",d[:,i,j,:],w)
    return dx,dw,d.sum(axis=(0,1,2))

d = rng.normal(size=conv2d(x,w,b).shape)
dx,dw,db = conv_backward(x,w,d)
def objective():
    return np.sum(conv2d(x,w,b)*d)
for param, grad in [(x,dx),(w,dw),(b,db)]:
    for k in np.ndindex(param.shape):
        old = param[k]
        param[k] = old+1e-5
        plus = objective()
        param[k] = old-1e-5
        minus = objective()
        param[k] = old
        np.testing.assert_allclose((plus-minus)/2e-5,grad[k],
                                   atol=1e-7,rtol=1e-5)
print("gradient check passed")

24.8 フィルタによる特徴抽出を可視化する

Sobelフィルタは方向別の輝度変化を検出する固定フィルタである。CNNの学習済みフィルタと同一ではないが、局所特徴の抽出を理解する教材として有用である。以下は縦方向の境界を持つ人工画像に横方向微分のフィルタを適用した実測結果（相互相関、valid、stride1）。

コード24.4　Sobel応答を描画する
import matplotlib.pyplot as plt
im = np.zeros((12,12)); im[:,6:] = 1
k = np.array([[-1,0,1],[-2,0,2],[-1,0,1]])
response = conv2d(im[None,:,:,None],k[:,:,None,None],np.zeros(1))[0,:,:,0]
fig, ax = plt.subplots(1,2)
ax[0].imshow(im,cmap="gray")
ax[1].imshow(response,cmap="coolwarm",vmin=-4,vmax=4)
plt.show()

特徴マップの可視化では色の尺度も重要である。個別に最大・最小を正規化すると弱い反応が強く見える場合がある。比較には共通の色尺度を用いる。

24.9 TensorFlowによるCNNの構築

Conv2D、MaxPooling2D、GlobalAveragePooling2Dを利用する。入力のshapeはバッチ軸を除いて指定する。10クラス分類では出力をロジットとし、SparseCategoricalCrossentropy(from_logits=True)を使う。

コード24.5　CNNを構築してshapeとパラメータ数を確認
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def make_cnn():
    return keras.Sequential([
        keras.Input(shape=(28,28,1)),
        layers.Conv2D(32,3,padding="same",activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64,3,padding="same",activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64,3,padding="same",activation="relu"),
        layers.GlobalAveragePooling2D(),
        layers.Dense(10)
    ])
model = make_cnn()
model.summary()
assert model.count_params() == 56394
assert model(tf.zeros((2,28,28,1))).shape == (2,10)

各層の空間サイズは28→28→14→14→7→7、チャネルは1→32→32→64→64→64。最後にGAPで64次元に集約する。学習用重みの総数は56,394。入力を画像のまま渡すことがMLPとの違いである。

24.10 実践：Fashion-MNISTでMLPとCNNを比較する

衣類のグレースケール画像10クラスを分類する。公式の訓練集合から検証集合を層化抽出し、公式テスト集合はモデル選択に使わない。ピクセルを255で割る固定変換はデータの統計量を学習しない。コード24.5〜24.7は順に実行する。比較では同じ分割、学習率、バッチサイズ、エポック上限を利用するが、モデルのパラメータ数や計算量が異なるため純粋な構造のみの比較ではない。

コード24.6　データ準備・モデル学習・検証曲線・テスト評価
from sklearn.model_selection import train_test_split
import numpy as np
import matplotlib.pyplot as plt
(x_all,y_all),(x_test,y_test) = keras.datasets.fashion_mnist.load_data()
tr,va = train_test_split(np.arange(len(y_all)),test_size=0.1,
                         stratify=y_all,random_state=24)
x_all = x_all[...,None].astype("float32")/255
x_test = x_test[...,None].astype("float32")/255

def make_mlp():
    return keras.Sequential([keras.Input(shape=(28,28,1)),
        layers.Flatten(),layers.Dense(128,activation="relu"),layers.Dense(10)])
results = {}
for name,factory in [("MLP",make_mlp),("CNN",make_cnn)]:
    keras.utils.set_random_seed(24)
    m = factory()
    m.compile(optimizer=keras.optimizers.Adam(1e-3),
              loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=[keras.metrics.SparseCategoricalAccuracy(name="accuracy")])
    history = m.fit(x_all[tr],y_all[tr],validation_data=(x_all[va],y_all[va]),
                    epochs=20,batch_size=128,verbose=2,
                    callbacks=[keras.callbacks.EarlyStopping(
                        monitor="val_loss",patience=4,restore_best_weights=True)])
    results[name] = (m,history.history)
    plt.plot(range(1, len(history.history["val_loss"])+1), history.history["val_loss"],label=name)
plt.legend(); plt.xlabel("Epoch"); plt.ylabel("Validation loss"); plt.show()
for name,(m,h) in results.items():
    print(name,m.count_params(),m.evaluate(x_test,y_test,return_dict=True,verbose=0))

テスト結果は比較条件を確定した後に確認する。実行にはデータセット取得とTensorFlow環境が必要である。本教材では学習の実測値を提示しない。複数シードで実験を繰り返し、精度と計算時間の双方を比較するとよい。

24.11 まとめと確認問題

畳み込みは局所構造を共有重みによって抽出する演算であり、ストライド・パディング・チャネル設計によって出力shapeと計算量が変化する。プーリングと受容野の理解は次章のCNNアーキテクチャの基礎となる。

問1　相互相関と数学的畳み込みの違いは？

カーネル反転の有無。

問2　28×28入力、3×3、valid、stride2の出力は？

13×13。floor((28−3)/2)+1。

問3　同じ条件でsameなら？

14×14。ceil(28/2)。

問4　3×3、入力8、出力16のパラメータ数は？

groups=1、バイアスありなら(9×8+1)×16=1168。

問5　GAPの出力shapeは？

NHWC入力でkeepdims=False（既定値）なら(B,C)。

問6　3×3 Convをstride1で3層重ねた受容野は？

膨張率1なら7×7（1+3×(3−1)）。

問7　重み共有の利点は？

位置によらず同じ局所特徴を検出でき、パラメータ数を抑えられる。

問8　検証データの役割は？

モデル選択やEarly Stopping。テストデータとは分離する。

問9　発展：NumPyのconv2dをKerasと照合せよ。

コード24.2のx,w,bを用い、keras.layers.Conv2Dを同じstride・padding、groups=1、activation=None、data_format="channels_last"で構築し、build後にset_weights([w,b])を呼び、同じ入力でnp.testing.assert_allcloseを実施する。float64を指定すればNumPy側と精度を揃えられる。float32ではatol=1e-5程度から検討する。TensorFlowとの照合は未実行。
