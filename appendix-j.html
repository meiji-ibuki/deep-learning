4.8　発展演習

問題： $L(w,b)$ の解析的勾配と中央差分を比較してください。学習率を変えたときの損失推移も観察しましょう。

コード4.9　解析勾配と数値勾配の比較
import numpy as np
x = np.array([-1., 0., 1.])
y = np.array([1., 3., 5.])
p = np.array([0.5, 1.])
def loss(p):
    return np.mean((p[0]*x+p[1]-y)**2)
e = p[0]*x+p[1]-y
g = np.array([2*np.mean(e*x), 2*np.mean(e)])
h = 1e-5
g_num = np.array([(loss(p+h*d)-loss(p-h*d))/(2*h)
                  for d in np.eye(2)])
assert np.allclose(g, g_num)
print(g, g_num)
for eta in [0.01, 0.1, 1.1]:
    w, b = p.copy()
    history = []
    for _ in range(20):
        e = w*x+b-y
        history.append(np.mean(e**2))
        w -= eta*2*np.mean(e*x)
        b -= eta*2*np.mean(e)
    print(eta, history[0], history[-1])

解析勾配と数値勾配は約 (−2,−4) で一致します。損失を展開すると $L(w,b)=\frac23(w-2)^2+(b-3)^2$ となるので、勾配は $((4/3)(w-2),2(b-3))$ です。初期値 (0.5,1) で損失5.5、勾配 (−2,−4) を得ます。学習率0.1は0.01より速く損失が減少し、1.1ではバイアス方向の更新が発散します。

X = np.array([[0,0],[0,1],[1,0],[1,1]])
def train_perceptron(X, y, eta=1., max_epochs=20):
    w = np.zeros(X.shape[1]); b = 0.
    history = []
    for epoch in range(max_epochs):
        mistakes = 0
        for xi, yi in zip(X, y):
            pred = int(xi @ w + b >= 0)
            error = yi - pred
            w += eta * error * xi
            b += eta * error
            mistakes += int(error != 0)
        history.append(mistakes)
        if mistakes == 0:
            break
    return w, b, history
