13.1 TensorFlowとKerasの役割

第12章では、順伝播・逆伝播・更新をNumPyで実装しました。TensorFlowはこれらの計算をテンソル演算と自動微分で支える基盤です。Kerasはレイヤーやモデル、学習ループを扱う高水準APIです。Keras 3は複数のバックエンドに対応しますが、本書ではTensorFlowを使用します。本章ではTensorFlow 2系とTensorFlowバックエンドのKeras 3を想定し、以降の章でモデルを自在に組み立てるための基礎を学びます。

第2章の実行環境を使用してください。ColabやKaggleでは既存のTensorFlowをまず確認し、必要がなければインストールし直さないようにしましょう。ローカル環境では仮想環境に公式の対応バージョンを導入します。GPUがなくても本章の例はCPUで実行できます。

コード13.1　環境を確認する
import numpy as np
import tensorflow as tf
print(tf.__version__)
print(tf.executing_eagerly())  # 通常 True
print(tf.config.list_physical_devices('GPU'))

以降のコードは同じNotebookで上から順に実行できます。GPUの一覧が空でも直ちにエラーではありません。TPUには別途初期化が必要です。

13.2 TensorとVariable

テンソルは同じdtypeを持つ多次元配列です。通常の tf.Tensor は値を直接書き換えられません。一方、tf.Variable は学習中の重みなど、更新を必要とする状態を保持します。

項目TensorVariable
生成tf.constant / tf.convert_to_tensortf.Variable
更新新しいテンソルを生成assign / assign_add / assign_sub
用途入力・中間出力重み・状態
勾配の監視通常は明示的にwatch既定のTapeではtrainable=Trueの変数をアクセス時に自動監視
コード13.2　生成と更新
x = tf.constant([[1., 2.], [3., 4.]])
w = tf.Variable([1., 2.])
print(x + 1)  # x 自体は変わらない
w.assign_sub([0.1, 0.2])
print(w.numpy())  # [0.9, 1.8] に近い値
arr = np.array([1, 2], dtype=np.float32)
t = tf.convert_to_tensor(arr)
print(t.numpy())

w = w - 0.1 はPythonの名前を別のテンソルに結び直す操作であり、Variableの更新ではありません。学習ではassign系を使います。.numpy() はEager実行時に値をNumPy配列として取り出す手段ですが、GPUからの転送や同期を伴う場合があります。

13.3 shape・rank・dtype

第3章のshapeは各軸の長さ、rankは軸の数です（行列のランクとは別の意味）。dtypeは要素の数値形式です。モデルの入力は通常float32、整数クラスラベルはint32またはint64を使います。

例shaperank意味
スカラー()0損失
ベクトル(3,)1特徴量3個
行列(32, 10)232標本×10特徴
画像バッチ(32, 64, 64, 3)4NHWC形式
コード13.3　形状と型を確認する
x = tf.zeros((32, 10), dtype=tf.float32)
print(x.shape, x.shape.rank, x.dtype)
print(tf.shape(x), tf.rank(x), tf.size(x))
a = tf.constant([1, 2], dtype=tf.int32)
b = tf.cast(a, tf.float32)
print(b + 0.5)
tf.debugging.assert_shapes([(x, ('B', 10))])

x.shape は静的なTensorShape、tf.shape(x) は実行時のshapeを表すテンソルです。グラフ内ではバッチサイズが未確定（None）でも、tf.shapeで実際の長さを取得できます。異なるdtypeのテンソル同士は自動変換されるとは限らないため、意図を明示してcastします。float16等の混合精度は第38章で扱います。

13.4 テンソル演算と軸の縮約

要素ごとの積と行列積を区別しましょう。行列積では内側の次元が一致する必要があります。tf.matmulでは両入力のrankは2以上で、先行するバッチ軸はブロードキャスト可能である必要があります。縮約とは、指定した軸について和や平均などを求める操作です。既定ではその軸を取り除き、keepdims=Trueなら長さ1として残します。

$$Z=XW+b$$
コード13.4　行列積と縮約
X = tf.constant([[1., 2., 3.], [4., 5., 6.]])
W = tf.constant([[1., 0.], [0., 1.], [1., 1.]])
b = tf.constant([0.5, -0.5])
Z = tf.matmul(X, W) + b
print(Z.numpy())  # [[4.5, 4.5], [10.5, 10.5]]
print(tf.reduce_sum(X, axis=0).numpy())  # [5, 7, 9]
print(tf.reduce_mean(X, axis=1).numpy())  # [2, 5]
print(tf.reduce_mean(X, axis=1, keepdims=True).shape)  # (2, 1)
print(tf.reduce_sum(X).numpy())  # 21
操作NumPyTensorFlow
要素積a * ba * b
行列積a @ btf.matmul(a,b) / a @ b
平均np.mean(a, axis=...)tf.reduce_mean(a, axis=...)
最大値np.max(a, axis=...)tf.reduce_max(a, axis=...)
最大要素の添字np.argmax(a, axis=...)tf.argmax(a, axis=...)

axis=-1は最後の軸です。分類モデルのロジットが(B,K)なら、通常tf.argmax(logits, axis=-1)で標本ごとの予測クラスを求めます。

13.5 reshape・転置・軸の追加と削除

reshapeは要素数を保ったまま形状を変更します。transposeは軸の順序を入れ替えます。例えば画像のNHWCからNCHWへの変換はreshapeではなくtransposeです。

コード13.5　形状の変更
a = tf.constant([[1, 2, 3], [4, 5, 6]])
print(tf.reshape(a, (3, 2)).numpy())
print(tf.transpose(a).numpy())  # [[1, 4], [2, 5], [3, 6]]
print(tf.reshape(a, (-1,)).shape)  # (6,)
print(tf.expand_dims(a, axis=-1).shape)  # (2, 3, 1)
print(tf.squeeze(tf.expand_dims(a, -1), axis=-1).shape)
images = tf.zeros((8, 16, 16, 3))
print(tf.transpose(images, [0, 3, 1, 2]).shape)

-1は他の軸から長さを推定する指定で、reshapeにつき1箇所だけ使えます。squeezeは長さ1の軸だけを削除します。バッチサイズ1で意図せずバッチ軸まで消すことを防ぐため、axisを明示しましょう。

13.6 ブロードキャストとインデックス操作

ブロードキャストは右端の軸から比較し、長さが等しいか一方が1なら演算できます。不足する先頭軸は長さ1とみなします。バイアス加算に便利ですが、誤ったshapeでも計算が成功することがあります。

コード13.6　shapeをそろえて損失を計算する
pred = tf.constant([[1.1], [1.9], [3.2]])
y = tf.constant([1., 2., 3.])
print((pred-y).shape)  # (3, 3): 意図しない結果
correct = pred - y[:, None]
print(correct.shape)  # (3, 1)
tf.debugging.assert_equal(tf.shape(pred), tf.shape(y[:, None]))
print(tf.reduce_mean(correct**2).numpy())  # 約 0.02
コード13.7　抽出・結合・マスク
a = tf.constant([[1, 2], [3, 4], [5, 6]])
print(a[:, 0])
print(tf.gather(a, [2, 0], axis=0))
print(tf.boolean_mask(a, [True, False, True]))
print(tf.concat([a, a], axis=0).shape)  # (6, 2)
print(tf.stack([a, a], axis=0).shape)   # (2, 3, 2)
print(tf.where(a > 3, a, tf.zeros_like(a)))

concatは既存軸に沿って結合し、stackは新しい軸を作ります。tf.whereの三引数形式は条件に応じて値を選択します。単引数形式は真の位置の添字を返す別の操作です。

13.7 Eager Executionとtf.function

Eager Executionでは演算を呼び出すたびに結果が得られるため、デバッグが容易です。tf.function はPython関数内のTensorFlow演算をトレースしてグラフを構築し、互換性のある入力で再利用します。Pythonの呼び出し負荷を減らしたり、グラフ最適化を可能にしたりしますが、常に高速になるわけではありません。

コード13.8　Eagerとグラフの結果を比較する
def eager_f(x):
    return tf.reduce_sum(x*x, axis=-1)

@tf.function(input_signature=[tf.TensorSpec([None, 3], tf.float32)])
def graph_f(x):
    print('tracing')  # Python: トレース時
    tf.print('batch:', tf.shape(x)[0])  # 実行時
    return eager_f(x)

for n in [2, 5]:
    a = tf.ones((n, 3))
    tf.debugging.assert_near(eager_f(a), graph_f(a))

入力のshapeやdtype、Python引数の値が変わると再トレースが発生する場合があります。上のTensorSpecは特徴量3個、可変バッチサイズを許可します。Pythonのprintやリストへのappendは実行ごとの処理として頼れません。tf.printやTensorFlow演算を使い、Variableは原則として関数の外で作成します。

データに依存する分岐にはtf.condなどを利用できます。AutoGraphがPython制御構文を変換する場合もありますが、ソースコードを取得できない環境などでは制約があります。まずEagerで正しさを確認してからグラフ化しましょう。速度比較では初回トレースを除き、デバイス同期を考慮します。

13.8 GradientTapeによる自動微分

第11章で実装した逆伝播をTensorFlowに任せます。GradientTapeは監視対象からの演算を記録し、連鎖律によって勾配を計算します。通常のTapeはgradientを一度呼び出すと消費されます。

$$L=(wx+b-y)^2,\qquad \frac{\partial L}{\partial w}=2(wx+b-y)x$$
コード13.9　変数とテンソルの微分
w = tf.Variable(3.)
b = tf.Variable(1.)
with tf.GradientTape() as tape:
    loss = (2*w+b-5)**2
dw, db = tape.gradient(loss, [w,b])
print(loss.numpy(), dw.numpy(), db.numpy())  # 4, 8, 4
w.assign_sub(0.1*dw)
b.assign_sub(0.1*db)

x = tf.constant(2.)
with tf.GradientTape() as tape:
    tape.watch(x)
    z = x**3
print(tape.gradient(z, x).numpy())  # 12

gradientの対象が非スカラーの場合、output_gradientsを指定しなければ各出力成分の和に対する勾配になります。個々の出力の微分を求める場合はjacobianを用います。同じTapeから複数回gradientやjacobianを呼び出す場合はpersistent=Trueを指定し、不要になったTapeを解放します。高階微分にはTapeを入れ子にします。

コード13.10　ヤコビ行列と二階微分
x = tf.constant([2., 3.])
with tf.GradientTape() as tape:
    tape.watch(x)
    y = x**2
print(tape.jacobian(y, x).numpy())  # [[4,0],[0,6]]
x = tf.Variable(2.)
with tf.GradientTape() as outer:
    with tf.GradientTape() as inner:
        y = x**3
    dy = inner.gradient(y,x)
print(outer.gradient(dy,x).numpy())  # 12

勾配がNoneなら計算経路がない可能性があります。Tapeの外で計算した、途中でNumPyへ変換した、整数型を微分した、stop_gradientを通した、などを確認します。Noneと数値0は異なります。

13.9 実践：TensorFlowだけで線形回帰を学習する

第12章のスクラッチ実装と対照的に、勾配を自動微分で求めます。人工データ $y=2x+1$ を使い、学習率0.1で全標本を一度に処理します。検証用データを別に用意し、学習には使いません。

コード13.11　カスタム学習ステップ
X = tf.constant([[-2.], [-1.], [0.], [1.], [2.]])
y = 2*X+1
Xv = tf.constant([[-1.5], [0.5], [1.5]])
yv = 2*Xv+1
w = tf.Variable([[0.]])
b = tf.Variable([0.])

@tf.function(input_signature=[tf.TensorSpec([None,1],tf.float32),
                              tf.TensorSpec([None,1],tf.float32)])
def train_step(x, target):
    with tf.GradientTape() as tape:
        pred = x@w+b
        loss = tf.reduce_mean((pred-target)**2)
    grads = tape.gradient(loss,[w,b])
    for g in grads:
        tf.debugging.assert_all_finite(g,'non-finite gradient')
    w.assign_sub(0.1*grads[0])
    b.assign_sub(0.1*grads[1])
    return loss

history = []
for epoch in range(40):
    train_step(X,y)
    tr = tf.reduce_mean((X@w+b-y)**2)
    va = tf.reduce_mean((Xv@w+b-yv)**2)
    history.append([float(tr.numpy()),float(va.numpy())])
print(w.numpy(),b.numpy())

初期値では訓練MSEは9です。データの平均が0、二乗平均が2なので、解析的には重みの誤差が更新ごとに0.6倍、バイアスの誤差が0.8倍になります。更新回数をkとすると、訓練MSEは 8×0.6の2k乗 + 0.8の2k乗です。40回後の重みは約1.9999999973、バイアスは約0.99986708、訓練MSEは約1.77×10⁻⁸となります（実数演算での理論値）。以下は理論式による予測であり、TensorFlowの実測値ではありません。

コード13.12　学習曲線を描画する
import matplotlib.pyplot as plt
h = np.asarray(history)
plt.semilogy(np.arange(1,len(h)+1),h[:,0],label='train')
plt.semilogy(np.arange(1,len(h)+1),h[:,1],label='validation')
plt.xlabel('epoch'); plt.ylabel('MSE'); plt.legend(); plt.show()

13.10 実装時のデバッグと再現性

エラーが生じたら、まずshape・dtype・値の有限性を調べます。処理を小さな単位で実行し、期待する計算と照合しましょう。GPUの利用有無で結果や速度が変わることもあります。

症状確認すること
Incompatible shapes行列積の内側次元・ブロードキャスト
dtype mismatchfloat32とfloat64、整数と浮動小数点
勾配NoneTape内の演算・監視対象・NumPyへの変換
NaN / Inf入力値・学習率・対数や除算
再トレースの警告入力shape・dtype・Python引数
OOMバッチサイズ・中間テンソル・デバイスメモリ
コード13.13　乱数と実行時の検査
tf.keras.utils.set_random_seed(42)
a = tf.random.stateless_normal((2,3), seed=[42,0])
b = tf.random.stateless_normal((2,3), seed=[42,0])
tf.debugging.assert_equal(a,b)
tf.debugging.assert_shapes([(a,('B',3))])
tf.debugging.assert_all_finite(a,'invalid input')

乱数シードを固定しても、異なるハードウェアやライブラリのバージョンで完全に同じ結果になるとは限りません。必要に応じて tf.config.experimental.enable_op_determinism() を使用しますが、速度低下や未対応演算に注意します。Kaggleでは環境バージョン、分割インデックス、シードを記録してください。

13.11 まとめと確認問題

TensorFlowの基本は、テンソルのshapeとdtypeを把握し、演算を組み合わせ、GradientTapeで微分し、Variableを更新することです。Eagerで検証してから必要に応じてtf.functionを使います。

問1　TensorとVariableの違いは？

Tensorは値を直接更新できない。Variableはassign系で状態を更新できる。

問2　shape (4, 3, 2) のrankと要素数は？

rankは3、要素数は24。

問3　shape (5, 4) をaxis=0で平均すると？

(4,) になる。keepdims=Trueなら(1,4)。

問4　reshapeとtransposeの違いは？

reshapeは要素の並びを保って形状を変え、transposeは軸の順番を入れ替える。

問5　予測(8,1)と正解(8,)の差のshapeは？

(8,8)。正解を(8,1)にしてから引く。

問6　tf.function内でPythonのprintを毎回実行できるか？

保証されない。実行ごとの出力にはtf.printを用いる。

問7　定数テンソルの微分を求めるには？

浮動小数点テンソルをtape.watchで監視し、Tape内で計算する。

問8　勾配Noneと0の違いは？

Noneは微分経路がない等の状態、0は計算された勾配がゼロであること。

発展演習：多出力の勾配チェック

入力2特徴、出力2個の全結合層について、MSEの重み勾配を第11章の公式とGradientTapeで比較してください。平均化は全要素数で行います。

解答・実装例
コード13.14　解析勾配と自動微分の照合
X = tf.constant([[1.,2.],[3.,4.]], dtype=tf.float64)
W = tf.Variable([[0.1,0.2],[0.3,0.4]], dtype=tf.float64)
y = tf.zeros((2,2),dtype=tf.float64)
with tf.GradientTape() as tape:
    z = X@W
    loss = tf.reduce_mean((z-y)**2)
auto = tape.gradient(loss,W)
manual = tf.transpose(X) @ (2*(z-y)/tf.cast(tf.size(z),z.dtype))
tf.debugging.assert_near(auto,manual,atol=1e-12,rtol=1e-12)
print(auto.numpy())

独立検算：Z = [[0.7, 1.0], [1.5, 2.2]]、MSE = 2.145、重み勾配は [[2.6, 3.8], [3.7, 5.4]] です。平均の分母は標本数×出力数の4です。
